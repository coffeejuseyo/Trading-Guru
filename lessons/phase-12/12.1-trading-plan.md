## 📖 開場故事：出國旅行前的完整行程表

小琪第一次自助旅行，她的朋友給她兩種建議：

**A. 「到了再說」**：機票買了就好，住哪裡、去哪裡，到了再決定。結果她在機場花了兩小時找住宿，第三天錢包被偷時，完全不知道該怎麼辦。

**B. 完整的行程表**：
- 每天去哪裡、怎麼去、住哪裡（**例行程序**）
- 總預算、每天花費上限（**風險規則**）
- 遇到下雨的備案行程（**市場狀態**）
- 護照遺失、生病時的緊急聯絡方式（**停止條件與緊急應變**）
- 哪些事情**不做**（不跟陌生人去不認識的地方）

第二次旅行，她用了行程表。遇到班機延誤時，她沒有慌張，因為**「班機延誤怎麼辦」早就寫在行程表裡了**。

> ✈️ **交易計畫書就是交易的完整行程表**：在你開始真正交易之前，把所有可能的情況都想好、寫下來——尤其是**壞情況**。因為當帳戶在虧錢、心跳加速的時候，你不會做出好的決定（Phase 7）。計畫書讓「冷靜的你」替「慌張的你」做決定。

### 3. ⭐ 第 8 段：預期範圍——「正常」長什麼樣子？

這是新版計畫書最重要的部分。用 11.5 的拔靴法，算出「如果策略和回測一樣好，30 筆交易後的結果會落在什麼範圍」：

```python
import numpy as np

# 回測得到的 150 筆交易（11.5 的範例；請換成你自己的回測交易）
rng = np.random.default_rng(5)
n = 150
win = rng.random(n) < 0.40
backtest_trades = np.where(win, rng.lognormal(np.log(1.6), 0.6, n), -rng.uniform(0.8, 1.2, n)).round(2)

boot = np.random.default_rng(1)
k = 30
total_r = np.array([boot.choice(backtest_trades, k).sum() for _ in range(10000)])
win_rate = np.array([(boot.choice(backtest_trades, k) > 0).mean() for _ in range(10000)])

print(f"每筆期望值：{backtest_trades.mean():.2f}R")
print(f"30 筆的總 R：5% 分位 {np.percentile(total_r, 5):.1f}R、中位數 {np.median(total_r):.1f}R、"
      f"95% 分位 {np.percentile(total_r, 95):.1f}R")
print(f"30 筆後總 R 為負的機率：{(total_r < 0).mean():.1%}")
print(f"30 筆的勝率範圍（5%～95%）：{np.percentile(win_rate, 5):.0%} ～ {np.percentile(win_rate, 95):.0%}")
```

輸出：

```
每筆期望值：0.24R
30 筆的總 R：5% 分位 -8.1R、中位數 7.0R、95% 分位 24.6R
30 筆後總 R 為負的機率：23.7%
30 筆的勝率範圍（5%～95%）：27% ～ 53%
```

> 🔑 **這張表是你在模擬交易期間的「心理錨」**：
> - 30 筆後總共虧了 5R？**在預期範圍內**（約四分之一的機率會虧錢），不代表策略壞掉。
> - 30 筆的勝率只有 30%？**也在範圍內**。
> - 30 筆後虧了 15R？**超出 5% 分位很多**——要啟動 12.6 的檢查流程。
>
> 沒有這張表，你很可能在正常的低潮中放棄好策略，或在明顯的異常中繼續硬撐。

### 4. ⭐ 完整範例（虛構）

以下是一份精簡但完整的範例（數字延續 Phase 10～11 的範例，**策略與資料皆為虛構**）：

| 段落 | 內容 |
|---|---|
| **1. 目標與限制** | 模擬資金 100 萬元；實盤資金 10 萬元（學費等級，12.5）；每週可投入 3 小時；目標：3 個月內完成 30 筆以上、規則遵守率 > 90% 的模擬交易 |
| **2. 市場與商品** | 台股流動性前 50 大個股與大盤 ETF（20 日均成交金額 > 5 億元）；理由：成本低、滑價小、熟悉 |
| **3. 策略** | 「ETF 趨勢 v1.2」（規格書連結、回測報告連結）；進出場規則見規格書；不交易：資料異常日、除權息前一日 |
| **4. 風險規則** | 每筆風險 **0.8%**（蒙地卡羅：1% 時 95% 回撤 −18%，超過可承受的 −15%，故降為 0.8%）；同時最多 5 筆；總風險 ≤ 4%；單月虧損 6% 暫停 |
| **5. 例行程序** | 每天收盤後：執行資料檢查 → 跑訊號程式（11.10 半自動）→ 記錄明天的委託 → 隔天開盤記錄模擬成交價；每週日：12.3 檢討 |
| **6. 心理規則** | 我的 3 大偏誤（7.3）：提早停利、連虧後跳過訊號、移動停損；對策：成交後立刻設好停損、連虧 5 筆時讀第 8 段 |
| **7. 停用條件** | 見第 10 段 |
| **8. 預期範圍** | 期望值 0.24R；30 筆總 R：−8.1R ～ +24.6R（5%～95%）；勝率 27%～53%；95% / 99% 回撤（0.8% 風險）約 −14% / −17%；95% 連虧 13 筆 |
| **9. 模擬與關卡** | 2025-02-03 開始，至少到 2025-05-02；關卡：遵守率 > 90%、總 R 在預期範圍內、日誌完整 |
| **10. 停止 / 修改 / 放棄** | 回撤達 −14% → 暫停新倉並檢查；達 −17% → 停用、重新研究；遵守率 < 90% → 不進實盤 |
| **11. 版本紀錄** | v1.0 初版；v1.1 修正除權息日處理；v1.2 每筆風險由 1% 改為 0.8%（依蒙地卡羅） |

> 💡 範例中每一個數字**都有來源**：回測報告、蒙地卡羅、你的風險承受度。沒有「我覺得」、「大概」。

### 5. ⭐ 計畫書的修改規則

計畫書不是不能改，但要**有規則地改**：

| ✅ 可以 | ❌ 不行 |
|---|---|
| 在**非交易時段**、冷靜時修改 | 在盤中、虧損當下修改 |
| 修改前寫進研究日誌，說明原因 | 「感覺」策略最近不好就改 |
| 改了策略規則 → 重新回測、升版本號 | 改了規則但沿用舊的回測結果 |
| 根據**資料**（12.4 的差異分析）修改 | 根據**單筆或少數幾筆**交易修改 |
| 修改後**重新簽名** | 默默改掉 |

> ✈️ 就像旅行中途想改行程：可以，但要在晚上回飯店後、查好交通、改好預算再決定，而不是在路邊被導遊說動就跟去。

## 📌 重點整理

1. 交易計畫書 = **出國前的完整行程表**：讓冷靜的你替慌張的你做決定。
2. 從 M2 升級：附規格書與回測報告、每筆風險由蒙地卡羅決定、模擬交易的例行程序。
3. 新增三段：**預期範圍、模擬交易與上路關卡、停止 / 修改 / 放棄**，以及**版本紀錄**。
4. **預期範圍**是心理錨：本例 30 筆總 R 落在 −8.1R ～ +24.6R 都算正常，約 24% 的機率會虧錢。
5. 每個數字都要有來源，不能是「我覺得」。
6. 修改要**冷靜、有紀錄、有資料、重新回測、重新簽名**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「計畫書寫一次就好」 | 它隨著研究與實戰更新，但要有版本紀錄與修改規則。 |
| 「期望值為正的策略，30 筆後應該會賺錢」 | 本例中 30 筆後仍有約 24% 的機率虧錢；要用預期範圍判斷，而不是單看賺賠。 |
| 「停止條件等遇到再想就好」 | 遇到時你正處於情緒中，很難做出好決定；要事先寫好。 |
| 「計畫書的數字憑經驗填就好」 | 每個數字都應該有來源：回測、蒙地卡羅、風險承受度。 |

## 🛠️ 練習（約 2 小時）

**練習 1：計算你的預期範圍**
把第 3 節的 `backtest_trades` 換成你在 Phase 10 回測得到的交易報酬（R 倍數或報酬率），算出 30 筆的總報酬範圍、勝率範圍，以及 11.5 的 95% / 99% 回撤。

**練習 2：完成計畫書定稿**
用更新後的 [templates/trading-plan.md](../../templates/trading-plan.md)，把 M2 的計畫書升級成上路版，12 個段落全部填完，每個數字都註明來源。

**練習 3：簽名並存檔**
列印或存成 PDF，簽名、寫上日期，並用 Git commit（訊息：「交易計畫書 v1.0 定稿」）。開始模擬交易後，任何修改都要升版本號。

## ✅ 自我測驗

**Q1. 新版計畫書比 M2 多了哪些關鍵段落？**

<details><summary>看答案</summary>

預期範圍（來自回測與蒙地卡羅的勝率、總報酬、回撤、連虧範圍）、模擬交易與上路關卡（模擬期間、每日流程、進入實盤的條件、實盤資金）、停止 / 修改 / 放棄的決策規則，以及版本紀錄。

</details>

**Q2. 為什麼「預期範圍」是模擬交易期間最重要的心理錨？**

<details><summary>看答案</summary>

因為即使期望值為正的策略，短期結果也有很大的隨機性（本例中 30 筆後約 24% 的機率虧錢）。事先知道「正常」的範圍，遇到範圍內的虧損時就不會恐慌放棄好策略；遇到遠超出範圍的虧損時，則能及早察覺異常並啟動檢查。

</details>

**Q3. 計畫書可以修改嗎？要遵守哪些規則？**

<details><summary>看答案</summary>

可以，但要在非交易時段、冷靜狀態下進行；先寫進研究日誌說明原因；根據足夠的資料而不是少數幾筆交易；改了策略規則要重新回測並升版本號；修改後重新簽名並存檔。

</details>
