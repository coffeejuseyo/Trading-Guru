## 📖 開場故事：模擬考與正式考試的落差

小傑的模擬考平均 80 分，正式考試卻只考了 68 分。他很沮喪：「我是不是根本沒讀好？」

老師陪他一起分析：

| 落差來源 | 扣了多少 |
|---|---|
| 正式考試的題目本來就比較難（**環境不同**） | 約 3 分 |
| 緊張，有兩題會寫的算錯（**執行失誤**） | 約 6 分 |
| 時間分配不好，最後一大題沒寫完（**流程問題**） | 約 3 分 |

老師說：「你的**實力**沒有問題——如果沒有緊張算錯、時間分配好，你大概會考 77 分，在你模擬考的正常範圍內。要改進的是**考試技巧和心態**，而不是重新讀一遍課本。」

> 📝 **差異分析就是找出「落差從哪裡來」**：模擬交易的結果和回測不一樣時，要分清楚是**策略本身**變差了（要回去研究），還是**執行**出了問題（要改善紀律與流程）。兩者的對策完全不同。

## 🧠 正文

### 1. ⭐ 回測和實際交易不一樣的 6 大原因

| # | 原因 | 例子 | 影響方向 | 回想 |
|---|---|---|---|---|
| 1 | **成交價與滑價** | 開盤跳空、買賣價差、追價 | 幾乎都變差 | 10.6 |
| 2 | **執行與紀律** | 提早停利、放寬停損、跳過訊號 | 通常變差 | 7.2、12.3 |
| 3 | **運氣（樣本太少）** | 30 筆交易的隨機性很大 | 可好可壞 | 11.5 |
| 4 | **過度擬合** | 回測時的參數只適合過去 | 變差 | 10.12 |
| 5 | **市場改變** | 優勢被套利掉、市場結構改變 | 變差 | 8.2 |
| 6 | **回測的錯誤** | 前視偏差、倖存者偏差、成本低估 | 變差（而且通常很大） | 10.10、10.11 |

> 🔑 **大部分的原因都只會讓結果變差。** 所以實際結果比回測差一點是正常的；比回測好很多反而要小心——可能只是運氣（原因 3）。

### 2. ⭐ 滑價分析

```python
import numpy as np
import pandas as pd

journal = pd.read_csv("paper_journal.csv")
slippage = journal["fill_price"] / journal["signal_price"] - 1
print(f"平均滑價：{slippage.mean():.3%}，中位數 {slippage.median():.3%}，最大 {slippage.max():.3%}")
```

輸出：`平均滑價：0.122%，中位數 0.144%，最大 0.307%`

| 比較 | 數值 | 判斷 |
|---|---|---|
| 模擬交易的平均滑價 | 0.12% | |
| 回測假設的滑價（10.6 的「個股＋滑價」情境） | 0.10% | 實際略高於假設 ⚠️ |

> 💡 如果實際滑價明顯高於回測假設，要**回頭用實際的滑價重新回測**（10.6），看策略是否還有足夠的利潤空間（損益兩平成本）。

### 3. ⭐⭐ 結果有沒有落在預期範圍內？

用回測的交易做拔靴法（11.5、12.1），產生「**如果策略和回測一樣好，做 36 筆會得到什麼結果**」的分布，再看模擬交易的實際結果落在哪裡：

```python
# 回測的 150 筆交易（11.5 的範例；請換成你自己的）
rng = np.random.default_rng(5)
n = 150
win = rng.random(n) < 0.40
backtest_trades = np.where(win, rng.lognormal(np.log(1.6), 0.6, n), -rng.uniform(0.8, 1.2, n)).round(2)

k = len(journal)
boot = np.random.default_rng(2)
sims = np.array([boot.choice(backtest_trades, k) for _ in range(10000)])
total_r = sims.sum(axis=1)

print(f"回測：每筆期望值 {backtest_trades.mean():.2f}R，勝率 {(backtest_trades > 0).mean():.0%}")
print(f"{k} 筆的總 R 預期範圍：5% 分位 {np.percentile(total_r, 5):.1f}R、"
      f"中位數 {np.median(total_r):.1f}R、95% 分位 {np.percentile(total_r, 95):.1f}R")
for label, value in [("實際模擬結果", journal["R"].sum()), ("照規則的模擬結果", journal["R_if_rules"].sum())]:
    pct = (total_r < value).mean()
    print(f"{label}：{value:.2f}R，落在預期分布的第 {pct * 100:.0f} 百分位")
```

輸出：

```
回測：每筆期望值 0.24R，勝率 40%
36 筆的總 R 預期範圍：5% 分位 -8.3R、中位數 8.4R、95% 分位 27.8R
實際模擬結果：3.71R，落在預期分布的第 33 百分位
照規則的模擬結果：9.32R，落在預期分布的第 53 百分位
```

**怎麼解讀？**

| 結果 | 百分位 | 判斷 |
|---|---:|---|
| 實際模擬（3.71R） | 第 33 | 在預期範圍內，但偏低 |
| 照規則（9.32R） | 第 53 | **幾乎正好在中間**——策略表現完全正常 |

> 🔑 **策略本身沒有問題**：如果照規則執行，結果剛好在回測預期的中間。**落差主要來自執行**（12.3 的 4 次違規）。這就是開場故事中「實力沒問題，要改進的是考試技巧」的情況。

| 百分位 | 一般的解讀（參考） |
|---|---|
| 第 5～95 之間 | 正常範圍，繼續執行 |
| 低於第 5 | 異常差：檢查執行、資料、成本；可能策略已經改變（12.6） |
| 高於第 95 | 異常好：很可能只是運氣，**不要因此加碼**；檢查有沒有記錄錯誤 |

### 4. ⭐ 差異拆解：落差從哪裡來？

```python
rows = [
    ("回測（期望值 × 筆數）", backtest_trades.mean() * k),
    ("模擬交易：照規則", journal["R_if_rules"].sum()),
    ("模擬交易：實際", journal["R"].sum()),
]
for label, value in rows:
    print(f"{label:<14}{value:>7.2f}R")

followed = journal[journal["followed_rules"] == "Y"]
print(f"\n回測的平均虧損 {backtest_trades[backtest_trades <= 0].mean():.2f}R，"
      f"模擬中照規則的平均虧損 {followed.loc[followed['R'] <= 0, 'R'].mean():.2f}R")
```

輸出：

```
回測（期望值 × 筆數）   8.79R
模擬交易：照規則         9.32R
模擬交易：實際           3.71R

回測的平均虧損 -0.99R，模擬中照規則的平均虧損 -1.07R
```

| 階段 | 總 R | 落差 | 來源 |
|---|---:|---:|---|
| 回測期望 | 8.79R | | |
| → 照規則的模擬 | 9.32R | +0.53R | **運氣 + 環境**（在正常範圍內的隨機波動） |
| → 實際模擬 | 3.71R | **−5.61R** | **執行（違規）** |

> 💡 另一個細節：照規則的虧損交易平均 −1.07R，比回測的 −0.99R 大一點——這來自**滑價與跳空**（停損單在跳空時以更差的價格成交，10.3）。這個差距很小，但值得在回測中用更保守的成本假設反映。

### 5. 策略問題還是執行問題？

| 情況 | 判斷 | 對策 |
|---|---|---|
| 照規則的結果在範圍內，實際結果變差 | **執行問題** | 改善紀律與流程（12.3），不改策略 |
| 照規則的結果本身就低於第 5 百分位 | **可能是策略問題** | 檢查資料、成本、市場狀態；走 12.6 的流程 |
| 滑價明顯高於假設 | **成本問題** | 用實際滑價重新回測；考慮換流動性更好的商品 |
| 結果遠高於預期 | **可能是運氣** | 不加碼；繼續累積樣本 |

### 6. ⭐ 上路關卡的判斷

回到 [README](README.md) 的上路關卡，用本例的資料判斷：

| 條件 | 本例 | 通過？ |
|---|---|---|
| 至少 3 個月、30 筆以上 | 4 個月、36 筆 | ✅ |
| 規則遵守率 > 90% | **88.9%** | ❌ |
| 結果落在預期範圍內 | 第 33 百分位 | ✅ |
| 日誌與月報完整 | 是 | ✅ |

**結論：還不能進入小額實盤。** 策略本身沒有問題，但規則遵守率差一點點。對策是**再模擬一個月**，專注改善「提早停利」（最貴的違規），等遵守率穩定超過 90% 再上路。

> 🚗 **這就像路考前的模擬測驗**：開得很好，但有兩次忘了打方向燈——不是不會開車，而是習慣還沒養成。多練一個月，比帶著壞習慣上路好得多。而且記住：**真金白銀只會讓違規變多，不會變少**（12.5）。

## 📌 重點整理

1. 差異的 6 大原因：**滑價、執行、運氣、過度擬合、市場改變、回測錯誤**；大部分只會讓結果變差。
2. **滑價分析**：本例實際 0.12%，略高於回測假設的 0.10%。
3. 用**拔靴法**判斷結果是否在預期範圍：實際在第 33 百分位、照規則在第 53 百分位。
4. **差異拆解**：回測 8.79R → 照規則 9.32R → 實際 3.71R；落差幾乎全部來自**執行**。
5. 區分**策略問題**與**執行問題**，對策完全不同。
6. 本例遵守率 88.9% 未達 90%，**還不能上路**——再模擬一個月。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「實際結果比回測差，就代表策略失效」 | 可能是執行、滑價或運氣；要拆解落差來源再判斷。 |
| 「實際結果比回測好，可以加碼了」 | 很可能只是運氣；繼續累積樣本，不要加碼。 |
| 「滑價差一點點沒關係」 | 要用實際滑價重新回測，確認策略仍有足夠的利潤空間。 |
| 「遵守率 88% 和 90% 差不多，可以上路了」 | 真金白銀只會讓違規變多；先改善再上路。 |

## ✅ 自我測驗

**Q1. 為什麼回測和實盤結果會不一樣？列出 3 個原因。**

<details><summary>看答案</summary>

任選 3 個：成交價與滑價（跳空、價差、追價）；執行與紀律（提早停利、放寬停損、跳過訊號）；運氣（樣本少、隨機性大）；過度擬合（參數只適合過去）；市場改變（優勢消失）；回測本身的錯誤（前視偏差、倖存者偏差、成本低估）。

</details>

**Q2. 如何判斷落差來自「策略」還是「執行」？**

<details><summary>看答案</summary>

比較「照規則的模擬結果」和「實際模擬結果」，並把兩者放進回測預期分布中看百分位。如果照規則的結果在正常範圍內、實際結果變差，落差來自執行（違規）；如果照規則的結果本身就異常差（例如低於第 5 百分位），則可能是策略、資料或成本出了問題。

</details>

**Q3. 模擬結果遠高於預期（例如第 98 百分位）時，應該怎麼做？**

<details><summary>看答案</summary>

不要因此加碼或提早上實盤，因為很可能只是運氣；先檢查是否有記錄錯誤（例如成交價記錄得太理想），然後繼續依計畫累積樣本，讓結果回到更可靠的判斷基礎。

</details>
