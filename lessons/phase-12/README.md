# Phase 12｜上場：模擬交易到小額實盤

> **預計時數：30 小時 + 至少 3 個月日曆時間**（6 個單元）
> **生活比喻：考到駕照後，先在教練陪同下上路，再自己開短程，最後才上高速公路。**

到 Phase 11 為止，你做的所有事情都在「模擬器」裡：歷史資料、回測、蒙地卡羅。這個階段，你要第一次面對**真實的市場**：

| 回測裡沒有的 | Phase 12 會遇到 |
|---|---|
| 完美的成交價 | 滑價、跳空、沒成交 |
| 冷靜的電腦 | 你自己的恐懼、貪婪、懷疑（Phase 7） |
| 一瞬間跑完 14 年 | 一天一天、一筆一筆地等待 |
| 「最大回撤 −18%」只是一個數字 | 真的看著帳戶一天一天縮水 |

> 🔑 **這個階段的目標不是賺錢，而是驗證兩件事**：
> 1. **策略在真實市場中，表現是否落在回測預期的範圍內？**
> 2. **你能不能照著規則執行？**（規則遵守率）
>
> 兩者都通過，才用很小的資金進入實盤。這是整個課程中**唯一需要「等待時間」**的階段：至少 3 個月、30 筆以上的模擬交易，急不得。

## 時間安排（重要）

```
  W49          W50 ─────────────────────────────────── 約 W61
  12.1 計畫書   12.2 模擬交易（每天收盤後 15～30 分鐘）
  定稿          12.3 每週檢討（每週 1 小時）＋ 每月報告
               12.4 差異分析（第 1、2、3 個月底）
                                                        ↓
                                        通過關卡 → 12.5 小額實盤
               12.6 停止 / 修改 / 放棄的規則（貫穿全程）

  ※ Phase 13（畢業專題）可以和模擬交易同時進行
```

| 週次 | 做什麼 |
|---|---|
| W49 | 讀 12.1～12.6，**完成交易計畫書定稿**，開始模擬交易 |
| W50～約 W61 | 每天執行模擬交易、每週檢討、每月一份報告（每週約 2～3 小時） |
| 第 3 個月底 | 用 12.4 的方法做總檢討，判斷是否通過「上路關卡」 |
| 通過後 | 12.5 小額實盤，繼續每週檢討 |

## 上路關卡（進入小額實盤的條件）

- [ ] 模擬交易至少 **3 個月**、**30 筆**以上
- [ ] **規則遵守率 > 90%**
- [ ] 結果落在**回測預期範圍內**（12.4 的方法）
- [ ] 每週檢討與每月報告都有完成
- [ ] 交易計畫書中寫好了**停止、修改、放棄**的條件（12.6）

## 🎮 本階段的模擬交易：第 6 關：正式模擬

本階段就是正式模擬交易。前五關累積的日誌，可以直接用 12.3、12.4 的程式分析（欄位相同）。

> 工具：[課程練習器](../../tools/trading-simulator/README.md)（模擬資料、可快轉）或 TradingView 模擬交易。完整說明見 [模擬交易路線圖](../../docs/SIMULATION.md)。

## 完成 Phase 12 的標準

- [ ] 完成並簽署交易計畫書（12.1）
- [ ] 完成至少 3 個月、30 筆以上的模擬交易，每筆都有日誌
- [ ] 每月一份檢討報告（[templates/monthly-review.md](../../templates/monthly-review.md)）
- [ ] 能用資料說明模擬交易與回測的差異來源
- [ ] 通過上路關卡後，開始小額實盤（或明確記錄為什麼還沒通過）
- [ ] 能說出何時該停止、修改或放棄一個策略
