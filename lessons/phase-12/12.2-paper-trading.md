## 📖 開場故事：駕訓班的場內練習

拿到駕照之前，你要先在駕訓班的**場內**練習：倒車入庫、路邊停車、S 型彎道。

場內練習有幾個特點：
- **不會真的撞到人**，犯錯的代價很低
- 但你要**當作真的在開車**：繫安全帶、打方向燈、看後照鏡——如果在場內就隨便亂開，上路時這些習慣也不會出現
- 教練會在旁邊**記錄**你的每個錯誤：哪裡忘了打燈、哪裡壓線
- 練到**熟練、穩定**之後，才能去路考

但場內練習也有它的限制：場內沒有突然衝出來的機車、沒有後面一直按喇叭的大卡車，所以**場內開得好，不代表上路一定開得好**。

> 🚗 **模擬交易就是駕訓班的場內練習**：用假的錢，但要**當作真的**——照計畫書執行、記錄每一筆、不挑交易、不事後補記。它能驗證你的策略與執行流程；但它沒有真金白銀帶來的恐懼與貪婪，所以這只是上路前的第一關（12.5）。

## 🧠 正文

### 1. 模擬交易的兩個目的

| 驗證什麼 | 問題 | 怎麼衡量 |
|---|---|---|
| **策略** | 在「沒看過的未來」，策略表現是否落在回測預期範圍內？ | 12.4 的差異分析 |
| **你自己** | 你能不能照著規則，每天、每筆、持續執行？ | **規則遵守率**（7.6） |

> 🔑 模擬交易是**真正的樣本外測試**（10.13）：回測時你已經看過歷史，但模擬交易面對的是**真的還沒發生**的未來。這是任何回測技巧都無法取代的。

### 2. 三種模擬交易方式

| 方式 | 做法 | 優點 | 缺點 |
|---|---|---|---|
| **券商模擬帳戶** | 部分券商或平台提供模擬下單功能 | 最接近真實下單流程 | 模擬撮合可能過於理想（例如成交太容易）；功能與規則依平台而異 |
| **試算表** | 每天收盤後依規則記錄「明天的委託」，隔天記錄模擬成交價 | 簡單、完全掌控 | 要自律，容易事後美化 |
| **半自動程式** | 用 11.10 的骨架程式產生訊號，人工確認並記錄 | 和回測使用同一套程式，最一致 | 需要一點程式基礎 |

> 💡 **建議**：用「半自動程式產生訊號 + 試算表或 CSV 記錄」。訊號由程式產生，保證和回測一致；記錄由你手動完成，練習執行的紀律。

### 3. ⭐ 讓模擬交易盡量真實的 7 條規則

| # | 規則 | 為什麼 |
|---|---|---|
| 1 | **用計畫書規定的部位大小與資金** | 用 100 萬模擬、實盤只有 10 萬，就要用比例換算；不要用 1 億模擬 |
| 2 | **成交價用實際可以成交的價格**：開盤成交就記錄隔天**真實的開盤價**，再加上合理的滑價 | 不要記錄「理想的價格」（10.6） |
| 3 | **每個訊號都要執行**，不挑交易 | 挑交易就是在偷偷改策略；而且利潤常常集中在少數幾筆（10.9） |
| 4 | **收盤後立刻記錄**，不事後補記 | 事後補記會不自覺地美化（7.3 後見之明） |
| 5 | **停損一律執行**，不「這次例外」 | 模擬時都不停損，實盤更不會停 |
| 6 | **計算成本**：手續費、交易稅 | 和回測的成本假設一致 |
| 7 | **記錄情緒**：進場前、持倉中 | 模擬交易也會有情緒，這是了解自己的機會 |

> 🚗 **場內也要繫安全帶**：模擬交易時的每一個「這次就算了」，都會變成實盤時的壞習慣。

### 4. ⭐ 每日例行程序（收盤後 15～30 分鐘）

```
  □ 1. 更新資料，執行資料檢查（9.10 檢查清單）
  □ 2. 記錄今天開盤成交的委託：實際成交價、成本
  □ 3. 檢查持倉：有沒有碰到停損 / 出場條件？
  □ 4. 執行訊號程式，產生「明天的委託清單」
  □ 5. 風控檢查：部位大小、總風險、單月虧損（計畫書第 4 段）
  □ 6. 寫下明天的委託（買 / 賣 / 停損價）
  □ 7. 記錄今天的情緒與任何「想違規」的衝動（交易日誌的「想交易但沒交易」）
  □ 8. 更新資金曲線與回撤
```

> 💡 回想 7.7 的例行程序：把它變成每天固定時間、固定順序的習慣，就像刷牙一樣。**時間固定比時間長短重要。**

### 5. ⭐ 每筆交易要記錄的欄位

本階段的練習資料 [`data/paper_journal.csv`](data/paper_journal.csv) 就是用以下欄位記錄的：

| 欄位 | 意思 | 用途 |
|---|---|---|
| `trade_id` | 交易編號 | |
| `entry_date` / `exit_date` | 進出場日期 | 持有時間 |
| `symbol` / `strategy` | 商品、策略 | 分組分析 |
| `signal_price` | 訊號出現時的參考價（例如訊號日收盤價） | **計算滑價**（12.4） |
| `fill_price` | 實際（模擬）成交價 | |
| `stop_price` | 停損價 | 計算 R |
| `exit_price` | 出場價 | |
| `R` | 實際的 R 倍數 | 績效 |
| `R_if_rules` | **如果完全照規則**，這筆會是多少 R | **計算違規成本**（12.3） |
| `followed_rules` | 是否完全遵守規則（Y / N） | 規則遵守率 |
| `violation` | 違規類型 | 找出最常犯的錯 |
| `emotion` | 進場前情緒（1 = 平靜 ～ 5 = 非常焦慮或興奮） | 情緒與結果的關係 |

**用程式記錄日誌：**

```python
import csv
import os
from datetime import date

JOURNAL = "my_paper_journal.csv"
FIELDS = ["trade_id", "entry_date", "exit_date", "symbol", "strategy", "signal_price", "fill_price",
          "stop_price", "exit_price", "R", "R_if_rules", "followed_rules", "violation", "emotion"]


def add_trade(**record):
    """新增一筆已平倉的交易到 CSV；自動計算 R（多單）。"""
    risk = record["fill_price"] - record["stop_price"]
    record["R"] = round((record["exit_price"] - record["fill_price"]) / risk, 2)
    record.setdefault("R_if_rules", record["R"])
    is_new = not os.path.exists(JOURNAL)
    with open(JOURNAL, "a", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=FIELDS)
        if is_new:
            writer.writeheader()
        writer.writerow(record)
    return record["R"]


r = add_trade(trade_id=1, entry_date=date(2025, 2, 3), exit_date=date(2025, 2, 26),
              symbol="ETF-A", strategy="趨勢", signal_price=50.00, fill_price=50.08,
              stop_price=48.00, exit_price=54.20, followed_rules="Y", violation="", emotion=2)
print(f"記錄完成，這筆是 {r}R")
```

輸出：`記錄完成，這筆是 1.98R`

> 💡 `R_if_rules` 預設等於實際的 R（有遵守規則時兩者相同）；違規時，另外填入「照規則會是多少」。這一欄是 12.3「違規成本」分析的關鍵。

### 6. ⚠️ 模擬交易最常見的 6 個陷阱

| 陷阱 | 說明 | 對策 |
|---|---|---|
| **成交太理想** | 記錄了實際上買不到的價格（例如漲停價、盤中最低點） | 只用規則規定的成交方式（例如開盤價）+ 滑價 |
| **挑交易** | 「這個訊號看起來不好，跳過」 | 每個訊號都執行；想跳過的記在「想交易但沒交易」 |
| **事後補記** | 隔了幾天才記錄，記憶已經被結果影響 | 每天收盤後立刻記錄 |
| **部位不切實際** | 模擬用的資金遠大於實盤資金 | 依實盤資金換算 |
| **太早下結論** | 5 筆虧損就認定策略失敗，或 5 筆獲利就急著上實盤 | 看 12.1 的預期範圍；至少 30 筆、3 個月 |
| **以為模擬賺錢＝實盤賺錢** | 模擬沒有真金白銀的情緒 | 12.5 小額實盤是必要的下一步 |

## 📌 重點整理

1. 模擬交易 = **駕訓班場內練習**：低成本犯錯，但要當作真的。
2. 兩個目的：驗證**策略**（是否落在預期範圍）與驗證**你自己**（規則遵守率）。
3. 它是**真正的樣本外測試**：面對真的還沒發生的未來。
4. 7 條規則：**真實部位、真實成交價、不挑交易、立刻記錄、一律停損、計算成本、記錄情緒**。
5. 每日 15～30 分鐘的固定流程；每筆記錄訊號價、成交價、R、**照規則的 R**、是否遵守、情緒。
6. 陷阱：成交太理想、挑交易、事後補記、部位不切實際、太早下結論、以為模擬＝實盤。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「模擬交易是假的，隨便做做就好」 | 隨便做會養成壞習慣，也無法驗證策略與執行；要當作真的。 |
| 「看起來不好的訊號可以跳過」 | 挑交易等於偷偷改策略，而且可能剛好錯過最賺錢的那幾筆。 |
| 「模擬賺錢，實盤就一定會賺」 | 模擬沒有真金白銀的情緒與執行落差；小額實盤是必要的下一關。 |
| 「10 筆就夠判斷了」 | 樣本太少，運氣的影響太大；至少 30 筆、3 個月，並對照預期範圍。 |

## ✅ 自我測驗

**Q1. 為什麼說模擬交易是「真正的樣本外測試」？**

<details><summary>看答案</summary>

因為回測時你已經看過歷史資料，策略設計難免受到影響；模擬交易面對的是真正尚未發生的未來，任何人都無法偷看或擬合，所以它最接近策略在實際未來的表現。

</details>

**Q2. 為什麼模擬交易不能挑交易？**

<details><summary>看答案</summary>

挑交易等於用主觀判斷偷偷修改策略，模擬結果就不再代表原本的策略；而且很多策略的利潤集中在少數幾筆交易（10.9），跳過的可能剛好是最賺錢的那一筆。想跳過的衝動應該記錄在「想交易但沒交易」的紀錄中，而不是執行它。

</details>

**Q3. 記錄 `R_if_rules`（照規則的 R）有什麼用？**

<details><summary>看答案</summary>

用來計算違規的成本：比較實際的 R 與照規則會得到的 R，就能知道每一次違規讓你多賺或少賺多少，並找出最昂貴的違規類型（12.3）。它把「紀律」從抽象的觀念變成具體的數字。

</details>
