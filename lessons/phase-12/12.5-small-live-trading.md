# 12.5｜小額實盤：用「學費」等級的資金

## 🎯 學完你會知道

- 為什麼通過模擬交易之後，還要先用**很小的資金**上路

## 📖 開場故事：先在家附近的巷子開車

小蓉考到駕照了，駕訓班的場內練習她開得很好。但第一次自己開車上路，她發現：

- 後面的車一按喇叭，她就**緊張到忘了打方向燈**
- 場內從來沒遇過**機車從旁邊鑽出來**
- 停車時，因為怕刮到別人的車，**比在場內慢了三倍**

她的爸爸說：「這很正常。不要一開始就上高速公路。先在**家附近的巷子**開，熟悉了再開到市區，最後才上高速公路。」

> 🚙 **小額實盤就是在家附近的巷子開車**：技術上你已經會了（模擬交易通過），但真實的道路（真金白銀）會帶來完全不同的壓力。用一筆「虧光也沒關係」的小錢先上路，讓自己適應真實的情緒與執行，再一步一步加大資金。

## 🧠 正文

### 1. ⭐ 真金白銀會改變什麼？

| 面向 | 模擬交易 | 真實交易 |
|---|---|---|
| **情緒** | 虧損只是一個數字 | 虧損是「真的錢」，會影響睡眠與心情（7.1） |
| **執行** | 很容易照規則 | 停損時會猶豫、獲利時想提早跑（7.2） |
| **成交** | 用開盤價 + 假設的滑價 | 真的委託、真的排隊、可能沒成交、可能跳空 |
| **成本** | 依公式計算 | 真的手續費、最低收費、交易稅 |
| **後勤** | 不會出錯 | 下錯單、網路斷線、券商系統問題 |

> 🔑 回想 Phase 12 的費曼檢核題：**「模擬交易賺錢，實盤就一定會賺」是錯的**——真金白銀會讓你的情緒完全不同。小額實盤的目的，就是在損失很小的情況下，**測量這個差距有多大**。

### 2. ⭐ 學費等級的資金

| 條件 | 說明 |
|---|---|
| **全部虧光也不影響生活** | 不影響房租、生活費、緊急預備金、還款 |
| **不是借來的錢** | 不用信貸、不用融資、不用槓桿（2.6） |
| **心理上真的「接受」虧光** | 把它當作學費，而不是投資本金 |
| **大到會在意** | 太小（例如 1,000 元）沒有情緒壓力，測不出真實的你；要讓虧損會「有點痛」 |

> 💡 **沒有標準金額**，取決於你的收入與資產。很多人會用「幾個月可存下來的金額」或「總投資資產的一小部分（例如 5%～10% 以下）」作為參考。重點是**虧光也不影響生活，但虧損會有感覺**。

### 3. ⚠️ 小資金的特殊問題：最低手續費

台股手續費通常有**最低收費**（常見 20 元，以券商規定為準）。資金小、部位小時，最低手續費會讓**實際成本變高**（10.6 練習 4）：

```python
def round_trip_cost(value, fee_rate=0.001425, discount=0.6, min_fee=20, tax=0.003):
    """一買一賣的總成本（元）。"""
    fee = max(value * fee_rate * discount, min_fee)
    return fee + fee + value * tax


for value in [5_000, 16_000, 50_000]:
    cost = round_trip_cost(value)
    print(f"部位 {value:>6,} 元：來回成本 {cost:>6.1f} 元，佔部位 {cost / value:.2%}")
```

輸出：

```
部位  5,000 元：來回成本   55.0 元，佔部位 1.10%
部位 16,000 元：來回成本   88.0 元，佔部位 0.55%
部位 50,000 元：來回成本  235.5 元，佔部位 0.47%
```

> 🔑 部位只有 5,000 元時，來回成本高達 **1.10%**，是回測假設（0.47%）的兩倍多。小額實盤時：
> - **用實際的部位大小重新計算成本**，確認策略在小資金下仍有利潤空間
> - 盡量選擇**手續費低、最低收費低**的券商（各券商的折扣與最低收費不同，以券商公告為準）
> - 可以考慮**零股交易**（台股有盤中零股交易，交易規則與流動性和整股不同，以證交所規定為準），但要注意零股的買賣價差可能較大
> - 如果策略同時持有很多檔，小資金可能**無法照比例執行**——可以先只執行其中一部分，或選擇單一 ETF 的策略

**範例：10 萬元的學費資金**

| 項目 | 計算 |
|---|---|
| 每筆風險 0.8% | 800 元 |
| 50 元的股票、停損距離 2.5 元（5%） | 800 ÷ 2.5 = 320 股 |
| 部位金額 | 320 × 50 = 16,000 元（佔資金 16%） |
| 來回成本 | 約 88 元 ≈ **0.11R** |

> 💡 這筆交易光是成本就要先付出約 0.11R。如果策略的期望值是 0.24R（12.1），成本就吃掉了將近一半——**小資金時，成本是決定性的因素**。

### 4. ⭐ 逐步加碼的階梯

| 階段 | 資金（範例） | 升級條件 | 降級條件 |
|---|---|---|---|
| **0. 模擬交易** | 0（虛擬 100 萬） | 3 個月、30 筆、遵守率 > 90%、在預期範圍內 | — |
| **1. 學費** | 10 萬 | 再 3 個月、30 筆、遵守率 > 90%、結果在預期範圍內 | 遵守率 < 90% 或觸發停止條件 → 回到模擬 |
| **2. 小額** | 30 萬 | 再 6 個月，結果仍在預期範圍內 | 回撤超過 95% 信心值 → 回到學費階段 |
| **3. 逐步加碼** | 每次增加不超過目前的 50% | 每階至少 6 個月 | 同上 |

> 🚗 **巷子 → 市區 → 高速公路**：每升一級，都要**重新證明**一次——而且只有「規則遵守率」和「結果在預期範圍內」**同時**達成才能升級。
>
> ⚠️ **不要因為賺錢就加速升級**：短期賺很多常常只是運氣（12.4）。也**不要在虧損後加碼想要「扳回來」**（7.4 報復性交易）。加碼只在事先規定的時間點、依事先規定的條件進行。

### 5. 實盤要額外記錄的事

在模擬交易日誌的基礎上，多記錄：

| 欄位 | 為什麼 |
|---|---|
| **委託價 vs. 成交價** | 真實的滑價（12.4） |
| **實際手續費與稅** | 確認成本假設 |
| **沒成交 / 部分成交** | 回測沒有的情況 |
| **下單失誤** | 下錯數量、方向、商品 |
| **和模擬的差異** | 同時繼續模擬交易，比較兩者的差距 |
| **情緒分數** | 和模擬期間比較：真金白銀讓情緒高了多少？ |

> 💡 **建議**：開始小額實盤後，**同時繼續用同一套規則做模擬交易**。兩者的差距 = 真實市場與真實情緒的成本，這是你在這個階段最重要的資料。

### 6. ⭐ 第一筆實盤交易的檢查清單

- [ ] 交易計畫書已更新（第 1 段的實盤資金、第 9 段的上路關卡已通過）
- [ ] 帳戶中只放學費等級的資金；**沒有開啟融資融券**
- [ ] 熟悉券商下單介面：委託類型（市價、限價）、零股、刪改單（2.2）
- [ ] 先用**最小數量**下一筆測試單，確認下單流程與成交回報
- [ ] 停損單的設定方式（券商是否有觸價單、條件單；或每天收盤後手動檢查）
- [ ] 知道系統出問題時怎麼辦：券商客服電話、手機 App 備援
- [ ] 實盤日誌已建立，欄位包含第 5 節的內容
- [ ] 寫下：「這筆錢我已經當作學費，虧光也不影響生活」

## 📌 重點整理

1. 小額實盤 = **在家附近的巷子開車**：技術會了，但要適應真實的壓力。
2. 真金白銀會改變**情緒、執行、成交、成本、後勤**。
3. **學費等級資金**：虧光不影響生活、不借錢、心理接受，但虧損要有感覺。
4. 小資金的**最低手續費**會讓成本變高：5,000 元部位的來回成本達 1.10%。
5. **逐步加碼階梯**：每一階都要同時達成遵守率與預期範圍才升級；不要因為賺錢加速，也不要虧損後加碼。
6. 實盤時**同時繼續模擬**，兩者的差距就是真實市場與情緒的成本。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「模擬交易賺錢，實盤就一定會賺」 | 真金白銀會改變情緒與執行；小額實盤就是要測量這個差距。 |
| 「學費資金越小越安全，100 元就好」 | 太小沒有情緒壓力，測不出真實的你；要讓虧損有感覺，但不影響生活。 |
| 「小額實盤賺錢了，可以馬上加大資金」 | 短期獲利可能是運氣；依事先規定的階梯與時間升級。 |
| 「回測的成本假設適用所有資金規模」 | 小資金受最低手續費影響，實際成本可能高出很多。 |

## ✅ 自我測驗

**Q1. 為什麼要先模擬交易、再小額實盤，而不是直接用全部資金上路？**

<details><summary>看答案</summary>

模擬交易能以零成本驗證策略與執行流程，但沒有真金白銀帶來的情緒壓力；小額實盤則以可承受的小損失，測量真實情緒、真實成交與真實成本帶來的差距。兩階段都通過後再逐步加碼，能在最小代價下發現問題，避免一開始就用大資金承擔未知的風險。

</details>

**Q2. 什麼是「學費等級」的資金？**

<details><summary>看答案</summary>

全部虧光也不影響生活（房租、生活費、緊急預備金、還款）、不是借來的錢、心理上真的把它當作學費接受可能虧光，但金額又大到虧損時會有感覺，才能測出真實的情緒反應。

</details>

**Q3. 小資金交易時，最低手續費會帶來什麼問題？怎麼處理？**

<details><summary>看答案</summary>

部位很小時，手續費可能達不到依費率計算的金額而被收取最低收費，使實際成本率大幅高於回測假設（例如 5,000 元部位的來回成本約 1.10%），侵蝕策略的期望值。處理方式：用實際部位重新計算成本並確認策略仍有利潤空間、選擇費率與最低收費較低的券商、考慮零股交易（注意價差）、或先執行較少檔數或單一 ETF 的策略。

</details>
