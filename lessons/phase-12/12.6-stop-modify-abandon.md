# 12.6｜什麼時候該停止、修改或放棄一個策略

> ⏱️ 約 3 小時｜[← 上一單元：12.5](12.5-small-live-trading.md)｜[Phase 12 目錄](README.md)｜[總複習 →](review.md)

## 🎯 學完你會知道

- 最困難的問題：**「這是正常的低潮，還是策略壞掉了？」**
- 為什麼 36 筆交易**在統計上幾乎什麼都證明不了**
- 要多少筆交易，才能確認策略有優勢？
- **三層決策規則**：暫停檢查、修改、放棄
- **修改策略的正確流程**：回到研究，而不是在實盤中亂改
- 兩個相反的陷阱：**太早放棄**（策略跳躍）與**太晚放棄**（沉沒成本）

---

## 📖 開場故事：什麼時候該換一條路線

阿凱每天開車上班，走的是一條平常 30 分鐘的路線。

- 有一天塞了 45 分鐘——**他沒有換路線**，因為偶爾塞車很正常
- 連續三天都塞 45 分鐘——**他開始注意**：是不是有施工？查了一下，原來前面在修路，預計三個月。**他換了路線**
- 他的同事小明，只要有一天塞車，**隔天就換一條路**。結果他每條路都只走一兩次，永遠不知道哪條路平均最快，還常常因為不熟路而迷路

> 🛣️ **什麼時候該放棄一個策略，就像什麼時候該換路線**：偶爾塞車（正常的回撤）不該換；但如果有證據顯示路況真的變了（策略失效），就要換。最糟的是小明——**每遇到一次低潮就換策略**，永遠在追逐「最近表現最好」的路線。關鍵是：**事先決定「塞多久、塞幾次」才換路線**，而不是每天看心情決定。

## 🧠 正文

### 1. ⭐ 為什麼這麼難判斷？

回到 12.4 的模擬交易日誌，用統計方法估計「每筆平均 R」的範圍：

```python
import numpy as np
import pandas as pd

journal = pd.read_csv("paper_journal.csv")
for col, label in [("R", "實際"), ("R_if_rules", "照規則")]:
    r = journal[col]
    se = r.std(ddof=1) / np.sqrt(len(r))
    print(f"{label}：每筆平均 {r.mean():.2f}R，95% 信賴區間約 {r.mean() - 1.96 * se:.2f}R ～ {r.mean() + 1.96 * se:.2f}R")
```

輸出：

```
實際：每筆平均 0.10R，95% 信賴區間約 -0.42R ～ 0.63R
照規則：每筆平均 0.26R，95% 信賴區間約 -0.28R ～ 0.80R
```

> 🚨 **36 筆交易，每筆平均 R 的 95% 信賴區間從 −0.42R 到 +0.63R**——真正的期望值可能是負的，也可能比回測還好。換句話說，**36 筆交易在統計上幾乎什麼都證明不了**：既不能證明策略有效，也不能證明它失效。

**要多少筆交易才能確認？**

```python
rng = np.random.default_rng(5)
n = 150
win = rng.random(n) < 0.40
backtest_trades = np.where(win, rng.lognormal(np.log(1.6), 0.6, n), -rng.uniform(0.8, 1.2, n)).round(2)
mu, sd = backtest_trades.mean(), backtest_trades.std(ddof=1)
print(f"回測：每筆期望值 {mu:.2f}R，標準差 {sd:.2f}R")
for z, conf in [(1.645, "90%"), (1.96, "95%")]:
    print(f"要在 {conf} 信心下確認期望值 > 0，大約需要 {(z * sd / mu) ** 2:.0f} 筆交易")
```

輸出：

```
回測：每筆期望值 0.24R，標準差 1.83R
要在 90% 信心下確認期望值 > 0，大約需要 152 筆交易
要在 95% 信心下確認期望值 > 0，大約需要 215 筆交易
```

> 🔑 一個期望值 0.24R 的策略，需要**大約 150～220 筆交易**，才能在統計上確認它有優勢。如果一年只交易 30 筆，那要 5～7 年。（這是簡化的近似：假設每筆交易獨立、報酬分布穩定。）
>
> **結論：你不能等到「統計上證明失效」才行動**——那可能要好幾年，損失也會很大。所以要用**事先設定的護欄**（第 2 節）：不是證明策略壞了，而是「**如果策略和回測一樣好，這種情況很少發生**」時就啟動檢查。

### 2. ⭐⭐ 三層決策規則

| 層級 | 觸發條件（範例，寫進計畫書第 10 段） | 動作 |
|---|---|---|
| 🟡 **第 1 層：暫停檢查** | 回撤達到蒙地卡羅 **95%** 信心值（11.5）；或累計結果低於預期分布第 **5** 百分位（12.4）；或單月虧損達上限 | **暫停新倉**（既有部位照規則處理），檢查：執行、資料、成本、程式。**沒發現問題 → 恢復交易** |
| 🟠 **第 2 層：修改** | 檢查發現**特定、可解釋**的問題：成本假設錯誤、規則漏洞、資料錯誤、滑價遠高於假設 | 回到**研究流程**（11.11）：寫研究日誌 → 修改 → 重新回測 → 重新模擬交易 |
| 🔴 **第 3 層：放棄** | 回撤超過 **99%** 信心值；或策略的優勢來源明顯消失（例如規則改變、市場結構改變）；或修改後重新驗證仍然失敗 | **停用策略**，寫下結案報告，歸檔 |

> 🛣️ **事先決定「塞多久、塞幾次」才換路線**：這些門檻都要在開始交易**之前**寫進計畫書。觸發時照表操課，而不是在虧損的當下重新思考「要不要停」——那時候你的判斷一定會受情緒影響。

**用蒙地卡羅結果設定門檻（以 12.1 的範例，每筆風險 0.8%）：**

| 狀態 | 帳戶回撤 | 動作 |
|---|---|---|
| 正常 | 0 ～ −14% | 照規則執行 |
| 🟡 暫停檢查 | 達到 −14%（約 95% 信心值） | 暫停新倉、檢查 |
| 🔴 放棄 | 超過 −17%（約 99% 信心值） | 停用、重新研究 |

### 3. 什麼「不是」修改的好理由

| ❌ 不好的理由 | 為什麼 |
|---|---|
| 「最近 5 筆都虧錢」 | 在預期範圍內的連虧是正常的（12.1 的 95% 連虧是 13 筆） |
| 「別的策略最近表現比較好」 | 策略跳躍：追逐最近的贏家（10.12、11.6） |
| 「我覺得市場變了」 | 沒有具體證據的感覺，常常是近因偏誤（7.3） |
| 「我想讓它賺更多」 | 在實盤中最佳化 = 用實盤資料過度擬合 |
| 「這一筆如果有過濾條件就不會虧」 | 根據單筆交易修改規則，是最典型的過度擬合 |

### 4. ⭐ 修改策略的正確流程

```
  發現具體問題（例如：滑價是假設的 2 倍）
        ↓
  寫進研究日誌（11.11）：問題、證據、新的假說
        ↓
  在「研究環境」中修改：新版本號（v1.3）
        ↓
  重新回測：用新的成本假設、原本的樣本內外切分
        ↓
  通過 → 重新模擬交易（可以縮短，但不能跳過）
        ↓
  更新交易計畫書（版本紀錄）、重新簽名
```

> 🔑 **修改後的策略是一個新策略**，要重新走一次驗證流程。最常見的錯誤是在實盤中「順手改一下」，然後繼續用舊的回測結果當作預期——那等於完全沒有預期。

### 5. ⚠️ 兩個相反的陷阱

| | 太早放棄（策略跳躍） | 太晚放棄（沉沒成本） |
|---|---|---|
| 比喻 | 小明：塞一次車就換路線 | 明知道在修路三個月，還是每天走同一條 |
| 表現 | 每次低潮就換策略，永遠在追逐最近的贏家 | 「我研究了一年，不能放棄」、「再等一下就會回來」 |
| 後果 | 每個策略都在低點放棄，錯過反彈；永遠累積不了足夠的樣本 | 越虧越多 |
| 心理偏誤 | 近因偏誤、FOMO（7.3、7.4） | 沉沒成本、損失趨避（7.2） |
| 對策 | **事先寫好的門檻**：沒觸發就繼續 | **事先寫好的門檻**：觸發就停 |

> 🛣️ 兩個陷阱的解藥一樣：**事先寫好規則，照表操課**。這也是為什麼整個課程一直強調「先寫計畫，再執行」。

### 6. 放棄策略時要做的事

- [ ] 寫下**結案報告**：策略做了多久、多少筆、結果、放棄的原因（研究日誌第 6 段）
- [ ] 計算**總學費**：模擬期間的時間、實盤的虧損
- [ ] 記錄**學到的事**：哪些假設錯了？哪些檢驗應該更早發現問題？
- [ ] **不要立刻用同一筆資金跳到另一個未驗證的策略**——新策略要重新走一次完整流程
- [ ] 檢查核心配置（8.11）是否仍然正常運作——主動策略失敗，不影響你的長期被動配置

> 💡 **放棄一個策略不是失敗**。回想 10.16 和 11.11：大部分策略都會被淘汰，研究者的價值在於**用最少的代價淘汰**。在學費階段就發現問題並放棄，正是這套流程設計的目的。

## 📌 重點整理

1. 最難的問題：**正常低潮還是策略壞掉？** 就像判斷偶爾塞車還是道路施工。
2. **36 筆交易在統計上幾乎證明不了什麼**：每筆平均 R 的 95% 信賴區間是 −0.42R ～ +0.63R。
3. 確認一個 0.24R 期望值的策略，需要約 **150～220 筆**交易 → 不能等統計證明，要用**事先的護欄**。
4. 三層決策：🟡 **暫停檢查**（95% 信心回撤、第 5 百分位）→ 🟠 **修改**（具體可解釋的問題）→ 🔴 **放棄**（99% 信心回撤、優勢來源消失、修改後仍失敗）。
5. **修改後是新策略**：研究日誌 → 重新回測 → 重新模擬 → 更新計畫書。
6. 兩個陷阱：**太早放棄**（策略跳躍）與**太晚放棄**（沉沒成本）；解藥都是事先寫好的規則。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「連虧 5 筆，策略一定壞了」 | 在預期範圍內的連虧是正常的；要對照事先設定的門檻。 |
| 「等統計上證明失效再停就好」 | 可能需要好幾年與很大的損失；要用事先設定的護欄。 |
| 「實盤中順手調整一下參數沒關係」 | 修改後是新策略，要重新回測與模擬；否則等於沒有預期。 |
| 「放棄策略就是失敗」 | 用最小的代價淘汰不可行的策略，正是這套流程的目的。 |

## ✅ 自我測驗

**Q1. 為什麼不能等到「統計上證明策略失效」才停止？**

<details><summary>看答案</summary>

因為交易結果的雜訊很大，要在統計上確認一個策略的期望值（無論有效或失效）需要非常多筆交易（本例約 150～220 筆），可能要好幾年，期間的損失會很大。因此要事先用蒙地卡羅與預期範圍設定護欄，當結果落在「策略若正常則很少發生」的區域時就啟動檢查或停用。

</details>

**Q2. 三層決策規則分別在什麼情況下觸發？**

<details><summary>看答案</summary>

第 1 層暫停檢查：回撤達到 95% 信心值、累計結果低於預期第 5 百分位或單月虧損達上限，暫停新倉並檢查執行、資料、成本、程式。第 2 層修改：發現具體可解釋的問題（成本、規則漏洞、資料錯誤、滑價），回到研究流程修改並重新驗證。第 3 層放棄：回撤超過 99% 信心值、優勢來源消失，或修改後重新驗證仍失敗，停用並寫結案報告。

</details>

**Q3. 「策略跳躍」和「沉沒成本」分別是什麼陷阱？共同的解藥是什麼？**

<details><summary>看答案</summary>

策略跳躍是太早放棄：每次低潮就換策略、追逐最近表現好的策略，結果在低點放棄、永遠累積不了足夠樣本。沉沒成本是太晚放棄：因為已經投入很多時間金錢而不願停止，越虧越多。共同的解藥是事先寫好明確的門檻與動作，觸發就照表操課，沒觸發就繼續執行。

</details>
