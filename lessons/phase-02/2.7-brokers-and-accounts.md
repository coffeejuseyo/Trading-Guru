## 📖 開場故事：選一家銀行

小華第一次領薪水，要選一家銀行開戶。她比較了幾家：

- 這家跨行轉帳免手續費次數比較多
- 那家 App 很難用，常常當機
- 另一家離家近，但存款利率比較低
- 還有一家沒聽過的「網路銀行」，利率高得不合理……她決定先查查看它有沒有合法執照

> 🏦 **選券商就像選銀行**：比手續費、比 App 好不好用、比服務，但**最重要的是安全和合法**。

## 🧠 正文

### 1. 證券帳戶 + 交割帳戶：兩個帳戶一組

在台灣開證券戶時，通常會開**兩個帳戶**：

| 帳戶 | 在哪裡 | 用途 | 比喻 |
|---|---|---|---|
| **證券帳戶** | 券商 + 集保 | 記錄你持有哪些股票 | 你的「股票存摺」 |
| **交割帳戶** | 券商配合的銀行 | 買股票時扣款、賣股票時入帳、收股利 | 你的「錢包」 |

**流程：**
```
買進股票 → T+2 從交割帳戶扣款 → 股票記入證券帳戶（集保）
賣出股票 → 股票從證券帳戶扣除 → T+2 錢匯入交割帳戶
```

> 🔑 回想 1.11：**台股 T+2 交割前，交割帳戶一定要有足夠的錢，否則會違約交割。** 也回想 1.3：股票登記在**集保**，不是放在券商那裡。

### 2. 帳戶類型一覽

| 帳戶類型 | 可以做什麼 | 開戶條件（概略） | 本課程何時需要 |
|---|---|---|---|
| **現股帳戶**（一般證券戶） | 用現金買賣股票、ETF，含零股、定期定額 | 成年即可開立 | Phase 12 |
| **信用交易帳戶** | 融資、融券（2.5、2.6） | 需另外申請，通常要求開戶滿一定期間、一定交易紀錄與財力證明 | **不需要** |
| **當沖資格** | 現股當日沖銷 | 通常要求開戶滿一定期間、一定成交紀錄，並簽署風險預告書 | **不需要** |
| **複委託帳戶** | 透過國內券商買賣外國股票（如美股） | 另外申請，通常搭配外幣交割帳戶 | 選修 |
| **期貨帳戶** | 期貨、選擇權（1.6、1.7） | 在期貨商開立，需了解風險 | **Phase 6 之後才考慮** |
| **借券帳戶** | 借券、出借股票 | 另外申請 | 不需要 |

> 🔑 **新手只需要「現股帳戶」。** 信用帳戶、當沖、期貨都是放大風險的工具，在完成 Phase 6 風險管理、並經過回測與模擬驗證之前，都不需要開。

### 3. 選擇券商的六個標準

| # | 標準 | 要看什麼 | 為什麼重要 |
|---|---|---|---|
| 1 | 🛡️ **安全與合法** | 是否為主管機關（金管會）核准的證券商；公司規模與信譽 | 最重要，其他都是其次 |
| 2 | 💰 **手續費** | 折扣幾折、退佣方式（當下扣或月退）、**零股低消** | 直接影響交易成本（2.4） |
| 3 | 📱 **下單系統** | App / 電腦版是否穩定、好用；盤中是否常當機 | 關鍵時刻當機可能造成損失 |
| 4 | 🧰 **功能** | 零股交易、定期定額、條件單 / 停損單（2.2）、看盤工具 | 依你的需求 |
| 5 | 🌎 **複委託** | 若要買美股：費率、低消、可交易市場 | 選修 |
| 6 | 🙋 **服務** | 客服回應速度、是否有實體分公司 | 出問題時找得到人 |

**手續費比較表範本**（自己填，比較 3 家）：

| 項目 | 券商 A | 券商 B | 券商 C |
|---|---|---|---|
| 整股手續費折扣 | | | |
| 整股低消 | | | |
| 零股手續費 / 低消 | | | |
| 退佣方式 | | | |
| 定期定額手續費 | | | |
| 停損 / 條件單功能 | | | |
| App 評價 | | | |

> 💡 **不要只比手續費。** 一家便宜但系統常當機的券商，在你需要停損的那一天可能讓你損失更多。

### 4. 開戶流程（一般步驟）

1. **準備文件**：身分證、第二證件、要作為交割帳戶的銀行帳戶（或同時開立）
2. **選擇開戶方式**：多數券商提供**線上開戶**，也可以臨櫃
3. **填寫資料與風險屬性問卷**（KYC）：誠實填寫，它會影響你能交易的商品
4. **簽署契約**：記得閱讀費用、委託方式的說明
5. **審核通過**：收到帳號、設定密碼、下載憑證
6. **安裝 App、設定安全措施**

### 5. 帳戶安全：一定要做的事

| 要做 ✅ | 不要做 ❌ |
|---|---|
| 設定強密碼、開啟雙重驗證 | 把帳號密碼告訴任何人（包括自稱客服、營業員、老師的人） |
| 只從官方 App 商店下載券商 App | 點簡訊、LINE 裡的不明連結登入 |
| 定期查看對帳單與成交回報 | 讓別人「幫你操作」帳戶 |
| 設定成交通知 | **出借或出租帳戶**給別人使用 |

> 🚨 **兩件會讓你觸法或血本無歸的事：**
> 1. **出借 / 出租證券帳戶、銀行帳戶**：可能被用於詐騙、洗錢或炒股，你可能要負法律責任。
> 2. **讓沒有合法執照的人「代操」**：除了容易被騙，未經許可替他人操作也可能違法。
>
> 正規的券商營業員**不能**保證你獲利，也不應該替你決定買賣。

### 6. 網路上的「券商」小心是假的

回想 0.2 與 1.9 的詐騙特徵。如果一個交易平台：
- 不在主管機關的合法業者名單中
- 要你下載不明 App、或在網頁上直接儲值
- 用 LINE 客服溝通
- 出金要先繳「稅金」「保證金」

**→ 幾乎可以確定是詐騙。** 開戶前，請到金管會或證券商業同業公會的網站查詢合法業者名單。

### 7. 本課程的開戶時機建議

| 階段 | 帳戶 | 用途 |
|---|---|---|
| Phase 0–11 | **不需要真實帳戶** | 用 TradingView 模擬交易（2.8） |
| Phase 12 | **現股帳戶**（加上複委託，若要交易美股） | 用「學費預算」小額實盤 |
| 之後 | 期貨、信用帳戶 | 只有在策略經過回測、模擬、小額實盤驗證，且確實需要時才考慮 |

> 🔑 **開戶很容易，關戶也很容易；但學費繳出去就拿不回來了。** 不急，先學好再開。

## 📌 重點整理

1. 台股開戶 = **證券帳戶**（股票存摺）+ **交割帳戶**（錢包）。
2. 帳戶類型：現股、信用（融資融券）、當沖、複委託、期貨、借券。**新手只需要現股帳戶。**
3. 選券商六標準：**安全合法 > 手續費 > 系統穩定 > 功能 > 複委託 > 服務**。
4. 帳戶安全：強密碼、雙重驗證、不給別人密碼、**絕不出借帳戶**、不找人代操。
5. 開戶前查詢**合法業者名單**，避開假平台。
6. 本課程：**Phase 12 才需要開現股帳戶**。

## 🗣️ 一分鐘講給朋友聽（示範稿）

> 「開證券戶其實是開兩個帳戶：一個是證券帳戶，像股票的存摺；另一個是銀行的交割帳戶，像錢包，買股票從這裡扣錢、賣股票錢匯回這裡。
>
> 帳戶種類很多，有可以借錢買股票的信用帳戶、當沖、期貨等等，但新手其實只需要最基本的現股帳戶就夠了，其他都是放大風險的工具。
>
> 選券商就像選銀行，可以比手續費、App 好不好用，但最重要的是要合法、安全。網路上很多假的交易平台，開戶前一定要查主管機關的合法名單。還有，帳戶絕對不能借給別人用，那可能會觸法。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「手續費最便宜的券商就是最好的」 | 安全性、系統穩定度同樣重要。 |
| 「開了信用帳戶比較專業」 | 信用帳戶是放大風險的工具，新手不需要。 |
| 「把帳戶借給朋友用沒關係」 | 出借帳戶可能涉及詐騙、洗錢，出借人可能要負法律責任。 |
| 「營業員推薦的股票應該不錯」 | 營業員不能保證獲利；投資決策要自己負責，要有自己的方法。 |

## 🛠️ 練習（約 30 分鐘）

**練習 1：券商比較表**
選 3 家券商，上官網查資料，填寫本單元第 3 節的「手續費比較表範本」。（只是比較，不需要開戶。）

**練習 2：查合法業者**
到金管會或證券商業同業公會網站，找到「合法證券商名單」的查詢頁面，把網址存到你的筆記「99-我還不懂的問題清單」旁邊的「常用網站」區。

**練習 3：安全檢查**（已有帳戶者）
檢查你現有的證券帳戶：密碼強度、是否開啟雙重驗證或憑證、是否開啟成交通知、最近一個月的對帳單有沒有異常。

## ✅ 自我測驗

**Q1. 證券帳戶和交割帳戶分別是什麼？**

<details><summary>看答案</summary>

證券帳戶記錄你持有的股票（登記在集保），像股票存摺；交割帳戶是券商配合的銀行帳戶，用來在買進時扣款、賣出時入帳、收取股利，像錢包。

</details>

**Q2. 選擇券商時，最重要的標準是什麼？為什麼？**

<details><summary>看答案</summary>

安全與合法：必須是主管機關核准的證券商，否則可能遇到詐騙或資產無法取回，手續費再便宜也沒有意義。

</details>

**Q3. 為什麼新手只需要現股帳戶？**

<details><summary>看答案</summary>

信用帳戶（融資融券）、當沖、期貨等都會放大風險或交易頻率，在尚未學會風險管理、也還沒有經過驗證的策略之前使用，很容易快速虧損。現股帳戶已足以進行小額實盤練習。

</details>
