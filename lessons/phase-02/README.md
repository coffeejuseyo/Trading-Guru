# Phase 2｜遊戲規則：下單、成本與槓桿

> **預計時數：25 小時**（8 個單元）
> **生活比喻：排隊買演唱會門票——要知道怎麼排隊、手續費多少、黃牛票（滑價）是怎麼來的。**

Phase 1 帶你逛了整個金融菜市場，知道每一攤賣什麼。Phase 2 要教你**怎麼真正買東西**：

- 按下「買進」之後，到底發生了什麼事？
- 為什麼我想用 100 元買，結果成交在 100.5 元？
- 一筆交易有哪些「看不見的成本」？
- 怎麼靠「股價下跌」賺錢？
- 借錢買股票（融資）為什麼會被「斷頭」？

學完這個階段，你就完全了解一筆交易從下單到成交、從持有到出場的完整流程，以及每一步的成本與風險。

## 一筆交易的完整旅程

```
① 你決定要買        ② 選擇委託單種類      ③ 券商送單到交易所
  （Phase 3–8 教      （2.2 市價 / 限價 /    （2.7 選對券商）
   你怎麼決定）         停損）
        │                    │                    │
        ▼                    ▼                    ▼
④ 進入委託簿排隊    ⑤ 撮合成交            ⑥ 付出成本
  （2.1 買賣價差）    （2.3 可能有滑價）     （2.4 手續費、稅）
        │                    │                    │
        ▼                    ▼                    ▼
⑦ 持有部位：做多或放空（2.5），可能使用槓桿（2.6）
        │
        ▼
⑧ 出場：再走一次 ②～⑥（成本再付一次！）
```

## 🎮 本階段的模擬交易：第 1 關：會下單

完成 [2.8](2.8-paper-trading-practice.md) 的 8 個委託單任務；用練習器體會「今天收盤後決定、明天開盤成交」。

> 工具：[課程練習器](../../tools/trading-simulator/README.md)（模擬資料、可快轉）或 TradingView 模擬交易。完整說明見 [模擬交易路線圖](../../docs/SIMULATION.md)。

## 完成 Phase 2 的標準

- [ ] 能看懂委託簿（五檔報價），說明買賣價差是什麼
- [ ] 能說明市價單、限價單、停損單、停損限價單的差別與使用時機
- [ ] 能解釋滑價怎麼發生，以及流動性為什麼重要
- [ ] 能算出一筆交易的完整成本
- [ ] 能說明放空怎麼賺錢，以及為什麼風險理論上無限
- [ ] 能計算融資維持率，說明什麼時候會被追繳、斷頭
- [ ] 完成至少 5 種委託單的模擬下單
- [ ] 總複習測驗答對 80% 以上 → 🏁 **達成里程碑 M1：能解釋市場怎麼運作**

> ⚠️ 本階段提到的費率、稅率、融資成數、維持率、帳戶資格等，都是撰寫時的一般情況，**實際以主管機關、交易所與券商的最新規定為準**。
