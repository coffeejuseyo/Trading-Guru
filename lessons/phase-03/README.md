# Phase 3｜數字的語言：機率、統計與交易數學

> **預計時數：45 小時**（12 個單元）
> **生活比喻：賭場每一局不一定贏，但為什麼一整年下來一定賺錢？答案就是「期望值」。**

前兩個階段，你學會了市場的「名詞」：股票、期貨、委託單、成本。這個階段，你要學市場的「文法」——**數字**。

為什麼要在技術分析（Phase 4）之前先學數學？因為：

> 🔑 **沒有統計觀念，你就無法判斷一個指標、一個策略、一個「老師」到底有沒有用。**

學完這個階段，你可以回答這些問題：

- 為什麼虧 50% 要賺 100% 才能回本？
- 為什麼勝率 90% 的策略可能虧錢，勝率 35% 的卻能賺錢？
- 為什麼一個好策略也會連輸 7、8 次？
- 朋友說他「這個月賺了 30%」，這代表他很厲害嗎？
- 「回測 20 筆交易、勝率 70%」可以相信嗎？

> 📌 **不用怕數學。** 本階段只用到加減乘除和一點點次方，所有計算都可以用計算機或試算表完成。重點是**觀念**，不是公式。
