## 📖 開場故事：科學家的實驗室

科學家不會只靠「想」就下結論，他們會**做實驗**。

我們無法讓時光倒流、讓市場重來 1,000 次，但我們可以用**隨機數字**模擬：「如果一個策略真的有某個勝率和賠率，它的結果可能長什麼樣子？」

> 🧪 這種方法叫做**蒙地卡羅模擬**（Monte Carlo Simulation），名字來自摩納哥著名的賭場。Phase 11 會用 Python 做更進階的版本，今天先用試算表。

---

## 🛠️ 動手做

### 實驗設定

我們模擬一個**有優勢但不誇張**的策略：

| 參數 | 數值 | 說明 |
|---|---|---|
| 勝率 | **40%** | 像趨勢跟隨策略（3.5） |
| 獲利時 | **+2R** | |
| 虧損時 | **−1R** | |
| 每筆期望值 | 0.4 × 2 − 0.6 × 1 = **+0.2R** | 正期望值 ✅ |
| 交易筆數 | **100 筆** | |
| 起始資金 | **100,000** | |

> 💡 你也可以用課綱原本的設定（勝率 50%、賺 2 賠 1，期望值 +0.5R），但那個優勢非常大，現實中很少見。用 +0.2R 的設定，更能看到真實的波動。

---

### 步驟 1：建立參數區（10 分鐘）

開一個新的 Google Sheets，在左上角建立參數區：

| | A | B |
|---|---|---|
| 1 | **參數** | |
| 2 | 勝率 | 0.4 |
| 3 | 獲利（R） | 2 |
| 4 | 虧損（R） | 1 |
| 5 | 每筆風險（佔資金 %） | 0.01 |
| 6 | 起始資金 | 100000 |
| 7 | 期望值（R） | `=B2*B3-(1-B2)*B4` |

> 💡 把參數放在固定位置，之後只要改這幾格，整個模擬就會跟著變。

---

### 步驟 2：建立一次模擬（30 分鐘）

從第 10 列開始建立表格：

| | D | E | F | G | H | I |
|---|---|---|---|---|---|---|
| 10 | 筆數 | 隨機數 | 結果 | R | 資金 | 最高資金 |
| 11 | 0 | | | | `=$B$6` | `=H11` |
| 12 | 1 | `=RAND()` | `=IF(E12<$B$2,"W","L")` | `=IF(F12="W",$B$3,-$B$4)` | `=H11*(1+$B$5*G12)` | `=MAX(I11,H12)` |

把第 12 列往下拉到第 111 列（共 100 筆交易）。

再加上統計區：

| | A | B |
|---|---|---|
| 9 | **結果** | |
| 10 | 期末資金 | `=H111` |
| 11 | 總報酬 | `=H111/B6-1` |
| 12 | 勝率（實際） | `=COUNTIF(F12:F111,"W")/100` |
| 13 | 總 R | `=SUM(G12:G111)` |
| 14 | 最大回撤 | `=MAX(ARRAYFORMULA(1-H12:H111/I12:I111))` |

> 💡 **欄位說明：**
> - **H 欄（資金）**：每筆交易以「當時資金」的固定比例（B5）承擔風險。賺 2R 就是資金 × (1 + 1% × 2)，虧 1R 就是資金 × (1 − 1%)。
> - **I 欄（最高資金）**：到目前為止的最高點，用來計算回撤。
> - **最大回撤**：從最高點往下跌最深的幅度（Phase 6 會詳細介紹）。

**最長連虧（選做）**：在 J 欄計算目前連虧次數：
- J11 填 `0`，J12：`=IF(F12="L",J11+1,0)`，往下拉到 J111
- 最長連虧：`=MAX(J12:J111)`

---

### 步驟 3：畫出資金曲線，按 F9 重算（20 分鐘）

1. 選取 D11:D111 和 H11:H111，插入**折線圖**
2. 按 **F9**（或修改任何一個儲存格，Google Sheets 會重新產生隨機數）
3. 每按一次，就是一個「平行宇宙」裡的同一個策略

**記錄 20 次的結果：**

| 次數 | 期末資金 | 實際勝率 | 總 R | 最大回撤 | 最長連虧 |
|---:|---:|---:|---:|---:|---:|
| 1 | | | | | |
| 2 | | | | | |
| … | | | | | |
| 20 | | | | | |

> 🔑 **一模一樣的策略、一模一樣的規則，20 次結果卻可能天差地遠。** 有幾次可能還會虧錢。這就是 3.9 說的：100 筆交易的樣本，仍然有很大的隨機性。

---

### 步驟 4（進階）：一次跑 20 條資金曲線（30 分鐘）

想在同一張圖上看 20 條曲線，可以這樣做：

1. 開一個新工作表「多次模擬」
2. A 欄是筆數 0～100
3. B 欄到 U 欄各是一次模擬（共 20 欄）。第 1 列（筆數 0）都填起始資金
4. B3 的公式（第 2 筆之後同理往下拉、往右拉）：
   ```
   =B2*(1+參數!$B$5*IF(RAND()<參數!$B$2,參數!$B$3,-參數!$B$4))
   ```
   （把「參數」換成你步驟 1 的工作表名稱）
5. 選取全部資料，插入折線圖

> 🎨 你會看到 20 條像義大利麵一樣散開的曲線。**大部分往上，但有幾條在底部掙扎。** 這就是「正期望值」的真實樣貌。

---

### 步驟 5：改變部位大小，觀察「破產」（30 分鐘）

把參數區的 **每筆風險（B5）** 依序改成 1%、2%、5%、10%、20%、30%，每種設定都按 F9 多次，觀察資金曲線。

**以下是用電腦模擬 2 萬次的參考結果**（勝率 40%、+2R / −1R、100 筆交易）：

| 每筆風險 | 期末資金中位數 | 最差 5% 的情況 | 最後虧錢的機率 | 最後虧超過一半的機率 | 最大回撤中位數 |
|---:|---:|---:|---:|---:|---:|
| 1% | 1.21 倍 | 0.95 倍 | 約 10% | 0% | 約 10% |
| 2% | 1.43 倍 | 0.89 倍 | 約 9% | 0% | 約 18% |
| 5% | 2.09 倍 | 0.65 倍 | 約 13% | 約 3% | 約 41% |
| 10% | 2.64 倍 | 0.26 倍 | 約 24% | 約 13% | 約 69% |
| 20% | **1.07 倍** | 0.01 倍 | **約 46%** | **約 38%** | **約 94%** |
| 30% | **0.07 倍** | 接近 0 | **約 77%** | **約 70%** | **接近 100%** |

（隨機模擬，你自己跑的數字會略有不同，但趨勢一樣。）

**觀察重點：**

1. **風險 1%～2%**：成長穩定，最大回撤可以忍受，幾乎不會大虧
2. **風險 5%～10%**：中位數變高，但**最大回撤非常深**（40%～70%），很少人受得了
3. **風險 20%**：中位數**反而下降**到只比本金多一點，而且將近一半的人虧錢
4. **風險 30%**：**一個正期望值的策略，大部分人最後虧光**

> 🤯 **同一個「長期會賺錢」的策略，只是每筆押得太大，就從賺錢機器變成破產機器。**
>
> 原因就是 3.2 的**回本不對稱**和 3.10 的**連虧**：部位太大時，一段正常的連虧就會把你打到很深的洞裡，後面的獲利再也爬不回來。
>
> 🔑 **期望值決定「這個遊戲值不值得玩」，部位大小決定「你能不能活著玩到最後」。** 這是 Phase 6 風險管理的核心，你現在已經親眼看到了。

---

### 步驟 6：反思（20 分鐘）

在學習日誌中回答：

1. 20 次模擬中，最好和最差的期末資金差了多少？
2. 有幾次在 100 筆交易後是**虧錢**的？如果你是那個「平行宇宙」的交易者，你會不會在第 50 筆就放棄這個策略？
3. 你觀察到的最長連虧是幾次？和 3.10 的表格吻合嗎？
4. 部位大小從 1% 增加到 30% 時，你的感受是什麼？
5. 如果你只看到其中一次模擬的結果（就像現實中你只會活一次），你能判斷這個策略好不好嗎？

## 🧩 把 Phase 3 串起來

| Phase 3 觀念 | 在模擬器中看到的 |
|---|---|
| 3.1 複利 | 資金以「當時資金」的比例計算，賺的錢會繼續滾 |
| 3.2 回本不對稱 | 大部位時，跌深之後很難爬回來 |
| 3.3 獨立事件 | 每一筆都是新的 `RAND()`，不受前一筆影響 |
| 3.4 期望值 | +0.2R：長期會賺，但不是每次都賺 |
| 3.5 勝率 vs. 賠率 | 勝率只有 40%，靠 2:1 的賠率賺錢 |
| 3.6 標準差 | 20 條曲線散開的程度 |
| 3.7 肥尾 | （這個簡單模型**沒有**肥尾——真實市場會更極端！） |
| 3.9 樣本數 | 100 筆交易，實際勝率可能從 30% 到 50% 不等 |
| 3.10 連虧 | 幾乎每次都會出現 5～8 次的連虧 |
| 3.11 運氣 vs. 實力 | 同樣的「實力」（策略），不同的「運氣」，結果天差地遠 |

> ⚠️ **這個模型比真實市場「友善」很多**：它假設勝率和賠率固定不變、每筆獨立、沒有跳空、沒有肥尾、沒有交易成本。**真實的波動和風險只會更大。**

---

## 📌 重點整理

1. **蒙地卡羅模擬**：用隨機數字模擬一個策略的各種可能結果。
2. 同一個正期望值策略，**100 筆交易的結果差異非常大**，甚至約 1 成會虧錢。
3. **部位太大會把正期望值變成破產**：每筆 20% 時近一半的人虧錢、30% 時大部分人虧光。
4. **期望值決定值不值得玩，部位大小決定能不能活到最後。**
5. 真實市場比模型更殘酷（肥尾、成本、條件改變）。

## 🗣️ 一分鐘講給朋友聽（示範稿）

> 「我做了一個擲硬幣交易的試算表實驗：一個勝率 40%、賺 2 賠 1 的策略，算起來每筆平均賺 0.2 倍風險，是會賺錢的策略。我讓它跑 100 筆交易，重複 20 次，結果每次都不一樣，最好的翻了一倍多，最差的還虧錢。
>
> 更可怕的是，我把每筆押的比例調大，押 1% 的時候穩穩成長；押到 20%，將近一半的人最後是虧錢的；押到 30%，大部分人都虧光了。同一個會賺錢的策略，只是押太大，就變成破產機器。
>
> 所以結論是：策略有沒有優勢決定值不值得做，但每次押多少，決定你能不能活著等到賺錢的那一天。」
