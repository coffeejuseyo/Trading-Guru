## 📖 開場故事：飛行員的檢查清單

每一架飛機起飛前，不管機長飛了 20 年還是 2 年，都要拿出**檢查清單**，一項一項確認：燃油、襟翼、儀表、通訊……

有人會問：「經驗這麼豐富的機長，還需要清單嗎？」

答案是：**正因為經驗豐富，才更容易因為「習慣了」而漏掉某一項。** 而在高壓、緊急的情況下，人的大腦更容易出錯。

外科醫師阿圖・葛文德（Atul Gawande）在《清單革命》一書中，描述了檢查清單如何幫助醫療團隊減少手術中的疏失。

> ✈️ **交易也是高壓、需要快速決策的環境。** 例行程序和檢查清單，讓你在情緒升高的時候，還能照著步驟做對的事。

## 🧠 正文

### 1. 為什麼需要例行程序？

| 沒有例行程序 | 有例行程序 |
|---|---|
| 每次都臨時決定要看什麼、做什麼 | 固定步驟，減少決策疲勞 |
| 情緒來的時候，容易亂做（7.1） | 步驟引導你回到規則 |
| 容易漏掉重要的事（例如財報日期） | 檢查清單確保不遺漏 |
| 交易時間沒有邊界，一直盯盤 | 固定時間開始、固定時間結束 |

> 🔑 **例行程序把「好的交易行為」從需要意志力的事，變成習慣。** 回想 7.1：不靠意志力，靠流程和環境。

### 2. 四段例行程序

#### ① 盤前（交易前）

| 步驟 | 內容 | 回想 |
|---|---|---|
| **狀態檢查** | 今天睡得好嗎？情緒分數幾分？有沒有 HALT？（見第 4 節） | 7.1 |
| **事件檢查** | 今天 / 這幾天有沒有重大經濟數據、持股財報、除權息？ | 5.10 |
| **市場環境** | 大盤趨勢？夜盤 / 美股昨晚表現？波動度（ATR、VIX）是否異常？ | 1.10、4.4 |
| **持倉檢查** | 每一筆持倉的停損單是否都還有效？是否需要更新移動停損？ | 2.2、6.3 |
| **風險檢查** | 目前總風險多少？離每日 / 每月上限還有多少空間？回撤狀態？ | 6.6、6.8 |
| **觀察名單** | 哪些股票接近我的進場條件？預先算好部位大小 | 5.11、6.4 |

#### ② 盤中（交易時）

| 原則 | 內容 |
|---|---|
| **只執行計畫** | 只交易盤前已經規劃好的設定；臨時看到的機會，放進觀察名單，明天再評估 |
| **下單前檢查清單** | 每一筆都跑一遍（見第 3 節） |
| **限制看盤時間** | 日線交易者不需要一直盯盤；設好單就離開 |
| **情緒溫度計** | 4 分以上不下單；觸發報復性交易警訊時執行緊急煞車 SOP（7.4） |
| **遵守虧損上限** | 達到每日上限就關掉軟體（6.6） |

#### ③ 盤後（交易後）

| 步驟 | 內容 | 回想 |
|---|---|---|
| **記錄** | 填寫今天每一筆交易的日誌（R、是否遵守規則、情緒） | 7.6 |
| **更新** | 更新持倉的停損、移動停損 | 6.3 |
| **掃描** | 用策略規則掃描明天可能的機會，更新觀察名單 | Phase 8 |
| **收工** | 關掉軟體，結束今天的交易時間 | |

#### ④ 每週（週末）

| 步驟 | 內容 | 回想 |
|---|---|---|
| **每週檢討** | 數字、最好 / 最差交易、錯誤成本、下週改進一件事 | 7.6 |
| **下週行事曆** | 經濟數據、央行會議、財報、長假 | 5.10 |
| **規則檢查** | 是否需要修改規則？（只在週末、冷靜時、有資料依據時） | 6.10 |
| **學習** | 讀一章書、看一份研究，持續學習 | |

### 3. 下單前檢查清單（整合版）

這是 2.8 檢查清單的完整升級版，整合了 Phase 4～7 的內容：

```markdown
## ✈️ 下單前檢查清單

### 狀態
- [ ] 情緒分數 ≤ 3？
- [ ] 不是在停損後的冷靜期內？
- [ ] 今天還沒達到每日虧損上限？

### 訊號
- [ ] 這筆交易符合我的策略規則嗎？（不是 FOMO、不是無聊）
- [ ] 大週期 / 環境支持這個方向嗎？（4.3、4.12）
- [ ] 近期有沒有重大事件？（5.10）

### 風險
- [ ] 停損價已決定，位置有邏輯（哪裡代表我錯了）？（6.2）
- [ ] 部位用計算器算過，已無條件捨去？（6.4）
- [ ] 加入這筆後，總風險與群組風險仍在上限內？（6.8）
- [ ] 出場規則已決定（目標或移動停損）？（6.3）

### 反方
- [ ] 事前驗屍：如果這筆大虧，最可能的原因是？（7.3）

### 執行
- [ ] 商品代號、方向、價格、數量都正確？（2.8）
- [ ] 成交後立刻掛停損單
- [ ] 記錄到交易日誌
```

### 4. 照顧「交易的身體」：HALT 原則

心理健康領域常用一個縮寫 **HALT**，提醒自己在以下狀態時**不要做重要決定**：

| 字母 | 狀態 | 交易中的影響 |
|---|---|---|
| **H**ungry | 飢餓 | 血糖低時容易煩躁、衝動 |
| **A**ngry | 生氣 | 報復性交易的溫床（7.4） |
| **L**onely | 孤單 / 情緒低落 | 判斷力下降、想用交易填補情緒 |
| **T**ired | 疲累 | 決策品質大幅下降、容易犯低級錯誤（胖手指） |

> 🔑 **如果你處於 HALT 的任何一種狀態，今天就不要新進場。** 已經掛好的停損單會保護你的持倉，你不需要做任何事。

**其他照顧自己的方式：**
- **睡眠**：不要為了看美股熬夜到天亮（1.10）
- **運動**：降低壓力、提高專注力
- **交易以外的生活**：交易不是你的全部；把它當作一份需要紀律的工作，而不是情緒的出口

### 5. 環境設計

| 讓好行為變容易 | 讓壞行為變困難 |
|---|---|
| 檢查清單貼在螢幕旁邊 | 刪掉手機上的看盤 App（或關閉推播） |
| 部位計算器設成瀏覽器首頁 | 退出喊單群組、FOMO 來源（7.4） |
| 《個人風險規則》印出來放在桌上 | 不開信用帳戶、期貨帳戶（2.7） |
| 固定的交易時段寫進行事曆 | 隱藏 App 上的即時損益欄位（7.2） |
| 停損單用條件單自動執行 | 交易時段以外不登入券商 App |

> 🍰 回到 7.1 的比喻：**不在家裡放蛋糕。**

### 6. 範例：上班族的日線交易例行程序

| 時間 | 做什麼 | 時長 |
|---|---|---|
| **平日早上（出門前）** | 看一眼：昨晚美股、夜盤；確認持倉停損單都有效 | 5 分鐘 |
| **平日上班時間** | **不看盤**。停損單、條件單會自動執行 | 0 分鐘 |
| **平日晚上（收盤後）** | 盤後例行程序：記錄、更新移動停損、掃描觀察名單、為明天掛好進場條件單 | 20～30 分鐘 |
| **週日** | 每週例行程序：檢討、行事曆、規則檢查 | 30～60 分鐘 |

> 🔑 **日線交易者每天只需要 30 分鐘左右。** 不需要辭職、不需要盯盤，也能做系統化的交易。這也是本課程以日線為主的原因（4.3）。

## 📌 重點整理

1. 例行程序與檢查清單把好的行為變成**習慣**，在情緒升高時引導你做對的事。
2. 四段例行程序：**盤前（狀態、事件、環境、持倉、風險、觀察名單）→ 盤中（只執行計畫）→ 盤後（記錄、更新、掃描、收工）→ 每週（檢討、行事曆、規則、學習）**。
3. **下單前檢查清單**整合狀態、訊號、風險、反方、執行五大區塊。
4. **HALT**：飢餓、生氣、孤單、疲累時不做重要決定。
5. **環境設計**：讓好行為變容易，壞行為變困難。
6. 上班族的日線交易，**每天約 30 分鐘**就夠。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「有經驗就不需要檢查清單」 | 經驗豐富反而容易因習慣而漏掉步驟；飛行員與醫療團隊都在用清單。 |
| 「要賺錢就要一直盯盤」 | 日線交易者每天約 30 分鐘就夠，一直盯盤反而增加衝動交易。 |
| 「累的時候也可以照規則交易」 | 疲累會大幅降低決策品質；HALT 時不新進場。 |
| 「例行程序很死板」 | 它減少的是決策疲勞與錯誤，讓你把精力留給真正重要的判斷。 |

## 🛠️ 練習（約 45 分鐘）

**練習 1：設計你的例行程序**
根據你的作息（0.5、4.3），寫下你自己的盤前、盤中、盤後、每週例行程序，包含**具體時間**與**時長**。

**練習 2：客製化檢查清單**
把第 3 節的下單前檢查清單，加上你在 7.3 找出的「3 大偏誤」對應的檢查項目，印出來或存成手機桌面。

**練習 3：環境設計**
從第 5 節的表格中，選 3 項**本週就做**的環境調整，做完後打勾。

**練習 4：執行一週**
接下來一週，每天照你的例行程序執行，並在學習日誌記錄：哪些步驟做到了？哪些常常忘記？

## ✅ 自我測驗

**Q1. 為什麼經驗豐富的人也需要檢查清單？**

<details><summary>看答案</summary>

因為經驗豐富容易因為習慣而跳過步驟，而在高壓、緊急、情緒升高的情況下大腦更容易出錯。檢查清單確保重要步驟不被遺漏，減少低級錯誤。

</details>

**Q2. HALT 代表什麼？為什麼對交易重要？**

<details><summary>看答案</summary>

Hungry（飢餓）、Angry（生氣）、Lonely（孤單）、Tired（疲累）。在這些狀態下，人的決策品質會下降、情緒更容易失控（例如報復性交易、胖手指），所以處於 HALT 狀態時不應新進場。

</details>

**Q3. 為什麼日線交易者不需要一直盯盤？**

<details><summary>看答案</summary>

因為日線策略的訊號以收盤價為主，可以在收盤後分析並事先掛好進場與停損條件單；盤中自動執行即可。一直盯盤反而增加衝動交易、FOMO 與報復性交易的機會。

</details>
