# Phase 7｜管好自己：交易心理

> **預計時數：15 小時**（7 個單元）
> **生活比喻：大家都知道「少吃多動」就會瘦，但減肥最難的從來不是知識，而是執行。**

你已經有了：市場知識（Phase 1～2）、統計眼光（Phase 3）、看圖與看財報的能力（Phase 4～5），以及一份《個人風險規則》（Phase 6）。

但所有交易者都會遇到同一個問題：

> **「我明明知道要停損，為什麼就是下不了手？」**
> **「我明明知道不該追高，為什麼又追了？」**
> **「我明明寫好了規則，為什麼虧了三筆就全忘了？」**

答案是：**你的大腦，天生就不是為交易而設計的。** 它是為了在草原上躲避獅子、搶奪食物而演化的。在市場上，那些曾經救命的本能，常常會讓你做出完全錯誤的決定。

> 🔑 **這個階段的目標不是讓你「沒有情緒」——那不可能。** 目標是：
> 1. **認識**大腦會怎麼騙你
> 2. **預先**建立規則與流程，在情緒出現時保護你
> 3. **記錄**與**檢討**，讓自己一次比一次進步

## 心理問題 → 對策地圖

```
【大腦的陷阱】                         【對策：規則與流程】
恐懼：不敢進場、太早停利（7.1）    ──▶  事先寫好的進出場規則（Phase 6、8）
貪婪：部位太大、不停利（7.1）      ──▶  固定比例風險、部位計算器（6.4）
損失趨避：不停損、凹單（7.2）      ──▶  進場前設停損、停損只往有利方向移（6.2）
處分效應：賺小賠大（7.2）          ──▶  移動停損、R 倍數思考（6.3）
確認偏誤：只看支持自己的（7.3）    ──▶  交易前寫下「我錯的條件」（7.7）
過度自信：有把握就押大（7.3）      ──▶  每筆風險固定（6.4）
FOMO、報復性交易（7.4）           ──▶  每日虧損上限、冷靜期規則（6.6、6.10）
結果導向：用輸贏判斷對錯（7.5）    ──▶  機率思維、看長期統計（3.4、3.9）
重複犯錯（7.6）                   ──▶  交易日誌、規則遵守率、每週檢討
臨場慌亂（7.7）                   ──▶  盤前 / 盤中 / 盤後例行程序、檢查清單
```
