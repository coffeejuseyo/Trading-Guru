## 📖 開場故事：運動員看比賽錄影

職業籃球員打完比賽後，不會直接回家睡覺。他們會和教練一起**看比賽錄影**：

- 「這一球為什麼沒防到？」——是**體力不夠**，還是**站錯位置**？
- 「這一球投進了，但出手姿勢其實是錯的」——**運氣好**，下次不一定進
- 「第四節我們連續失誤 5 次」——是不是**累了**？下次要提早換人

他們不是只看比分，而是看**每一個動作背後的原因**，然後在下次練習時改進。

> 🎥 **交易日誌就是你的比賽錄影。** 沒有記錄的交易者，就像從來不看錄影的球員——同樣的錯誤會犯一百次（0.2）。

## 🧠 正文

### 1. 交易日誌要記錄什麼？

回顧 [templates/trading-journal.md](../../templates/trading-journal.md)，每一筆交易至少記錄：

| 類別 | 欄位 | 為什麼重要 |
|---|---|---|
| **基本資料** | 日期、商品、方向、策略 | 之後可以分類統計 |
| **計畫** | 進場理由、進場價、停損價、目標 / 出場規則、部位大小、風險金額（1R） | 檢查「有沒有計畫」 |
| **結果** | 出場價、出場原因、損益（元與 **R**） | 統計績效 |
| **執行** | **是否完全遵守規則？哪裡沒遵守？** | 最重要的欄位（6.10 的規則遵守率） |
| **心理** | 進場前情緒分數（1～5）、持倉中情緒 | 找出情緒與結果的關係（7.1） |
| **反思** | 截圖、學到了什麼 | 未來回顧時的線索 |

> 🔑 **最重要的兩個欄位是「R 倍數」和「是否遵守規則」。** R 讓你用統一的尺評估每筆交易（3.4），規則遵守讓你分辨「策略的問題」和「自己的問題」。

### 2. 升級成試算表

文字日誌適合寫反思，但**統計**要用試算表。建議在 Google Sheets 建立以下欄位：

| 日期 | 商品 | 策略 | 方向 | 進場 | 停損 | 出場 | 股數 | 1R（元） | 損益（元） | **R** | **遵守規則（Y/N）** | 違反哪條 | 情緒（1-5） | 備註 |
|---|---|---|---|---:|---:|---:|---:|---:|---:|---:|---|---|---:|---|

**R 的公式**：`=損益 / 1R`

**自動統計區：**

| 指標 | 公式（假設 R 在 K 欄、遵守規則在 L 欄） |
|---|---|
| 交易筆數 | `=COUNTA(K2:K)` |
| 勝率 | `=COUNTIF(K2:K,">0")/COUNTA(K2:K)` |
| 平均獲利（R） | `=AVERAGEIF(K2:K,">0")` |
| 平均虧損（R） | `=AVERAGEIF(K2:K,"<0")` |
| **期望值（R / 筆）** | `=AVERAGE(K2:K)` |
| 總 R | `=SUM(K2:K)` |
| **規則遵守率** | `=COUNTIF(L2:L,"Y")/COUNTA(L2:L)` |
| 遵守規則的交易平均 R | `=AVERAGEIF(L2:L,"Y",K2:K)` |
| **違反規則的交易平均 R** | `=AVERAGEIF(L2:L,"N",K2:K)` |

> 💡 最後兩行特別有啟發性：很多交易者會發現，**違反規則的交易，平均 R 明顯比較差**。這是讓自己願意遵守規則最有力的證據。

### 3. ⭐ 錯誤分類：正常虧損 vs. 執行錯誤

不是所有虧損都是「錯誤」。檢討時，把每一筆虧損分成兩類：

| | 正常虧損 | 執行錯誤 |
|---|---|---|
| 定義 | 照規則做，但結果虧錢 | 沒照規則做 |
| 例子 | 符合訊號進場、停損被觸發 | 沒設停損、追高、部位太大、提早出場、跳過訊號 |
| 來源 | 機率（7.5） | 情緒、偏誤（7.1～7.4） |
| 該怎麼做 | **什麼都不用改**，這是營業成本 | **找出原因，建立防範規則** |

> 🔑 **只有「執行錯誤」需要改正。** 如果你因為正常虧損而去改規則，就是近因偏誤（7.3）。

**常見執行錯誤清單**（建議在日誌中用代號標記）：

| 代號 | 錯誤 |
|---|---|
| E1 | 沒有訊號就進場（FOMO、無聊） |
| E2 | 沒設停損 / 停損往不利方向移 |
| E3 | 部位大於計算結果 |
| E4 | 太早停利（沒照移動停損） |
| E5 | 跳過符合規則的訊號（恐懼） |
| E6 | 停損後報復性交易 |
| E7 | 超過每日 / 每月虧損上限仍交易 |
| E8 | 重大事件前未依規則減碼 |

### 4. 錯誤成本：違反規則讓你損失多少？

**錯誤成本 = 實際結果的 R − 如果照規則做的 R**（負數代表違反規則讓你少賺或多虧）

**例子：**

| 交易 | 照規則應該 | 實際上 | 錯誤 | 錯誤成本 |
|---|---|---|---|---:|
| #12 | 停損 −1R | 停損往下移，最後 −2.5R | E2 | **−1.5R** |
| #15 | 移動停損出場 +3R | 怕獲利飛走，+0.8R 就賣 | E4 | **−2.2R** |
| #18 | 不進場（無訊號） | FOMO 追高，−1R | E1 | **−1R** |
| #19 | 不進場（已達單日上限） | 報復性交易，−1.5R | E6、E7 | **−1.5R** |

**這個月的錯誤總成本：−6.2R**

> 😱 如果你每筆風險 1 萬元，這個月光是「**不照自己的規則做**」就讓你少賺（或多虧）了 **6.2 萬元**。
>
> 🔑 **錯誤成本常常比策略本身的虧損還大。** 把它算出來，你就會很清楚：改善紀律，可能是提高績效最快的方法。

### 5. 檢討的節奏

| 頻率 | 花多久 | 做什麼 |
|---|---|---|
| **每筆交易後** | 3～5 分鐘 | 填寫日誌（趁記憶還新鮮） |
| **每天收盤後** | 10 分鐘 | 檢查當天的交易是否都照規則；記錄情緒 |
| **每週日** | 30 分鐘 | 每週檢討（見下方範本） |
| **每月 / 每 20 筆** | 1 小時 | 統計檢討：和回測預期比較（7.5 的「一組 20 筆」） |

**每週檢討範本：**

```markdown
## 第 __ 週檢討

### 數字
- 交易筆數：__　勝率：__%　總 R：__　平均 R：__
- 規則遵守率：__%
- 錯誤成本：__R（錯誤代號：__）

### 最好的一筆交易（過程最好，不一定賺最多）
- 為什麼好？

### 最差的一筆交易（過程最差）
- 犯了什麼錯？當時的情緒分數？
- 根本原因是什麼？（不是「我太笨」，而是「什麼情況讓我犯錯」）

### 我的模式
- 這週出現了哪個偏誤？（7.3 的 3 大偏誤有出現嗎？）

### 下週只改進一件事
- ____
```

> 💡 **每週只改進一件事。** 想一次改掉所有問題，通常一個也改不了。

### 6. 從日誌中找出你的模式

累積 30～50 筆以上的交易後，用試算表的篩選或樞紐分析，回答：

| 問題 | 可能的發現 |
|---|---|
| **情緒分數 vs. R**：情緒 4～5 分時的平均 R 是多少？ | 「我在情緒高的時候，平均虧 0.8R」→ 加強情緒溫度計規則 |
| **哪個策略 / 設定表現最好？** | 「回檔到支撐的交易比突破的好很多」→ 專注在強項 |
| **星期幾 / 什麼時段表現最差？** | 「我週一開盤的交易特別差」→ 週一開盤前 30 分鐘不交易 |
| **連賺之後的下一筆表現如何？** | 「連賺 3 筆後，下一筆常常部位過大」→ 過度自信規則 |
| **最常犯的錯誤代號是哪個？** | 「E4 最多」→ 優先處理太早停利的問題 |

> 🔑 **你的交易日誌，就是一份專門研究「你自己」的資料庫。** 4.13 那種統計檢驗的思維，也可以用來研究你自己的行為。

---

## 📌 重點整理

1. 交易日誌 = 比賽錄影；最重要的欄位是 **R 倍數**與**是否遵守規則**。
2. 用**試算表**自動計算勝率、平均 R、期望值、**規則遵守率**。
3. 錯誤分類：**正常虧損**（不用改）vs. **執行錯誤**（要改），用代號標記。
4. **錯誤成本**常常比策略本身的虧損還大。
5. 檢討節奏：**每筆、每天、每週、每月（每 20 筆）**；每週只改進一件事。
6. 累積樣本後，從日誌找出**你自己的模式**。

> 「交易日誌就像運動員的比賽錄影。我每筆交易都會記錄進場理由、停損、結果，最重要的是兩件事：這筆是幾 R，還有我有沒有照規則做。
>
> 檢討的時候，我會把虧損分成兩種：照規則做但虧錢的，那是正常的營業成本，不用改；沒照規則做的，才是真正的錯誤。我還會算『錯誤成本』，就是如果照規則做會怎樣、實際上差了多少。很多時候，光是不照自己的規則，一個月就少賺了好幾 R。
>
> 每週日我花半小時檢討，但每週只改一件事。累積夠多筆之後，還能發現自己的模式，例如情緒高的時候特別容易虧。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「記帳就好，日誌太麻煩」 | 只記損益看不出原因；日誌要記錄計畫、執行、情緒。 |
| 「每一筆虧損都要檢討改進」 | 照規則的正常虧損不需要改；只有執行錯誤需要。 |
| 「賺錢的交易不用檢討」 | 違反規則的獲利也要檢討，它會強化壞習慣。 |
| 「一次改掉所有缺點」 | 每週只改一件事，比較容易真正改變。 |

## ✅ 自我測驗

**Q1. 交易日誌中最重要的兩個欄位是什麼？為什麼？**

<details><summary>看答案</summary>

R 倍數與是否遵守規則。R 倍數讓每筆交易用統一的尺度衡量；是否遵守規則讓你分辨結果是來自策略本身（機率）還是來自執行錯誤（情緒與偏誤）。

</details>

**Q2. 正常虧損和執行錯誤有什麼不同？各該怎麼處理？**

<details><summary>看答案</summary>

正常虧損是照規則執行但結果虧錢，屬於機率分佈的一部分，不需要修改規則；執行錯誤是沒有照規則做（如沒設停損、追高、部位過大），需要找出原因並建立防範規則。

</details>

**Q3. 什麼是錯誤成本？為什麼要計算它？**

<details><summary>看答案</summary>

錯誤成本 = 實際結果 − 照規則執行的結果（以 R 計，負數代表損失）。計算它可以清楚看到違反規則對績效造成的實際損失，通常比策略本身的虧損還大，能強化遵守規則的動機，並指出最需要改善的地方。

</details>

**Q4. 練習 2 參考答案**

<details><summary>看答案</summary>

1. 實際 −3R − 規則 −1R → 錯誤成本 **−2R**
2. 實際 +1R − 規則 +2.5R → 錯誤成本 **−1.5R**
3. 實際 +1.5R − 規則 0R（不應進場）→ 帳面上 **+1.5R**，但這是**壞的獲利**（違反規則，7.5），仍要記錄為執行錯誤 E1
4. 實際 0R − 規則 +2R → 錯誤成本 **−2R**（跳過訊號 E5）

第 3 筆提醒我們：錯誤成本有時是正的，但違反規則就是違反規則，長期來看會傷害你。

</details>
