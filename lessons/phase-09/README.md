# Phase 9｜給電腦下指令：Python 與資料處理

> **預計時數：60 小時**（14 個單元）
> **生活比喻：教一個超聽話但完全不會變通的機器人照著食譜做菜——你要把每個步驟寫得一清二楚。**

Phase 8 你寫了 3 份策略規格書，也用眼睛目測了 90 筆交易。你應該已經發現：

- 手動記錄**很慢**：30 筆就花了好幾個小時
- 手動記錄**容易出錯**：看錯一根 K 棒、算錯一個 ATR
- 手動記錄**樣本太少**：30 筆很難判斷策略好壞（3.9 大數法則）

這個階段要學會**用 Python 叫電腦幫你做這些事**。電腦就像一個超聽話、速度超快、但**完全不會變通**的機器人：你寫清楚，它幾秒鐘就能算完十年的資料；你寫錯一個字，它就停下來抱怨。這正好和 8.13 的規格書精神一樣——**規則要明確到機器人都能照做**。

> 🔑 **零程式基礎也可以學會。** 本階段的目標不是成為軟體工程師，而是學會「足以做回測」的 Python：讀資料、算報酬、算指標、畫圖。每個單元都附上**可以直接複製執行**的程式碼。

## 練習資料

本階段大部分範例使用 [`data/sample_prices.csv`](data/sample_prices.csv)：一份**模擬產生**的日線資料（2021–2023 年、780 個交易日，欄位：Date、Open、High、Low、Close、Volume）。

> ⚠️ 這是用亂數產生的**假資料**，只用來練習程式，**不代表任何真實商品**，也沒有扣除台灣的國定假日。用假資料的好處是：不需要網路、每個人的結果都一樣，方便對照講義上的輸出。9.10 之後會教你下載真實資料。
