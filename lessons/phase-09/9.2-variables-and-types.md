## 📖 開場故事：貼了標籤的收納盒

搬家時，你把東西裝進一個個紙箱，並在每個箱子上**貼標籤**：「廚房用品」、「冬天衣服」、「書」。

- 要找東西時，看標籤就知道在哪個箱子
- 箱子裡的東西可以換：把冬天衣服拿出來，放夏天衣服進去，標籤也跟著改
- 不同的箱子裝不同**種類**的東西：易碎品、衣服、書，處理方式不一樣

> 📦 **變數就是貼了標籤的收納盒**：標籤是變數名稱（例如 `capital`），箱子裡裝的是值（例如 `1000000`）。值的**種類**（數字、文字……）就叫做**資料型別**，不同型別能做的事情不一樣——你不能把「書」和「3」加在一起。

## 🧠 正文

### 1. 變數：把值裝進盒子

```python
capital = 1000000      # 總資金
risk_pct = 0.01        # 每筆風險 1%
symbol = "0050"        # 股票代號
print(capital)
print(symbol)
```

| 部分 | 意思 |
|---|---|
| `capital` | 變數名稱（標籤） |
| `=` | **指派**：把右邊的值裝進左邊的盒子（不是數學的「等於」） |
| `1000000` | 值 |
| `#` 後面 | **註解**：寫給人看的說明，電腦會忽略 |

**變數可以重新指派：**

```python
price = 50
price = price * 1.1    # 先算右邊（50 × 1.1），再把結果裝回 price
print(price)
```

> 💡 `price = price * 1.1` 在數學上不成立，但在程式中的意思是：「把 price 盒子裡的值拿出來乘以 1.1，再放回 price 盒子」。
>
> 執行後你會看到 `55.00000000000001` 而不是 `55.0`——這不是你寫錯，是浮點數的小誤差，第 4 節會解釋。

**命名規則：**

| 規則 | ✅ 可以 | ❌ 不行 |
|---|---|---|
| 英文字母、數字、底線 | `close_price`、`ma20` | `close-price`（有減號） |
| 不能用數字開頭 | `ma20` | `20ma` |
| 大小寫不同 | `Close` 和 `close` 是**兩個不同的變數** | |
| 不要用 Python 保留字 | `my_list` | `list`、`print`、`if` |

> 🔑 **取有意義的名字**：`stop_price` 比 `x` 好懂一百倍。三個月後回來看程式的你，會感謝現在的你。

### 2. ⭐ 四種基本資料型別

| 型別 | 名稱 | 例子 | 收納盒比喻 |
|---|---|---|---|
| `int` | 整數 | `1000`、`-5`、`0` | 數量（幾張股票） |
| `float` | 浮點數（小數） | `52.3`、`0.01`、`-2.5` | 價格、比例 |
| `str` | 字串（文字） | `"0050"`、`"台積電"` | 名字、代號 |
| `bool` | 布林值 | `True`、`False` | 是 / 否（有沒有訊號） |

```python
shares = 1000
price = 52.3
name = "元大台灣50"
has_signal = True

print(type(shares))
print(type(price))
print(type(name))
print(type(has_signal))
```

輸出：

```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

> ⚠️ **股票代號要用字串**：`"0050"` 是字串；如果寫成數字 `0050`，Python 會出錯（數字不能以 0 開頭），寫成 `50` 又會遺失前面的 0。

**型別轉換：**

```python
print(int("1000") + 1)       # 字串轉整數
print(float("52.3") * 2)     # 字串轉浮點數
print("代號：" + str(50))     # 數字轉字串
print(int(4123.9))           # 浮點數轉整數：直接捨去小數（不是四捨五入）
```

### 3. ⭐ 算術運算

| 運算子 | 意思 | 例子 | 結果 |
|---|---|---|---|
| `+` | 加 | `10 + 3` | `13` |
| `-` | 減 | `10 - 3` | `7` |
| `*` | 乘 | `10 * 3` | `30` |
| `/` | 除（結果一定是浮點數） | `10 / 4` | `2.5` |
| `//` | 整數除法（無條件捨去） | `17 // 5` | `3` |
| `%` | 餘數 | `17 % 5` | `2` |
| `**` | 次方 | `1.07 ** 30` | `7.6122...` |

**交易中的用法：**

```python
# 1. 複利：100 萬以年報酬 7% 成長 30 年（回想 3.1）
print(1000000 * 1.07 ** 30)

# 2. 用零股算出 4,321 股，換算成幾張整股、剩幾股零股
shares = 4321
print(shares // 1000, "張")
print(shares % 1000, "股零股")

# 3. 報酬率
buy = 50
sell = 56
print((sell - buy) / buy)
```

> 💡 運算順序和數學一樣：**次方 → 乘除 → 加減**，括號優先。不確定時就加括號，`(sell - buy) / buy` 和 `sell - buy / buy` 的結果差很多。

### 4. ⚠️ 浮點數的小誤差

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(round(0.1 + 0.2, 2))
```

輸出：

```
0.30000000000000004
False
0.3
```

電腦用二進位儲存小數，有些小數（例如 0.1）沒辦法精確表示，就像 1/3 寫成小數是 0.3333……永遠寫不完。

> 🔑 **實務原則**：
> - 顯示結果時用 `round()` 或 f-string 控制小數位數
> - **不要用 `==` 比較兩個小數是否相等**；改成比較「差距是否夠小」，例如 `abs(a - b) < 0.000001`
> - 這種誤差非常小，對回測績效幾乎沒有影響，但會讓「價格剛好等於停損價」這種判斷出錯

### 5. ⭐ f-string：漂亮地印出結果

在字串前面加 `f`，就可以用 `{}` 把變數放進文字裡，還能控制格式：

```python
capital = 1234567.891
ret = 0.0532

print(f"總資金：{capital}")
print(f"總資金：{capital:,.0f} 元")      # 千分位、不要小數
print(f"總資金：{capital:,.2f} 元")      # 千分位、2 位小數
print(f"報酬率：{ret:.2%}")              # 百分比、2 位小數
```

輸出：

```
總資金：1234567.891
總資金：1,234,568 元
總資金：1,234,567.89 元
報酬率：5.32%
```

| 格式 | 意思 |
|---|---|
| `:.2f` | 2 位小數 |
| `:,.0f` | 千分位、0 位小數 |
| `:.1%` | 乘以 100 並加上 %，1 位小數 |

### 6. ⭐ 實作：部位大小計算機

回想 6.4：**股數 = 總資金 × 每筆風險 % ÷（進場價 − 停損價）**

```python
# ===== 輸入 =====
capital = 1_000_000    # 總資金（底線只是方便閱讀，等於 1000000）
risk_pct = 0.01        # 每筆風險 1%
entry = 52.3           # 進場價
stop = 49.8            # 停損價
fee_rate = 0.001425    # 手續費率

# ===== 計算 =====
risk_per_share = entry - stop
risk_amount = capital * risk_pct
shares = int(risk_amount / risk_per_share)   # 無條件捨去
position_value = shares * entry
buy_fee = int(position_value * fee_rate)     # 手續費（簡化：無條件捨去、未計折扣與最低收費）

# ===== 輸出 =====
print(f"每股風險：{risk_per_share:.2f} 元")
print(f"可承受虧損：{risk_amount:,.0f} 元")
print(f"可買股數：{shares:,} 股（{shares / 1000:.1f} 張）")
print(f"部位金額：{position_value:,.0f} 元（佔總資金 {position_value / capital:.1%}）")
print(f"買進手續費：{buy_fee} 元")
```

輸出：

```
每股風險：2.50 元
可承受虧損：10,000 元
可買股數：4,000 股（4.0 張）
部位金額：209,200 元（佔總資金 20.9%）
買進手續費：298 元
```

> 🤖 這就是機器人的威力：下次換一檔股票，**只要改上面「輸入」區的數字**，重新執行，答案就出來了。

## 📌 重點整理

1. **變數** = 貼了標籤的收納盒；`=` 是「把右邊的值裝進左邊」。
2. 四種型別：**int（整數）、float（小數）、str（文字）、bool（是/否）**；股票代號用字串。
3. 運算：`+ - * /`，加上 `//`（整除）、`%`（餘數）、`**`（次方）。
4. **浮點數有微小誤差**：顯示時四捨五入，比較小數不要用 `==`。
5. **f-string** 控制格式：`:,.0f`（千分位）、`:.2%`（百分比）。
6. 把輸入、計算、輸出分開寫，改輸入就能重複使用。

> 「變數就像搬家時貼了標籤的紙箱，標籤是名字，箱子裡放的是值。例如我寫 capital = 1000000，就是把一百萬放進一個叫 capital 的箱子。
>
> 箱子裡的東西有不同種類：整數、小數、文字、是或否。不同種類不能亂混，像文字『價格』加上數字 100，電腦就會抱怨。
>
> 有個小陷阱：電腦算小數會有一點點誤差，0.1 加 0.2 會變成 0.30000000000000004，所以比較兩個小數的時候不要直接用等號。我用這些基本功寫了一個部位大小計算機，換股票只要改進場價和停損價，答案馬上出來。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「`=` 是等於的意思」 | `=` 是指派（裝進盒子）；判斷是否相等要用 `==`（9.3）。 |
| 「`int(4.9)` 會得到 5」 | `int()` 是直接捨去小數，得到 4；四捨五入要用 `round()`。 |
| 「電腦算小數一定精確」 | 浮點數有微小誤差；顯示時四捨五入，比較時要容許誤差。 |
| 「股票代號可以存成數字」 | `0050` 前面的 0 會遺失，應該用字串 `"0050"`。 |

## ✅ 自我測驗

**Q1. `price = price * 1.1` 是什麼意思？**

<details><summary>看答案</summary>

先計算右邊：把 price 目前的值乘以 1.1；再把結果指派回 price 這個變數。`=` 在程式中是「指派」，不是數學上的「等於」。

</details>

**Q2. 為什麼 `0.1 + 0.2 == 0.3` 的結果是 False？實務上怎麼處理？**

<details><summary>看答案</summary>

電腦以二進位儲存小數，0.1、0.2 無法被精確表示，相加後得到 0.30000000000000004，和 0.3 有極小差距。實務上顯示時用 round() 或 f-string 控制位數；比較兩個小數時改用「差距是否小於一個很小的數」，例如 `abs(a - b) < 1e-9`。

</details>
