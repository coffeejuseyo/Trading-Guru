import pandas as pd
import numpy as np

df = pd.read_csv("sample_prices.csv", parse_dates=["Date"], index_col="Date")

### 1. SMA 與 EMA（回想 4.7、9.9）

```python
def sma(series, n):
    """簡單移動平均。"""
    return series.rolling(n).mean()

def ema(series, n):
    """指數移動平均（與多數看盤軟體相同的遞迴算法）。"""
    return series.ewm(span=n, adjust=False).mean()

df["SMA20"] = sma(df["Close"], 20)
df["EMA20"] = ema(df["Close"], 20)
```

### 2. ⭐ RSI（回想 4.8）

**步驟：**
1. 每日漲跌 = 今天收盤 − 昨天收盤
2. 漲的部分（跌的日子記 0）、跌的部分（取正值，漲的日子記 0）
3. 用 **Wilder 平滑法** 算「平均漲幅」和「平均跌幅」
4. RS = 平均漲幅 ÷ 平均跌幅；**RSI = 100 − 100 ÷（1 + RS）**

**Wilder 平滑法**：今天的平均 = 昨天的平均 × (n−1)/n + 今天的值 × 1/n。它就是 `ewm(alpha=1/n)` 的一種指數平均，TradingView 中稱為 RMA。

```python
def rsi(close, n=14):
    """RSI，使用 Wilder 平滑法（alpha = 1/n）。"""
    delta = close.diff()
    gain = delta.clip(lower=0)          # 負數變 0
    loss = -delta.clip(upper=0)         # 正數變 0，再取正值
    avg_gain = gain.ewm(alpha=1 / n, adjust=False, min_periods=n).mean()
    avg_loss = loss.ewm(alpha=1 / n, adjust=False, min_periods=n).mean()
    rs = avg_gain / avg_loss
    return 100 - 100 / (1 + rs)

df["RSI14"] = rsi(df["Close"], 14)
df["RSI2"] = rsi(df["Close"], 2)        # 8.5 康納斯式短週期 RSI
```

| 函式 | 意思 |
|---|---|
| `diff()` | 今天 − 昨天（和 `pct_change` 類似，但是差額不是比例） |
| `clip(lower=0)` | 小於 0 的值改成 0 |
| `min_periods=n` | 前 n 筆資料不足時給 NaN |

> 💡 **如果整段期間都沒有下跌**，avg_loss = 0，RS 會變成無限大，RSI = 100——這在數學上是對的。

### 3. ⭐ 用手算的小例子驗證 RSI

把 RSI(3) 用在 8 個價格上，手算和程式比對：

```python
s = pd.Series([10, 11, 10.5, 11.5, 12, 11, 11.5, 12.5])
print(rsi(s, 3).round(2).tolist())
```

輸出：

```
[nan, nan, nan, 87.5, 90.24, 54.41, 64.87, 79.19]
```

**手算第 4 個值（位置 3）：**

| 位置 | 價格 | 漲跌 | 漲 | 跌 | 平均漲（α = 1/3） | 平均跌 |
|---:|---:|---:|---:|---:|---:|---:|
| 0 | 10 | — | — | — | — | — |
| 1 | 11 | +1 | 1 | 0 | 1（第一個值） | 0 |
| 2 | 10.5 | −0.5 | 0 | 0.5 | 1 × 2/3 + 0 × 1/3 = 0.6667 | 0 × 2/3 + 0.5 × 1/3 = 0.1667 |
| 3 | 11.5 | +1 | 1 | 0 | 0.6667 × 2/3 + 1 × 1/3 = 0.7778 | 0.1667 × 2/3 + 0 = 0.1111 |

RS = 0.7778 ÷ 0.1111 = 7；RSI = 100 − 100 ÷ 8 = **87.5** ✅

> 🔑 **每寫一個指標，都用一個小例子手算驗證**（9.5 的測試習慣）。如果手算和程式對不上，一定有一邊錯了——通常是程式。

### 4. ⭐ ATR（回想 4.10、6.5）

**真實區間（True Range）** = 以下三者中最大的：
1. 今天最高 − 今天最低
2. |今天最高 − 昨天收盤|
3. |今天最低 − 昨天收盤|

（後兩項考慮了**跳空**：如果今天開盤就跳空大漲，光看今天的高低差會低估波動。）

**ATR** = 真實區間的 Wilder 平滑平均。

```python
def atr(df, n=14):
    """平均真實區間（Wilder 平滑）。"""
    prev_close = df["Close"].shift(1)
    tr = pd.concat([
        df["High"] - df["Low"],
        (df["High"] - prev_close).abs(),
        (df["Low"] - prev_close).abs(),
    ], axis=1).max(axis=1)
    return tr.ewm(alpha=1 / n, adjust=False, min_periods=n).mean()

df["ATR14"] = atr(df, 14)
df["ATR20"] = atr(df, 20)
```

> 💡 `pd.concat([...], axis=1)` 把三欄並排，`.max(axis=1)` 取每一列（每一天）的最大值。

**用 ATR 計算部位大小（6.5 + 9.5）：**

```python
capital = 1_000_000
last = df.iloc[-1]
stop_distance = 2 * last["ATR20"]
shares = int(capital * 0.01 / stop_distance)
print(f"收盤 {last['Close']:.2f}，ATR20 {last['ATR20']:.2f}，停損距離 {stop_distance:.2f}，股數 {shares}")
```

### 5. 布林通道（回想 4.10）

```python
def bollinger(close, n=20, k=2):
    """回傳（中軌, 上軌, 下軌）。標準差用母體標準差（ddof=0），與多數看盤軟體相同。"""
    mid = close.rolling(n).mean()
    sd = close.rolling(n).std(ddof=0)
    return mid, mid + k * sd, mid - k * sd

df["BB_mid"], df["BB_up"], df["BB_low"] = bollinger(df["Close"])
df["BB_width"] = (df["BB_up"] - df["BB_low"]) / df["BB_mid"]     # 帶寬：8.4 波動收斂用
```

> ⚠️ pandas 的 `std()` 預設 `ddof=1`（樣本標準差），而布林通道通常用母體標準差（`ddof=0`）。兩者差異不大，但和看盤軟體比對時會造成小數點後的差距。這就是「自己下廚才知道的細節」。

### 6. MACD（回想 4.9）

```python
def macd(close, fast=12, slow=26, signal=9):
    """回傳（MACD 線, 訊號線, 柱狀體）。"""
    line = ema(close, fast) - ema(close, slow)
    sig = line.ewm(span=signal, adjust=False).mean()
    return line, sig, line - sig

df["MACD"], df["MACD_signal"], df["MACD_hist"] = macd(df["Close"])
```

### 7. KD（回想 4.8，台灣常用版本）

```python
def kd(df, n=9):
    """台灣常用的 KD：RSV 用 n 日高低，K、D 以 1/3 權重平滑，初始值 50。"""
    low_n = df["Low"].rolling(n).min()
    high_n = df["High"].rolling(n).max()
    rsv = (df["Close"] - low_n) / (high_n - low_n) * 100

    k_values, d_values = [], []
    k, d = 50.0, 50.0
    for v in rsv:
        if np.isnan(v):
            k_values.append(np.nan)
            d_values.append(np.nan)
            continue
        k = k * 2 / 3 + v / 3
        d = d * 2 / 3 + k / 3
        k_values.append(k)
        d_values.append(d)
    return pd.Series(k_values, index=df.index), pd.Series(d_values, index=df.index)

df["K"], df["D"] = kd(df)
```

> 💡 KD 的遞迴有「初始值 50」這個規定，用迴圈寫最清楚（9.4）。不同軟體的 KD 公式可能略有不同（例如美股常見的 Stochastic 是用簡單平均），比對時要確認公式。

### 9. ⭐ 和 TradingView 比對

| 步驟 | 做法 |
|---|---|
| ① 用同一份資料 | 同一個商品、同樣的還原設定（TradingView 的「調整股利」開關要和你的資料一致） |
| ② 選幾個日期 | 挑**資料後段**的 3～5 個日期 |
| ③ 比對數值 | 把滑鼠移到 TradingView 的 K 棒上看指標值 |
| ④ 容許小誤差 | 小數點第 2 位的差距通常是資料或算法細節 |

**為什麼前段數值可能對不上？**

| 原因 | 說明 |
|---|---|
| **起始值不同** | EMA、RSI、ATR 都是遞迴計算，第一個值怎麼設會影響前面一段。例如 TradingView 的 RMA 以前 n 筆的簡單平均當起點，本單元的寫法以第一筆當起點；**資料越往後，影響越小**，通常一兩百根 K 棒之後就幾乎一致 |
| **資料長度不同** | TradingView 從商品上市第一天開始算，你的資料可能只從 10 年前開始 |
| **標準差定義** | ddof=0 還是 ddof=1 |
| **還原權值** | 有沒有調整股利會讓價格不同，指標當然不同 |
| **公式版本** | KD、Stochastic 等指標有不同版本 |

## 📌 重點整理

1. 自己寫指標 = **自己下廚**：會發現平滑法、起始值、標準差定義等細節。
2. SMA：`rolling(n).mean()`；EMA：`ewm(span=n, adjust=False).mean()`。
3. RSI 與 ATR 用 **Wilder 平滑**：`ewm(alpha=1/n, adjust=False)`。
4. **真實區間**考慮了跳空：高低差、|高 − 昨收|、|低 − 昨收| 取最大。
5. 布林通道通常用**母體標準差**（ddof=0）；KD 有**初始值 50** 的遞迴。
6. **用手算的小例子驗證**每一個指標函式。
7. 和 TradingView 比對：同資料、同還原設定、比對**後段**數值，容許小誤差。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「RSI 的平均漲跌幅是簡單平均」 | 經典 RSI 使用 Wilder 平滑法（指數平均的一種）；用簡單平均會得到不同的數值。 |
| 「ATR 就是每天最高減最低的平均」 | 真實區間還要考慮與昨收的差距（跳空）。 |
| 「我的指標和 TradingView 前幾天不一樣，所以算錯了」 | 遞迴指標的起始值與資料長度不同會影響前段；比對後段的數值。 |
| 「指標算好就可以直接當訊號用」 | 收盤後才知道的指標值，要 shift(1) 到隔天才能進場。 |

## ✅ 自我測驗

**Q1. 什麼是 Wilder 平滑法？在 pandas 中怎麼寫？**

<details><summary>看答案</summary>

一種指數平均：今天的平均 = 昨天的平均 × (n−1)/n + 今天的值 × 1/n。RSI 的平均漲跌幅與 ATR 都使用這種平滑法。在 pandas 中寫成 `series.ewm(alpha=1/n, adjust=False).mean()`。

</details>

**Q2. 真實區間為什麼要比較昨天的收盤價？**

<details><summary>看答案</summary>

因為有跳空的情況。例如昨天收盤 100，今天跳空開在 106、整天在 105～108 之間，今天的高低差只有 3，但實際的價格變動從 100 到 108 是 8。真實區間取「高低差、|最高 − 昨收|、|最低 − 昨收|」三者最大者，才能完整反映包含跳空在內的波動。

</details>

**Q3. 練習 2 參考答案**

<details><summary>看答案</summary>

真實區間：第 1 天 102 − 99 = **3**；第 2 天 max(3, |103 − 101|, |100 − 101|) = **3**；第 3 天 max(3, |108 − 102|, |105 − 102|) = **6**（跳空）；第 4 天 max(4, |107 − 107|, |103 − 107|) = **4**。ATR(3) 以第一筆為起點、alpha = 1/3：3 → 3 → 3 × 2/3 + 6 × 1/3 = **4** → 4 × 2/3 + 4 × 1/3 = **4**；因為 `min_periods=3`，前兩天顯示 NaN，第 3 天起為 4.0、4.0。

</details>
