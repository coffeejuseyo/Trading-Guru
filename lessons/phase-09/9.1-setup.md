## 📖 開場故事：超聽話的機器人廚師

你買了一台機器人廚師。它的優點是：

- **速度超快**：一秒鐘可以切 1,000 顆洋蔥
- **永遠不累**：24 小時工作也不會抱怨
- **完全照做**：你說什麼它就做什麼，不會偷懶，也不會被情緒影響

但它有一個大缺點：**完全不會變通**。

- 你說「加一點鹽」→ 它停下來問：「一點是幾克？」
- 你說「把洋蔥切好」→ 它問：「切丁還是切絲？多大？」
- 你不小心寫成「加一匙**鹽巴吧**」→ 它說：「我不認識『鹽巴吧』這種材料」，然後停止工作

> 🤖 **電腦就是這個機器人，Python 就是你跟它溝通的語言。** 一開始會覺得它很笨、很囉唆，但一旦你學會用它聽得懂的方式下指令，它可以在幾秒鐘內幫你回測十年的資料——你用眼睛目測 30 筆要花好幾小時的事。

## 🧠 正文

### 1. 為什麼交易者要學寫程式？

| | 手動目測（Phase 8） | 用程式回測（Phase 10） |
|---|---|---|
| 速度 | 30 筆要好幾小時 | 十年資料、上千筆交易，幾秒鐘 |
| 正確性 | 容易看錯、算錯 | 規則寫對就不會算錯 |
| 樣本數 | 太少，很難判斷好壞 | 可以測很多商品、很多年 |
| 偏誤 | 不自覺挑「好看」的交易 | 照規則全部算進去 |
| 修改 | 改一個參數要重做一次 | 改一個數字，重新執行 |

### 2. 為什麼是 Python？

| 優點 | 說明 |
|---|---|
| **語法接近英文** | 比較容易讀懂，適合初學者 |
| **金融與資料分析的主流** | pandas、NumPy 等套件就是為了處理表格資料而生 |
| **資源最多** | 遇到問題，幾乎都能找到別人問過的答案 |
| **免費** | 所有工具都免費 |

### 3. ⭐ 三種寫程式的地方

| 工具 | 是什麼 | 優點 | 缺點 | 建議 |
|---|---|---|---|---|
| **Google Colab** | 在瀏覽器裡寫 Python，Google 提供電腦 | **不用安裝**、有 Google 帳號就能用、常用套件都裝好了 | 要網路；閒置一段時間會斷線，變數會消失 | ⭐ **新手首選** |
| **Jupyter Notebook** | 在自己電腦上的筆記本式環境 | 資料存在自己電腦、不怕斷線 | 要先安裝 Python | 熟悉後可以改用 |
| **VS Code** | 專業的程式編輯器 | 適合寫比較大的程式、整合 Git（9.14） | 一開始比較複雜 | Phase 10 之後再考慮 |

> 🍳 **比喻**：Colab 像租一間設備齊全的共享廚房，拎包就能煮；Jupyter 是在自己家裡布置廚房；VS Code 是專業餐廳的廚房。**本階段的範例都可以直接在 Colab 執行。**

### 4. ⭐ 在 Colab 執行第一段程式

**步驟：**
1. 用瀏覽器打開 Google Colab（搜尋「Google Colab」）並登入 Google 帳號
2. 點「新增筆記本」（New notebook）
3. 你會看到一個灰色的格子，叫做**儲存格（cell）**
4. 在格子裡輸入以下程式，按 **Shift + Enter** 執行

```python
print("Hello, 交易者！")
print(1 + 1)
```

輸出：

```
Hello, 交易者！
2
```

🎉 恭喜，你寫了第一個 Python 程式！

**筆記本的兩種儲存格：**

| 類型 | 用途 |
|---|---|
| **程式碼儲存格** | 寫 Python，執行後顯示結果 |
| **文字儲存格** | 寫筆記、說明（可以把學習筆記寫在旁邊） |

> 💡 **筆記本的特色**：可以一格一格執行、馬上看到結果，很適合邊學邊試。但要注意：**執行順序很重要**。如果你跳著執行，或是改了上面的格子沒有重新執行，結果可能和你想的不一樣。不確定時，用選單的「執行階段 → 全部執行」從頭跑一次。

### 5. 安裝套件與上傳檔案

**套件（Package）** = 別人寫好的工具包，就像買現成的廚具，不用自己打造。

```python
import pandas as pd
import numpy as np
print(pd.__version__)
```

Colab 已經內建 pandas、NumPy、matplotlib 等常用套件。如果需要額外的套件（例如 9.10 的 yfinance），在儲存格中輸入：

```
!pip install yfinance
```

（前面的 `!` 表示「這是給系統的指令，不是 Python」。）

**上傳練習資料：**
1. 從本課程的 [`data/sample_prices.csv`](data/sample_prices.csv) 下載檔案到你的電腦
2. 在 Colab 左側點「檔案」圖示（資料夾）→「上傳」
3. 上傳後就可以用 `pd.read_csv("sample_prices.csv")` 讀取（9.8 會教）

> ⚠️ Colab 上傳的檔案在**斷線後會消失**。長期使用可以把檔案放在 Google 雲端硬碟，並在 Colab 中「掛接雲端硬碟」。

**在自己電腦安裝（選讀）：**
1. 到 Python 官方網站下載安裝（安裝時勾選「Add Python to PATH」）
2. 打開終端機（Windows：命令提示字元；Mac：終端機），輸入 `pip install pandas numpy matplotlib jupyter`
3. 輸入 `jupyter notebook` 啟動

（版本與步驟可能隨時間改變，以官方說明為準。）

### 6. ⭐ 看懂錯誤訊息

錯誤訊息不是在罵你，而是機器人在告訴你**它卡在哪裡**。

```python
# ⚠️ 這段會出錯（示範用）
print("價格是" + 100)
```

```
TypeError: can only concatenate str (not "int") to str
```

| 部分 | 意思 |
|---|---|
| `TypeError` | 錯誤的**種類**：資料型別錯誤 |
| `can only concatenate str (not "int") to str` | 錯誤的**原因**：文字只能和文字接在一起，不能接數字 |

**常見錯誤種類：**

| 錯誤 | 意思 | 常見原因 |
|---|---|---|
| `SyntaxError` | 語法錯誤 | 少了括號、引號、冒號 |
| `NameError` | 不認識這個名字 | 變數名稱打錯，或還沒定義（或忘記執行上面的格子） |
| `TypeError` | 型別錯誤 | 把文字和數字相加 |
| `IndentationError` | 縮排錯誤 | 空格對不齊（9.3 會說明） |
| `KeyError` | 找不到這個鍵 | 欄位名稱打錯（例如 `"close"` vs. `"Close"`） |
| `FileNotFoundError` | 找不到檔案 | 檔案沒上傳，或檔名打錯 |
| `ModuleNotFoundError` | 找不到套件 | 套件沒安裝 |

> 🔑 **讀錯誤訊息的方法**：從**最後一行**開始看（錯誤種類 + 原因），再往上找到**你自己寫的那一行**。

### 7. 卡住時怎麼問問題？

| 步驟 | 做法 |
|---|---|
| ① 自己先試 | 重讀錯誤訊息的最後一行；檢查拼字、大小寫、括號 |
| ② 搜尋 | 把錯誤訊息的最後一行**完整複製**貼到搜尋引擎 |
| ③ 問 AI 助理 | 貼上：你的程式碼 + 完整錯誤訊息 + 你想做什麼 + 你已經試過什麼 |
| ④ 理解答案 | **不要只複製答案**，要搞懂為什麼錯，不然下次還會錯 |

> ⚠️ **AI 助理很好用，但它也會出錯**——特別是金融計算的細節（例如報酬率、除權息、前視偏差）。拿到的程式碼一定要**用小例子手算驗證**，這是 Phase 10 回測最重要的習慣。

## 📌 重點整理

1. 電腦 = **超聽話但不會變通的機器人**；Python = 跟它溝通的語言。
2. 寫程式的好處：**快、準、樣本多、沒有挑選偏誤、容易修改**。
3. 新手首選 **Google Colab**：不用安裝，打開瀏覽器就能寫。
4. **Shift + Enter** 執行儲存格；注意執行順序，不確定就「全部執行」。
5. 錯誤訊息從**最後一行**看：錯誤種類 + 原因。
6. 卡住時：自己試 → 搜尋 → 問 AI（附上程式碼與錯誤訊息）→ **理解並驗證答案**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「要數學很好才能寫程式」 | 本課程用到的程式只需要基本的加減乘除和邏輯。 |
