## 📖 開場故事：去市場採買食材

想做一桌好菜，第一步是**買食材**。你有幾種選擇：

| 去哪裡買 | 特色 |
|---|---|
| **傳統市場** | 便宜、方便，但品質參差不齊，有時候攤位沒開 |
| **超市** | 品質穩定、有標示，價格中等 |
| **高級食材行** | 品質最好、資訊最完整，但很貴 |
| **自己種菜** | 完全掌握，但很花時間 |

而且不管在哪裡買，**回家都要檢查**：有沒有爛掉、份量對不對、是不是你要的那一種。

> 🛒 **金融資料也一樣**：免費的資料來源（像 yfinance）很方便，但可能有缺漏或錯誤；付費的資料庫品質好但要花錢；官方網站的資料最權威但整理起來比較麻煩。**不管從哪裡拿，都要先檢查再使用**——回測的結果只會跟你的資料一樣好（垃圾進、垃圾出）。

## 🧠 正文

### 1. ⭐ 常見的資料來源

| 來源 | 類型 | 優點 | 缺點 |
|---|---|---|---|
| **yfinance**（Yahoo Finance） | 免費 Python 套件 | 一行下載、台美股都有、新手最方便 | **非官方**、可能突然失效或有錯誤；資料品質不保證 |
| **證交所、櫃買中心網站** | 官方 | 最權威 | 需要自己整理格式；大量下載不方便 |
| **TradingView、券商軟體匯出** | 圖表平台 | 和你看的圖一致 | 匯出功能可能需要付費方案 |
| **FinMind 等台股資料 API** | 免費 / 付費 API | 台股資料齊全（含財報、法人） | 需要註冊、有使用次數限制 |
| **TEJ、彭博等專業資料庫** | 付費 | 品質最好、含下市股票 | 很貴，通常是機構或學校使用 |

> 🔑 **新手建議**：學習階段用 yfinance 就夠了；但要知道它的限制，**重要的結論要用第二個來源交叉驗證**。（各平台的功能、費用、限制可能改變，以官方說明為準。）

### 2. ⭐ 用 yfinance 下載資料

**安裝（Colab 中執行一次）：**

```
!pip install yfinance
```

**下載 0050 的日線資料：**

```python
import yfinance as yf
import pandas as pd

df = yf.download("0050.TW", start="2014-01-01", end="2024-01-01", auto_adjust=False)

# 新版 yfinance 的欄位可能是兩層（欄位名稱 + 代號），只下載一檔時把它攤平成一層
if isinstance(df.columns, pd.MultiIndex):
    df.columns = df.columns.get_level_values(0)

print(df.head())
print(df.shape)
```

**代號寫法：**

| 市場 | 寫法 | 例子 |
|---|---|---|
| 台股上市 | 代號 + `.TW` | `0050.TW`、`2330.TW` |
| 台股上櫃 | 代號 + `.TWO` | 上櫃股票要用 `.TWO` |
| 美股 | 直接寫代號 | `SPY`、`AAPL` |
| 台股加權指數 | `^TWII` | |
| 美股 S&P 500 指數 | `^GSPC` | |

**參數說明：**

| 參數 | 意思 |
|---|---|
| `start`、`end` | 起訖日期（`end` 那天通常**不包含**） |
| `interval` | 頻率，預設 `"1d"`（日線）；也有 `"1wk"`、`"1mo"` |
| `auto_adjust` | 是否把價格調整成**還原權值**（見下方） |

### 3. ⚠️ yfinance 的幾個坑

| 坑 | 說明 | 對策 |
|---|---|---|
| **還原權值的設定** | `auto_adjust=True` 時，Open / High / Low / Close 都會依除權息調整；`False` 時保留原始價格，另外提供 `Adj Close` 欄位。**新版的預設值曾經改變過** | **永遠明確寫出 `auto_adjust=...`**，不要依賴預設值；9.11 會說明何時用哪一種 |
| **欄位格式改變** | 新版可能回傳兩層欄位（MultiIndex） | 用上面的程式攤平 |
| **資料缺漏或錯誤** | 某些日子缺資料、價格異常跳動、成交量為 0 | 下載後一定要檢查（第 7 節） |
| **下載失敗卻沒報錯** | 網路或服務出問題時，可能只印出「Failed download」並回傳**空的表格**，程式繼續往下跑 | 下載後檢查 `if df.empty:`，空的就停下來 |
| **服務不穩定** | 下載失敗、被限制次數、套件因網站改版而失效 | 存到本機（第 6 節）；必要時更新套件 `!pip install -U yfinance` |
| **倖存者偏差** | 只能下載**現在還存在**的股票，已下市的股票通常找不到 | Phase 10 會討論對回測的影響 |
| **時區與日期** | 日期可能帶有時區資訊 | 必要時用 `df.index = df.index.tz_localize(None)` 移除 |

> ⚠️ **yfinance 是社群維護的非官方工具**，Yahoo 並沒有承諾提供這項服務。它可能某天突然不能用，或資料有誤——學習夠用，但不要把它當成唯一的真相。

### 4. 一次下載多檔

```python
tickers = ["0050.TW", "2330.TW", "SPY"]
data = yf.download(tickers, start="2020-01-01", end="2024-01-01", auto_adjust=True)
close = data["Close"]          # 每一檔的收盤價，一欄一檔
print(close.tail())
```

> 💡 台股和美股的交易日不同（假日不一樣），合併在一起時會出現 NaN，9.11 會說明怎麼處理。

### 5. 用 CSV 匯入網站下載的資料

很多網站（證交所、TradingView、券商）可以下載 CSV 檔。讀入的基本方法和 9.8 一樣，但常常需要處理格式：

```python
import pandas as pd

df = pd.read_csv("sample_prices.csv", parse_dates=["Date"], index_col="Date")
print(df.dtypes)
```

**常見的格式問題：**

| 問題 | 例子 | 解法 |
|---|---|---|
| 欄位名稱是中文 | 「日期、開盤價、收盤價」 | `df = df.rename(columns={"收盤價": "Close", ...})` |
| 數字有千分位逗號 | `"12,345"` 被讀成文字 | `pd.read_csv(..., thousands=",")` |
| 民國年 | `"112/01/03"` | 先拆出年份 + 1911，再轉成日期 |
| 檔案編碼 | 讀入後出現亂碼 | `pd.read_csv(..., encoding="big5")` 或 `"utf-8-sig"` |
| 日期格式特殊 | `"03/01/2023"` 是 3 月 1 日還是 1 月 3 日？ | `pd.to_datetime(..., format="%m/%d/%Y")` 明確指定 |

**範例：處理民國年與千分位**

```python
import pandas as pd
from io import StringIO

raw = """日期,開盤價,最高價,最低價,收盤價,成交股數
112/01/03,"110.50","111.20","109.80","110.90","12,345,678"
112/01/04,"111.00","112.50","110.60","112.30","15,678,901"
"""
tw = pd.read_csv(StringIO(raw), thousands=",")

# 民國年轉西元年：拆成年、月、日，年份加 1911
parts = tw["日期"].str.split("/", expand=True).astype(int)
tw["Date"] = pd.to_datetime(dict(year=parts[0] + 1911, month=parts[1], day=parts[2]))

tw = tw.rename(columns={"開盤價": "Open", "最高價": "High", "最低價": "Low",
                        "收盤價": "Close", "成交股數": "Volume"})
tw = tw.set_index("Date")[["Open", "High", "Low", "Close", "Volume"]]
print(tw)
print(tw.dtypes)
```

輸出：

```
             Open   High    Low  Close    Volume
Date
2023-01-03  110.5  111.2  109.8  110.9  12345678
2023-01-04  111.0  112.5  110.6  112.3  15678901
Open      float64
High      float64
Low       float64
Close     float64
Volume      int64
dtype: object
```

（`StringIO` 讓我們把一段文字當成檔案來讀，方便示範；實際使用時換成檔名即可。以上數字是示範用的假資料。）

### 6. ⭐ 把資料存在本機

**不要每次執行都重新下載**：慢、可能被限制、而且資料來源可能悄悄修正了歷史資料，讓你的結果無法重現。

```python
import os
import pandas as pd

def load_prices(symbol, start, end, folder="data"):
    """先找本機的 CSV；沒有才下載，並存檔。"""
    os.makedirs(folder, exist_ok=True)
    path = os.path.join(folder, f"{symbol}_{start}_{end}.csv")
    if os.path.exists(path):
        print(f"讀取本機檔案：{path}")
        return pd.read_csv(path, parse_dates=["Date"], index_col="Date")

    import yfinance as yf
    print(f"下載：{symbol}")
    df = yf.download(symbol, start=start, end=end, auto_adjust=False)
    if df.empty:
        raise ValueError(f"{symbol} 下載失敗或沒有資料")
    if isinstance(df.columns, pd.MultiIndex):
        df.columns = df.columns.get_level_values(0)
    df.index.name = "Date"
    df.to_csv(path)
    return df

df = load_prices("0050.TW", "2014-01-01", "2024-01-01")
```

> 🔑 **可重現性**：存下來的檔案就是你回測時用的「那一份資料」。Phase 10 寫回測報告時，要記錄資料來源、下載日期、是否還原權值（[回測報告範本](../../templates/backtest-report.md)）。

### 7. API 是什麼？

**API（應用程式介面）** = 餐廳的點餐窗口：你照著菜單（文件）的格式點餐（發出請求），廚房（伺服器）把餐點（資料）交給你。

```python
# 示意：多數資料 API 的基本流程（網址與參數依各服務的文件為準）skip-test
import requests
import pandas as pd

url = "https://api.example.com/v1/prices"          # 假的網址，僅示意
params = {"symbol": "0050", "start": "2023-01-01", "token": "你的金鑰"}
resp = requests.get(url, params=params, timeout=30)
resp.raise_for_status()                             # 失敗就報錯
data = resp.json()                                  # 多數 API 回傳 JSON 格式
df = pd.DataFrame(data["data"])                     # 欄位名稱依各 API 而定
```

| 觀念 | 說明 |
|---|---|
| **金鑰（token / API key）** | 身分證明；**不要把金鑰寫進要分享或上傳到 GitHub 的程式**（9.14） |
| **使用限制** | 每分鐘、每天可以請求幾次；超過會被拒絕 |
| **JSON** | 一種資料格式，長得很像 9.6 的「串列裡放字典」 |
| **讀文件** | 每個 API 的網址、參數、欄位都不同，一定要讀官方文件 |

### 8. ⭐ 拿到資料後的檢查清單

```python
import pandas as pd

df = pd.read_csv("sample_prices.csv", parse_dates=["Date"], index_col="Date")

print("期間：", df.index.min().date(), "～", df.index.max().date())
print("筆數：", len(df))
print("缺值：", df.isna().sum().to_dict())
print("重複日期：", df.index.duplicated().sum())
print("日期是否遞增：", df.index.is_monotonic_increasing)
print("非正價格：", (df[["Open", "High", "Low", "Close"]] <= 0).sum().sum())
print("High < Low 的筆數：", (df["High"] < df["Low"]).sum())
print("Close 超出高低範圍：", ((df["Close"] > df["High"]) | (df["Close"] < df["Low"])).sum())
print("成交量為 0：", (df["Volume"] == 0).sum())
big = df["Close"].pct_change().abs() > 0.15
print("單日漲跌超過 15%：", big.sum())
```

輸出（練習資料是乾淨的模擬資料）：

```
期間： 2021-01-04 ～ 2023-12-29
筆數： 780
缺值： {'Open': 0, 'High': 0, 'Low': 0, 'Close': 0, 'Volume': 0}
重複日期： 0
日期是否遞增： True
非正價格： 0
High < Low 的筆數： 0
Close 超出高低範圍： 0
成交量為 0： 0
單日漲跌超過 15%： 0
```

| 檢查項目 | 為什麼 |
|---|---|
| 期間、筆數 | 是不是你要的範圍？10 年大約應該有 2,400～2,500 筆 |
| 缺值、重複、順序 | 9.11 會教怎麼處理 |
| 價格合理性 | 負價格、High < Low 代表資料錯誤 |
| 單日大漲大跌 | 台股有漲跌幅限制（目前為 10%，以官方規定為準），超過很可能是**除權息、分割或資料錯誤**（9.11） |

> 🛒 這就是「買菜回家要檢查」。**把這段檢查寫成函式，每次拿到新資料都跑一次**。

## 📌 重點整理

1. 資料來源：**yfinance（免費方便但非官方）、官方網站、API、付費資料庫**；重要結論要交叉驗證。
2. yfinance：`yf.download("0050.TW", start=..., end=..., auto_adjust=...)`；上市 `.TW`、上櫃 `.TWO`。
3. 坑：**明確指定 auto_adjust**、攤平多層欄位、資料缺漏、服務不穩、倖存者偏差。
4. CSV 匯入常見問題：中文欄名、千分位、民國年、編碼、日期格式。
5. **資料存在本機**：快、穩、可重現；記錄來源與下載日期。
6. API = 點餐窗口；**金鑰不要外流**。
7. 拿到資料先跑**檢查清單**：期間、缺值、重複、順序、價格合理性、異常漲跌。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「免費資料一定是對的」 | 免費資料可能有缺漏、錯誤或格式改變；要檢查並交叉驗證。 |
| 「每次執行都重新下載最即時」 | 會變慢、可能被限制，也可能讓結果無法重現；歷史資料應存在本機。 |
| 「yfinance 的預設值永遠不會變」 | 預設值曾經改變過；重要參數（例如 auto_adjust）要明確寫出來。 |
| 「API 金鑰寫在程式裡沒關係」 | 分享或上傳程式時金鑰會外流，可能被盜用。 |

## 🛠️ 練習（約 90 分鐘）

**練習 1：下載與檢查（課綱作業準備）**
用 yfinance 下載 0050.TW（或 SPY）最近 10 年的日線資料，`auto_adjust=False`，攤平欄位後存成 CSV，再對它執行第 8 節的檢查清單。資料有幾筆？有沒有缺值或異常的大漲大跌？如果有，記下日期，9.11 會用到。

**練習 2：交叉驗證**
在 TradingView 上找出 0050 某 3 天的開高低收，和你下載的資料比對。一樣嗎？如果不一樣，可能是什麼原因？（提示：還原權值、資料來源不同）

**練習 3：把檢查清單寫成函式**
把第 8 節的檢查寫成函式 `check_prices(df)`，回傳一個字典（例如 `{"rows": 780, "missing": 0, ...}`），並用練習資料與你下載的資料各測一次。

## ✅ 自我測驗

**Q1. 為什麼要把下載的資料存在本機，而不是每次重新下載？**

<details><summary>看答案</summary>

速度較快、不受網路或服務不穩定影響、避免被限制請求次數；更重要的是可重現性——資料來源可能修正或改變歷史資料，存下來的檔案確保你和別人能用同一份資料重現回測結果。

</details>

**Q2. 下載台股資料時，單日漲跌超過 15% 可能代表什麼？**

<details><summary>看答案</summary>

台股一般有每日漲跌幅限制（目前為 10%），單日變動超過這個範圍，常見原因是除權息（原始價格在除息日下跌）、股票分割或減資，或是資料錯誤。需要檢查原因，並決定是否使用調整後的價格（9.11）。

</details>

**Q3. 為什麼要明確寫出 `auto_adjust=True` 或 `False`？**

<details><summary>看答案</summary>

因為它決定了價格是否已經依除權息調整，會影響報酬率與指標的計算結果；而且 yfinance 的預設值曾經改變過，依賴預設值可能在套件更新後悄悄得到不同的資料。明確寫出才能確保結果可重現，也讓讀程式的人知道用的是哪一種價格。

</details>
