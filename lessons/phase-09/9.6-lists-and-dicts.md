## 📖 開場故事：購物清單與電話簿

**購物清單**：
> 1. 雞蛋　2. 牛奶　3. 麵包　4. 蘋果

清單有**順序**。你可以說「第 2 項是什麼？」「最後一項是什麼？」「前三項是什麼？」也可以隨時在最後面加一項。

**電話簿**：
> 媽媽 → 0912-xxx-xxx　　阿明 → 0933-xxx-xxx

電話簿不在意順序，你是用**名字**去查號碼。你不會說「第 37 個人的電話」，而是說「阿明的電話」。

> 📋 **串列就是購物清單**（用位置找資料，適合每日價格這種有順序的資料）；**字典就是電話簿**（用名字找資料，適合「股票代號 → 持股數」這種對照關係）。

## 🧠 正文

### 1. ⭐ 串列：有順序的一排資料

```python
prices = [100, 102, 101, 105, 103, 108, 107, 110]

print(prices[0])      # 第一個（位置 0）
print(prices[-1])     # 最後一個
print(len(prices))    # 有幾個
```

輸出：`100`、`110`、`8`

**位置（索引）對照表：**

| 值 | 100 | 102 | 101 | 105 | 103 | 108 | 107 | 110 |
|---|---|---|---|---|---|---|---|---|
| 正索引 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| 負索引 | −8 | −7 | −6 | −5 | −4 | −3 | −2 | −1 |

> 💡 **負索引從後面數**：`-1` 是最後一個、`-2` 是倒數第二個。在交易中很好用：「最新的價格」就是 `prices[-1]`。

### 2. ⭐ 切片：一次拿出一段

**語法：`串列[開始:結束]`**（包含開始、**不包含結束**，和 `range` 一樣）

```python
prices = [100, 102, 101, 105, 103, 108, 107, 110]

print(prices[2:5])    # 位置 2, 3, 4
print(prices[:3])     # 前 3 個
print(prices[-3:])    # 最後 3 個
print(sum(prices[-5:]) / 5)   # 最近 5 天的平均 = 5 日均線的最新值
```

輸出：

```
[101, 105, 103]
[100, 102, 101]
[108, 107, 110]
106.6
```

**用切片算出每一天的 5 日均線：**

```python
prices = [100, 102, 101, 105, 103, 108, 107, 110]
ma5 = []
for i in range(len(prices)):
    if i < 4:
        ma5.append(None)              # 前 4 天資料不足 5 天，沒有均線
    else:
        window = prices[i - 4:i + 1]  # 包含今天在內的最近 5 天
        ma5.append(sum(window) / 5)
print(ma5)
```

輸出：

```
[None, None, None, None, 102.2, 103.8, 104.8, 106.6]
```

> 🔑 `prices[i - 4:i + 1]` 是「第 i−4 天到第 i 天」（因為結束位置不包含，所以寫 `i + 1`）。**這種「差一個」的錯誤（off-by-one）是程式中最常見的 bug**——用 4.7 學過的方法手算第一個均線值（100+102+101+105+103）÷ 5 = 102.2 ✅ 驗證一下。

### 3. 常用操作

| 操作 | 寫法 | 例子結果 |
|---|---|---|
| 加到最後 | `lst.append(x)` | 清單多一個元素 |
| 長度 | `len(lst)` | 8 |
| 加總 | `sum(lst)` | |
| 最大 / 最小 | `max(lst)`、`min(lst)` | 110、100 |
| 排序（產生新串列） | `sorted(lst)`、`sorted(lst, reverse=True)` | 由小到大 / 由大到小 |
| 是否包含 | `x in lst` | `True` / `False` |

```python
watchlist = ["0050", "2330"]
watchlist.append("2317")
print(watchlist)
print("2330" in watchlist)
print(sorted([3.2, -1.0, 2.5], reverse=True))
```

### 4. ⭐ 串列生成式：一行產生新串列

把 9.4 的「用迴圈算每日報酬」縮成一行：

```python
prices = [100, 102, 101, 105, 103, 108, 107, 110]
rets = [prices[i] / prices[i - 1] - 1 for i in range(1, len(prices))]
print([round(r, 4) for r in rets])
```

輸出：

```
[0.02, -0.0098, 0.0396, -0.019, 0.0485, -0.0093, 0.028]
```

**加上條件篩選：**

```python
trades = [2.0, -1, -1, 2.5, -1, -1, -1, -1, 3.5, -1]
wins = [r for r in trades if r > 0]
losses = [r for r in trades if r < 0]
print(wins, losses)
print(f"平均獲利 {sum(wins) / len(wins):.2f}R，平均虧損 {sum(losses) / len(losses):.2f}R")
```

> 💡 讀法：「**對 trades 中的每一個 r，如果 r > 0，就把 r 放進新串列**」。

### 5. ⭐ 字典：用名字查值

```python
holdings = {"0050": 2000, "2330": 300, "2317": 1000}   # 代號 → 股數

print(holdings["2330"])           # 用「鍵」查「值」
holdings["2454"] = 50             # 新增
holdings["0050"] = 2500           # 修改
print(holdings)
print(holdings.get("2603", 0))    # 查不到時回傳預設值 0，不會報錯
```

| 名詞 | 意思 | 電話簿比喻 |
|---|---|---|
| **鍵（key）** | 用來查詢的名字 | 人名 |
| **值（value）** | 查到的內容 | 電話號碼 |
| `d[key]` | 查詢；查不到會出現 `KeyError` | |
| `d.get(key, 預設)` | 查詢；查不到回傳預設值 | |

**走訪字典：計算投資組合市值與權重**

```python
holdings = {"0050": 2000, "2330": 300, "2317": 1000}
last_price = {"0050": 150.5, "2330": 980, "2317": 105}

total = 0
for symbol, shares in holdings.items():
    total = total + shares * last_price[symbol]

print(f"總市值：{total:,.0f}")
for symbol, shares in holdings.items():
    value = shares * last_price[symbol]
    print(f"{symbol}：{value:>10,.0f} 元，權重 {value / total:.1%}")
```

輸出：

```
總市值：700,000
0050：   301,000 元，權重 43.0%
2330：   294,000 元，權重 42.0%
2317：   105,000 元，權重 15.0%
```

> 💡 `.items()` 每次給你一組（鍵, 值）；另外還有 `.keys()`（只有鍵）和 `.values()`（只有值）。
> （以上價格是為了練習而設的假設數字。）

### 6. ⭐ 串列裡放字典：交易紀錄表

把 7.6 的交易日誌變成程式可以處理的格式——**每一筆交易是一個字典，所有交易放在一個串列裡**：

```python
trades = [
    {"symbol": "2330", "entry": 950, "exit": 1010, "shares": 100},
    {"symbol": "0050", "entry": 152, "exit": 148,  "shares": 1000},
    {"symbol": "2317", "entry": 100, "exit": 108,  "shares": 500},
]

pnls = [(t["exit"] - t["entry"]) * t["shares"] for t in trades]
print(pnls)
print(f"總損益：{sum(pnls):,} 元")
print(f"勝率：{len([p for p in pnls if p > 0]) / len(pnls):.0%}")
```

輸出：

```
[6000, -4000, 4000]
總損益：6,000 元
勝率：67%
```

> 🔑 這其實就是一張**表格**：每個字典是一列，每個鍵是一欄。下一個問題自然是——有沒有更方便處理表格的工具？有，就是 9.8 的 **pandas DataFrame**。

### 7. 為什麼之後要改用 NumPy 和 pandas？

```python
# ⚠️ 這段會出錯（示範用）：串列不能直接做數學運算
prices = [100, 102, 101]
print(prices * 1.1)
```

| 想做的事 | 用串列 | 用 NumPy / pandas |
|---|---|---|
| 所有價格乘以 1.1 | 要寫迴圈 | `prices * 1.1` |
| 算每日報酬 | 串列生成式 | `close.pct_change()` |
| 5 日均線 | 迴圈 + 切片 | `close.rolling(5).mean()` |
| 速度（大量資料） | 慢 | 快很多 |

> 🛒 串列與字典是 Python 的基本功，**理解它們才看得懂後面的工具**；但處理大量價格資料時，我們會改用專門的工具。

---

## 📌 重點整理

1. **串列** = 購物清單：有順序，用位置找（從 0 開始；`-1` 是最後一個）。
2. **切片** `lst[a:b]` 包含 a、不包含 b；`lst[-20:]` 是最近 20 筆。
3. 小心「**差一個**」的錯誤，用手算驗證第一個值。
4. **串列生成式**：`[運算 for x in 串列 if 條件]`。
5. **字典** = 電話簿：用鍵查值；`.get()` 查不到不會報錯；`.items()` 走訪。
6. **串列裡放字典** = 一張表格（交易紀錄）→ 下一步就是 pandas。

> 「串列就像購物清單，有順序，可以說『第一項』、『最後一項』、『最後三項』。每天的收盤價就很適合放在串列裡，要算 5 日均線，就切出最後 5 個價格來平均。要注意 Python 從 0 開始數，而且切片不包含結尾，很容易差一個。
>
> 字典就像電話簿，不看順序，用名字查。例如『0050 → 2000 股』、『2330 → 300 股』，要知道 2330 有幾股，直接查就好。
>
> 把每一筆交易寫成一個字典，再放進串列裡，就變成一張交易紀錄表。不過處理大量資料時，會改用 pandas，它就像超強版的 Excel。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「`prices[1]` 是第一個元素」 | 第一個是 `prices[0]`；`prices[1]` 是第二個。 |
| 「`prices[2:5]` 包含位置 5」 | 切片不包含結束位置，只有 2、3、4。 |
| 「字典用 `d[key]` 查不到會回傳空值」 | 會出現 KeyError；要安全查詢用 `d.get(key, 預設值)`。 |
| 「串列可以直接乘以 1.1」 | 串列不支援這種數學運算；要用迴圈、生成式，或改用 NumPy。 |

## ✅ 自我測驗

**Q1. 串列和字典分別適合存什麼樣的資料？**

<details><summary>看答案</summary>

串列適合有順序、用位置存取的資料，例如每日收盤價、一串 R 倍數；字典適合「名稱對應值」的資料，例如股票代號對應股數、參數名稱對應參數值。

</details>

**Q2. 為什麼練習 1 第 4 題要「不含今天」？**

<details><summary>看答案</summary>

突破規則是「今天收盤價 > 過去 N 日最高價」。如果過去 N 日的範圍包含今天，今天的收盤價永遠不可能大於包含自己在內的最高價（最多相等），訊號就永遠不會出現。所以要用 `prices[-6:-1]` 這種不含今天的切片（對應 pandas 中的 `shift(1)`，9.9 會教）。

</details>

**Q3. 練習 1 參考答案**

<details><summary>看答案</summary>

1. `prices[-3:]` → `[56, 58, 57]`（最後 3 個：位置 7、8、9）
2. `prices[2:6]` → `[49, 52, 53, 55]`
3. `max(prices)` → `58`
4. `max(prices[-6:-1])` → 位置 4～8 的 `[53, 55, 54, 56, 58]`，最高 `58`

</details>
