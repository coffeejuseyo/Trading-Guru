## 📖 開場故事：超強化版的 Excel

小芳在公司負責整理銷售報表。她每天打開 Excel：

- 篩選「台北店」→ 按好幾下滑鼠
- 新增一欄「毛利 = 營收 − 成本」→ 輸入公式、往下拉

- 隔天資料更新了 → **全部重做一次**

後來她學了 pandas，把這些步驟寫成幾行程式。資料更新時，**按一下執行，所有報表自動重做**；資料有 100 萬列也不會當機。

> 📊 **pandas 就是超強化版的 Excel**：一張有欄位名稱、有索引（列名稱）的表格叫做 **DataFrame**；其中一欄叫做 **Series**。Excel 能做的篩選、公式、樞紐分析，pandas 都能做，而且可以**重複執行、處理大量資料、不會手滑**。

## 🧠 正文

### 1. ⭐ 讀入資料

```python
import pandas as pd
import numpy as np

df = pd.read_csv("sample_prices.csv", parse_dates=["Date"], index_col="Date")
print(df.head())
```

輸出：

```
              Open    High     Low   Close  Volume
Date
2021-01-04  100.63  101.38  100.53  101.28   17815
2021-01-05  101.49  103.69  101.37  103.34   16210
2021-01-06  103.11  105.21  102.66  104.81   10866
2021-01-07  105.31  106.14  103.05  103.64   12596
2021-01-08  103.69  103.84  101.95  101.96   11658
```

| 參數 | 意思 |
|---|---|
| `parse_dates=["Date"]` | 把 Date 欄位轉成**日期型別**（而不是普通文字） |
| `index_col="Date"` | 把 Date 設為**索引**（每一列的名字） |

> 🔑 **金融資料的標準格式：日期當索引，每一欄是一個欄位**（開高低收量）。把日期設為索引後，就可以用日期來選資料、做時間序列計算（9.9）。

### 2. 快速檢視資料

```python
print(df.shape)         # (列數, 欄數)
print(df.tail(3))       # 最後 3 列
df.info()               # 欄位型別、有沒有缺值
print(df.describe().round(2))   # 各欄位的統計摘要
```

`df.shape` 輸出 `(780, 5)`：780 個交易日、5 個欄位。

`df.describe()` 的輸出（節錄）：

```
         Open    High     Low   Close    Volume
count  780.00  780.00  780.00  780.00    780.00
mean   116.63  117.59  115.74  116.67  14356.42
std     12.43   12.52   12.32   12.44   4975.42
min     92.13   93.38   91.69   92.35   3331.00
max    150.01  150.02  148.23  149.01  34107.00
```

> 💡 **拿到新資料的第一件事：先看 `head`、`tail`、`info`、`describe`**。檢查日期範圍對不對、有沒有缺值（`info` 的 Non-Null Count）、有沒有不合理的數字（例如負的價格、成交量為 0）。9.11 會深入討論資料清理。

### 3. ⭐ 選取欄位

```python
close = df["Close"]             # 一欄 → Series
print(type(close))
print(close.head(3))

print(df[["Open", "Close"]].head(3))   # 多欄 → DataFrame（注意是兩層中括號）
```

| 寫法 | 得到 | 比喻 |
|---|---|---|
| `df["Close"]` | **Series**（一欄，帶著日期索引） | Excel 的一整欄 |
| `df[["Open", "Close"]]` | **DataFrame**（多欄） | 隱藏其他欄後的表格 |

> ⚠️ **欄位名稱大小寫要完全一樣**：`df["close"]` 會出現 `KeyError`，因為欄位叫 `Close`。

### 4. ⭐ 選取列：loc 與 iloc

| 方法 | 用什麼選 | 例子 |
|---|---|---|
| `df.loc[...]` | **標籤**（日期、欄位名稱） | `df.loc["2022-03-01", "Close"]` |
| `df.iloc[...]` | **位置**（第幾列、第幾欄，從 0 開始） | `df.iloc[0]`、`df.iloc[-1]` |

```python
print(df.loc["2022-03-01", "Close"])        # 某一天的收盤價
print(df.loc["2022-03-01":"2022-03-04"])    # 一段日期（包含頭尾！）
print(df.iloc[-1]["Close"])                 # 最後一列的收盤價
print(df.loc["2022"].shape)                 # 只取 2022 年
```

輸出（節錄）：

```
121.98
              Open    High     Low   Close  Volume
Date
2022-03-01  120.08  122.19  119.90  121.98   11726
2022-03-02  121.78  122.08  120.61  120.94   12041
2022-03-03  119.99  122.72  119.87  122.30   13440
2022-03-04  122.54  123.27  122.53  122.58   23541
126.97
(260, 5)
```

> ⚠️ **用 `loc` 做日期切片時，頭尾都包含**；但用 `iloc` 做位置切片時，和串列一樣**不包含結尾**。這是 pandas 新手常搞混的地方。

### 5. ⭐ 新增欄位：整欄一起算

```python
df["Return"] = df["Close"].pct_change()       # 每日報酬
df["Range"] = df["High"] - df["Low"]          # 當日高低價差
df["Up"] = df["Close"] > df["Open"]           # 收紅 K？（True / False）
print(df[["Close", "Return", "Range", "Up"]].head(4).round(4))
```

輸出：

```
             Close  Return  Range     Up
Date
2021-01-04  101.28     NaN   0.85   True
2021-01-05  103.34  0.0203   2.32   True
2021-01-06  104.81  0.0142   2.55   True
2021-01-07  103.64 -0.0112   3.09  False
```

> 💡 `pct_change()` = 「今天 ÷ 昨天 − 1」，就是 9.7 的 `prices[1:] / prices[:-1] - 1`，但會**保留日期索引**並在第一天填入 `NaN`（Not a Number，代表「沒有值」，因為第一天沒有前一天）。

### 6. ⭐⭐ shift()：取得前一天的值

`shift(1)` 把整欄**往下移一格**，讓每一列都能看到「前一天」的值：

```python
df["PrevClose"] = df["Close"].shift(1)
df["Gap"] = df["Open"] / df["PrevClose"] - 1     # 開盤跳空幅度（回想 1.10）
print(df[["Close", "PrevClose", "Open", "Gap"]].head(4).round(4))
```

輸出：

```
             Close  PrevClose    Open     Gap
Date
2021-01-04  101.28        NaN  100.63     NaN
2021-01-05  103.34     101.28  101.49  0.0021
2021-01-06  104.81     103.34  103.11 -0.0022
2021-01-07  103.64     104.81  105.31  0.0048
```

| 寫法 | 意思 | 用途 |
|---|---|---|
| `shift(1)` | 前一天的值 | 昨收、昨天的訊號 |
| `shift(-1)` | **明天**的值 | ⚠️ 只能用來計算「事後的結果」，**絕對不能**拿來產生今天的訊號 |

> 🔑 **為什麼 shift 是回測中最重要的函式之一？** 回想 8.1：收盤後才知道訊號，隔天開盤才能下單。在 pandas 中，就是「今天算出的訊號，要 `shift(1)` 到明天才能用」。Phase 10 會反覆用到這個觀念。`shift(-1)` 就是偷看明天——前視偏差的頭號來源。

### 7. ⭐ 條件篩選

```python
big_drop = df[df["Return"] < -0.025]          # 單日跌超過 2.5%
print(len(big_drop))
print(big_drop[["Close", "Return"]].head(3).round(4))
```

輸出：

```
15
             Close  Return
Date
2021-05-26  110.57 -0.0292
2021-06-02  109.40 -0.0289
2021-07-08  100.56 -0.0334
```

**多個條件：用 `&`（且）、`|`（或），每個條件要加括號**

```python
vol_avg = df["Volume"].mean()
strong = df[(df["Return"] > 0.02) & (df["Volume"] > vol_avg * 1.5)]
print(f"漲超過 2% 且爆量的天數：{len(strong)}")
```

輸出：`漲超過 2% 且爆量的天數：6`

> ⚠️ 在 pandas 中**不能用 `and`、`or`**，要用 `&`、`|`，而且**每個條件都要用括號包起來**，否則會出現錯誤或得到錯的結果。
>
> ⚠️ 上面用「全期間的平均成交量」只是為了示範篩選。在回測中，這樣做會用到**未來的資料**（2023 年的成交量影響了 2021 年的判斷）——應該用 9.9 的 rolling 計算「過去 20 日均量」。

### 8. 統計、排序與分組

```python
print(df["Return"].describe().round(4))
print(f"上漲天數比例：{(df['Return'] > 0).mean():.1%}")

print(df.sort_values("Return").head(3)[["Close", "Return"]].round(4))   # 跌最多的 3 天
```

**分組統計：每一年的報酬特性**

```python
yearly = df.groupby(df.index.year)["Return"].agg(["mean", "std", "count"])
print(yearly.round(4))
```

輸出：

```
        mean     std  count
Date
2021  0.0004  0.0118    259
2022  0.0005  0.0122    260
2023  0.0002  0.0123    260
```

> 📊 `groupby` 就是 Excel 的**樞紐分析表**：依某個欄位分組（這裡是年份），再對每組做統計。`df.index.year` 從日期索引中取出年份。

**每年年底收盤價與年報酬：**

```python
year_end = df["Close"].groupby(df.index.year).last()
print(year_end)
print(year_end.pct_change().round(4))
```

輸出：

```
Date
2021    111.51
2022    123.31
2023    126.97
Name: Close, dtype: float64
Date
2021       NaN
2022    0.1058
2023    0.0297
Name: Close, dtype: float64
```

### 9. 累積報酬與存檔

```python
df["Growth"] = (1 + df["Return"]).cumprod()   # 第一天是 NaN，cumprod 會略過
print(f"期間累積報酬：{df['Growth'].iloc[-1] - 1:.2%}")
print(f"驗算：{df['Close'].iloc[-1] / df['Close'].iloc[0] - 1:.2%}")

```

輸出：

```
期間累積報酬：25.37%

```

> 💡 `to_csv` 會把整個 DataFrame（含新增的欄位）存成檔案，可以用 Excel 打開檢查。**用 Excel 抽查幾列手算的結果**，是驗證程式最簡單的方法。

### 10. pandas 常用語法速查

| 想做的事 | 寫法 |
|---|---|
| 讀 CSV | `pd.read_csv("檔名", parse_dates=["Date"], index_col="Date")` |
| 前 / 後幾列 | `df.head(n)`、`df.tail(n)` |
| 列數、欄數 | `df.shape` |
| 選一欄 / 多欄 | `df["Close"]`、`df[["Open", "Close"]]` |
| 用標籤 / 位置選 | `df.loc[日期, 欄位]`、`df.iloc[列, 欄]` |
| 某一年 / 某段期間 | `df.loc["2022"]`、`df.loc["2022-01":"2022-06"]` |
| 每日報酬 | `df["Close"].pct_change()` |
| 前一天的值 | `df["Close"].shift(1)` |
| 條件篩選 | `df[(條件1) & (條件2)]` |
| 排序 | `df.sort_values("欄位", ascending=False)` |
| 分組統計 | `df.groupby(df.index.year)["欄位"].mean()` |
| 存檔 | `df.to_csv("檔名")` |

## 📌 重點整理

1. **DataFrame** = 超強 Excel 表格；**Series** = 其中一欄；金融資料用**日期當索引**。
2. 拿到資料先看 `head`、`tail`、`shape`、`info`、`describe`。
3. `loc` 用**標籤**（日期切片頭尾都包含）、`iloc` 用**位置**（不含結尾）。
4. 新增欄位整欄一起算：`pct_change()`、相減、比較。
5. **`shift(1)` = 前一天**，是避免前視偏差的核心工具；**`shift(-1)` 是偷看明天**。
6. 條件篩選用 `&`、`|` 並加括號；注意**不要用到未來資料**（例如全期平均）。
7. `groupby` = 樞紐分析表；`to_csv` 存檔後用 Excel 抽查驗證。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「`df.loc["2022-03-01":"2022-03-04"]` 不包含 3/4」 | `loc` 的標籤切片頭尾都包含；`iloc` 的位置切片才不含結尾。 |
| 「篩選可以寫 `df[a > 1 and b > 2]`」 | 要寫 `df[(a > 1) & (b > 2)]`，用 `&`、`|` 並加括號。 |
| 「第一天的報酬是 NaN 代表資料有問題」 | 第一天沒有前一天，所以報酬本來就無法計算，NaN 是正常的。 |
| 「用全期間的平均值當門檻沒關係」 | 回測中會用到未來資料（前視偏差）；應該用只看過去的滾動計算。 |

## ✅ 自我測驗

**Q1. `loc` 和 `iloc` 有什麼不同？**

<details><summary>看答案</summary>

`loc` 用標籤選取（例如日期、欄位名稱），標籤切片頭尾都包含；`iloc` 用位置選取（第幾列、第幾欄，從 0 開始），位置切片不包含結尾。

</details>

**Q2. 為什麼說 `shift(1)` 是避免前視偏差的核心工具？`shift(-1)` 有什麼危險？**

<details><summary>看答案</summary>

`shift(1)` 把資料往後移一天，讓每一列只看到前一天（已經發生）的資訊。因為收盤後才確認的訊號只能在隔天執行，所以今天算出的訊號要 shift(1) 才能對應到實際交易的那一天。`shift(-1)` 則把明天的資料移到今天，若拿來產生訊號，就等於偷看未來，回測績效會被嚴重高估。

</details>

**Q3. 練習 4 的 bug 是什麼？怎麼修？**

<details><summary>看答案</summary>

`rolling(20).max()` 的 20 日視窗**包含今天**，所以今天的收盤價最多只能「等於」20 日最高價，`>` 永遠不會成立，結果會是 0 筆。應該比較「不含今天的過去 20 日最高價」：

```python
df["High20"] = df["Close"].rolling(20).max().shift(1)
signal = df[df["Close"] > df["High20"]]
```

（rolling 會在 9.9 詳細介紹。）

</details>
