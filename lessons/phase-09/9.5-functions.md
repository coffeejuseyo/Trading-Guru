# 9.5｜函式：把常用步驟包成一個按鈕

## 🎯 學完你會知道

- **函式**是什麼，為什麼要用它
- 用 `def` 定義函式、用 `return` 回傳結果
- **參數**與**預設值**；用名稱指定參數
- 回傳**多個值**
- **說明文字（docstring）**與**區域變數**的概念
- 把部位計算、交易成本、最大回撤寫成可以重複使用的函式
- 用「**小例子測試**」確認函式正確

---

## 📖 開場故事：微波爐的按鈕

微波爐上有一個「**爆米花**」按鈕。按一下，它就會自動：

1. 用高火加熱 2 分 30 秒
2. 中途轉盤持續旋轉
3. 結束時嗶三聲

你不需要每次都記住「高火、2 分 30 秒」，只要按一個按鈕。而且有些按鈕可以**調整**：「解凍」按鈕會問你「幾克？」，你輸入 500，它就自動算出要解凍多久。

> 🔘 **函式就是把一串步驟包成一個按鈕**：取一個名字（爆米花），需要時按一下（呼叫函式），可以給它不同的輸入（解凍幾克 → **參數**），它會給你結果（**回傳值**）。寫一次，到處都能用。

## 🧠 正文

### 1. 為什麼需要函式？

9.2 的部位計算機每次換股票都要改數字、重新執行。如果要一次算 50 檔股票呢？

| 沒有函式 | 有函式 |
|---|---|
| 同樣的程式複製貼上 50 次 | 寫一次，呼叫 50 次 |
| 發現公式錯了，要改 50 個地方 | 只要改一個地方 |
| 程式很長，很難讀 | `position_size(...)` 一看就知道在做什麼 |

### 2. ⭐ 定義與呼叫函式

```python
def pct_change(old, new):
    return new / old - 1

r = pct_change(50, 56)
print(f"{r:.2%}")
print(f"{pct_change(100, 92):.2%}")
```

輸出：

```
12.00%
-8.00%
```

| 部分 | 意思 | 微波爐比喻 |
|---|---|---|
| `def` | 定義（define）一個函式 | 設計一個新按鈕 |
| `pct_change` | 函式名稱 | 按鈕上的字 |
| `(old, new)` | **參數**：函式需要的輸入 | 解凍要輸入幾克 |
| `return` | **回傳**結果，並結束函式 | 嗶三聲，把食物拿給你 |
| `pct_change(50, 56)` | **呼叫**函式 | 按下按鈕 |

> ⚠️ **`print` 和 `return` 不一樣**：`print` 只是把結果「顯示在螢幕上」，`return` 是把結果「交回給呼叫的人」，讓你可以存進變數、繼續計算。函式裡沒有 `return`，呼叫的結果會是 `None`（什麼都沒有）。

### 3. ⭐ 參數預設值與部位計算函式

```python
def position_size(capital, entry, stop, risk_pct=0.01, max_pct=0.20):
    """計算股數：依每筆風險 % 與單一部位上限，取較小者。"""
    risk_per_share = entry - stop
    if risk_per_share <= 0:
        return 0                                  # 停損價不在進場價下方：不交易
    shares = int(capital * risk_pct / risk_per_share)
    max_shares = int(capital * max_pct / entry)
    return min(shares, max_shares)

print(position_size(1_000_000, 52.3, 49.8))                  # 用預設的 1% 風險
print(position_size(1_000_000, 52.3, 49.8, risk_pct=0.005))  # 改成 0.5%
print(position_size(1_000_000, 120, 110))
print(position_size(1_000_000, 50, 52))                      # 停損價寫錯
```

輸出：

```
3824
2000
1000
0
```

| 技巧 | 說明 |
|---|---|
| **預設值** `risk_pct=0.01` | 沒有指定時就用 1%；要改再指定 |
| **用名稱指定** `risk_pct=0.005` | 不用記參數的順序，也比較好讀 |
| **說明文字** `"""..."""` | 寫在函式第一行，說明它做什麼（叫做 docstring） |
| **防呆** `if risk_per_share <= 0` | 處理不合理的輸入，避免算出負的股數 |

> 🔑 第一個結果是 3,824 股而不是 4,000 股：因為 4,000 股會超過單一部位上限 20%（9.3 第 5 節）。函式把這個規則**永遠記住了**，不會因為你忘記而出錯。

### 4. 交易成本函式

回想 2.4：買進付手續費，賣出付手續費 + 交易稅。

```python
def trade_cost(price, shares, side, fee_rate=0.001425, discount=0.6,
               tax_rate=0.003, min_fee=20):
    """計算單筆交易成本（手續費 + 賣出時的交易稅），單位：元。"""
    value = price * shares
    fee = max(int(value * fee_rate * discount), min_fee)   # 手續費有最低收費
    tax = int(value * tax_rate) if side == "sell" else 0
    return fee + tax

print(trade_cost(52.3, 3824, "buy"))
print(trade_cost(55, 3824, "sell"))
print(trade_cost(10, 100, "buy"))      # 小額交易：碰到最低手續費
```

輸出：

```
170
809
20
```

> 💡 `tax = ... if ... else 0` 是 if / else 的**一行寫法**：條件成立取前面的值，否則取 `else` 後面的值。
>
> ⚠️ 手續費率、折扣、最低收費、交易稅率（例如 ETF、當沖的稅率不同）**以券商與政府最新規定為準**；寫成參數的好處是，規定改了只要改預設值。

### 5. 回傳多個值

```python
def trade_pnl(entry, exit_price, shares):
    """回傳（損益金額, 報酬率）。"""
    pnl = (exit_price - entry) * shares
    ret = exit_price / entry - 1
    return pnl, ret

pnl, ret = trade_pnl(52.3, 55, 3824)
print(f"損益 {pnl:,.0f} 元，報酬 {ret:.2%}")
```

輸出：`損益 10,325 元，報酬 5.16%`

### 6. ⭐ 把迴圈包進函式：最大回撤

```python
def max_drawdown(equity):
    """輸入資金曲線（一串數字），回傳最大回撤（負數）。"""
    peak = equity[0]
    mdd = 0
    for v in equity:
        peak = max(peak, v)
        mdd = min(mdd, v / peak - 1)
    return mdd

print(f"{max_drawdown([100, 110, 105, 120, 96, 100, 130]):.1%}")
```

輸出：`-20.0%`（從 120 跌到 96）

> 💡 `max(a, b)` 取較大者、`min(a, b)` 取較小者，可以取代 9.4 中的 `if v > peak: peak = v`，更簡潔。

### 7. ⭐ 測試你的函式

寫好函式後，用**答案已知的小例子**檢查：

```python
assert abs(pct_change(100, 110) - 0.1) < 1e-9          # 小數比較要容許誤差（9.2）
assert position_size(100_000, 10, 9) == 1000            # 風險 1,000 元 ÷ 每股 1 元
assert position_size(100_000, 10, 9, max_pct=0.05) == 500   # 被上限擋住
assert max_drawdown([100, 50, 100]) == -0.5
assert max_drawdown([100, 110, 120]) == 0
print("全部測試通過 ✅")
```

`assert 條件` 的意思是「我確定這個條件成立；如果不成立就報錯」。

> 🔑 **這是寫回測程式最重要的習慣之一**：每寫一個函式，就用幾個手算得出答案的例子測試，包括**邊界情況**（沒有回撤、停損價寫錯、碰到上限）。一個錯誤的函式被用在上千筆交易裡，錯誤會被放大上千倍。

### 8. 區域變數：函式裡的盒子是私人的

```python
def calc():
    temp = 123       # 這個 temp 只存在於函式裡面
    return temp * 2

print(calc())
# print(temp)   → 會出現 NameError：函式外面看不到 temp
```

> 🔘 就像微波爐內部的計時器，你在外面看不到它，也不需要知道。**函式需要的東西，用參數傳進去；函式產生的結果，用 return 傳出來。** 這樣函式才不會互相干擾。

---

## 📌 重點整理

1. 函式 = **把步驟包成按鈕**：寫一次、到處用、改一處就全部更新。
2. `def 名稱(參數):` 定義、`return` 回傳；**print 是顯示，return 是交回結果**。
3. **預設值**讓常用設定不必每次輸入；用**名稱指定**參數更好讀。
4. 可以回傳多個值：`pnl, ret = trade_pnl(...)`。
5. 寫說明文字、加**防呆**處理不合理輸入。
6. 用 `assert` 和**已知答案的小例子**測試函式，包括邊界情況。
7. 函式內的變數是**區域變數**；輸入靠參數、輸出靠 return。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「函式裡 print 出結果就等於回傳了」 | print 只是顯示；要用 return 才能把結果交給呼叫者繼續使用。 |
| 「函式寫好能執行就沒問題」 | 要用已知答案的例子與邊界情況測試，邏輯錯誤不會自動報錯。 |
| 「函式裡可以直接用外面的變數，很方便」 | 依賴外部變數容易出錯；需要的值應該用參數傳入。 |
| 「參數越多越好，越有彈性」 | 常用設定給預設值，保持呼叫簡單；太多參數反而難用。 |

## ✅ 自我測驗

**Q1. print 和 return 有什麼不同？**

<details><summary>看答案</summary>

print 只是把值顯示在螢幕上，程式無法再使用這個結果；return 會把值交回給呼叫函式的地方，可以存進變數、繼續運算，並且會結束函式的執行。沒有 return 的函式會回傳 None。

</details>

**Q2. 為什麼要用 assert 測試函式？測試時要注意什麼？**

<details><summary>看答案</summary>

因為邏輯錯誤不會自動報錯，而回測程式中的一個錯誤函式會被重複使用上千次，錯誤會被放大。用已知答案的小例子驗證，可以及早發現錯誤。要注意涵蓋一般情況與邊界情況（例如沒有回撤、停損價不合理、碰到部位上限）。

</details>

**Q3. 練習 1 參考答案**

<details><summary>看答案</summary>

```python
def r_multiple(entry, exit_price, stop):
    risk = entry - stop
    return (exit_price - entry) / risk

assert r_multiple(100, 110, 95) == 2.0
assert r_multiple(100, 95, 95) == -1.0
assert r_multiple(100, 100, 95) == 0
```

（進階：可以加上防呆，`risk <= 0` 時回傳 None 或報錯。）

</details>
