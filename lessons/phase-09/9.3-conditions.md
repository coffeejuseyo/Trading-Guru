## 📖 開場故事：出門前的判斷

每天早上出門前，你會在腦中跑一段「程式」：

> 如果下雨 → 帶傘
> 否則如果很熱 → 戴帽子
> 否則 → 什麼都不帶

你可能沒意識到，但你每天都在做**條件判斷**。而且**順序很重要**：如果又下雨又很熱，你會先帶傘（第一個條件成立就執行，後面就不看了）。

> ☂️ **if / else 就是教機器人做判斷**：「如果條件成立，就做 A；否則做 B」。Phase 8 寫的每一條進場、出場規則，本質上都是一連串的 if。

---

## 🧠 正文

### 1. 比較運算子：結果是 True 或 False

| 運算子 | 意思 | 例子 | 結果 |
|---|---|---|---|
| `>` | 大於 | `103.5 > 98.2` | `True` |
| `<` | 小於 | `7.5 < 10` | `True` |
| `>=` | 大於等於 | `10 >= 10` | `True` |
| `<=` | 小於等於 | `9 <= 10` | `True` |
| `==` | 等於 | `"0050" == "0050"` | `True` |
| `!=` | 不等於 | `5 != 3` | `True` |

```python
close = 103.5
ma200 = 98.2
print(close > ma200)
print(close == ma200)
```

> ⚠️ **`=` 和 `==` 不一樣**：`=` 是指派（裝進盒子），`==` 是比較（問「是否相等」）。這是新手最常見的錯誤之一。

### 2. ⭐ if / elif / else

```python
close = 103.5
ma200 = 98.2

if close > ma200:
    print("多頭：價格在 200 日均線上方")
else:
    print("空頭：價格在 200 日均線下方")
```

**三個規則：**

| 規則 | 說明 |
|---|---|
| ① **冒號** | `if` 條件的最後要加 `:` |
| ② **縮排** | 條件成立時要做的事，要往右縮排（建議 4 個空格） |
| ③ **縮排一致** | 同一層的程式，縮排要對齊 |

> 🔑 **縮排在 Python 裡不是為了好看，而是語法的一部分**：它告訴機器人「哪些步驟屬於這個條件」。就像食譜中的「如果是素食者：」下面縮排的步驟，只有素食者才要做。

**多個條件：elif**

```python
rsi = 25

if rsi < 30:
    print("超賣")
elif rsi > 70:
    print("超買")
else:
    print("中性")
```

### 3. ⭐ 邏輯運算子：組合條件

| 運算子 | 意思 | 生活例子 |
|---|---|---|
| `and` | 兩個都要成立 | 「有空**而且**有錢，才去旅行」 |
| `or` | 其中一個成立就好 | 「下雨**或**很冷，就搭計程車」 |
| `not` | 反過來 | 「**不是**假日，就要上班」 |

**把 8.5 的 RSI(2) 回檔進場規則寫成程式：**

```python
close = 103.5
ma200 = 98.2
rsi2 = 7.5

if close > ma200 and rsi2 < 10:
    print("買進訊號：隔天開盤買進")
else:
    print("沒有訊號")
```

**出場條件常用 or：**

```python
close = 101.2
ma5 = 100.8
stop_price = 96.0
days_held = 4

if close < stop_price or close > ma5 or days_held >= 10:
    print("出場")
else:
    print("繼續持有")
```

> 💡 條件很長時，可以先把每個條件存成有意義的變數，程式會更好讀：

```python
close = 101.2
ma5 = 100.8
stop_price = 96.0
days_held = 4

hit_stop = close < stop_price
hit_target = close > ma5
time_out = days_held >= 10

if hit_stop or hit_target or time_out:
    print("出場")
```

### 4. ⭐ 條件的順序很重要

if / elif 會**由上往下**檢查，**第一個成立的就執行，後面的就跳過**。

```python
def check_signal(close, ma200, rsi2):
    if close <= ma200:
        return "不交易：在 200 日均線下方"
    elif rsi2 < 10:
        return "買進訊號"
    elif rsi2 > 90:
        return "過熱，不追"
    else:
        return "觀望"

print(check_signal(95, 98, 5))
print(check_signal(103, 98, 5))
print(check_signal(103, 98, 95))
print(check_signal(103, 98, 50))
```

輸出：

```
不交易：在 200 日均線下方
買進訊號
過熱，不追
觀望
```

（`def` 和 `return` 是 9.5 會教的「函式」，現在先看懂 if 的部分就好。）

> 🔑 第一組（95, 98, 5）的 RSI(2) = 5 雖然 < 10，但因為**環境過濾**放在最前面，先被擋下了。這就是 8.1 的「環境過濾」：**先決定能不能交易，再看有沒有訊號**。如果把順序反過來，就會在空頭中接刀。

**停損優先的例子（8.13 的「同時成立」規則）：**

```python
low = 95.0          # 今天最低價
high = 112.0        # 今天最高價
stop_price = 96.0
target_price = 110.0

if low <= stop_price:
    print("觸發停損（保守假設：停損先發生）")
elif high >= target_price:
    print("觸發停利")
else:
    print("繼續持有")
```

> 💡 今天的 K 棒同時碰到了停損和停利，但日線資料無法知道哪個先發生。把停損寫在前面，就是「保守假設」。

### 5. 巢狀 if 與部位上限

if 裡面還可以再放 if（要再縮排一層）：

```python
capital = 1_000_000
entry = 52.3
shares = 4000
max_pct = 0.20

position_value = shares * entry
if position_value > capital * max_pct:
    shares = int(capital * max_pct / entry)
    print(f"超過單一部位上限，調整為 {shares} 股")
else:
    print(f"部位在上限內：{shares} 股")
```

輸出：

```
超過單一部位上限，調整為 3824 股
```

> 🔑 回想 9.2 的部位計算機：4,000 股 × 52.3 = 209,200 元，佔 20.9%，超過 20% 上限，所以要調整。

### 6. 常見錯誤

```python
# ⚠️ 這段會出錯（示範用）：少了冒號
if close > ma200
    print("多頭")
```

```python
# ⚠️ 這段會出錯（示範用）：縮排不一致
if close > ma200:
    print("多頭")
      print("價格在均線上方")
```

| 錯誤 | 訊息 | 修正 |
|---|---|---|
| 少了冒號 | `SyntaxError: expected ':'` | 在條件最後加 `:` |
| 縮排不一致 | `IndentationError: unexpected indent` | 同一層對齊（統一用 4 個空格） |
| 用 `=` 比較 | `SyntaxError` | 比較要用 `==` |
| 浮點數用 `==` | 不會報錯，但結果可能是 False | 用 `>=`、`<=` 或容許誤差（9.2） |

---

## 📌 重點整理

1. 比較運算子產生 **True / False**；`==` 是比較，`=` 是指派。
2. `if 條件:` + **縮排**；`elif` 處理更多情況；`else` 處理其他所有情況。
3. **縮排是語法**，告訴電腦哪些步驟屬於這個條件。
4. `and`（都要）、`or`（其一）、`not`（相反）組合條件；長條件先存成有意義的變數。
5. **由上往下、第一個成立就執行**：環境過濾放前面、停損放在停利前面。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「縮排只是為了好看」 | 在 Python 中縮排是語法，決定哪些程式屬於哪個條件。 |
| 「if / elif 會檢查所有條件」 | 第一個成立的就執行，後面的 elif 和 else 都會跳過。 |
| 「條件寫的順序沒關係」 | 順序會改變結果，例如環境過濾、停損優先都要放在前面。 |
| 「`if x = 5:` 可以判斷 x 是不是 5」 | 要用 `==`；`=` 是指派，會造成語法錯誤。 |

## ✅ 自我測驗

**Q1. 為什麼把環境過濾放在 if 的最前面很重要？**

<details><summary>看答案</summary>

因為 if / elif 由上往下檢查，第一個成立的條件就執行、後面就跳過。把環境過濾（例如收盤價 <= 200 日均線就不交易）放在最前面，才能確保在不允許交易的環境下，就算有進場訊號也不會買進。

</details>

**Q2. `and` 和 `or` 有什麼不同？各舉一個交易例子。**

<details><summary>看答案</summary>

`and` 需要所有條件都成立，例如「收盤價 > 200 日均線 and RSI(2) < 10」才進場；`or` 只要任一條件成立，例如「碰到停損 or 碰到目標 or 持有滿 10 天」就出場。

</details>

**Q3. 練習 2、3 參考答案**

<details><summary>看答案</summary>

練習 2：

```python
drawdown = 0.15
if drawdown >= 0.20:
    print("暫停交易，全面檢討")
elif drawdown >= 0.10:
    print("每筆風險減半")
else:
    print("正常交易")
```

0.05 → 正常交易；0.10 → 每筆風險減半；0.15 → 每筆風險減半；0.25 → 暫停交易。若先寫 `if drawdown >= 0.10`，回撤 25% 也會先符合這一條而只印出「風險減半」，永遠到不了「暫停交易」。

練習 3：`if rsi = 25` 要改成 `if rsi == 25`、最後要加冒號 `:`、`print` 那一行要縮排 4 個空格。

</details>
