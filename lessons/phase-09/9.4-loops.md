# 9.4｜迴圈：for / while

## 🎯 學完你會知道

- **for 迴圈**：對一串資料的每一個元素，重複做同樣的事
- `range()`、`enumerate()` 的用法
- **while 迴圈**：條件成立就一直重複
- `break`（提早結束）與 `continue`（跳過這一次）
- **累加器**的寫法：加總、計數、追蹤最大值
- 用迴圈計算**每日報酬、最大連虧、資金曲線、最大回撤**

---

## 📖 開場故事：洗 100 個碗

餐廳打烊後，水槽裡堆了 100 個碗。你會怎麼教機器人洗？

**笨方法**：寫 100 次「拿起碗 → 抹洗碗精 → 沖水 → 放到架上」。

**聰明的方法**：
> 對水槽裡的**每一個碗**：拿起來 → 抹洗碗精 → 沖水 → 放到架上

不管是 100 個還是 10,000 個碗，指令都一樣短。

另一種情況：
> **只要**水槽裡還有碗，就繼續洗

這次你不知道有幾個碗，但機器人會一直洗到洗完為止。

> 🍽️ **第一種是 for 迴圈**（對每一個元素做一次），**第二種是 while 迴圈**（條件成立就一直做）。回測的本質就是：**對每一天的資料，檢查一次規則**——這就是迴圈。

---

## 🧠 正文

### 1. ⭐ for 迴圈：對每一個元素做一次

```python
symbols = ["0050", "2330", "2317"]

for s in symbols:
    print(f"檢查 {s} 的訊號")
```

輸出：

```
檢查 0050 的訊號
檢查 2330 的訊號
檢查 2317 的訊號
```

| 部分 | 意思 |
|---|---|
| `for s in symbols:` | 每次從 symbols 取出一個元素，放進變數 `s` |
| 縮排的部分 | 每一次都要做的事（迴圈的「身體」） |

（`["0050", "2330", "2317"]` 叫做**串列**，9.6 會詳細介紹，現在把它想成一張清單就好。）

### 2. range()：產生一串數字

| 寫法 | 產生的數字 |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4（**不包含 5**） |
| `range(1, 5)` | 1, 2, 3, 4 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 |

```python
# 複利表：每年 7%，看 1～5 年
capital = 1_000_000
for year in range(1, 6):
    capital = capital * 1.07
    print(f"第 {year} 年：{capital:,.0f}")
```

> ⚠️ **`range(5)` 從 0 開始、不包含 5**。Python 的位置編號都從 0 開始，這是新手最常搞混的地方。

### 3. ⭐ 用迴圈計算每日報酬

```python
prices = [100, 102, 101, 105, 103, 108]

for i in range(1, len(prices)):
    r = prices[i] / prices[i - 1] - 1
    print(f"第 {i} 天：{prices[i - 1]} → {prices[i]}，報酬 {r:.2%}")
```

輸出：

```
第 1 天：100 → 102，報酬 2.00%
第 2 天：102 → 101，報酬 -0.98%
第 3 天：101 → 105，報酬 3.96%
第 4 天：105 → 103，報酬 -1.90%
第 5 天：103 → 108，報酬 4.85%
```

| 部分 | 意思 |
|---|---|
| `len(prices)` | 清單的長度（6） |
| `prices[i]` | 第 i 個位置的價格（從 0 開始數） |
| `range(1, len(prices))` | 從 1 開始，因為第 0 天沒有「前一天」 |

> 🔑 **注意 `prices[i - 1]`**：計算第 i 天的報酬，只用到第 i 天和之前的資料。回測時**絕對不能**用到 `prices[i + 1]`（明天的價格）來做今天的決定——那就是前視偏差（8.1）。

### 4. enumerate()：同時拿到位置和值

```python
symbols = ["0050", "2330", "2317"]
for i, s in enumerate(symbols):
    print(i, s)
```

### 5. ⭐ 累加器：加總、計數、追蹤最大值

迴圈最常見的用法：**先準備一個「盒子」，每次迴圈更新它**。

**範例：10 筆交易的 R 倍數**

```python
trades = [2.0, -1, -1, 2.5, -1, -1, -1, -1, 3.5, -1]

total = 0         # 加總用
wins = 0          # 計數用
for r in trades:
    total = total + r
    if r > 0:
        wins = wins + 1

print(f"總 R：{total}")
print(f"期望值：{total / len(trades):.2f} R")
print(f"勝率：{wins / len(trades):.0%}")
```

輸出：

```
總 R：1.0
期望值：0.10 R
勝率：30%
```

> 🔑 **手算驗證**：3 筆獲利 2.0 + 2.5 + 3.5 = 8，7 筆虧損共 −7，總 R = 1.0 ✅。**永遠不要相信「看起來合理」的數字**，寫完程式先用小例子手算一次。Phase 10 回測時，這個習慣能幫你抓到很多錯誤。

**範例：最大連虧筆數（回想 3.10）**

```python
trades = [2.0, -1, -1, 2.5, -1, -1, -1, -1, 3.5, -1]

streak = 0        # 目前連虧幾筆
max_streak = 0    # 最大連虧
for r in trades:
    if r < 0:
        streak = streak + 1
        if streak > max_streak:
            max_streak = streak
    else:
        streak = 0    # 賺錢就歸零

print(f"最大連虧：{max_streak} 筆")
```

輸出：`最大連虧：4 筆`

### 6. ⭐ 資金曲線與最大回撤

每筆風險 1%，把 R 倍數換算成帳戶金額（回想 6.4、6.6）：

```python
trades = [2.0, -1, -1, 2.5, -1, -1, -1, -1, 3.5, -1]
equity = 100_000
peak = equity
max_dd = 0

for r in trades:
    equity = equity + equity * 0.01 * r     # 每筆風險 = 當時資金的 1%
    if equity > peak:
        peak = equity                       # 創新高
    dd = equity / peak - 1                  # 目前回撤
    if dd < max_dd:
        max_dd = dd                         # 更新最大回撤
    print(f"R = {r:>4}，資金 {equity:,.0f}，回撤 {dd:.2%}")

print(f"最終資金：{equity:,.0f}")
print(f"最大回撤：{max_dd:.2%}")
```

> 💡 `{r:>4}` 的意思是「靠右對齊、佔 4 格」，讓輸出比較整齊。

### 7. while 迴圈：條件成立就一直做

```python
# 100 萬元，年報酬 7%，幾年會翻倍？
capital = 1_000_000
years = 0
while capital < 2_000_000:
    capital = capital * 1.07
    years = years + 1

print(f"{years} 年後翻倍，金額 {capital:,.0f}")
```

輸出：`11 年後翻倍，金額 2,104,852`

> 💡 回想「72 法則」：72 ÷ 7 ≈ 10.3 年，和程式算出的 11 年（第 11 年底才超過）一致。

> ⚠️ **無窮迴圈**：如果 while 的條件永遠成立（例如忘了寫 `capital = capital * 1.07`），程式會永遠跑不完。在 Colab 中可以按儲存格左邊的「停止」按鈕中斷。

### 8. break 與 continue

```python
prices = [100, 98, 97, 93, 95, 99]
stop_price = 94

for day, p in enumerate(prices):
    if p <= stop_price:
        print(f"第 {day} 天價格 {p}，觸發停損，出場")
        break                       # 提早結束整個迴圈
    print(f"第 {day} 天價格 {p}，繼續持有")
```

```python
volumes = [1200, 0, 1500, 0, 1800]
for v in volumes:
    if v == 0:
        continue                    # 跳過這一次（例如停牌沒有成交），繼續下一個
    print(f"成交量 {v}")
```

| 指令 | 意思 | 比喻 |
|---|---|---|
| `break` | 立刻結束整個迴圈 | 發現碗破了，整個停下來 |
| `continue` | 跳過這一次，直接下一個 | 這個碗已經乾淨了，跳過 |

> 🔑 **預告**：用 for 迴圈一天一天跑回測很直覺，但資料一多就會變慢。9.7～9.8 會教你用 NumPy 和 pandas「一次處理整排資料」，速度可以快上百倍。不過**理解迴圈的邏輯**仍然很重要，Phase 10 的事件驅動回測就是用迴圈的概念。

---

## 📌 重點整理

1. **for** = 對每個元素做一次（洗每一個碗）；**while** = 條件成立就一直做（還有碗就繼續洗）。
2. `range(a, b)` 從 a 到 b−1；**位置從 0 開始**。
3. **累加器**：先準備變數，迴圈中更新——加總、計數、追蹤最大值。
4. 用迴圈可以計算每日報酬、最大連虧、資金曲線、最大回撤。
5. 計算第 i 天時只能用 `i` 和之前的資料，**不能偷看 `i + 1`**。
6. `break` 結束迴圈、`continue` 跳過這一次；小心 while 的**無窮迴圈**。
7. **永遠用小例子手算驗證程式的結果。**

> 「迴圈就像教機器人洗碗：不用寫 100 次『拿碗、抹洗碗精、沖水』，只要說『對水槽裡的每一個碗做這些事』。for 迴圈是對清單裡每個東西做一次，while 迴圈是只要條件成立就一直做，例如『只要資金還沒翻倍，就再過一年』。
>

>
> 最重要的一點：算今天的時候只能用今天和以前的資料，不能偷看明天，不然就是作弊。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「`range(5)` 會產生 1 到 5」 | 產生 0 到 4；從 0 開始、不包含結尾。 |
| 「程式執行沒有報錯，結果就是對的」 | 沒有報錯只代表語法正確；邏輯可能錯，要用小例子手算驗證。 |
| 「回測一定要用迴圈一天一天跑」 | 很多回測可以用 pandas 一次算整欄（向量化），速度快很多（Phase 10）。 |
| 「while 迴圈會自己停下來」 | 條件永遠成立時會變成無窮迴圈，要確保迴圈中有改變條件的步驟。 |

## ✅ 自我測驗

**Q1. for 迴圈和 while 迴圈的差別？各舉一個例子。**

<details><summary>看答案</summary>

for 迴圈對一串資料的每一個元素各做一次，次數由資料長度決定，例如對每檔股票檢查訊號、對每天的價格計算報酬。while 迴圈在條件成立時一直重複，次數事先不知道，例如「資金還沒翻倍就再複利一年」。

</details>

**Q2. 計算最大回撤時需要追蹤哪兩個值？**

<details><summary>看答案</summary>

1. 到目前為止的最高點（peak），每次創新高就更新；2. 最大回撤（max_dd），每次計算目前回撤 = 目前資金 ÷ peak − 1，若比目前記錄的最大回撤更深就更新。

</details>

**Q3. 練習 2 參考答案**

<details><summary>看答案</summary>

逐日追蹤最高價與移動停損（最高價 − 2.5，但不低於初始停損 47.5）：最高價在第 4 天（從 0 開始數）來到 53，移動停損變成 50.5。第 6 天價格 50.5 ≤ 50.5，觸發停損出場，出場價 50.5，每股賺 0.5 元。（若規則是「跌破」才出場，即 `<` 而非 `<=`，則第 7 天以 49.2 出場、每股虧 0.8 元——這就是規格書要寫清楚「觸及」還是「跌破」的原因，8.13。）

</details>
