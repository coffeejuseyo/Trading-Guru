# Phase 8｜策略工具箱：主流交易策略

> **預計時數：50 小時**（13 個單元）
> **生活比喻：衝浪（順著浪走 = 趨勢跟隨）vs. 橡皮筋（拉太遠會彈回來 = 均值回歸）。不同的海況要用不同的方法。**

你在 M2 寫了一份交易計畫書，但其中的「策略」還只是雛形。這個階段要打開完整的**策略工具箱**：

- 每一種主流策略的**邏輯**：它為什麼可能有效？優勢從哪裡來？
- 它的**適用環境**：什麼市場狀態下表現好？什麼時候會連續虧損？
- 它的**典型規則**：可以直接拿去 Phase 10 回測的具體範例
- 它的**弱點**：最大的風險是什麼？

最後，你會學會寫一份**策略規格書**：清楚到「別人照著做，會得到一模一樣的交易」。

> 🔑 **本階段介紹的所有策略規則，都是「待驗證的範例」，不是「保證賺錢的方法」。** 回想 4.13：任何規則都要經過回測、樣本外測試、模擬交易驗證。Phase 9～10 會教你用 Python 親手驗證它們。
