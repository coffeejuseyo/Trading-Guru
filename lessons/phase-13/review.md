## 🗺️ 整個課程的觀念地圖

```
  【核心問題】在充滿不確定的市場中，如何用有優勢的方法、可承受的風險，持續地做出好決定？
                                      │
  了解戰場        Phase 1 市場地圖、Phase 2 遊戲規則（成本、委託、帳戶）
  量化不確定      Phase 3 期望值 = 勝率 × 賠率；虧 50% 要賺 100%；大數法則、連虧
  尋找線索        Phase 4 技術分析、Phase 5 基本面與總經
  控制風險        Phase 6 停損、部位大小（每筆 1% 左右）、回撤、破產風險
  管好自己        Phase 7 心理偏誤、交易計畫、日誌、照規則的虧損是好交易
  找到優勢        Phase 8 優勢從哪裡來；趨勢、均值回歸、動能、因子；策略規格書
  證明優勢        Phase 9 Python → Phase 10 回測（成本、前視、倖存者、過度擬合、樣本外）
                  Phase 11 組合、蒙地卡羅、多重檢定、研究流程
  上場            Phase 12 計畫書 → 模擬 3 個月 → 遵守率 > 90% → 小額實盤 → 階梯加碼
  傳承            Phase 13 知識地圖、10 分鐘簡報、教會朋友、研究報告
```

## Part A｜選擇題（每題 1 分，共 10 分）

**1.** 勝率 40%、贏時賺 3 元、輸時虧 1 元，每次的期望值是：
- (A) −0.2 元
- (B) +0.6 元
- (C) +1.2 元
- (D) +2.0 元

**2.** 資金從 100 萬虧到 75 萬，要賺多少 % 才能回本？
- (A) 25%
- (B) 約 33%
- (C) 50%
- (D) 75%

**3.** 資金 10 萬、每筆最多虧 1%、買進 50 元、停損 45 元，最多可以買幾股？
- (A) 100 股
- (B) 200 股
- (C) 1,000 股
- (D) 2,000 股

**4.** 回測時用「當天收盤價」產生訊號，又用「當天收盤價」成交，最可能犯了什麼錯？
- (A) 倖存者偏差
- (B) 前視偏差
- (C) 交易成本太高
- (D) 多重檢定

**5.** 下列哪一項最能降低過度擬合的風險？
- (A) 增加參數數量直到樣本內夏普最高
- (B) 事先切分樣本外，策略凍結後只測一次
- (C) 只報告最好的一組參數
- (D) 看到樣本外結果後調整規則再測

**6.** 10 分鐘的簡報，最適合講幾個重點？
- (A) 1 個
- (B) 3 個
- (C) 10 個
- (D) 越多越好

**7.** 教學時，確認對方是否理解，最好的問法是：
- (A) 「懂了嗎？」
- (B) 「有沒有問題？」
- (C) 「你可以用自己的話說一次嗎？」
- (D) 「這很簡單吧？」

**8.** 策略研究報告和回測報告最主要的差別是，研究報告多了：
- (A) 更多技術指標
- (B) 風險分析與策略定案後的模擬交易紀錄
- (C) 更高的報酬
- (D) 更多參數組合

**9.** 模擬交易照規則的結果在預期分布第 53 百分位、實際結果在第 33 百分位、遵守率 88.9%，最適當的決策是：
- (A) 淘汰策略
- (B) 繼續模擬，先改善執行紀律
- (C) 立刻進入實盤並加碼
- (D) 修改參數直到結果變好

**10.** 給一年後自己的信中，下列哪一個是最好的目標？
- (A) 年報酬 30%
- (B) 每個月都賺錢
- (C) 全年規則遵守率 > 95%
- (D) 打敗所有朋友

<details><summary>Part C 終極費曼檢核題參考要點</summary>

**21.（國中生版，零術語）**
- **比喻**：夜市套圈圈的老闆。有人套中大獎，老闆看起來虧了，但他不怕，因為一整晚幾百個客人加起來，他一定賺。
- **核心**：交易能長期賺錢，不是因為每次都猜對，而是找到一種「平均下來賺的比虧的多」的玩法，然後重複很多很多次。
- **數字**：十次贏七次的遊戲，如果贏賺 100、輸虧 300，玩越多虧越多；十次只贏四次的遊戲，如果贏賺 300、輸虧 100，平均每次賺 60。
- **兩個條件**：① 每次輸的時候只輸一點點，才撐得過連輸（擲硬幣連續好幾次反面很常見）；② 這個玩法要先用過去的資料檢查過、再用假的錢練習過，確定不是運氣。
- **誠實補充**：大部分人做不到，所以「長期賺錢」是可能，不是保證。

**22.（為什麼大多數人虧錢）**
| 原因 | 避免方法 |
|---|---|
| **沒有優勢**：憑感覺、聽明牌、追新聞 | 先問「誰在虧錢給我」（8.2）；用回測與樣本外證明優勢（Phase 10） |
| **成本被忽略**：頻繁交易，手續費、稅、滑價吃掉獲利 | 把成本算進回測（10.6）；減少不必要的交易 |
| **一次押太大**：幾次虧損就元氣大傷（虧 50% 要賺 100%） | 每筆風險 1% 左右、事先設停損（Phase 6） |
| **管不住自己**：賺一點就跑、虧了不停損、報復性交易 | 交易計畫書、日誌、每週檢討、違規成本（Phase 7、12.3） |
| **被回測騙**：過度擬合、前視偏差、倖存者偏差 | 凍結策略、樣本外只測一次、記錄測試次數（10.10～10.13、11.6） |
| **太快上真錢** | 模擬 3 個月、遵守率 > 90%、小額實盤、階梯加碼（Phase 12） |

**23.（回測年化 80% 的 5 個問題）**
1. **有扣成本嗎？** 手續費、稅、滑價怎麼假設？交易頻率多高？（10.6）
2. **試了幾次才找到這個結果？** 參數有幾個？換個參數還好嗎？（10.12、10.15、11.6）
3. **樣本外表現如何？** 有沒有在調整規則時沒看過的資料上測試？walk-forward 呢？（10.13、10.14）
4. **最慘的時候虧多少、虧多久？** 最大回撤、最長回撤期間、最多連虧幾筆？你撐得住嗎？（6.6、10.7、11.5）
5. **有真的用錢做過嗎？** 模擬或實盤多久、幾筆？結果和回測差多少？（12.2～12.4）

加分問題：資料有沒有前視偏差或倖存者偏差（10.10、10.11）？和買進持有、曝險相當的基準比呢（10.16）？為什麼這個優勢存在、為什麼還沒被別人賺走（8.2）？

</details>

## 🎓 恭喜畢業！

一年前，你可能以為交易就是「猜漲跌」。

現在，你知道交易是**在不確定中做決定**：用期望值思考，而不是用感覺；先想會虧多少，再想會賺多少；用回測與樣本外證明優勢，而且知道回測會怎麼騙人；用規則、日誌與檢討管理自己；用模擬交易和小額資金，一步一步走進真實的市場。

更重要的是，**你能把這些講給別人聽，而且對方聽得懂**——這正是這個課程從第一天就寫下的目標。

最後送你三句話，也是這整個課程最想留給你的：

> 1. **沒有聖杯**，只有期望值為正、被誠實驗證過的小優勢。
> 2. **活下來最重要**：控制每一次的虧損，時間才會站在你這邊。
> 3. **最大的對手是自己**：照規則做，持續記錄，持續檢討。

畢業不是終點，是開始。祝你在市場裡，做出許多好的決定。🎉
