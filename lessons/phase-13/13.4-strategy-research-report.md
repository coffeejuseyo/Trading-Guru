## 📖 開場故事：寫一篇畢業論文

研究所的學長要寫畢業論文了。他手上有兩年來的實驗紀錄、十幾份週報、三篇期中報告。

他原本以為把這些東西「訂在一起」就是論文了。指導教授翻了兩頁就退回來：

> 「論文不是資料夾。它要回答**一個問題**：你的假說是什麼？你怎麼檢驗？結果支持還是不支持？有哪些限制？
>
> 還有，你第三章那個失敗的實驗也要寫進去。**失敗的實驗告訴讀者你排除了什麼可能**，這和成功的實驗一樣有價值。」

學長花了一個月，把散落的紀錄重新組織成一條清楚的故事線。完成後他發現：寫論文的過程，讓他看見了自己兩年來研究的全貌，也找到了兩個之前沒注意到的漏洞。

> 🎓 **策略研究報告就是你的畢業論文。** 你手上已經有策略規格書（8.13）、回測報告（10.17）、研究日誌（11.11）、蒙地卡羅（11.5）、交易計畫書（12.1）、模擬交易日誌與每月檢討（12.2～12.4）。13.4 要做的，是把它們組織成**一份回答一個問題的文件**：「**這個策略值得用真錢交易嗎？為什麼？**」

## 🧠 正文

### 1. 回測報告 vs. 策略研究報告

| | 10.17 回測報告 | 13.4 策略研究報告 |
|---|---|---|
| 回答的問題 | 「回測結果如何？可信嗎？」 | 「**這個策略值得用真錢交易嗎？**」 |
| 涵蓋範圍 | 假說 → 回測 → 穩健性 | 假說 → 回測 → 樣本外 → 風險 → **模擬交易** → 決策 |
| 讀者 | 自己、研究夥伴 | **任何人**，包括完全沒參與的人 |
| 比喻 | 一份實驗報告 | 一篇畢業論文 |

> 🔑 **最重要的差別：研究報告包含「真正的未來」**——模擬交易是策略定案後才發生的，是唯一沒有被你的選擇污染過的資料（12.2）。

### 2. ⭐ 報告的結構：摘要＋九個章節

課綱要求報告包含：**假說、規則、回測、樣本外結果、風險分析、模擬交易紀錄**。完整的結構如下：

| # | 章節 | 要回答的問題 | 來源 |
|---|---|---|---|
| 0 | **摘要** | 用 5 句話：做了什麼、發現什麼、決定什麼 | 最後寫 |
| 1 | **假說** | 為什麼這個策略應該有效？誰在虧錢給你？什麼結果會推翻它？ | 8.2、11.11 |
| 2 | **規則** | 進場、出場、停損、部位、交易標的、不交易的條件——別人能照做嗎？ | 8.13 規格書 |
| 3 | **資料與方法** | 資料來源、期間、清理、成本假設、樣本內外切分、凍結紀錄 | 9.x、10.6、10.13 |
| 4 | **回測結果（樣本內）** | 績效、交易統計、與基準比較、測試了幾組參數 | 10.7～10.9、10.16 |
| 5 | **樣本外與穩健性** | 樣本外、walk-forward、參數敏感度、成本加倍、延遲一天 | 10.13～10.15、11.7 |
| 6 | **風險分析** | 蒙地卡羅回撤、連虧、部位大小、最壞情境、失效條件 | 6.x、11.5 |
| 7 | **模擬交易紀錄** | 筆數、期間、照規則 vs. 實際、預期百分位、遵守率、滑價 | 12.2～12.4 |
| 8 | **結論與決策** | 淘汰／繼續研究／模擬／小額實盤／加碼？理由？ | 10.18、12.4～12.6 |
| 9 | **限制與下一步** | 這份研究**沒有**證明什麼？下一步要測什麼？ | 11.11 |

> 📋 直接使用範本：[templates/strategy-research-report.md](../../templates/strategy-research-report.md)

### 3. 各章撰寫要點

#### 第 1 章：假說——先寫「為什麼」，再看「結果」

| 好的假說 | 不好的假說 |
|---|---|
| 「趨勢延續：資訊慢慢擴散、投資人追漲，讓價格趨勢在數週到數月內延續；如果樣本外夏普 < 0.3 或打不贏曝險相當基準，假說不成立」 | 「均線交叉會賺錢」 |
| 說明**優勢從哪裡來**（8.2） | 只描述規則 |
| **事先寫下**推翻條件（11.11） | 什麼結果都說得通 |

> ⚠️ 假說必須是**研究日誌裡事先寫的版本**。看了結果才寫的假說是 HARKing（11.11），報告的讀者會被誤導——而第一個被誤導的就是你自己。

#### 第 2 章：規則——讓陌生人也能照做

檢驗方法：把規則交給一位沒看過你回測的人，請他用同一份資料手動算 5 筆交易，結果應該和你的程式**完全一樣**。

#### 第 3 章：資料與方法——讓別人能重現

| 必寫項目 | 例子 |
|---|---|
| 資料來源與期間 | 某資料商的日線，2010–2023 |
| 調整方式 | 還原權值、處理下市股票（10.11） |
| 成本假設 | 手續費、稅、滑價各多少（10.6） |
| 樣本切分 | 樣本內 2010–2018、樣本外 2019–2023，**研究開始前決定** |
| 凍結紀錄 | Git commit 編號與日期（10.18） |
| 程式與環境 | 程式檔案連結、套件版本 |

#### 第 4～5 章：回測與樣本外——報告全部，不只最好的

- 一定要附**同期基準**與**曝險相當基準**（10.16）
- 一定要寫**測試了幾組參數**（11.6）——「我試了 48 組，報告的是第 23 組，選它的理由是……」
- 樣本外表現**變差是正常的**，要寫出變差多少、還在不在可接受範圍

#### 第 6 章：風險分析——想像最糟的情況

| 項目 | 問題 |
|---|---|
| 蒙地卡羅回撤 | 95% / 99% 信心的最大回撤是多少？（11.5） |
| 連虧 | 95% 信心下最多連虧幾筆？心理上撐得住嗎？ |
| 部位大小 | 每筆風險多少 %？為什麼？（6.4、6.9） |
| 失效情境 | 什麼樣的市場環境會讓策略失效？（8.12） |
| 黑天鵝 | 跳空、停牌、流動性消失時會怎樣？ |

#### 第 7 章：模擬交易——最誠實的一章

| 必寫項目 | 說明 |
|---|---|
| 期間與筆數 | 至少 3 個月、30 筆以上 |
| 照規則 vs. 實際 | 兩者都要寫，差距就是執行成本（12.3） |
| 預期百分位 | 照規則與實際，各落在回測預期分布的第幾百分位（12.4） |
| 遵守率與違規成本 | 違規幾次、總共花了多少 R |
| 成本差異 | 實際滑價 vs. 回測假設 |

> 💡 如果模擬交易還沒滿 3 個月，這一章先寫「進行中」與目前的數據，**結論章暫時不能寫「進入實盤」**。

#### 第 8 章：結論——五種決策

| 決策 | 條件（摘要） |
|---|---|
| **淘汰** | 樣本外明顯失敗、打不贏基準、參數敏感、或模擬結果遠低於預期範圍 |
| **繼續研究** | 有正面跡象但某些檢驗沒過 → 提出**新假說**，用新資料測 |
| **繼續模擬** | 策略正常，但遵守率 < 90% 或筆數不足 |
| **小額實盤** | 遵守率 > 90%、結果在預期範圍內（12.4 上路關卡） |
| **逐步加碼** | 小額實盤達到加碼階梯的條件（12.5） |

> 🔑 **「淘汰」是一個完全合格的結論。** 10.18 說過：一份方法嚴謹、結論是「假說不成立」的報告，比一份方法有漏洞、結論很漂亮的報告有價值得多。畢業條件看的是**方法與誠實**，不是策略賺不賺錢。

#### 第 9 章：限制——這份研究沒有證明什麼

例如：
- 「36 筆模擬交易不足以在統計上證明期望值 > 0（約需 150～220 筆，12.6）。」
- 「只測試了一個市場、一段期間。」
- 「回測期間沒有包含長期的高利率環境。」

> 💡 **會寫限制的人，才是真正懂的人。** 這一章也是讀者最信任你的一章。

### 4. ⭐ 範例報告摘要

> 📌 以下為**示範用**的摘要：數字取自本課程 10.17 與 Phase 12 的範例，拼接成一份完整的樣子，**不是同一個策略的真實研究結果**。請用你自己的研究填寫。

> **策略研究報告：ETF 趨勢 v1.2**
>
> **摘要**：本研究檢驗「價格趨勢在數週到數月內延續」的假說。以均線趨勢規則在 2010–2018 樣本內開發、2019–2023 樣本外測試，樣本外年化 8.12%、夏普 0.69、最大回撤 −17.60%，報酬低於同期買進持有（16.79%），但回撤與波動較低。36 筆模擬交易照規則的結果（9.32R）落在回測預期分布的第 53 百分位，策略表現正常；但實際結果只有 3.71R（第 33 百分位），規則遵守率 88.9%，未達 90% 的上路門檻。**決策：繼續模擬交易，改善執行紀律後再判斷是否進入小額實盤。**

| 章節 | 範例重點 |
|---|---|
| 1 假說 | 趨勢延續；推翻條件：樣本外夏普 < 0.3，或打不贏曝險相當基準 |
| 2 規則 | 見規格書 v1.2；每筆風險 0.8% |
| 3 方法 | 樣本內 2010–2018、樣本外 2019–2023；成本含手續費、稅、滑價 0.10%；凍結 commit 記錄於研究日誌 |
| 4 回測 | 樣本內年化 3.36%、夏普 0.30、最大回撤 −35.36% |
| 5 樣本外 | 年化 8.12%、夏普 0.69、最大回撤 −17.60%；買進持有夏普 1.12 → **策略的優勢在於降低回撤，不是提高報酬** |
| 6 風險 | 期望值 0.24R；30 筆總 R 預期範圍 −8.1R ～ +24.6R；95% / 99% 回撤約 −14% / −17%；95% 連虧 13 筆 |
| 7 模擬 | 36 筆；照規則 9.32R（第 53 百分位）、實際 3.71R（第 33 百分位）；4 次違規共 −5.61R；滑價 0.12% > 假設 0.10% |
| 8 結論 | 繼續模擬：策略正常、落差來自執行；以 0.12% 滑價重新回測 |
| 9 限制 | 36 筆無法證明期望值 > 0；樣本外期間大多是多頭；只測試一個市場 |

注意這份摘要的幾個特點：

- **誠實寫出輸給買進持有**，並說明策略的價值在哪裡（回撤較小）
- **把「策略好不好」和「我執行得好不好」分開**（第 53 vs. 第 33 百分位）
- **決策有明確的條件**，而不是「感覺還不錯」
- **限制寫得很具體**

### 5. 寫作的五個原則

| 原則 | 說明 |
|---|---|
| **一個問題貫穿全文** | 每一章都在回答「這個策略值得用真錢交易嗎？」 |
| **每個數字都有來源** | 附上程式、資料、日誌的連結 |
| **壞消息和好消息一樣大聲** | 樣本外變差、輸給基準、違規，都要寫在正文，不是藏在附錄 |
| **讓外行人也看得懂摘要** | 摘要用 13.2 的語言：比喻少一點沒關係，但不要有沒解釋的術語 |
| **可重現** | 別人拿你的程式和資料，能跑出同樣的數字 |

### 6. ⭐ 交出前的品質檢查清單

- [ ] 摘要在 5 句以內，包含**決策**
- [ ] 假說是**事先寫下的**，包含推翻條件
- [ ] 規則清楚到**陌生人可以照做**
- [ ] 成本假設、樣本切分、凍結紀錄都有寫

## 📌 重點整理

1. 研究報告回答一個問題：「**這個策略值得用真錢交易嗎？**」
2. **摘要＋九個章節**：假說、規則、資料與方法、回測、樣本外與穩健性、風險、模擬交易、結論、限制。
3. 大部分內容**來自既有文件**：規格書、回測報告、研究日誌、蒙地卡羅、計畫書、模擬日誌。
4. **報告全部**：測試次數、樣本外變差、輸給基準、違規都要寫。
5. 把「**策略好不好**」和「**執行好不好**」分開判斷。
6. **「淘汰」是合格的結論**；畢業看的是方法與誠實，不是賺不賺錢。

## ❌ 常見誤解

| 誤解 | 正確觀念 |
|---|---|
| 研究報告就是把所有文件訂在一起 | 要組織成一條回答單一問題的故事線 |
| 策略賠錢就不用寫報告 | 「淘汰」也是合格的結論，失敗的研究一樣有價值 |
| 不好看的結果放在附錄就好 | 壞消息要和好消息一樣寫在正文 |
| 報告只要給自己看 | 要讓沒參與的人也能看懂、能重現 |
| 模擬交易賺錢就可以寫「進入實盤」 | 要看遵守率與預期百分位，而不是賺賠 |
| 限制寫太多會顯得研究很差 | 會寫限制，才代表你知道這份研究證明了什麼、沒證明什麼 |

## 🛠️ 練習（課綱作業）

**練習 1：整理素材**
把你手上的文件列出來，對照第 2 節的摘要與九個章節，標出每一章的來源；找出**缺的部分**（例如沒寫測試次數、沒有曝險相當基準），先補齊。

**練習 2：完成報告**
使用[策略研究報告範本](../../templates/strategy-research-report.md)完成你的報告。模擬交易還沒滿 3 個月的話，第 7 章先寫目前進度，第 8 章寫「暫定」。

**練習 3：品質檢查**
用第 6 節的清單逐項檢查。最後一項請一位朋友（可以是 13.3 的學生）讀你的摘要，請他說出「這個策略在做什麼、結論是什麼」。

**練習 4：存檔**
把報告與程式、資料、日誌一起用 Git commit 存檔，commit 訊息寫「策略研究報告 v1」。

## ✅ 自我測驗

**Q1. 策略研究報告和回測報告最大的不同是什麼？**

<details><summary>看答案</summary>

回測報告回答「回測結果如何、可信嗎」，涵蓋假說到穩健性；策略研究報告回答「這個策略值得用真錢交易嗎」，除了回測與樣本外，還包含風險分析與模擬交易紀錄。模擬交易發生在策略定案之後，是唯一沒有被研究者選擇污染過的資料，也是兩者最重要的差別。

</details>

**Q2. 模擬交易照規則的結果在第 53 百分位、實際結果在第 33 百分位、遵守率 88.9%，結論應該怎麼寫？**

<details><summary>看答案</summary>

策略本身表現正常（照規則的結果在預期分布中間），落差主要來自執行；遵守率 88.9% 未達 90% 的上路門檻，所以決策是「繼續模擬交易」，改善紀律後再判斷是否進入小額實盤。不應該因為結果偏低就修改策略，也不應該因為照規則的結果正常就直接上實盤。

</details>

**Q3. 為什麼報告要寫「限制」？請舉兩個例子。**

<details><summary>看答案</summary>

限制說明這份研究沒有證明什麼，讓讀者（和自己）不會過度相信結果，也指出下一步要測試什麼。例如：36 筆模擬交易不足以在統計上證明期望值 > 0（約需 150～220 筆）；只測試了一個市場、一段期間；樣本外期間大多是多頭市場。

</details>
