# Phase 13｜畢業專題：把它教給別人

> **預計時數：20 小時**（5 個單元）
> **生活比喻：從學生變老師。能教會別人，才代表你真的學會了。**

還記得 [Phase 0](../phase-00/README.md) 的費曼學習法嗎？「**如果你沒辦法用簡單的話解釋一件事，代表你還沒真正懂它。**」

這個課程的終極目標，從第一天就寫在 README 上：**學完之後，能從容地和其他人說明，而且對方聽得懂。** Phase 13 就是檢驗這個目標的時刻。

| 你要做的 | 證明什麼 |
|---|---|
| 整理知識地圖 | 你看得到整片森林，而不只是一棵棵樹 |
| 10 分鐘簡報 | 你能把 500 小時的內容濃縮成重點 |
| 教會一位新手朋友 | 對方真的聽得懂、記得住 |
| 完整策略研究報告 | 你能獨立走完整個研究流程 |
| 回顧與下一步 | 你知道自己從哪裡來、要往哪裡去 |

> 🔑 **Phase 13 可以和 Phase 12 的模擬交易同時進行**：模擬交易需要至少 3 個月的日曆時間，而 13.4 的策略研究報告，正好需要模擬交易的紀錄。

## 🏁 畢業條件（M4）

- [ ] 用 **10 分鐘**向非金融背景的朋友講解「交易、風險、回測」，**對方能用自己的話複述重點**（13.2、13.3）
- [ ] 完成一份**策略研究報告**：假說、規則、回測、樣本外結果、風險分析、模擬交易紀錄（13.4）
- [ ] **不看筆記**，回答[費曼檢核題總題庫](feynman-question-bank.md)中的 **80%**（13.1、複習）

## 建議讀法（標準版：第 52–53 週）

| 週次 | 單元 | 實作 |
|---|---|---|
| W52 | 13.1、13.2 | 畫出知識地圖；完成 10 分鐘簡報並錄影一次 |
| W52～W53 | 13.3 | 教朋友 3 次（每次 30 分鐘，間隔幾天） |
| W53 | 13.4、13.5 + 複習 | 策略研究報告（模擬交易紀錄可以之後補齊）；回顧與規劃；🏁 **M4** |

> 💡 如果你的模擬交易還沒滿 3 個月，可以先完成 13.1～13.3 與 13.5，13.4 的報告先寫到「樣本外驗證」，等模擬交易完成後再補上最後一章。
