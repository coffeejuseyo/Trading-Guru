## 📖 開場故事：畢業典禮，以及下一段旅程

畢業典禮那天，小芸翻出了大一時寫的「入學自我介紹」：

> 「我希望四年後可以找到一份好工作。我現在連 Excel 都不太會用。」

她笑了出來。四年前的她，根本想像不到自己現在能做的事。

典禮結束後，教授對所有畢業生說：

> 「畢業不是終點，英文叫 *commencement*——**開始**。從今天起，沒有人會再幫你排課表、出作業、打分數了。**你要自己決定學什麼、自己檢查做得好不好。**這四年最重要的，不是你學會的知識，而是你學會了『怎麼學』。」

> 🎓 **你的畢業也一樣。** 回頭看 Phase 0 的自己，再想想接下來的路：沒有講義、沒有複習題，只有市場、你的交易計畫書、你的日誌，和你自己。

## 🧠 正文

### 1. ⭐ 回顧：從哪裡出發，走到了哪裡

翻出 [Phase 0](../phase-00/README.md) 時寫的學習目標與自我評估，和現在的自己比較：

| 面向 | Phase 0 的我 | 現在的我 |
|---|---|---|
| 交易是什麼 | 「低買高賣」「猜漲跌」 | 重複一個期望值為正的優勢，並控制風險 |
| 風險 | 「停損就是認輸」 | 先算會虧多少；每筆風險 1% 左右；活下來最重要 |
| 判斷一個策略 | 「聽說很準」「回測很漂亮」 | 假說、成本、樣本外、測試次數、模擬交易 |
| 自己的心理 | 「我不會被情緒影響」 | 知道自己會，所以用規則、日誌、檢討來管理 |
| 工具 | 看新聞、看別人推薦 | Python、回測、蒙地卡羅、交易計畫書 |
| 解釋給別人聽 | 講不清楚 | 10 分鐘簡報、教會一位朋友 |

**回顧三問**（寫下來）：

1. 這一年**最大的觀念轉變**是什麼？
2. 哪一個階段**最難**？你怎麼撐過去的？
3. 如果重新開始，你會**怎麼調整**學習方式？

### 2. ⭐ 畢業之後的四條路線

學完這個課程，**不是每個人都應該成為主動交易者**。誠實評估自己，選一條適合的路：

| 路線 | 適合誰 | 下一步 |
|---|---|---|
| **A. 被動投資為主** | 時間有限、模擬交易遵守率一直很低、或發現自己不喜歡盯盤 | 資產配置 + 定期定額 + 再平衡（8.11、11.4）；這門課讓你**不會被騙** |
| **B. 兼職系統化交易** | 有正職、喜歡研究、模擬交易紀律良好 | 依 12.5 的階梯慢慢加碼；每年研究 1～2 個新策略 |
| **C. 深入量化研究** | 熱愛程式與統計、想往專業發展 | 更深入的統計、機器學習、資料工程；參與開源專案或競賽 |
| **D. 教學與分享** | 享受 13.2、13.3 的過程 | 持續寫作、教學；教別人是最好的複習 |

> 🔑 **選 A 不是失敗。** 長期而言，大多數主動交易者的績效輸給簡單的指數投資（相關研究結論大致如此）。你學會了判斷自己有沒有優勢——如果答案是「目前沒有」，選擇被動投資就是一個**有優勢的決定**。

> 💡 路線可以**組合**：例如核心資金走 A、小部分資金走 B，同時用 D 來維持學習。這其實就是 11.1 的「組合」思維。

### 3. 長期維持系統：讓好習慣自動運轉

課程結束後，最大的風險是**慢慢鬆懈**。用固定的節奏取代意志力：

| 頻率 | 做什麼 | 時間 |
|---|---|---|
| **每天** | 依計畫書的例行程序：檢查訊號、下單、記錄日誌 | 15～30 分鐘 |
| **每週** | 每週檢討：遵守率、違規、情緒（12.3） | 30 分鐘 |
| **每月** | 每月檢討報告：預期百分位、違規成本、成本差異（12.4） | 1～2 小時 |
| **每季** | 檢查停止 / 修改 / 放棄規則（12.6）；讀一本書或一篇研究 | 半天 |
| **每年** | 年度回顧：更新交易計畫書、重新做一次[費曼題庫](feynman-question-bank.md)、規劃下一年的研究 | 1～2 天 |

> 💡 **每年重新做一次費曼題庫**，是檢查自己有沒有「慢慢忘記」或「慢慢走偏」最簡單的方法。

### 4. ⭐ 畢業後最常見的五個陷阱

| 陷阱 | 症狀 | 對策 |
|---|---|---|
| **過度自信** | 「我學完了，可以加大資金了」 | 加碼只看階梯條件（12.5），不看學了多久 |
| **策略跳躍** | 看到新方法就想換 | 新策略要重新走完整流程（12.6）；寫進研究日誌排隊 |
| **紀律鬆懈** | 日誌越寫越短，最後不寫 | 固定的週檢討與月報告；找一位夥伴互相檢查 |
| **資訊焦慮** | 每天看大量新聞、社群、分析 | 回到計畫書：規則沒用到的資訊，可以不看 |
| **忘記風險** | 一段順利的期間後，部位悄悄變大 | 每月檢查實際每筆風險 vs. 計畫書 |

> 🔑 這五個陷阱有一個共同點：**它們都發生在「順利」的時候。** 虧錢時大家都會檢討；賺錢時最容易放鬆。

### 5. 繼續學習的方向

依你選的路線，可以參考 [docs/RESOURCES.md](../../docs/RESOURCES.md) 的資源清單。幾個方向：

| 方向 | 內容 |
|---|---|
| 統計與研究方法 | 更嚴謹的假設檢定、時間序列分析、貝氏方法 |
| 市場微結構 | 委託簿、流動性、成交成本的細節 |
| 衍生性商品 | 選擇權定價與避險（8.10 的延伸） |
| 行為財務 | 更深入了解市場與自己的偏誤（Phase 7 的延伸） |
| 軟體工程 | 測試、資料管線、自動化系統的可靠性（11.10 的延伸） |

> ⚠️ 學新東西時，記得 Phase 0 的原則：**一次一個主題、用費曼學習法檢查、有產出才算學會。**

### 6. ⭐ 給一年後自己的信

最後一個作業：寫一封信給一年後的自己。內容包括：

1. **現在的狀態**：模擬或實盤在哪個階段？遵守率多少？
2. **選擇的路線**（A／B／C／D 或組合）與理由
3. **一年後的目標**：用**過程目標**，而不是報酬目標
   - ✅「全年規則遵守率 > 95%」「完成 2 份策略研究報告」「再教 2 位朋友」
   - ❌「年賺 30%」（報酬不完全由你控制）
4. **給未來自己的提醒**：最怕自己忘記的一句話
5. **如果一年後的你虧了錢，你想對他說什麼？**

把信存在你的學習資料夾（例如 Git repo 的 `letters/` 資料夾），在行事曆上設定一年後的提醒。

> 💡 第 5 題很重要。一年後的你可能正處在低潮——預先寫給他的話，會比當下任何人的安慰都有力量。

---

## 📌 重點整理

1. **回顧**：和 Phase 0 的自己比較，寫下最大的觀念轉變。
2. **四條路線**：被動投資、兼職系統化交易、深入量化研究、教學分享；**選被動投資不是失敗**。
3. **維持系統**：每天例行、每週檢討、每月報告、每季檢查、每年回顧（含重做費曼題庫）。
4. **五個陷阱**：過度自信、策略跳躍、紀律鬆懈、資訊焦慮、忘記風險——都發生在順利的時候。
5. **給一年後自己的信**：用過程目標，並寫下低潮時想聽的話。

## 🗣️ 一分鐘講給朋友聽（示範稿）

> 「我的交易課程終於學完了，最後一個單元像畢業典禮：回頭看一年前的自己，那時候我以為交易就是猜漲跌，現在我知道它是用可承受的風險，重複一個被證明過的小優勢。
>
> 接下來我要選一條路。老實說，不是每個人學完都適合主動交易；如果發現自己沒有優勢、或沒辦法照規則做，乖乖買指數基金反而是最聰明的選擇。我打算大部分資金做被動投資，小部分繼續用我的策略，照計畫慢慢加碼。
>
> 我也寫了一封信給一年後的自己，目標不是賺多少，而是遵守率要超過 95%。因為報酬我控制不了，但紀律我可以。」

## ❌ 常見誤解

| 誤解 | 正確觀念 |
|---|---|
| 學完課程就代表會賺錢 | 學完代表你會判斷、會驗證、會控制風險；賺不賺錢還要時間與紀律 |
| 學了這麼多，不主動交易很浪費 | 判斷出自己沒有優勢而選擇被動投資，正是這門課的價值 |
| 畢業後就不用再複習 | 不複習會慢慢忘記、慢慢走偏；每年重做費曼題庫 |
| 目標應該設定報酬率 | 報酬不完全由你控制；過程目標（遵守率、研究份數）才可控 |
| 賺錢的時候不需要檢討 | 大部分陷阱發生在順利的時候 |

## ✅ 自我測驗

**Q1. 為什麼「選擇被動投資」不是失敗？**

<details><summary>看答案</summary>

這門課的核心是判斷自己有沒有優勢、能不能照規則執行。如果誠實評估後發現目前沒有優勢，或沒辦法維持紀律，選擇低成本的被動投資就是一個有根據、有優勢的決定；而且長期而言，大多數主動交易者的績效輸給簡單的指數投資。課程讓你至少不會被誇大的說法騙走。

</details>

**Q2. 畢業後最常見的陷阱有什麼共同點？**

<details><summary>看答案</summary>

過度自信、策略跳躍、紀律鬆懈、資訊焦慮、忘記風險，大多發生在「順利」的時候：賺錢時容易放鬆紀律、加大部位、覺得自己已經學會了。對策是用固定的節奏（每週檢討、每月報告、每季檢查、年度回顧）取代意志力，加碼只看事先寫好的條件。

</details>

**Q3. 給一年後自己的信，為什麼要用「過程目標」而不是報酬目標？**

<details><summary>看答案</summary>

報酬受到市場環境與運氣影響，不完全由自己控制；即使做對每件事，一年的結果也可能落在預期範圍的低端。過程目標（例如規則遵守率 > 95%、完成 2 份研究報告、再教 2 位朋友）完全由自己控制，能真正反映進步，也不會因為短期運氣好壞而做出錯誤的結論。

</details>
