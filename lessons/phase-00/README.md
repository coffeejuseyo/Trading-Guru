# Phase 0｜起跑線：心態與學習方法

> **預計時數：10 小時**（5 個單元 × 約 2 小時）
> **生活比喻：出發旅行前，先看地圖、確認行李、知道目的地。**

很多人學交易的第一步是「打開看盤軟體」。這就像還沒看地圖就開車上高速公路：很刺激，但很容易迷路，甚至出車禍。

Phase 0 不教你任何買賣技巧。它要先回答三個問題：

1. **交易到底是什麼？**（它跟投資、賭博有什麼不同？）
2. **為什麼大多數人會虧錢？**（先知道坑在哪裡，才能避開）
3. **我要怎麼學，才能真的學會，而且教得會別人？**

## 每個單元的結構

每份講義都長這樣，之後所有階段也一樣：

1. 🎯 **學完你會知道**：本單元的目標
2. 📖 **開場故事**：用一個生活情境帶入
3. 🧠 **正文**：觀念 + 生活比喻 + 數字例子
4. 📌 **重點整理**：考前只看這裡也行
5. 🗣️ **一分鐘講給朋友聽**：示範講稿，你可以照著練習
6. ❌ **常見誤解**
7. 🛠️ **練習**
8. ✅ **自我測驗**：附答案（點開才看得到）
