# Phase 6｜活下來最重要：風險與資金管理

> **預計時數：30 小時**（10 個單元）
> **生活比喻：開車技術再好，也要繫安全帶、買保險、保持車距。交易的第一原則是「先活下來」。**

到目前為止，你學的都是「**怎麼找機會**」：市場、商品、技術面、基本面。

但交易者真正的分水嶺，不是誰找到比較好的機會，而是：**誰在犯錯時還能活下來。**

回想你已經學過的：
- **3.2**：虧 50% 要賺 100% 才能回本
- **3.10**：好策略也一定會連續虧損
- **3.12**：同一個賺錢的策略，每筆押太大，大部分人會破產
- **4.10**：ATR 可以幫你決定停損距離和部位大小

Phase 6 要把這些觀念**整合成一套完整的系統**，最後寫下你自己的《個人風險規則》。

> 🔑 **這是整門課最重要的一個階段。** 你可以用普通的策略賺錢，但沒有風險管理，再好的策略也會讓你破產。

## 一筆交易的風險管理流程

```
① 找到交易機會（Phase 4、5、8）
        ↓
② 決定「哪裡代表我錯了」→ 停損價（6.2、6.5）
        ↓
③ 決定每筆願意虧多少 → 例如總資金的 1%（6.4）
        ↓
④ 計算部位大小 = 願意虧的錢 ÷ 每股停損距離（6.4、6.5）
        ↓
⑤ 檢查整體曝險：同時持有幾筆？彼此相關嗎？（6.8）
        ↓
⑥ 決定怎麼出場賺錢：停利或移動停損（6.3）
        ↓
⑦ 持續監控：回撤是否超過預期？是否該降低風險？（6.6、6.9）
        ↓
⑧ 全部寫進《個人風險規則》（6.10）
```

> 🔑 注意順序：**先決定停損和虧損金額，才決定買多少。** 大部分新手是反過來的：「我有 10 萬，全部買」——然後才想停損要放哪裡。

## 🎮 本階段的模擬交易：第 4 關：守住風險

每筆風險 1%、進場同時設停損；開始記錄是否遵守規則與違規類型。

> 工具：[課程練習器](../../tools/trading-simulator/README.md)（模擬資料、可快轉）或 TradingView 模擬交易。完整說明見 [模擬交易路線圖](../../docs/SIMULATION.md)。

## 完成 Phase 6 的標準

- [ ] 能說明為什麼專業交易者每筆只冒總資金 1%～2% 的風險
- [ ] 能用「停損距離」計算部位大小（含 ATR 版本）
- [ ] 能計算最大回撤，並說明它為什麼比報酬率更能反映痛苦程度
- [ ] 能解釋凱利公式，以及為什麼實務上要打折使用
- [ ] 能說明分散的關鍵是**低相關**，以及危機時相關性上升
- [ ] 完成**部位大小計算器**試算表
- [ ] 寫下並簽署你的《個人風險規則》
- [ ] 總複習測驗答對 80% 以上
