# Phase 4｜看懂價格：技術分析

> **預計時數：50 小時**（14 個單元）
> **生活比喻：看天氣預報——用過去的雲圖與氣壓來推測明天「比較可能」的天氣，但永遠不是 100%。**

到目前為止，你知道了市場是什麼（Phase 1）、交易怎麼完成（Phase 2）、怎麼用數字思考（Phase 3）。現在，我們終於要打開**價格圖表**了。

技術分析是交易者最常用、也最常被誤用的工具。這個階段有兩個目標：

1. **看懂**：K 線、趨勢、支撐壓力、成交量、均線、RSI、KD、MACD、布林通道、ATR、常見型態
2. **不迷信**：用 Phase 3 的統計眼光，知道每個工具**能做什麼、不能做什麼**

> 🔑 **本階段的核心態度：技術分析是「描述過去、整理資訊」的工具，不是「預測未來」的水晶球。** 任何「看到 XX 就一定會漲」的說法，都需要用資料驗證（4.13、Phase 10）。

## 工具分類地圖

```
                      【價格本身】
              4.2 K 線 ─ 4.3 時間週期
                          │
         ┌────────────────┼────────────────┐
     【結構】          【參與度】          【指標：價格的二次加工】
   4.4 趨勢           4.6 成交量          ┌─ 趨勢類：4.7 均線、4.9 MACD
   4.5 支撐壓力                          ├─ 動能類：4.8 RSI、KD
   4.11 型態                             └─ 波動類：4.10 布林通道、ATR
         └────────────────┼────────────────┘
                          ▼
              4.12 怎麼組合 → 4.13 怎麼驗證 → 4.14 大量練習
```

> 💡 **所有指標都是用「開高低收量」算出來的**，所以它們不會提供價格以外的新資訊，只是換個角度整理。理解這一點，就不會被花俏的指標迷惑。
