# 4.11｜常見型態：頭肩、雙底、三角收斂、旗形

> ⏱️ 約 5 小時｜[← 上一單元：4.10](4.10-bollinger-and-atr.md)｜[Phase 4 目錄](README.md)｜[下一單元：4.12 →](4.12-combining-indicators.md)

## 🎯 學完你會知道

- **反轉型態**：頭肩頂 / 頭肩底、雙重頂 / 雙重底
- **延續型態**：三角收斂、旗形、矩形
- 型態的「頸線」「突破」「量度目標」
- 為什麼型態判讀**高度主觀**，以及如何讓它變得比較客觀
- 型態的正確用法：**定義風險的結構**，而不是預言

---

## 📖 開場故事：看雲的形狀猜天氣

小時候躺在草地上看雲，你會說：「那朵雲像一隻兔子！」「那朵像一艘船！」

旁邊的朋友卻說：「哪裡像兔子？明明像一隻狗。」

人類的大腦天生就喜歡**在隨機的東西裡找出圖案**（心理學稱為「空想性錯視」）。看到兩個點一條線，就覺得像一張臉。

> ☁️ **圖表型態就像看雲的形狀**：有時候真的有意義（積雨雲確實可能代表要下雨），但很多時候只是我們的大腦在「找圖案」。同一張圖，兩個人可能看出完全不同的型態。

## 🧠 正文

### 1. 型態是什麼？

**型態 = 價格在圖表上形成的、可以辨認的形狀，被認為反映了買賣雙方的力量變化。**

| 類型 | 意思 | 代表型態 |
|---|---|---|
| **反轉型態** | 原本的趨勢**可能要結束**了 | 頭肩頂 / 底、雙重頂 / 底 |
| **延續型態** | 趨勢中的**休息**，之後**可能繼續**原方向 | 三角收斂、旗形、矩形 |

### 2. 反轉型態

#### 頭肩頂（Head and Shoulders Top）

出現在**上升趨勢之後**，由三個高點組成：

| 部分 | 描述 |
|---|---|
| **左肩** | 上漲到一個高點後回落 |
| **頭** | 再上漲到**更高**的高點，又回落 |
| **右肩** | 再上漲，但**沒有超過頭部**（和左肩差不多高），又回落 |
| **頸線** | 連接兩次回落的低點 |
| **確認** | 價格**跌破頸線**（常見要求：以收盤價跌破） |

**背後的故事（回想 4.4）**：右肩沒有創新高 → 上漲動能減弱；跌破頸線 → 低點也開始下降 → 「高點、低點都墊高」的上升趨勢結構**被破壞**。

> 🔑 所以頭肩頂其實就是 4.4「**趨勢結構被破壞**」的一個具體樣子，不是什麼神秘的圖案。

**頭肩底**：上下顛倒，出現在下降趨勢之後，突破頸線確認。

#### 雙重頂 / 雙重底（M 頭 / W 底）

| 型態 | 描述 | 確認 |
|---|---|---|
| **雙重頂**（M 頭） | 兩次漲到**差不多的高點**都被壓回 | 跌破兩個高點之間的低點（頸線） |
| **雙重底**（W 底） | 兩次跌到**差不多的低點**都撐住 | 突破兩個低點之間的高點（頸線） |

**背後的故事（回想 4.5）**：兩次在同一個價位被擋住 → 那裡是強壓力（或支撐）；突破頸線 → 結構改變。

### 3. 延續型態

#### 三角收斂

價格波動越來越小，高點越來越低、低點越來越高，像一個**越來越窄的三角形**。

| 類型 | 上緣 | 下緣 | 常見解讀 |
|---|---|---|---|
| **對稱三角形** | 往下 | 往上 | 方向不明，等待突破 |
| **上升三角形** | 水平（壓力） | 往上 | 買方越來越積極，偏向往上突破 |
| **下降三角形** | 往下 | 水平（支撐） | 賣方越來越積極，偏向往下跌破 |

> 🌀 回想 4.10：三角收斂就是**波動度在縮小**（布林通道擠壓），之後常常出現一段較大的波動。

#### 旗形與三角旗形

出現在**一段急漲（或急跌）之後**：

| 部分 | 描述 |
|---|---|
| **旗桿** | 一段又快又急的上漲 |
| **旗面** | 之後價格**小幅、短暫**地反向整理（像一面小旗子） |
| **確認** | 價格突破旗面，往原方向繼續 |

> 🚩 比喻：短跑選手衝刺之後，停下來喘口氣（旗面），然後繼續衝。

#### 矩形（箱型整理）

價格在**水平的支撐與壓力之間**來回（回想 4.4 的盤整），等待突破。

### 4. 量度目標（Measured Move）

很多型態有一個傳統的「目標價」算法：

| 型態 | 目標價算法（傳統） |
|---|---|
| 頭肩頂 | 從頸線往下，量出「頭部到頸線」的距離 |
| 雙重底 | 從頸線往上，量出「底部到頸線」的距離 |
| 旗形 | 從突破點，量出「旗桿」的長度 |
| 矩形 | 從突破點，量出「矩形的高度」 |

**例子：雙重底**
兩個低點在 50 元，中間的高點（頸線）在 58 元。突破 58 元後：
> 目標 = 58 + (58 − 50) = **66 元**

> ⚠️ **量度目標只是一個參考，不是預言。** 價格可能遠遠超過，也可能完全到不了。它比較適合用來**估算風險報酬比**（4.5），而不是當作「一定會到」的價格。

### 5. ⚠️ 型態的最大問題：主觀

| 問題 | 說明 |
|---|---|
| **定義模糊** | 右肩要多低才算右肩？兩個高點差多少以內算「差不多」？三角形要碰幾次邊才算數？ |
| **事後很清楚，事前不確定** | 型態「完成」之前，你不知道它會變成什麼。正在形成的「頭肩頂」可能變成「繼續上漲」 |
| **確認偏誤** | 你想做多，就會「看到」雙重底；想做空，就會「看到」頭肩頂（Phase 7） |
| **選擇性記憶** | 書上和網路上展示的都是**成功的**例子；失敗的型態沒人拿出來講（3.11 倖存者偏差） |
| **時間週期** | 日線上的頭肩頂，在週線上可能只是上升趨勢的一小段回檔（4.3） |

> ☁️ 回到看雲：如果你帶著「我想看到兔子」的心情去看雲，你一定會看到兔子。

**研究怎麼說？**
有學者嘗試用電腦**客觀地定義**型態並檢驗它們（例如 Lo、Mamaysky、Wang 在 2000 年的研究），發現部分型態出現後，報酬分布會有一些變化，帶有某些資訊；但也有很多研究發現，單獨使用傳統型態、扣除成本後，**很難得到穩定的優勢**。結論是：**型態可能有一點點資訊，但遠不如書上說得那麼神準。**

### 6. 讓型態判讀變得比較客觀

| 做法 | 例子 |
|---|---|
| **寫下明確的定義** | 「雙重底：兩個低點相差 3% 以內、間隔至少 10 天、中間反彈至少 8%」 |
| **等待確認** | 收盤價突破頸線才算完成，而不是「看起來快完成了」 |
| **事前畫圖、事後檢查** | 在型態完成**前**就截圖記錄你的判斷，之後誠實檢查結果 |
| **統計自己的紀錄** | 記錄 30、50、100 次型態判斷的結果（4.14、3.9） |
| **用程式回測**（Phase 10） | 只有能被寫成明確規則的型態，才能被回測 |

### 7. 型態的正確用法：定義風險的結構

與其把型態當成「預言」，不如把它當成**一個讓你清楚知道「哪裡代表我錯了」的結構**：

**例子：用雙重底設計一筆交易**

| 項目 | 價格 | 理由 |
|---|---:|---|
| 進場 | 58.5 | 收盤突破頸線 58 |
| 停損 | 55 | 突破失敗、跌回型態中間（或用 ATR 決定，4.10） |
| 目標 | 66 | 量度目標 |
| 風險 | 3.5 | |
| 報酬 | 7.5 | |
| 風險報酬比 | 約 1:2.1 | 損益兩平勝率約 32%（3.5） |

> 🔑 **型態的價值不在於「告訴你會漲」，而在於「告訴你在哪裡進場、在哪裡認錯、值不值得做」。** 這比任何預測都實用。

## 📌 重點整理

1. **反轉型態**：頭肩頂 / 底、雙重頂 / 底；**延續型態**：三角收斂、旗形、矩形。
2. 頭肩頂、雙重頂的本質是 4.4「**趨勢結構被破壞**」、4.5「**強壓力**」的具體樣子。
3. 型態通常以**突破 / 跌破頸線**確認；**量度目標**只是參考。
4. 型態判讀**高度主觀**：定義模糊、事後才清楚、確認偏誤、選擇性記憶、時間週期。
5. 研究顯示型態**可能有一點資訊，但遠不如傳說中神準**。
6. 讓它更客觀：**明確定義、等確認、事前記錄、統計結果、回測**。
7. 最佳用法：用型態**定義進場、停損、目標**，計算風險報酬比。

>
> 我覺得型態比較好的用法，是幫你規劃交易：在哪裡進場、跌到哪裡代表你錯了要停損、目標大概在哪裡，然後算算看這筆交易值不值得做，而不是把它當成一定會漲的預言。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「看到頭肩頂就一定會跌」 | 型態只代表機率傾向，很多型態會失敗，而且判讀主觀。 |
| 「型態快完成了，可以提前進場」 | 型態完成前，你不知道它會變成什麼；提前進場常常變成猜測。 |
| 「量度目標一定會到」 | 只是參考，價格可能遠遠超過，也可能到不了。 |
| 「書上的型態例子都這麼準」 | 書上展示的是挑選過的成功案例（倖存者偏差）。 |

## 🛠️ 練習（約 90 分鐘）

**練習 1：找型態**
在 TradingView 上（任何商品、任何時間），找出以下型態各 1 個並截圖：
- 頭肩頂或頭肩底
- 雙重頂或雙重底
- 三角收斂
- 旗形
- 矩形

**記錄每個型態的後續**：突破方向、是否達到量度目標、是否失敗。5 個裡面有幾個「照書上的劇本走」？

**練習 2：寫出客觀定義**
選一個型態（例如雙重底），寫出一個**明確到可以讓別人照著判斷**的定義（包含：兩個低點的差距、間隔天數、反彈幅度、確認條件）。請朋友用你的定義去看同一張圖，看看你們的判斷是否一致。

**練習 3：設計交易**
上升三角形：上緣（壓力）在 120 元，最近的低點在 112 元，三角形開口的高度是 15 元。價格以收盤價突破 120 元，收在 121 元。
1. 量度目標是多少？
2. 停損可以放在哪裡？
3. 風險報酬比大約是多少？

## ✅ 自我測驗

**Q1. 頭肩頂的本質是什麼？為什麼跌破頸線被視為確認？**

<details><summary>看答案</summary>

本質是上升趨勢結構被破壞：右肩沒有超過頭部（高點不再墊高），跌破頸線代表低點也開始下降，原本「高點、低點都墊高」的上升趨勢定義不再成立。

</details>

**Q2. 為什麼型態判讀很主觀？列出三個原因。**

<details><summary>看答案</summary>

例如：(1) 型態的定義模糊（多高算肩、差多少算相同）；(2) 型態完成前無法知道會變成什麼，事後才清楚；(3) 確認偏誤，想做多就看到底部型態；(4) 書上只展示成功案例；(5) 換時間週期，型態就不同。

</details>

**Q3. 型態最實用的用法是什麼？**

<details><summary>看答案</summary>

用來定義交易的結構：進場點（突破確認）、停損點（型態失敗的位置）、目標價（量度目標），進而計算風險報酬比與損益兩平勝率，判斷這筆交易值不值得做。

</details>

**Q4. 練習 3 參考答案**

<details><summary>看答案</summary>

1. 量度目標 = 120 + 15 = **135 元**
2. 例如跌回三角形內、低於最近的低點附近，或用 ATR 決定；簡單示例：**115 元**（突破失敗的位置）
3. 從 121 元進場：風險 121 − 115 = 6；報酬 135 − 121 = 14；風險報酬比約 **1:2.3**

</details>
