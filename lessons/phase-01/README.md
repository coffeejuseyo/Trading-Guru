# Phase 1｜市場地圖：金融市場與商品

> **預計時數：40 小時**（11 個單元）
> **生活比喻：逛一座超大的菜市場——有賣菜的、賣肉的、賣「明年月餅預購單」的，每一攤的規則都不一樣。**

在 Phase 0，你知道了交易是什麼、坑在哪裡。現在我們要**走進市場**，認識裡面每一攤在賣什麼。

學完這個階段，當朋友問你「股票跟 ETF 差在哪？」「期貨是什麼？」「選擇權為什麼像保險？」「比特幣能買嗎？」，你都能用生活例子回答，而且清楚說出**每種商品的風險**。

## 完成 Phase 1 的標準

- [ ] 能用供需解釋價格為什麼會變動
- [ ] 能說明股票、債券、ETF 的差別（用「飲料店」的例子）
- [ ] 能說明期貨和選擇權的差別，以及為什麼選擇權像保險
- [ ] 能解釋為什麼利率上升，債券價格會下跌
- [ ] 能說出槓桿型 ETF、期貨、加密貨幣的主要風險
- [ ] 知道台股、美股、期貨、加密貨幣的交易時間
- [ ] 完成「金融商品比較表」
- [ ] 總複習測驗答對 80% 以上

> ⚠️ 本階段提到的費率、稅率、交易時間、合約規格等，都是撰寫時的一般情況，**實際以交易所、主管機關與券商的最新公告為準**。
