# 1.1｜什麼是市場？價格如何由供需決定

> ⏱️ 約 3 小時｜[Phase 1 目錄](README.md)｜[下一單元：1.2 →](1.2-stocks.md)

## 🎯 學完你會知道

- 「市場」到底是什麼
- 價格是怎麼由**買方和賣方**共同決定的
- 為什麼價格每分每秒都在變
- 什麼是「價格已經反映了」，以及為什麼「好消息出來卻下跌」

---

## 📖 開場故事：颱風天的高麗菜

每年颱風季，新聞都會出現這種標題：「颱風過境，高麗菜一顆飆到 200 元！」

平常一顆 40 元的高麗菜，為什麼幾天內就漲了好幾倍？

- 颱風把菜田打壞了 → **能賣的高麗菜變少了**（供給減少）
- 大家擔心之後買不到，趕快去囤貨 → **想買的人變多了**（需求增加）

東西變少、想要的人變多，價格就漲了。

過了一兩個月，新的菜種出來了，或是從其他地方運來了，價格又慢慢回到 40 元。

> 🥬 **你已經懂得市場最核心的道理了：價格是由「有多少人想買」和「有多少人想賣」決定的。** 股票、黃金、比特幣、外幣，全部都一樣。

---

## 🧠 正文

### 1. 市場是什麼？

**市場 = 買方和賣方見面、交換東西的地方。**

| 市場 | 交換的東西 | 在哪裡見面 |
|---|---|---|
| 傳統菜市場 | 蔬菜、肉、水果 | 實體攤位 |
| 二手拍賣網站 | 二手物品 | 網路平台 |
| 房屋市場 | 房子 | 仲介、實價登錄 |
| **股票市場** | 公司的股份 | **證券交易所**（現在全部電子化） |
| **期貨市場** | 期貨合約 | **期貨交易所** |
| **外匯市場** | 各國貨幣 | 銀行之間的網路（沒有單一中心） |
| **加密貨幣市場** | 比特幣等數位資產 | 加密貨幣交易所 |

> 🏪 金融市場就是一個「超大型的電子菜市場」。差別在於：這裡賣的不是高麗菜，而是**公司的所有權、合約、貨幣**。

### 2. 供給與需求：價格的蹺蹺板

想像一個蹺蹺板：

```
   想買的人多（需求 ↑）                想賣的人多（供給 ↑）
          ▼                                   ▼
     價格往上 ⬆                           價格往下 ⬇
```

| 情況 | 生活例子 | 價格 |
|---|---|---|
| 需求 ↑，供給不變 | 演唱會門票：歌手爆紅，想看的人變多 | ⬆ 上漲（黃牛票變貴） |
| 需求 ↓，供給不變 | 冬天的冰淇淋 | ⬇ 下跌（第二件半價） |
| 供給 ↓，需求不變 | 颱風後的高麗菜 | ⬆ 上漲 |
| 供給 ↑，需求不變 | 盛產季的芒果 | ⬇ 下跌（一箱 200 元） |

**在股票市場中：**
- 公司公布很好的財報 → 更多人想買這家公司的股票 → 股價上漲
- 公司爆發醜聞 → 很多人想賣掉 → 股價下跌
- 整體經濟變差，大家都想把股票換成現金 → 大部分股價下跌

### 3. 價格是怎麼「成交」的？拍賣會

股票的價格不是公司決定的，也不是交易所決定的，而是**買方和賣方「喊價」喊出來的**。

想像一場拍賣會：

| 想買的人（出價） | | 想賣的人（要價） |
|---|---|---|
| 阿明：我出 99 元 | | 小華：100 元我就賣 |
| 小美：我出 98 元 | | 阿傑：101 元我才賣 |
| 大雄：我出 97 元 | | 胖虎：102 元我才賣 |

現在：
- 最高的出價是 **99 元**（阿明）
- 最低的要價是 **100 元**（小華）
- 兩個人差了 1 元，**沒有成交**

這時候，如果有個新的買家說：「**我現在就要，100 元我買！**」→ 他和小華成交，**最新成交價變成 100 元**。

> 🔑 **你在看盤軟體上看到的「股價」，就是「最近一筆成交的價格」。** 它是買賣雙方在那一刻都同意的價格。

這個「喊價清單」叫做**委託簿**，Phase 2 會詳細介紹。

### 4. 為什麼價格每分每秒都在變？

因為每一秒鐘，都有新的人進來：

- 有人看到新聞，想買
- 有人需要用錢，想賣
- 有人的停損被觸發，被迫賣
- 有電腦程式根據演算法在買賣

**每一筆新的買賣，都在推動蹺蹺板。** 價格就像一個一直被推來推去的球，永遠不會靜止。

### 5. 價格反映的是「預期」，不只是「現在」

這是新手最容易困惑的地方：

> ❓「公司明明公布了賺錢的好消息，為什麼股價反而下跌？」

因為**市場交易的是對未來的預期**。

🍜 **生活例子：排隊名店**

一家拉麵店被傳說「下個月會被米其林推薦」：
- 消息傳出時，大家就開始排隊了（股價已經先漲）
- 下個月米其林真的推薦了 → 但大家早就知道了，排隊的人沒有變更多
- 甚至有人覺得「推薦後一定很擠，不想去了」→ 排隊人潮反而變少

這就是股市常說的：
- **「買在謠言，賣在事實」**
- **「利多出盡」**：好消息公布時，期待已經被提前反映在價格裡了

| 市場原本預期 | 實際公布 | 股價可能的反應 |
|---|---|---|
| 賺 10 億 | 賺 12 億（比預期好） | ⬆ 上漲 |
| 賺 10 億 | 賺 10 億（符合預期） | ➡ 差不多，甚至下跌 |
| 賺 10 億 | 賺 8 億（雖然還是賺錢，但比預期差） | ⬇ 下跌 |

> 🔑 **影響價格的，不是「好或壞」，而是「比預期好或壞」。**

### 6. 市場有多「聰明」？效率市場的概念

既然價格會反映大家的預期，那麼：

> 如果有一個公開的好消息，價格是不是**很快就漲上去了**？

是的。在大型、熱門的市場（例如台積電、蘋果），公開消息通常在幾秒到幾分鐘內就反映在價格上。這個概念叫做**效率市場假說**。

🛒 **生活例子：超市結帳隊伍**

在超市，如果有一條結帳隊伍特別短，大家很快就會換過去，於是各條隊伍的長度很快就變得差不多。想靠「找最短的隊伍」節省很多時間，其實很難。

這告訴我們：
- 在交易中，**「看新聞就買」很難賺錢**，因為等你看到，價格早就動了
- 真正的優勢通常來自別的地方（Phase 0 的 0.3 有提到：行為、結構、耐心、紀律……）
- 但市場也**不是完全有效率**：恐慌、貪婪、被迫買賣，都會讓價格偏離合理的位置

> 學者對「市場到底多有效率」爭論了幾十年。比較實際的看法是：**市場大部分時候很有效率，但不是永遠**。交易者就是在找那些「不完全有效率」的小縫隙。

### 7. 流動性：熱鬧的市場 vs. 冷清的市場

**流動性 = 你能多快、以多合理的價格把東西買到或賣掉。**

| | 高流動性 | 低流動性 |
|---|---|---|
| 生活例子 | 便利商店的礦泉水：隨時買得到，價格固定 | 一幅冷門畫家的畫：可能好幾個月都找不到買家 |
| 股票例子 | 台積電、0050：每秒都有人買賣 | 冷門小型股：可能幾分鐘才成交一筆 |
| 買賣價差 | 很小 | 很大 |
| 想急著賣時 | 馬上就能賣，價格差不多 | 可能要降價很多才賣得掉 |

> 🔑 **新手應該優先交易流動性高的商品。** 流動性低的商品，光是買賣價差和滑價就會吃掉你的獲利，而且急著賣的時候可能賣不掉。

---

## 📌 重點整理

1. **市場** = 買方和賣方見面交換的地方。
2. 價格由**供給與需求**決定：想買的多就漲，想賣的多就跌。
3. 你看到的股價 = **最近一筆成交價**，是買賣雙方喊價的結果。
4. 價格反映的是**預期**：影響價格的是「比預期好或壞」，所以會有「利多出盡」。
5. 大型市場**大部分時候很有效率**，看新聞追價很難賺錢。
6. **流動性**決定你能不能快速、以合理價格買賣，新手優先選流動性高的商品。

## 🗣️ 一分鐘講給朋友聽（示範稿）

> 「你知道股價是怎麼決定的嗎？其實跟颱風天高麗菜變貴是一樣的道理。颱風把菜田打壞，菜變少，大家又搶著囤貨，價格就漲。股票也是：想買的人多，價格就漲；想賣的人多，價格就跌。
>
> 而且股價不是公司決定的，是大家喊價喊出來的，像拍賣會。你在 App 上看到的價格，就是最近一筆成交的價格。
>
> 還有一個很重要的點：股價反映的是大家對未來的期待。所以有時候公司公布賺錢，股價反而跌，因為大家原本期待它賺更多——就像排隊名店真的拿到米其林之後，反而沒那麼多人排了，因為大家早就知道了。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「股價是公司或交易所決定的」 | 股價是市場上買賣雙方成交出來的。 |
| 「公司賺錢，股價就一定會漲」 | 要看是否比市場**預期**的好。 |
| 「看到好新聞馬上買，就能賺錢」 | 大型市場對公開消息反應極快，你看到時通常已經反映了。 |
| 「股價下跌代表公司變差了」 | 也可能是整體市場下跌、有人急需用錢、或預期改變。 |
| 「冷門股比較少人注意，比較容易賺」 | 冷門股流動性差，買賣成本高、想賣時可能賣不掉。 |

## 🛠️ 練習（約 40 分鐘）

**練習 1：供需判斷**
判斷以下情況，對該商品的價格可能造成什麼影響（上漲 / 下跌），並說明是供給還是需求的變化：

1. 一款新手機大受歡迎，全球缺貨。（對該手機品牌的股價）
2. 中東發生衝突，石油產量可能減少。（對石油價格）
3. 政府宣布大幅放寬某種農產品的進口。（對國內該農產品的價格）
4. 某家公司宣布要發行大量新股票來籌錢。（對該公司的股價）

**練習 2：預期遊戲**
市場預期某公司本季每股賺 5 元。請判斷以下結果公布後，股價比較可能上漲還是下跌：
(a) 賺 6 元　(b) 賺 5 元，但說下一季會變差　(c) 虧損 1 元，但比原本傳聞的虧損 3 元好

**練習 3：觀察流動性**
在 TradingView 上，比較 `TWSE:2330`（台積電）和一檔你隨便找的冷門小型股，看它們每天的**成交量**差多少。

## ✅ 自我測驗

**Q1. 用一句話說明價格是怎麼決定的。**

<details><summary>看答案</summary>

價格由供給與需求決定：想買的人多（需求大於供給）就上漲，想賣的人多（供給大於需求）就下跌；實際成交價是買賣雙方都同意的價格。

</details>

**Q2. 為什麼公司公布賺錢的消息，股價卻可能下跌？**

<details><summary>看答案</summary>

因為價格反映的是預期。如果市場原本預期它賺更多，實際結果雖然賺錢但低於預期，股價就可能下跌；或者好消息早已被提前反映（利多出盡）。

</details>

**Q3. 什麼是流動性？為什麼新手應該選流動性高的商品？**

<details><summary>看答案</summary>

流動性是能多快、以多合理的價格買賣某樣東西。流動性高的商品買賣價差小、滑價小、想賣時能馬上賣掉；流動性低的商品交易成本高，而且可能賣不掉。

</details>

**Q4. 練習參考答案**

<details><summary>看答案</summary>

練習 1：(1) 需求增加 → 上漲；(2) 供給減少 → 上漲；(3) 供給增加 → 下跌；(4) 股票供給增加、每股分到的獲利被稀釋 → 通常下跌（但若市場相信籌到的錢會帶來很好的成長，也可能不跌）。

練習 2：(a) 比預期好 → 較可能上漲；(b) 這季符合預期，但未來預期變差 → 較可能下跌；(c) 雖然虧損，但比預期好 → 有可能上漲。重點是「和預期比」。

</details>
