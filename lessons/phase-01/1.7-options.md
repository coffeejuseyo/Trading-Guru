# 1.7｜選擇權：付訂金買「權利」

> ⏱️ 約 6 小時｜[← 上一單元：1.6](1.6-futures.md)｜[Phase 1 目錄](README.md)｜[下一單元：1.8 →](1.8-forex.md)

## 🎯 學完你會知道

- 選擇權是什麼，和期貨最大的差別
- **買權（Call）** 和 **賣權（Put）**
- 四種基本部位：買 Call、賣 Call、買 Put、賣 Put
- 履約價、權利金、到期日、損益兩平點
- 為什麼**時間**和**波動度**會影響選擇權價格
- 為什麼「賣方」看起來勝率高，卻可能一次賠光

> 📌 選擇權是 Phase 1 最難的單元，所以給了 6 小時。**看不懂很正常，慢慢來。** 記住兩個比喻就抓到 80%：**買房訂金（Call）** 和 **汽車保險（Put）**。

---

## 📖 開場故事：兩個比喻

### 比喻一：買房訂金（買權 Call）

你看中一間房子，現在售價 1,000 萬。你覺得附近要蓋捷運，房價可能會漲，但還不確定。

你和屋主談好：

> 「我付你 **10 萬元訂金**，換取一個**權利**：未來 3 個月內，我**可以**用 1,000 萬買這間房子。如果我不買，10 萬元訂金歸你。」

3 個月後：
- **捷運確定要蓋，房價漲到 1,300 萬** → 你行使權利，用 1,000 萬買下價值 1,300 萬的房子。扣掉 10 萬訂金，賺 **290 萬**。
- **捷運取消，房價跌到 800 萬** → 你當然不買，放棄權利。你只損失 **10 萬訂金**，而不是 200 萬。

> 🏠 **這就是買權（Call）：付一筆小錢，買一個「未來可以用約定價格買進」的權利。**

### 比喻二：汽車保險（賣權 Put）

你有一台 100 萬的新車，你每年付 **3 萬元保費**給保險公司。保單內容是：

> 「如果車子撞壞了，保險公司要賠你。」

- **一整年平安無事** → 3 萬元保費就是你為了安心付出的成本
- **車子撞爛了** → 保險公司賠你，你避免了大損失

> 🚗 **這就是賣權（Put）：付一筆保費，買一個「價格下跌時能得到保障」的權利。** 投資人持有股票時，可以買 Put 來「替股票買保險」。

## 🧠 正文

### 1. 選擇權是什麼？

**選擇權 = 一個「權利」（不是義務），讓你在未來某個時間之前（或某個時間點），用約定的價格買進或賣出某樣東西。**

| 術語 | 說明 | 買房比喻 |
|---|---|---|
| **標的物** | 選擇權綁定的東西（股票、指數、期貨……） | 房子 |
| **履約價** | 約定的買賣價格 | 1,000 萬 |
| **權利金** | 買方付給賣方的價格（選擇權本身的價格） | 10 萬元訂金 |
| **到期日** | 權利的最後期限 | 3 個月後 |
| **買方** | 付權利金，取得**權利** | 你（付訂金的人） |
| **賣方** | 收權利金，承擔**義務** | 屋主（收訂金，必須配合） |

### 2. 期貨 vs. 選擇權：義務 vs. 權利

| | 期貨 | 選擇權（買方） |
|---|---|---|
| 性質 | **義務**：到期一定要履約 | **權利**：有利才履約，不利就放棄 |
| 比喻 | 預購月餅，到時候一定要買 | 付訂金保留買房權，可以不買 |
| 最大虧損 | 理論上很大（可能超過保證金） | **最多就是權利金** |
| 成本 | 保證金（押金，會退） | 權利金（付了就是對方的） |

> 🔑 **選擇權買方的最大虧損是有限的（就是權利金），這是它最吸引人的地方。** 但代價是：大部分時候，權利金會慢慢消失（後面會解釋）。

### 3. 買權（Call）與賣權（Put）

| | 買權（Call） | 賣權（Put） |
|---|---|---|
| 給買方的權利 | 以履約價**買進**標的 | 以履約價**賣出**標的 |
| 買方的預期 | 價格**上漲** | 價格**下跌**（或想避險） |
| 生活比喻 | 買房訂金 | 汽車保險 |
| 記憶口訣 | **Call = 叫過來**（把東西買過來） | **Put = 放出去**（把東西賣出去） |

### 4. 四種基本部位

每一張選擇權都有一個買方和一個賣方，所以有四種組合：

| 部位 | 你做了什麼 | 預期 | 最大獲利 | 最大虧損 | 比喻 |
|---|---|---|---|---|---|
| **買 Call** | 付權利金 | 大漲 | 理論上**無限** | **權利金** | 付訂金的買房者 |
| **賣 Call** | 收權利金 | 不漲 | **權利金** | 理論上**無限** | 收訂金的屋主（房價暴漲也只能用原價賣） |
| **買 Put** | 付權利金 | 大跌 / 避險 | 很大（跌到 0 為止） | **權利金** | 買保險的車主 |
| **賣 Put** | 收權利金 | 不跌 | **權利金** | 很大（跌到 0 為止） | 保險公司 |

> 🔑 **買方**：付小錢、虧損有限、獲利可能很大，但**勝率通常較低**（像買保險，大部分時候用不到）。
> **賣方**：收小錢、獲利有限、虧損可能很大，**勝率通常較高**（像保險公司，大部分時候白收保費）。

### 5. 數字例子：台指選擇權

**台指選擇權每 1 點 = 50 元**（以期交所公告為準）。台指選擇權是**歐式**選擇權，只能在**到期日**履約（現金結算）。

假設現在加權指數 **20,000 點**。

#### 例子 A：買進 Call（看漲）

買進 1 口**履約價 20,000** 的 Call，權利金 **200 點**（= 200 × 50 = **10,000 元**）。

**損益兩平點** = 履約價 + 權利金 = 20,000 + 200 = **20,200 點**

| 到期時指數 | Call 價值（點） | 扣掉權利金後損益（點） | 損益（元） |
|---:|---:|---:|---:|
| 19,000 | 0（不履約） | −200 | **−10,000** |
| 19,500 | 0 | −200 | −10,000 |
| 20,000 | 0 | −200 | −10,000 |
| 20,200 | 200 | 0 | **0（兩平）** |
| 20,500 | 500 | +300 | +15,000 |
| 21,000 | 1,000 | +800 | **+40,000** |

```
損益（元）
 +40,000 |                          ╱
         |                       ╱
         |                    ╱
       0 |-----------------●------------  ← 損益兩平 20,200
         |               ╱
 -10,000 |______________╱                  ← 最多虧權利金
         +------+-------+------+------→ 到期指數
              19,500  20,000  20,500  21,000
```

> 🏠 跟買房訂金一模一樣：最多虧訂金，漲越多賺越多。

#### 例子 B：買進 Put（看跌 / 避險）

買進 1 口**履約價 20,000** 的 Put，權利金 **180 點**（= **9,000 元**）。

**損益兩平點** = 履約價 − 權利金 = 20,000 − 180 = **19,820 點**

| 到期時指數 | Put 價值（點） | 扣掉權利金後損益（點） | 損益（元） |
|---:|---:|---:|---:|
| 19,000 | 1,000 | +820 | **+41,000** |
| 19,500 | 500 | +320 | +16,000 |
| 19,820 | 180 | 0 | **0（兩平）** |
| 20,000 | 0（不履約） | −180 | −9,000 |
| 20,500 | 0 | −180 | **−9,000** |

> 🚗 跟汽車保險一樣：沒出事，保費就沒了；出大事，保險賠很多。

#### 例子 C：賣出 Call（賣方的風險）

如果你是例子 A 的**賣方**，損益剛好完全相反：

| 到期時指數 | 賣方損益（元） |
|---:|---:|
| 20,000 以下 | **+10,000**（白收權利金） |
| 20,200 | 0 |
| 21,000 | **−40,000** |
| 22,000 | **−90,000** |
| 23,000 | **−140,000**…… 漲越多賠越多 |

> 🔑 **賣方大部分時候都在「白收權利金」，勝率看起來很高。但市場一旦大幅波動，一次就可能賠掉好幾個月、甚至好幾年收的權利金。** 這就像在壓路機前面撿硬幣：大部分時候都撿得到，但一次沒閃開就完了。
>
> 而且**賣方需要繳保證金**（因為承擔義務），也會面臨追繳和斷頭，跟期貨一樣。

### 6. 價內、價平、價外

| 狀態 | Call | Put | 比喻 |
|---|---|---|---|
| **價內**（ITM） | 指數 > 履約價 | 指數 < 履約價 | 現在履約就有價值 |
| **價平**（ATM） | 指數 ≈ 履約價 | 指數 ≈ 履約價 | 剛好在邊界 |
| **價外**（OTM） | 指數 < 履約價 | 指數 > 履約價 | 現在履約沒有價值，只剩「希望」 |

> 🎟️ 價外選擇權很便宜，像彩券：可能 10 元、20 元一口，但大部分到期時都會變成 0。

### 7. 權利金由什麼組成？

**權利金 = 內含價值 + 時間價值**

| 組成 | 說明 | 比喻 |
|---|---|---|
| **內含價值** | 如果**現在**立刻履約，值多少錢 | 房價已經漲到 1,100 萬，你的 1,000 萬購買權現在就值 100 萬 |
| **時間價值** | 「還有時間，可能會變得更有價值」的**希望**值多少錢 | 離到期還有 3 個月，房價還可能再漲 |

例：指數 20,300 點，履約價 20,000 的 Call 權利金是 450 點
- 內含價值 = 20,300 − 20,000 = **300 點**
- 時間價值 = 450 − 300 = **150 點**

### 8. 時間是買方的敵人：時間價值遞減

**越接近到期日，時間價值就越少；到期那一刻，時間價值變成 0。**

而且時間價值的消失**不是平均的**，越接近到期，消失得越快。

> 🧊 **比喻：融化的冰塊**
> 選擇權的時間價值像一塊冰，每天都在融化。剛開始融得慢，快融完的時候融得特別快。
>
> 📅 比喻二：演唱會門票的「轉售價值」。演唱會前一個月，大家還有很多時間安排，票的價值很高；演唱會當天晚上散場後，這張票就一文不值。

**這代表什麼？**
- **買方**：就算你方向看對，如果漲得**不夠多**、**不夠快**，時間價值的流失仍可能讓你虧錢
- **賣方**：每過一天，時間站在你這邊（這是賣方的收入來源）

### 9. 波動度：市場越緊張，保險越貴

**標的價格波動越大（或市場預期越大），選擇權就越貴。**

> 🌀 **比喻：颱風季的保險**
> 如果氣象局預報下週有超強颱風，這時候才去買颱風險，保費一定很貴（甚至不給保）。
>
> 市場也是：當大家恐慌、預期股市會大幅波動時，選擇權的權利金（尤其是 Put）就會變得很貴。

**隱含波動率**：從選擇權價格「反推」出來，市場預期未來會波動多大。

> 💡 美國有一個很有名的指標叫 **VIX**（俗稱「恐慌指數」），就是根據 S&P 500 選擇權的價格計算出的預期波動率。VIX 越高，代表市場越恐慌。台灣期交所也有類似的臺指選擇權波動率指數。

### 10. 影響權利金的因素總整理

| 因素 | Call 價格 | Put 價格 | 直覺 |
|---|---|---|---|
| 標的價格 ⬆ | ⬆ | ⬇ | 漲了，買進權更有價值、保險更用不到 |
| 履約價越高 | ⬇ | ⬆ | 用越高的價買越不划算；用越高的價賣越划算 |
| 距離到期越久 | ⬆ | ⬆ | 時間越多，可能性越多 |
| 波動度 ⬆ | ⬆ | ⬆ | 變動越大，選擇權越可能變得很有價值 |

（還有利率、股利等因素，影響較小，Phase 8 再說。）

### 11. 選擇權可以拿來做什麼？

| 用途 | 做法（預告） | 比喻 |
|---|---|---|
| **避險** | 持有股票，買 Put 保護 | 替車子買保險 |
| **看方向，限制虧損** | 看漲買 Call、看跌買 Put | 付訂金保留購買權 |
| **收租金** | 持有股票，賣出 Call 收權利金（掩護性買權） | 把房子出租收租金 |
| **組合策略** | 同時買賣不同履約價（價差策略） | 組合式保單 |

這些策略在 **Phase 8** 會詳細介紹。

> 🔑 **新手提醒**：選擇權有很多變數（方向、時間、波動度），很容易「方向看對還是虧錢」。賣方策略看起來勝率高，但有尾端風險。在完成 Phase 6 風險管理之前，**只做觀念學習與紙上模擬**。

## 📌 重點整理

1. **選擇權 = 權利，不是義務**。買方付權利金取得權利，賣方收權利金承擔義務。
2. **Call（買權）** = 以履約價**買進**的權利 → 像**買房訂金**。
3. **Put（賣權）** = 以履約價**賣出**的權利 → 像**汽車保險**。
4. **買方**：虧損有限（權利金）、獲利可能很大、勝率通常較低。**賣方**：獲利有限、虧損可能很大、勝率通常較高。
5. 損益兩平：Call = 履約價 + 權利金；Put = 履約價 − 權利金。
6. **權利金 = 內含價值 + 時間價值**；時間價值像冰塊，越接近到期融化越快。
7. **波動度越高，選擇權越貴**（颱風前的保險）。
8. 台指選擇權每點 50 元，歐式、現金結算。

## 🗣️ 一分鐘講給朋友聽（示範稿）

> 「選擇權就是花一點錢買一個『權利』。最好懂的例子是買房訂金：你付 10 萬訂金，換一個三個月內可以用 1,000 萬買房子的權利。房價漲到 1,300 萬，你就用 1,000 萬買，大賺；房價跌了，你就不買，只虧訂金。這叫**買權**，賭的是上漲。
>
> 另一種叫**賣權**，像汽車保險：你付保費，車子沒事保費就沒了，車子撞壞保險公司賠你。投資人可以買賣權替股票買保險。
>
> 要注意兩件事：第一，選擇權有時間限制，時間價值像冰塊會一直融化，就算方向對了，漲得不夠快還是會虧。第二，賣選擇權的人像保險公司，大部分時候白收錢，但遇到大災難一次就可能賠很多。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「買選擇權最多虧權利金，所以很安全」 | 虧損有限，但**很容易全部虧光**：價外選擇權到期大多歸零。 |
| 「賣選擇權勝率高，是穩定收入」 | 勝率高但有尾端風險，一次大波動可能賠掉長期累積的獲利，甚至更多。 |
| 「方向看對就一定賺」 | 還要看漲跌幅度、速度、時間價值流失和波動度變化。 |
| 「便宜的價外選擇權比較划算」 | 便宜是因為到期變成有價值的機率低，像彩券。 |
| 「Put 就是放空」 | 買 Put 是付權利金取得賣出權，虧損有限；放空股票或做空期貨的虧損可能很大。兩者不同。 |

## ✅ 自我測驗

**Q1. 選擇權和期貨最大的差別是什麼？**

<details><summary>看答案</summary>

期貨買賣雙方都有「義務」到期履約；選擇權買方擁有「權利」，有利才履約、不利可以放棄，所以買方最大虧損是權利金。（選擇權賣方則承擔義務。）

</details>

**Q2. 用生活例子分別解釋 Call 和 Put。**

<details><summary>看答案</summary>

Call 像買房訂金：付一筆訂金，取得未來以約定價格買房的權利，房價漲就買、跌就放棄只虧訂金。Put 像汽車保險：付保費，價格下跌（出事）時能得到補償，沒事就損失保費。

</details>

**Q3. 為什麼選擇權賣方的勝率通常較高，卻被認為風險很大？**

<details><summary>看答案</summary>

因為大部分選擇權（尤其價外）到期時沒有價值，賣方常常能白收權利金；但賣方的獲利上限就是權利金，而虧損可能非常大。一次劇烈的市場波動就可能虧掉長期累積的收入。

</details>

**Q4. 為什麼越接近到期，買方越不利？**

<details><summary>看答案</summary>

選擇權的時間價值會隨時間流逝而減少，而且越接近到期減少得越快；到期時時間價值歸零。如果標的價格沒有在剩下的時間內朝有利方向大幅移動，權利金就會一直縮水。

</details>

**Q5. 練習參考答案**

<details><summary>看答案</summary>

練習 1：(1) 買 Call；(2) 買 Put（避險）；(3) 賣出選擇權（例如賣 Call 和/或賣 Put），但要了解虧損可能很大。

練習 2：
1. 120 × 50 = **6,000 元**
2. 20,200 + 120 = **20,320 點**
3. 20,000 → Call 價值 0，損益 **−6,000 元**；20,320 → 價值 120 點，損益 **0 元**；20,800 → 價值 600 點，扣權利金 120 → +480 點 × 50 = **+24,000 元**

練習 3：內含價值 = 20,000 − 19,700 = **300 點**；時間價值 = 380 − 300 = **80 點**

練習 4：最大獲利 = 權利金 150 點（7,500 元），發生在到期指數 ≥ 20,000；損益兩平 = 20,000 − 150 = **19,850 點**；指數越跌虧越多，在指數大跌（例如崩盤）時虧損最大。

</details>
