## 🎯 學完你會知道

- **再平衡**的目的：維持你**選定的風險水準**（回想 8.11）
- 不再平衡會發生什麼事：**配置漂移**
- 三種再平衡方法：**定期、門檻、用新資金**
- 實作：比較不再平衡、每月、每季、每年、5% 門檻
- 再平衡的**成本與換手率**
- 一個常見的誤解：再平衡是為了「提高報酬」？

---

## 📖 開場故事：定期把歪掉的盆栽扶正

陽台上的盆栽，因為陽光總是從同一個方向照過來，植物會**慢慢往光的方向長歪**。

- 每天轉一下盆栽：植物長得很直，但你每天都要記得（而且太頻繁也沒必要）
- 一年轉一次：大致上還好，但中間會歪得比較多
- 歪到一個程度才轉：省事，又不會歪太多
- 從來不轉：最後整盆植物都倒向一邊，一陣強風就翻倒了

> 🪴 **再平衡就是扶正盆栽**：你設定了「股票 60%、債券 40%」，但股票漲得比較多，幾年後可能變成 80% / 20%——你的組合「長歪了」，承擔的風險比你原本選的大很多。再平衡把它扶回 60% / 40%，**讓風險維持在你能承受的水準**。

## 🧠 正文

### 1. 配置漂移

```python
import numpy as np
import pandas as pd
from bt_toolkit import perf_stats

prices = pd.read_csv("multi_asset.csv", parse_dates=["Date"], index_col="Date")
rets = prices.pct_change().dropna()


def simulate(rets, target, rule="never", band=0.05, cost=0.001):
    """模擬再平衡。rule："never"、"M"（每月）、"Q"（每季）、"Y"（每年）、"band"（偏離超過 band 才調整）。
    cost：每次買賣的成本比例（買和賣都收）。"""
    target = np.array(target, dtype=float)
    w, value = target.copy(), 1.0
    values, turnover, n_rebal, last_period = [], 0.0, 0, None
    for date, r in rets.iterrows():
        grown = w * (1 + r.values)              # 每個資產今天的漲跌
        value *= grown.sum()
        w = grown / grown.sum()                 # 漲多的權重變大：漂移
        rebalance = False
        if rule in ("M", "Q", "Y"):
            period = {"M": (date.year, date.month),
                      "Q": (date.year, (date.month - 1) // 3),
                      "Y": date.year}[rule]
            rebalance = last_period is not None and period != last_period   # 進入新的月 / 季 / 年
            last_period = period
        elif rule == "band":
            rebalance = np.abs(w - target).max() > band
        if rebalance:
            traded = np.abs(w - target).sum() / 2   # 單邊換手率
            turnover += traded
            value *= 1 - 2 * traded * cost          # 賣出 + 買進的成本
            w = target.copy()
            n_rebal += 1
        values.append(value)
    return pd.Series(values, index=rets.index), n_rebal, turnover, w


equity, _, _, w_end = simulate(rets[["股票", "債券"]], [0.6, 0.4], "never")
print(f"股6債4，14 年都不再平衡，最後的權重：股票 {w_end[0]:.0%}、債券 {w_end[1]:.0%}")
```

輸出：`股6債4，14 年都不再平衡，最後的權重：股票 81%、債券 19%`

> 🪴 **盆栽長歪了**：你以為自己持有一個「股 6 債 4」的穩健組合，實際上已經變成「股 8 債 2」的積極組合。如果此時股市大跌，你承受的損失會遠超過當初的預期。

### 2. ⭐ 比較不同的再平衡方法

for name, cols, target in [("股6債4", ["股票", "債券"], [0.6, 0.4]),

**觀察：**

| 發現 | 說明 |
|---|---|
| **不再平衡的報酬最高** | 因為股票一路漲，組合越來越偏向報酬高的股票（但風險也越來越高） |
| **不再平衡的回撤最深** | 股 6 債 4 的最大回撤從約 −14.5% 變成 −20.5% |
| 再平衡的頻率影響不大 | 每月、每季、門檻的結果很接近；每年稍差 |
| **門檻法最有效率** | 只調整 9 次，結果和每月調整 167 次差不多 |

> 🔑 **再平衡的主要目的是控制風險，不是提高報酬。** 在一個長期上漲的資產（股票）與低報酬資產（債券）的組合中，不再平衡通常報酬更高——因為你等於一直加碼股票。但你承擔的風險也一直變大，那已經不是你當初選擇的組合了。

### 3. 三種再平衡方法

| 方法 | 做法 | 優點 | 缺點 |
|---|---|---|---|
| **定期** | 每月 / 每季 / 每年固定一天 | 簡單、好執行、可以排進行事曆 | 可能在不需要時也調整；或在兩次之間偏離太多 |
| **門檻** | 任一資產偏離目標超過 X%（例如 5 個百分點）才調整 | 調整次數少、效率高 | 需要定期檢查 |
| **用新資金** | 每次投入新的錢（例如每月定期定額）時，買偏低的那一邊 | 幾乎沒有賣出成本與稅 | 新資金相對於總資產變小後，效果有限 |

> 💡 **實務建議**：「每季檢查一次，偏離超過 5 個百分點才調整」，再加上「新資金優先買偏低的資產」。簡單又有效率。

### 4. 再平衡的成本

| 成本 | 說明 |
|---|---|
| 交易成本 | 手續費、交易稅、滑價（10.6）——頻率越高，成本越高 |
| 稅 | 在某些市場或帳戶中，賣出獲利要繳稅 |
| 時間與注意力 | 每次再平衡都要花時間；也可能因情緒而猶豫（Phase 7） |

> 🔑 回想 8.11：**再平衡是一種紀律化的逆向操作**——在大漲時賣一點、在大跌時買一點。這在心理上很難（大跌時要「加碼股票」需要勇氣），所以**事先寫好規則**很重要。

### 5. 策略組合的再平衡

11.1 的策略組合（`strats.mean(axis=1)`）其實假設了**每天再平衡**到等權重。實務上，策略組合也需要決定再平衡規則：

| 情況 | 處理方式 |
|---|---|
| 某策略連續賺錢，佔比越來越高 | 依規則把資金移回其他策略（避免組合變成單一策略） |
| 某策略進入長期回撤 | **照規則再平衡**（等於加碼它）——除非它觸發了失效條件（8.13、10.17） |
| 某策略觸發失效條件 | 停用，把資金分配給其他策略，記錄原因 |

## 📌 重點整理

1. 再平衡 = **扶正盆栽**：把漂移的配置調回目標，**維持你選定的風險水準**。
2. 不再平衡：股 6 債 4 在 14 年後漂移成**股 8 債 2**，報酬較高，但回撤從 −14.5% 變成 −20.5%。
3. **再平衡的主要目的是控制風險，不是提高報酬。**
4. 頻率影響不大；**門檻法**（偏離 5% 才調整）只需要很少的調整次數。
5. 實務建議：每季檢查、偏離 5% 才調整、新資金優先買偏低的資產。
6. 再平衡是紀律化的逆向操作，**事先寫好規則**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「再平衡一定會提高報酬」 | 主要目的是控制風險；在長期上漲的資產組合中，不再平衡的報酬常常更高。 |
| 「再平衡越頻繁越好」 | 頻率影響不大，太頻繁只會增加成本；門檻法很有效率。 |
| 「不再平衡也沒關係，讓贏家繼續跑」 | 配置會漂移到你沒有選擇的風險水準。 |
| 「大跌時應該暫停再平衡」 | 大跌時再平衡（買進下跌的資產）正是紀律的核心；除非觸發事先寫好的失效條件。 |

## ✅ 自我測驗

**Q1. 再平衡的主要目的是什麼？**

<details><summary>看答案</summary>

維持投資組合在你選定的目標配置與風險水準。不再平衡時，漲得多的資產（通常是風險較高的股票）比重會越來越大，組合的風險會漂移到你沒有選擇的水準。再平衡的主要目的是控制風險，而不是提高報酬。

</details>

**Q2. 為什麼不再平衡的組合，報酬常常比較高？**

<details><summary>看答案</summary>

因為長期報酬較高的資產（例如股票）會越漲越多，比重越來越大，等於一直加碼高報酬資產；但這也代表承擔的風險越來越高，回撤也更深。

</details>

**Q3. 門檻法有什麼優點？**

<details><summary>看答案</summary>

只有在配置偏離目標超過一定程度時才調整，所以調整次數少、交易成本低，同時又能避免配置偏離太多。本例中 14 年只調整 9 次，效果和每月調整 167 次接近。

</details>
