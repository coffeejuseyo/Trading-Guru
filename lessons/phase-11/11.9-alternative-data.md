# 11.9｜另類資料與情緒分析概念

## 🎯 學完你會知道

- **另類資料**是什麼：價格、財報以外的資訊來源

## 📖 開場故事：看停車場的車數推測百貨公司業績

一位分析師想知道某家百貨公司這一季的生意好不好。財報要三個月後才公布，他等不及。

他想到一個方法：**每個週末去數百貨公司停車場的車子**。

- 停車場常常客滿 → 生意可能不錯
- 停車場空蕩蕩 → 生意可能不好

後來他發現，有公司提供**衛星照片**，可以一次數全國所有分店的停車場。他用這些資料，在財報公布前就推測出業績。

但他也遇到問題：
- 衛星照片很貴
- 下雨天、陰天看不到車子
- 百貨公司開始推廣線上購物，**停車場的車變少，不代表生意變差**
- 而且很快，**其他分析師也開始買同樣的衛星照片**……

> 🛰️ **另類資料就是「停車場的車數」**：用價格與財報以外的資訊，更早、更細地了解真實世界發生了什麼。它可能提供優勢（8.2 的「資訊優勢」），但也充滿陷阱——而且一旦大家都在用，優勢就消失了。

---

## 🧠 正文

### 1. 常見的另類資料

| 類型 | 例子 | 想回答的問題 |
|---|---|---|
| **文字資料** | 新聞、財報電話會議逐字稿、公司公告、社群貼文 | 市場情緒如何？管理層的語氣有沒有變化？ |
| **衛星與地理資料** | 停車場車數、油槽存量、工廠夜間燈光、船舶航行 | 實體經濟活動的變化 |
| **消費資料** | 信用卡刷卡統計、電子發票、App 下載數 | 公司營收在財報前的趨勢 |
| **網路資料** | 搜尋熱度、網站流量、電商評論與價格 | 產品熱度、需求變化 |
| **供應鏈資料** | 進出口統計、海關資料、供應商關係 | 上下游的訂單變化 |
| **另類財務資料** | 內部人交易申報、法人持股變化、融資融券 | 知情者或大資金在做什麼 |

> 💡 台股投資人常看的「三大法人買賣超」、「融資融券餘額」，某種程度上也是「價格以外」的資料（回想 1.3、2.5）。它們公開、免費，所以大家都在看——這也代表優勢可能有限。

### 2. ⭐ 情緒分析：用字典替新聞打分數

最簡單的情緒分析：準備一份**正面詞**和**負面詞**的字典，計算每則新聞出現幾個。

```python
positive = ["成長", "創新高", "優於預期", "看好", "上修", "擴產", "獲利", "強勁"]
negative = ["衰退", "虧損", "不如預期", "下修", "裁員", "停工", "疲弱", "利空"]
negators = ["不", "未", "沒有", "並非"]


def sentiment(text):
    """正面詞 +1、負面詞 −1；正面詞前面緊接否定詞時改成 −1。"""
    score = 0
    for word in positive:
        if word in text:
            i = text.index(word)
            negated = any(text[max(0, i - len(n)):i] == n for n in negators)
            score += -1 if negated else 1
    for word in negative:
        if word in text:
            score -= 1
    return score


headlines = [
    "甲公司第三季營收成長 20%，獲利優於預期",
    "乙公司宣布裁員 10%，下修全年財測",
    "丙公司訂單強勁，計畫擴產",
    "分析師不看好丁公司下半年表現",
    "戊公司營收創新高，但毛利率疲弱",
    "市場傳出己公司停工利空，公司澄清並非事實",
]
for h in headlines:
    print(f"{sentiment(h):>3}  {h}")
```

輸出：

```
  3  甲公司第三季營收成長 20%，獲利優於預期
 -2  乙公司宣布裁員 10%，下修全年財測
  2  丙公司訂單強勁，計畫擴產
 -1  分析師不看好丁公司下半年表現
  0  戊公司營收創新高，但毛利率疲弱
 -2  市場傳出己公司停工利空，公司澄清並非事實
```

（以上標題都是虛構的示範例句。）

**檢查每一則：**

| 標題 | 分數 | 對嗎？ |
|---|---:|---|
| 甲：營收成長、獲利優於預期 | +3 | ✅ 正面 |
| 乙：裁員、下修財測 | −2 | ✅ 負面 |
| 丁：分析師**不**看好 | −1 | ✅ 否定詞處理成功 |
| 戊：創新高，**但**毛利率疲弱 | 0 | ⚠️ 正負抵銷；市場可能更在意「但」後面的內容 |
| 己：傳出停工利空，公司**澄清並非事實** | **−2** | ❌ **其實是利多（澄清謠言）**，字典法完全判斷錯誤 |

> 🔑 **字典法很簡單，但很容易出錯**：它不懂轉折（「但」）、不懂澄清與反諷、不懂上下文。實務上會用機器學習或大型語言模型處理文字，但它們同樣需要嚴格驗證——回想 11.8 的所有陷阱。

### 3. 從情緒分數到交易訊號

情緒分數要能用來交易，還要經過幾個步驟：

| 步驟 | 要注意的事 |
|---|---|
| ① 收集文字資料 | 來源、授權、**每則新聞的發布時間**（精確到分鐘） |
| ② 計算情緒分數 | 字典、機器學習、語言模型；用人工標記的樣本驗證準確度 |
| ③ 彙總 | 每檔股票每天的平均分數、分數的變化、新聞數量 |
| ④ 對齊時間 | **收盤後才發布的新聞，只能影響隔天的交易**（8.1） |
| ⑤ 回測 | 和 Phase 10 一樣：成本、樣本外、多重檢定、基準比較 |

> ⚠️ **時間戳記是另類資料最常見的前視偏差來源**：很多資料庫記錄的是「資料被整理進資料庫的時間」或「所屬日期」，而不是「市場第一次能看到的時間」。用錯了，就等於偷看未來（10.10）。

### 4. ⚠️ 使用另類資料的 6 個風險

| # | 風險 | 說明 |
|---|---|---|
| 1 | **成本高** | 衛星、刷卡、專業文字資料通常很貴，主要客戶是機構 |
| 2 | **歷史太短** | 很多資料只有幾年歷史，樣本太少，難以驗證（3.9、11.6） |
| 3 | **優勢會消失** | 一旦很多人用同樣的資料，資訊很快就反映在價格中（8.2） |
| 4 | **品質與一致性** | 資料來源改變定義、樣本變動、缺漏、雜訊（9.11） |
| 5 | **法律與倫理** | 個人隱私、資料授權、爬蟲是否違反網站條款；**內線交易**相關法規（重大未公開資訊不可使用） |
| 6 | **時間戳記與前視偏差** | 見第 3 節 |

> 🔑 對機構來說，另類資料是一場**軍備競賽**：比誰的資料更早、更細、更獨家。散戶很難在這場競賽中勝出。

### 5. 散戶怎麼看待另類資料？

| ✅ 可以做 | ❌ 避免 |
|---|---|
| **了解**機構在用什麼資料，理解市場為什麼有時候「提前反應」 | 花大錢買資料，期待找到聖杯 |
| 使用**免費、公開**的資料（政府統計、交易所公布的法人與融資資料、公司公告），但要知道大家都在看 | 用社群媒體上的「消息」交易 |
| 把文字資料當作**風險提醒**（例如重大負面新聞 → 檢查持股） | 以為情緒分數高就一定會漲 |
| 練習用 Python 處理文字資料（本單元的程式），培養技能 | 忽略時間戳記與前視偏差 |

> 💡 **對大部分散戶來說，最大的優勢不是資料，而是時間與耐心**（8.2 的「容量優勢」與「行為優勢」）：你不需要每季向客戶報告績效，可以持有長期策略、忍受機構無法忍受的回撤，也可以交易機構嫌太小而不做的標的。

## 📌 重點整理

1. 另類資料 = **停車場的車數**：用價格與財報以外的資訊，更早了解真實世界。
2. 類型：**文字、衛星地理、消費、網路、供應鏈、另類財務資料**。
3. 情緒分析字典法：正面詞 +1、負面詞 −1、處理否定詞；**簡單但很容易出錯**（轉折、澄清、反諷）。
4. 從分數到訊號：收集、評分、彙總、**對齊時間**、回測。
5. 6 個風險：**成本、歷史短、優勢消失、品質、法律倫理、時間戳記**。
6. 散戶：了解、善用免費資料、當作風險提醒；**真正的優勢是時間與耐心**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「有了另類資料就能打敗市場」 | 資料昂貴、歷史短、品質不一，且一旦普及優勢就消失。 |
| 「情緒分析很準」 | 簡單的字典法常誤判轉折、否定、澄清與反諷；任何方法都需要驗證。 |
| 「新聞日期就是可以交易的日期」 | 要用市場第一次能看到的時間；收盤後的新聞只能影響隔天交易。 |
| 「網路上的消息都可以拿來交易」 | 要注意資料授權、隱私與內線交易相關法規，以及消息的真偽。 |

## 🛠️ 練習（約 60 分鐘）

**練習 1：改進字典**
修改 `sentiment()`：遇到「但」、「不過」時，只計算轉折**之後**的部分（或給後半段兩倍權重）。重新計算戊公司那則標題的分數。

**練習 2：澄清新聞**
想一個方法讓「澄清」、「並非事實」、「不實」這類詞能正確處理（例如遇到澄清詞時把整則分數反轉）。它會不會造成新的誤判？舉一個例子。

**練習 3：觀察免費資料**
選一種免費、公開的「價格以外」的資料（例如交易所公布的三大法人買賣超或融資餘額），寫下：它想回答什麼問題？資料什麼時候公布？如果要回測，時間要怎麼對齊？

## ✅ 自我測驗

**Q1. 另類資料為什麼可能提供優勢？又為什麼優勢常常不持久？**

<details><summary>看答案</summary>

因為它能比傳統資料（價格、財報）更早或更細地反映真實的經濟活動，提供資訊優勢。但當越來越多人使用同樣的資料，這些資訊很快就會反映在價格中，優勢就消失了；加上資料昂貴、歷史短、品質不一，持續的優勢很難維持。

</details>

**Q2. 字典法情緒分析有哪些常見的錯誤？**

<details><summary>看答案</summary>

無法理解否定（若沒處理）、轉折（「但」後面的內容更重要）、澄清與反諷（例如澄清負面謠言其實是利多），也無法理解上下文與程度差異，常常誤判新聞的真正含義。

</details>

**Q3. 為什麼時間戳記是另類資料最常見的前視偏差來源？**

<details><summary>看答案</summary>

因為資料庫常記錄的是資料所屬日期或整理進資料庫的時間，而不是市場第一次能看到這筆資訊的時間。若用所屬日期回測，等於在資訊公開前就使用了它；收盤後才發布的資訊也必須對齊到隔天交易，否則就是偷看未來。

</details>
