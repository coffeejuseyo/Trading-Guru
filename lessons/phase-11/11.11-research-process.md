## 📖 開場故事：科學家做實驗的步驟

一位科學家懷疑「某種植物萃取物可以降血壓」。他不是直接給病人吃，然後說「你看，很多人吃了血壓下降！」而是：

1. **觀察**：吃這種植物的地區，高血壓的人好像比較少
2. **假說**：「這種萃取物能讓收縮壓平均下降至少 5 mmHg」——**寫清楚、可以被推翻**
3. **設計實驗**：一組吃萃取物、一組吃外觀相同的安慰劑；**事先決定**要測多少人、多久、什麼算成功
4. **執行與記錄**：每一個受試者的結果都記錄，包括退出的人
5. **分析**：和安慰劑組比較；考慮運氣的可能
6. **結論**：效果顯著 → 再找另一批人重複實驗；不顯著 → **誠實發表「無效」**
7. **重複驗證**：別的研究團隊也做一次

> 🔬 **量化交易研究就是同一套方法**：觀察 → 假說 → 設計 → 驗證 → 結論。安慰劑組就是你的基準（10.16），重複實驗就是樣本外與其他市場（10.13、11.7），事先決定成功條件就是規格書與淘汰條件（8.13）。**差別在於：市場不會告訴你「安慰劑效應」有多大——你必須自己刁難自己。**

## 🧠 正文

### 1. ⭐ 研究流程總覽

```
  ① 觀察與問題      「均值回歸策略好像在盤整時表現好？」
        ↓
  ② 假說（看資料前）  可推翻的預測 + 優勢來源 + 淘汰條件
        ↓
  ③ 研究設計（看資料前）資料、切分點、規則、成本、基準、測試次數上限
        ↓
  ④ 樣本內開發       回測、交叉驗證程式、成本、前視偏差檢查、記錄每次修改
        ↓
  ⑤ 凍結            Git commit：「樣本外測試前定案」
        ↓
  ⑥ 樣本外驗證（一次）樣本外、walk-forward、穩健性評分表、蒙地卡羅
        ↓
  ⑦ 結論            淘汰 / 新假說 / 模擬交易（Phase 12）
        ↓
  ⑧ 記錄與分享       回測報告 + 研究日誌
```

| 步驟 | 對應單元 |
|---|---|
| ② 假說、優勢來源 | 8.2、8.13 |
| ③ 設計 | 10.13（切分）、10.6（成本）、10.16（基準）、11.6（測試次數） |
| ④ 開發 | 10.2～10.10 |
| ⑥ 驗證 | 10.13～10.15、11.5、11.7 |
| ⑦⑧ 結論與記錄 | 10.17、本單元的研究日誌 |

### 2. ⭐ 好假說的條件

| 條件 | ❌ 壞例子 | ✅ 好例子 |
|---|---|---|
| **具體** | 「技術分析有用」 | 「收盤價在 200 日均線上方時，RSI(2) < 10 之後 5 天的平均報酬 > 0」 |
| **可以被推翻** | 「市場有時候會反彈」（永遠對） | 「……且扣除成本後，樣本外的夏普 > 同期曝險相當基準」 |
| **有理由** | 「回測出來最好的參數」 | 「短期恐慌賣壓造成過度反應（行為優勢，8.2）」 |
| **事先寫下淘汰條件** | 「看結果再說」 | 「樣本外夏普 < 0.3 或輸給曝險相當基準 → 淘汰」 |

> 🔑 **「可以被推翻」是科學假說最重要的特徵**（哲學家 Karl Popper 的核心觀點）。一個怎樣都說得通的假說，什麼也沒告訴你。

### 3. ⭐ 研究漏斗：大部分想法都應該被淘汰

```
  100 個想法
     ↓  優勢來源說不清楚 → 淘汰
   30 個有理由的假說
     ↓  樣本內回測扣成本後就不行 → 淘汰
   10 個樣本內還不錯
     ↓  樣本外 / walk-forward / 基準比較失敗 → 淘汰
    3 個通過驗證
     ↓  模擬交易 3 個月以上（Phase 12）
    1 個上場（小額實盤）
```

（數字只是示意，說明比例的概念。）

> 🎓 回想 Phase 10：你用一整套嚴謹的流程淘汰了均線策略（10.16）、在隨機資料上看到 Phase 8 的三個策略全部失敗（10.18）。**這不是失敗，而是漏斗正常運作。** 研究者的生產力，不是「找到多少賺錢策略」，而是「多快、多便宜地淘汰不賺錢的策略」。

### 4. ⚠️ 4 種研究壞習慣

| 壞習慣 | 意思 | 例子 | 對策 |
|---|---|---|---|
| **資料探勘（p-hacking）** | 反覆嘗試各種組合，直到找到「顯著」的結果 | 試了 200 組參數和 15 種過濾條件，報告最好的 | 記錄測試次數、提高門檻（11.6）、樣本外 |
| **事後假說（HARKing）** | 看了結果才編出假說，假裝是事先想的 | 發現「星期三效果最好」，才說「因為星期三法人調倉」 | 假說與設計**先寫、先 commit** |
| **說故事** | 用一個生動的故事解釋結果，忽略其他可能 | 「這個策略在 2020 年賺錢，因為它抓到了疫情恐慌」——但可能只是運氣 | 問「如果結果相反，我也能編出故事嗎？」（7.5 敘事謬誤） |
| **沉沒成本** | 已經花了很多時間，捨不得放棄 | 「我研究這個策略三個月了，再調整一下應該就行了」 | 事先寫淘汰條件；時間預算（第 6 節）（7.2） |

> 💡 這四種壞習慣，在學術界的「再現性危機」（很多已發表的研究結果無法被重複驗證）中都扮演了重要角色。交易研究也一樣——而且你的錢會替你的壞習慣買單。

### 5. ⭐ 研究日誌

使用 [templates/research-log.md](../../templates/research-log.md)，每個想法開一份：

| 段落 | 什麼時候寫 | 重點 |
|---|---|---|
| 1～3 觀察、假說、設計 | **看資料之前** | 寫完就用 Git commit，留下時間證據 |
| 4 測試紀錄 | 每一次修改 | 改了什麼、為什麼改、結果——包括失敗的 |
| 5 凍結與樣本外 | 定案後 | 只做一次 |
| 6～7 結論 | 最後 | 淘汰也是結論；學到了什麼 |

> 🔑 **研究日誌和回測報告（10.17）的差別**：回測報告是「成果展示」，研究日誌是「實驗記錄本」。日誌記錄的是**過程**——特別是你試過、失敗、放棄的東西，這些決定了最終結果的可信度（11.6 的測試次數）。

### 6. 時間預算與放棄的時機

| 原則 | 做法 |
|---|---|
| **設定時間預算** | 每個想法最多投入 N 小時（例如 10 小時）完成第一輪驗證 |
| **快速淘汰** | 先用最簡單的版本、最快的方法（向量化回測）檢查；不行就停 |
| **淘汰條件事先寫** | 碰到就停，不要「再調整一下」 |
| **定期回顧** | 每月看一次研究日誌：哪些想法卡住太久？ |
| **失敗也要結案** | 寫下結論與學到的東西，然後歸檔 |

### 7. 範例：一份精簡的研究日誌

以 11.1 的策略組合為例（節錄）：

| 段落 | 內容 |
|---|---|
| 假說 | 「三個低相關（相關係數 < 0.3）且各自期望值為正的策略，等權重組合後的夏普會高於任何單一策略，最大回撤會淺於任何單一策略。」 |
| 理由 | 組合波動小於加權平均（11.1 的公式）。 |
| 淘汰條件 | 組合夏普沒有高於最好的單一策略，或最大回撤沒有改善。 |
| 設計 | `strategy_returns.csv`，2010–2023；前 9 年樣本內、後 5 年樣本外；等權重、每日再平衡（之後測試每月）。 |
| 結果 | 全期間：組合夏普 1.01 vs. 單一最高 0.98；最大回撤 −11.67% vs. 最淺 −16.11%。 |
| 下一步 | 計算樣本外期間的同樣指標；用區塊拔靴（11.5）看組合回撤的分布；測試危機期間（例如 2020 年）的相關性是否上升（11.1 陷阱）。 |
| 測試次數 | 1（等權重）；之後若嘗試其他權重方法，逐一記錄。 |

## 📌 重點整理

1. 研究流程：**觀察 → 假說 → 設計 → 樣本內開發 → 凍結 → 樣本外驗證 → 結論 → 記錄**。
2. 好假說：**具體、可以被推翻、有理由、事先寫下淘汰條件**。
3. **研究漏斗**：大部分想法都應該被淘汰；生產力 = 多快多便宜地淘汰爛策略。
4. 4 種壞習慣：**資料探勘、事後假說、說故事、沉沒成本**。
5. **研究日誌**記錄過程（包括失敗），回測報告呈現成果；假說與設計先寫、先 commit。
6. 設定**時間預算**與**淘汰條件**，失敗也要結案。

## 🗣️ 一分鐘講給朋友聽（示範稿）

> 「做交易研究就像科學家做實驗：先觀察、再提出一個可以被推翻的假說，事先決定怎麼測、什麼結果算失敗，然後才看資料。最後不管結果好壞都要誠實記錄。
>
> 最常犯的錯有四種：一直試到結果好看為止、看了結果才編理由、用一個好聽的故事解釋運氣、還有花了很多時間捨不得放棄。我的對策是用研究日誌，看資料之前就把假說和淘汰條件寫下來存檔，每一次修改也都記錄。
>
> 大部分的想法都會被淘汰，這很正常。研究的價值不是找到多少賺錢策略，而是用很低的成本淘汰掉不賺錢的。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「研究就是找到賺錢的策略」 | 研究的主要產出是淘汰不可行的想法；真正通過驗證的策略很少。 |
| 「看了資料再提出假說也一樣」 | 事後假說會讓運氣看起來像規律；假說必須在看資料前寫下並留存證據。 |
| 「失敗的研究不用記錄」 | 失敗的嘗試決定了測試次數，也是避免重複犯錯的資產。 |
| 「已經花了很多時間，應該再調整看看」 | 這是沉沒成本謬誤；應依事先寫下的淘汰條件決定。 |

## ✅ 自我測驗

**Q1. 為什麼好的假說必須「可以被推翻」？**

<details><summary>看答案</summary>

因為一個無論結果如何都說得通的假說，無法被資料檢驗，也就沒有提供任何資訊。可以被推翻的假說會明確預測「應該看到什麼」與「看到什麼就承認錯誤」，讓研究結果真正有意義，也防止事後找藉口。

</details>

**Q2. 什麼是事後假說（HARKing）？怎麼預防？**

<details><summary>看答案</summary>

事後假說是先看到結果，再編造一個假說並假裝是事先提出的，例如發現某個日期效應後才編理由。它會讓運氣產生的結果看起來像有理論支持的規律。預防方法：在看資料之前寫下假說、研究設計與淘汰條件，並用 Git commit 等方式留下時間證據。

</details>

**Q3. 研究日誌和回測報告有什麼不同？**

<details><summary>看答案</summary>

回測報告是最終成果的整理與展示，重點在結果、穩健性與結論；研究日誌是過程的實驗記錄本，記錄假說、設計，以及每一次修改、失敗與放棄的嘗試。研究日誌決定了總測試次數與結果的可信度，也幫助避免重複犯錯。

</details>
