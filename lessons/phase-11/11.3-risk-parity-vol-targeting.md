## 📖 開場故事：讓每個隊員承擔差不多的防守責任

一支籃球隊有 4 名球員，教練說：「每個人上場時間一樣，很公平！」

但比賽打完一看，**失分幾乎都來自兩個人的防守位置**——他們負責盯對方最強的得分手，而另外兩個人幾乎沒什麼防守壓力。

「上場時間一樣」不代表「承擔的責任一樣」。教練改變做法：讓防守壓力大的位置**少上場一點、多換人**，防守壓力小的位置**多上場一點**，讓每個位置**承擔的失分責任差不多**。

> 🏀 **風險平價就是這個想法**：等權重組合給每個資產一樣多的「錢」，但波動大的資產（股票）承擔了大部分的「風險」。風險平價改成讓每個資產承擔**一樣多的風險**——波動大的少配一點，波動小的多配一點。

## 🧠 正文

### 1. ⭐ 資金權重 ≠ 風險權重

**風險貢獻**：每個資產對組合總波動「貢獻」了多少比例。

**資產 i 的風險貢獻 = 權重ᵢ ×（共變異數矩陣 × 權重）ᵢ ÷ 組合變異數**

```python
import numpy as np
import pandas as pd

prices = pd.read_csv("multi_asset.csv", parse_dates=["Date"], index_col="Date")
rets = prices.pct_change().dropna()
cov = rets.cov() * 252
assets = list(rets.columns)


def risk_contribution(w):
    """每個資產對組合變異數的貢獻比例（加總為 1）。"""
    port_var = w @ cov.values @ w
    return w * (cov.values @ w) / port_var


equal = np.ones(4) / 4
for a, w, rc in zip(assets, equal, risk_contribution(equal)):
    print(f"{a}：資金 {w:.0%}，風險貢獻 {rc:.1%}")
```

輸出：

```
股票：資金 25%，風險貢獻 37.7%
債券：資金 25%，風險貢獻 1.6%
黃金：資金 25%，風險貢獻 17.7%
海外股票：資金 25%，風險貢獻 43.0%
```

> 🏀 **四等分的組合，表面上很分散，但 80% 的風險來自兩種股票**，債券只貢獻了 1.6% 的風險——它在組合中幾乎沒有「防守責任」。同理，常見的「股 6 債 4」組合，絕大部分的風險其實都來自股票。

### 2. 反波動率權重：最簡單的近似

**權重 ∝ 1 ÷ 波動度**：波動越大，權重越小。

```python
vol = rets.std() * np.sqrt(252)
inv_vol = (1 / vol) / (1 / vol).sum()
for a, w, rc in zip(assets, inv_vol, risk_contribution(inv_vol.values)):
    print(f"{a}：波動 {vol[a]:.1%}，資金 {w:.1%}，風險貢獻 {rc:.1%}")
```

輸出：

```
股票：波動 18.0%，資金 16.0%，風險貢獻 28.1%
債券：波動 5.8%，資金 49.4%，風險貢獻 17.2%
黃金：波動 14.6%，資金 19.7%，風險貢獻 24.0%
海外股票：波動 19.4%，資金 14.9%，風險貢獻 30.7%
```

> 💡 反波動率權重只考慮波動，**沒有考慮相關性**。股票和海外股票高度相關（0.71），所以它們的風險貢獻還是偏高。

### 3. ⭐ 風險平價：讓風險貢獻完全相等

用 `scipy` 找出讓四個資產風險貢獻都等於 25% 的權重：

```python
from scipy.optimize import minimize

objective = lambda w: ((risk_contribution(w) - 0.25) ** 2).sum()
erc = minimize(objective, equal, bounds=[(0, 1)] * 4,
               constraints=({"type": "eq", "fun": lambda w: w.sum() - 1},)).x
for a, w, rc in zip(assets, erc, risk_contribution(erc)):
    print(f"{a}：資金 {w:.1%}，風險貢獻 {rc:.1%}")
```

輸出：

```
股票：資金 14.5%，風險貢獻 25.0%
債券：資金 54.6%，風險貢獻 25.0%
黃金：資金 18.5%，風險貢獻 25.0%
海外股票：資金 12.3%，風險貢獻 25.0%
```

> 🔑 **風險平價不需要預測報酬**，只需要波動與相關性——這兩個比預期報酬好估計得多（11.2）。這是它最大的優點。

### 4. ⭐ 實作：每月調整的風險平價組合

用**過去 60 天**的波動度，每月底計算反波動率權重，下個月使用（只用當時已知的資料）：

```python
from bt_toolkit import perf_stats

vol60 = rets.rolling(60).std() * np.sqrt(252)
weights = (1 / vol60).div((1 / vol60).sum(axis=1), axis=0)       # 每天的反波動率權重
month_end = rets.resample("ME").last().index
w_monthly = weights.reindex(month_end)                             # 只在月底決定
w_daily = w_monthly.reindex(rets.index, method="ffill").shift(1)   # 下一個交易日才開始用

start = "2010-05"                                                  # 前 60 天沒有權重
rp = (w_daily * rets).sum(axis=1).loc[start:]
ew = rets.mean(axis=1).loc[start:]
sixty_forty = (0.6 * rets["股票"] + 0.4 * rets["債券"]).loc[start:]
rp_scaled = rp * (ew.std() / rp.std())                             # 放大到和等權重一樣的波動

for name, r in [("等權重", ew), ("股6債4", sixty_forty), ("風險平價", rp), ("風險平價（同波動）", rp_scaled)]:
    p = perf_stats(r)
    print(f"{name}：年化 {p['年化報酬']:.2%}，波動 {p['年化波動']:.2%}，"
          f"最大回撤 {p['最大回撤']:.2%}，夏普 {p['夏普比率']:.2f}")
```

輸出：

```
等權重：年化 8.23%，波動 9.58%，最大回撤 -18.60%，夏普 0.84
股6債4：年化 7.51%，波動 10.55%，最大回撤 -14.51%，夏普 0.72
風險平價：年化 4.68%，波動 5.90%，最大回撤 -7.99%，夏普 0.78
風險平價（同波動）：年化 7.51%，波動 9.58%，最大回撤 -12.85%，夏普 0.78
```

**怎麼解讀？**

| 觀察 | 說明 |
|---|---|
| 風險平價的報酬低、波動低、回撤很淺 | 因為它配置了大量的債券（低波動資產） |
| 放大到同樣波動後 | 年化 7.51%，比等權重低一點，但**最大回撤淺很多**（−12.85% vs. −18.60%） |
| 夏普 0.78 vs. 等權重 0.84 | 在這份資料上，夏普沒有比較高——因為模擬資料中股票的報酬特別好，而風險平價配置得比較少 |

> 🔑 **風險平價不是「報酬比較高」的魔法**，它的價值在於：**不押注任何一種資產的報酬**、讓組合在不同環境下（例如股市大跌時）表現比較平均。在股票大漲的期間，它通常會落後股票比重高的組合。
>
> ⚠️ 風險平價要達到和股票組合相同的報酬，通常需要**槓桿**（把債券的部位放大）。槓桿有借貸成本與追繳風險，而且當債券和股票同時下跌（例如利率快速上升的時期），風險平價會受傷。

### 5. ⭐ 波動度目標：波動大時減碼

**波動度目標（Volatility Targeting）**：設定一個目標波動（例如 10%），每天依最近的波動調整部位：

**部位比例 = 目標波動 ÷ 最近的波動**（通常設上限，例如 1.5 倍）

| 最近 20 天的年化波動 | 部位比例（目標 10%） |
|---:|---:|
| 5% | 2.0 → 上限 1.5 |
| 10% | 1.0 |
| 20% | 0.5 |
| 40% | 0.25 |

> 💡 **為什麼可能有用？** 真實市場的波動會**群聚**（3.3、3.7）：大波動之後常常接著大波動，而且大跌常常發生在高波動時期。波動度目標在市場變得動盪時自動減碼，可能避開一部分的大跌。

`multi_asset.csv` 是用比較簡單的方法產生的，波動群聚不明顯，所以這裡另外模擬一份**有波動群聚**的價格（GARCH 模型，一種常用來描述「波動會群聚」的模型）：

```python
def garch_returns(seed, n=252 * 14):
    """模擬有波動群聚的日報酬（GARCH(1,1)）。"""
    rng = np.random.default_rng(seed)
    omega, alpha, beta = 0.000002, 0.09, 0.89
    var = omega / (1 - alpha - beta)
    r = np.empty(n)
    for t in range(n):
        r[t] = 0.0004 + np.sqrt(var) * rng.standard_normal()
        var = omega + alpha * (r[t] - 0.0004) ** 2 + beta * var   # 今天的大波動 → 明天的波動變大
    return pd.Series(r, index=pd.bdate_range("2010-01-04", periods=n))


r = garch_returns(1)
vol20 = r.rolling(20).std() * np.sqrt(252)
exposure = (0.10 / vol20).clip(upper=1.5).shift(1).dropna()     # 用昨天以前的波動決定今天的部位
base = r.loc[exposure.index]
targeted = exposure * base
constant = base * exposure.mean()                                # 對照：固定持有「平均部位」

for name, x in [("一直全額持有", base), ("波動度目標 10%", targeted), (f"固定 {exposure.mean():.0%} 部位", constant)]:
    p = perf_stats(x)
    print(f"{name}：年化 {p['年化報酬']:.2%}，波動 {p['年化波動']:.2%}，"
          f"最大回撤 {p['最大回撤']:.2%}，夏普 {p['夏普比率']:.2f}")
```

輸出：

```
一直全額持有：年化 7.26%，波動 16.01%，最大回撤 -40.13%，夏普 0.50
波動度目標 10%：年化 7.31%，波動 10.71%，最大回撤 -25.60%，夏普 0.69
固定 76% 部位：年化 5.73%，波動 12.16%，最大回撤 -31.80%，夏普 0.50
```

> 🔑 **關鍵比較是最後兩列**（回想 10.16 的「曝險相當基準」）：平均部位一樣是 76%，**固定持有**的夏普和全額持有一樣（0.50）；**依波動調整**的夏普提高到 0.69，最大回撤也明顯較淺。改善來自「在對的時候減碼」，而不只是「平均持有比較少」。
>
> ⚠️ 換成其他亂數種子，改善的幅度會不同（有時很小，練習 3）。學術研究（例如 Moreira 與 Muir 在 2017 年的研究）發現，在真實股市資料上波動度管理的組合常能改善風險調整後報酬，但效果因市場與期間而異，也有研究質疑它在樣本外的穩定性。**一樣要用你自己的資料驗證。**

### 6. 兩種方法的比較

| | 風險平價 | 波動度目標 |
|---|---|---|
| 調整什麼 | **資產之間**的權重 | **整體**的部位大小 |
| 依據 | 各資產的波動與相關性 | 最近的整體波動 |
| 需要預測報酬嗎？ | 不需要 | 不需要 |
| 主要優點 | 風險分散更平均 | 在動盪時自動減碼 |
| 主要風險 | 需要槓桿才能有足夠報酬；股債同跌時受傷 | 波動突然暴增時來不及反應；換手率較高 |
| 回想 | 6.8 分散 | 6.5 ATR 部位（同樣的概念：波動大就少買） |

## 📌 重點整理

1. **資金權重 ≠ 風險權重**：四等分的組合中，80% 的風險來自股票。
2. **反波動率權重**：權重 ∝ 1 ÷ 波動；簡單，但沒考慮相關性。
3. **風險平價（等風險貢獻）**：讓每個資產承擔一樣多的風險；不需要預測報酬。
4. 實作：風險平價回撤淺很多，但在股票強勢的期間報酬落後；要達到相同報酬需要槓桿。
5. **波動度目標**：部位 = 目標波動 ÷ 最近波動；在有波動群聚的資料上，夏普從 0.50 提高到 0.69。
6. 判斷是否有效：和**相同平均部位的固定持有**比較。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「資金平均分配就是風險平均分配」 | 波動大的資產會主導組合的風險。 |
| 「風險平價的報酬一定比較高」 | 它的價值在於風險更平均、不押注報酬；在單一資產大漲時常常落後。 |
| 「波動度目標一定會改善績效」 | 效果取決於波動是否群聚，因市場與期間而異；要和相同平均部位的固定持有比較。 |
| 「風險平價不需要槓桿」 | 不加槓桿時報酬通常偏低；加槓桿則帶來借貸成本與追繳風險。 |

## ✅ 自我測驗

**Q1. 為什麼四等分的組合，風險主要來自股票？**

<details><summary>看答案</summary>

因為風險貢獻取決於權重、波動與相關性。股票與海外股票的波動（約 18%～19%）遠高於債券（約 6%），而且兩者高度相關（0.71）。即使資金一樣多，它們對組合波動的貢獻也遠大於債券，本例中合計約 80%。

</details>

**Q2. 風險平價最大的優點與缺點是什麼？**

<details><summary>看答案</summary>

優點：不需要預測報酬，只需要較容易估計的波動與相關性；各資產承擔的風險平均，組合在不同環境下表現較平均、回撤較淺。缺點：配置大量低波動資產，不加槓桿時報酬偏低；加槓桿有借貸成本與追繳風險；當股債同時下跌時會受傷；在單一資產大漲時常落後。

</details>

**Q3. 評估波動度目標是否有效時，為什麼要和「相同平均部位的固定持有」比較？**

<details><summary>看答案</summary>

因為波動度目標平均下來持有的部位通常小於 100%，單純持有較少部位本身就會降低波動與回撤，但不會提高夏普（10.8）。和相同平均部位的固定持有比較，才能判斷改善是否來自「在高波動時減碼」的時機選擇，而不只是平均持股較少。

</details>
