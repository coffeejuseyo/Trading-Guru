## 📖 開場故事：同一道菜請不同的人試吃

小林研發了一道新菜，想知道好不好吃。

**錯誤的做法**：只請自己的媽媽試吃。媽媽說好吃——但媽媽本來就喜歡你做的菜，而且她已經吃過你練習時的每一個版本。

**比較好的做法**：
- 請**不同的人**試吃：同事、朋友、陌生人（**交叉驗證**：每個人都是新的考官）
- 換**不同的食材供應商**再做一次（**其他市場**：同樣的食譜，換一批材料還行嗎？）
- 鹽**多一點少一點**（**參數擾動**，10.15）
- 在**不同的季節**做（**子期間**：冬天好吃，夏天呢？）
- 故意讓火候**有點誤差**（**雜訊注入**：真實廚房不會那麼精準）

> 🍳 **穩健性測試就是「請不同的人、在不同的條件下試吃」**：一道真正好吃的菜，在大部分的情況下都好吃；一道只在「媽媽、你家的鍋、完美火候」下好吃的菜，不值得放上菜單。

## 🧠 正文

### 1. ⭐ 交叉驗證的想法

| 方法 | 做法 | 問題 |
|---|---|---|
| 一次樣本外（10.13） | 70% 練習、30% 考試 | 只考一次，受單一期間影響大 |
| Walk-forward（10.14） | 學一段、考下一段，往前滾動 | 早期的資料只能當訓練，不能當考題 |
| **K 折交叉驗證** | 把資料切成 K 段，**每一段輪流當考題**，其他段當訓練 | 時間序列要特別小心（第 2 節） |

### 2. ⚠️ 時間序列的特殊問題

一般的機器學習（例如辨識貓狗照片），交叉驗證會**隨機**把資料分成 K 份。但金融資料有**時間順序**：

| 問題 | 說明 | 後果 |
|---|---|---|
| **不能隨機切分** | 相鄰的日子高度相關（今天和昨天的 20 日均線幾乎一樣） | 訓練集和考題「偷看」到彼此 → 結果過度樂觀 |
| **未來資訊洩漏** | 用 2016～2023 的資料選參數，去考 2013～2015 | 2013 年的你不可能知道 2016 年之後的事 |
| **邊界的重疊** | 訓練期最後幾天的指標（例如 200 日均線）用到了考試期的資料，或反過來 | 資訊在邊界洩漏 |

**常見的處理方式：**

| 方法 | 做法 |
|---|---|
| **連續區塊切分** | 每一折是一段連續的時間，不隨機打亂 |
| **清除（Purging）** | 把訓練集中「和考試期重疊」的樣本刪掉（例如持有期跨越邊界的交易） |
| **禁區（Embargo）** | 考試期**之後**的一小段時間也不放進訓練集，避免短期相關造成洩漏 |
| **只往前（Walk-forward）** | 訓練永遠在考試之前——最嚴格、最接近實際交易 |

> 💡 「清除」與「禁區」的概念主要來自 Marcos López de Prado 的著作《Advances in Financial Machine Learning》（2018），在 11.8 的機器學習中特別重要。

### 3. 實作：時間序列 K 折交叉驗證

把 14 年分成 5 段連續的期間，每段輪流當考題：

```python
import numpy as np
import pandas as pd
from bt_toolkit import load_prices, sma, backtest, tw_costs, perf_stats

df = load_prices("sample_long.csv")
grid = [(f, s) for f in range(10, 101, 10) for s in range(40, 301, 20) if f < s]
returns = {p: backtest(df, (sma(df["Close"], p[0]) > sma(df["Close"], p[1])).astype(int),
                       *tw_costs())["strat_ret"] for p in grid}
bh = df["Close"].pct_change().fillna(0)

years = sorted(set(df.index.year))
folds = np.array_split(np.array(years), 5)
rows = []
for test_years in folds:
    test_years = list(test_years)
    train_mask = ~df.index.year.isin(test_years)
    test_mask = df.index.year.isin(test_years)
    best = max(grid, key=lambda p: perf_stats(returns[p][train_mask])["夏普比率"])
    rows.append({
        "考試期間": f"{test_years[0]}–{test_years[-1]}",
        "選出的參數": f"MA{best[0]}/MA{best[1]}",
        "訓練夏普": round(perf_stats(returns[best][train_mask])["夏普比率"], 2),
        "考試夏普": round(perf_stats(returns[best][test_mask])["夏普比率"], 2),
        "同期買進持有": round(perf_stats(bh[test_mask])["夏普比率"], 2),
    })
print(pd.DataFrame(rows).to_string(index=False))
```

輸出：

```
     考試期間     選出的參數  訓練夏普  考試夏普  同期買進持有
2010–2012 MA100/MA140  0.76  0.96    1.20
2013–2015 MA100/MA140  0.96  0.20   -0.28
2016–2018 MA100/MA140  0.79  0.93    0.03
2019–2021  MA90/MA140  0.77  0.83    1.03
2022–2023 MA100/MA140  0.77  1.02    1.26
```

**怎麼讀？**

| 觀察 | 說明 |
|---|---|
| 參數很穩定（幾乎都是 MA100/MA140） | 但它在 10.15 的熱力圖中**位於測試範圍的邊緣**，要小心 |
| 5 段中有 2 段贏過買進持有 | 剛好是 2013～2018 這兩段買進持有表現差的期間——又一次看到「空頭保險」的個性（10.14） |
| ⚠️ 中間的考試期，訓練資料包含了**未來** | 例如考 2013～2015 時，用了 2016～2023 的資料選參數——這在現實中做不到 |

> 🔑 **K 折交叉驗證的價值**：讓每一段資料都當過一次考題，看到策略在不同時期的表現差異。**它的限制**：中間的折會用到未來資料選參數，所以結果會偏樂觀。**最終判斷仍以 walk-forward（只往前）為準**；K 折是輔助的觀察工具。

### 4. ⭐ 穩健性測試工具箱

| 測試 | 問題 | 本課程單元 |
|---|---|---|
| **參數擾動** | 參數 ±20% 還行嗎？ | 10.15 |
| **成本加倍、延遲一天** | 對執行細節敏感嗎？ | 10.6、10.15 |
| **拿掉最好的交易** | 利潤是不是集中在少數幾筆？ | 10.9 |
| **蒙地卡羅** | 換個順序、換個組成，回撤會多深？ | 11.5 |
| **雜訊注入** | 價格有一點誤差，訊號還穩定嗎？ | 本單元 |
| **其他市場** | 同樣的規則，用在其他商品上還有效嗎？ | 本單元 |
| **不同起始日** | 結果是不是依賴某個特別的起點？ | 本單元 |
| **子期間 / 市場狀態** | 在多頭、空頭、盤整中各表現如何？ | 8.12、10.14 |
| **隨機資料** | 在沒有規律的資料上，它應該失敗 | 10.18 |

### 5. 雜訊注入

在**用來計算訊號的價格**上加一點隨機誤差（例如每天 ±0.5%），但用**真實價格**計算報酬，重複 100 次：

```python
base = perf_stats(returns[(50, 200)])["夏普比率"]
rng = np.random.default_rng(0)
noisy_sharpes = []
for _ in range(100):
    noisy_close = df["Close"] * np.exp(rng.normal(0, 0.005, len(df)))     # 訊號用的價格有誤差
    signal = (sma(noisy_close, 50) > sma(noisy_close, 200)).astype(int)
    noisy_sharpes.append(perf_stats(backtest(df, signal, *tw_costs())["strat_ret"])["夏普比率"])
noisy_sharpes = np.array(noisy_sharpes)
print(f"MA50/MA200 原始夏普 {base:.2f}；加入雜訊後：平均 {noisy_sharpes.mean():.2f}，"
      f"範圍 {np.percentile(noisy_sharpes, 5):.2f} ～ {np.percentile(noisy_sharpes, 95):.2f}")
```

輸出：`MA50/MA200 原始夏普 0.53；加入雜訊後：平均 0.54，範圍 0.52 ～ 0.55`

> 💡 長期均線本身就很平滑，一點雜訊幾乎不影響訊號，所以結果非常穩定 ✅。如果一個策略加了一點點雜訊，夏普就從 1.5 掉到 0.3，代表它的訊號非常依賴「精確的價格」——很可能是在擬合雜訊（10.12）。

### 6. 其他市場

同樣的 MA50/MA200 規則，用在 `multi_asset.csv` 的四種資產上（這份資料只有收盤價，用前一天收盤價近似開盤價）：

```python
prices = pd.read_csv("multi_asset.csv", parse_dates=["Date"], index_col="Date")
for asset in prices:
    d = pd.DataFrame({"Open": prices[asset].shift(1).fillna(prices[asset].iloc[0]),
                      "Close": prices[asset]})
    signal = (sma(d["Close"], 50) > sma(d["Close"], 200)).astype(int)
    s = perf_stats(backtest(d, signal, *tw_costs())["strat_ret"])
    b = perf_stats(d["Close"].pct_change().fillna(0))
    print(f"{asset}：策略夏普 {s['夏普比率']:.2f} vs. 買進持有 {b['夏普比率']:.2f}；"
          f"最大回撤 {s['最大回撤']:.1%} vs. {b['最大回撤']:.1%}")
```

輸出：

```
股票：策略夏普 0.47 vs. 買進持有 0.63；最大回撤 -28.4% vs. -25.0%
債券：策略夏普 0.09 vs. 買進持有 0.44；最大回撤 -18.6% vs. -9.1%
黃金：策略夏普 0.22 vs. 買進持有 0.42；最大回撤 -28.5% vs. -41.2%
海外股票：策略夏普 0.45 vs. 買進持有 0.65；最大回撤 -24.7% vs. -26.4%
```

> 🔑 **在四個其他市場上，策略的夏普全部輸給買進持有**，有兩個連最大回撤都比較深。如果一個策略真的抓到了「趨勢延續」的普遍特性，它應該在很多市場上都有一些效果；只在一個市場有效的策略，更可能是過度擬合。（這些都是隨機模擬的資料，沒有真正的趨勢，所以結果符合預期。）

### 7. 不同起始日

```python
for start in ["2010", "2011", "2012", "2013", "2014"]:
    s = perf_stats(returns[(50, 200)].loc[start:])["夏普比率"]
    b = perf_stats(bh.loc[start:])["夏普比率"]
    print(f"從 {start} 年開始：策略夏普 {s:.2f}，買進持有 {b:.2f}")
```

輸出：

```
從 2010 年開始：策略夏普 0.53，買進持有 0.56
從 2011 年開始：策略夏普 0.53，買進持有 0.43
從 2012 年開始：策略夏普 0.47，買進持有 0.36
從 2013 年開始：策略夏普 0.49，買進持有 0.37
從 2014 年開始：策略夏普 0.44，買進持有 0.32
```

> 💡 策略的夏普在 0.44～0.53 之間，相當穩定；但「贏不贏買進持有」取決於起始日——從 2010 年開始算就輸，從 2011 年之後開始算就贏。**結論對起始日敏感時，要特別小心不要挑一個「剛好好看」的起始日**（10.12 的資料探勘）。

### 8. ⭐ 整合所有測試：穩健性評分表

把每一項測試的結果寫成一張表，看整體的「證據強度」：

| 測試 | MA50/MA200（本範例） | 判斷 |
|---|---|---|
| 參數 ±20%（10.15） | 0.44～0.64 | ✅ 穩定 |
| 成本加倍、延遲一天（10.15） | 0.52、0.54 | ✅ 穩定 |
| 雜訊注入（本單元） | 0.52～0.55 | ✅ 穩定 |
| 不同起始日（本單元） | 0.44～0.53 | ✅ 穩定 |
| K 折考試期 vs. 買進持有（本單元，用 MA100/MA140） | 5 段中贏 2 段 | ⚠️ 依賴空頭期間 |
| 其他市場（本單元） | 4 個市場全輸給買進持有 | ❌ |
| 曝險相當基準（10.16，MA20/MA60 的結論） | 被打敗 | ❌ |

> 🔑 **穩定 ≠ 有優勢。** 這個策略的結果很「穩定」（各種擾動下夏普都差不多），但它**穩定地沒有贏過被動的替代方案**。穩健性測試回答「結果可不可靠」，基準比較回答「結果好不好」——兩個都要過關。

## 📌 重點整理

1. 穩健性測試 = **請不同的人、在不同條件下試吃**。
2. 交叉驗證讓每段資料都當一次考題；**時間序列不能隨機切分**，要注意未來資訊洩漏。
3. **清除（purging）、禁區（embargo）、只往前（walk-forward）**是處理洩漏的方法；最終判斷以 walk-forward 為準。
4. 工具箱：參數擾動、成本與延遲、拿掉最好的交易、蒙地卡羅、**雜訊注入、其他市場、不同起始日**、子期間、隨機資料。
5. 用**評分表**整合所有證據。
6. **穩定 ≠ 有優勢**：穩健性與基準比較都要通過。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「交叉驗證可以像一般機器學習一樣隨機切分」 | 時間序列相鄰資料高度相關，隨機切分會造成資訊洩漏，結果過度樂觀。 |
| 「K 折交叉驗證的結果和 walk-forward 一樣可信」 | 中間的折會用到未來資料選參數，結果偏樂觀；最終判斷以 walk-forward 為準。 |
| 「結果很穩定，策略就一定好」 | 穩定只代表可靠；還要和基準比較，看是否真的有優勢。 |
| 「只在一個市場有效也沒關係」 | 只在單一市場有效的策略更可能是過度擬合；真正的規律通常在多個市場都有一些效果。 |

## ✅ 自我測驗

**Q1. 為什麼時間序列資料不能隨機切分做交叉驗證？**

<details><summary>看答案</summary>

因為相鄰日期的資料高度相關（例如指標、持有中的交易會跨越多天），隨機切分會讓訓練集和測試集包含幾乎相同的資訊，造成資訊洩漏；而且會用未來的資料去預測過去，結果過度樂觀，無法反映實際交易時只能使用過去資料的情況。

</details>

**Q2. 雜訊注入在測試什麼？**

<details><summary>看答案</summary>

測試策略的訊號是否過度依賴精確的價格。在用來計算訊號的價格上加入小幅隨機誤差，如果績效大幅下降，代表策略可能在擬合價格中的雜訊，不夠穩健；如果績效幾乎不變，代表訊號穩定。

</details>

**Q3. 為什麼說「穩定 ≠ 有優勢」？**

<details><summary>看答案</summary>

穩健性測試確認的是結果在各種擾動下是否可靠、是否只是巧合；但一個策略可以穩定地表現普通，甚至穩定地輸給被動的替代方案。要判斷策略是否值得執行，還必須和適當的基準（買進持有、曝險相當基準）比較，兩方面都通過才行。

</details>
