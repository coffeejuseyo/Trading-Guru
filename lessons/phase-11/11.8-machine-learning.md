## 🎯 學完你會知道

- **機器學習（ML）**是什麼：從資料中自動找出規則
- 監督式學習的基本元素：**特徵、標籤、訓練集、測試集**
- 用 `scikit-learn` 預測「明天漲還是跌」
- 實驗：**隨機森林在訓練集 100% 正確，測試集只有 51%**
- **準確率要和基準率比**：52% 的準確率可能什麼都沒學到
- **資料洩漏**：一個偷看未來的特徵，讓準確率變成 80%
- 機器學習在交易中的 **7 個陷阱**，以及它真正能幫上忙的地方

## 📖 開場故事：很會背書的學生，不一定會應用

班上有兩個學生：

**小明**的記憶力驚人。他把課本上 500 道例題的**題目和答案**全部背下來。考試時只要遇到一模一樣的題目，他一定答對。但題目只要換個數字、換個問法，他就完全不會。

**小華**記不住那麼多題目，但她努力理解**每一類題目背後的原理**。遇到沒看過的題目，她也能推理出答案——雖然不一定每題都對。

> 🤖 **機器學習模型就像一個學生**：給它很多「歷史資料（題目）」和「結果（答案）」，它會試著找出規律。強大的模型（像小明）可以**完美記住**歷史資料，但如果資料中的規律很少、雜訊很多（金融資料正是如此），它記住的只是雜訊，**遇到新的資料就失效**。這就是 10.12 的過度擬合，只是規模更大、更隱蔽。

## 🧠 正文

### 1. 機器學習的基本元素

| 元素 | 意思 | 交易中的例子 | 考試比喻 |
|---|---|---|---|
| **特徵（Features, X）** | 用來預測的資訊 | 過去 5 天的報酬、波動度、均線乖離 | 題目 |
| **標籤（Label, y）** | 要預測的結果 | 明天漲（1）還是跌（0） | 答案 |
| **訓練集** | 讓模型學習的資料 | 前 70% 的日子 | 練習題 |
| **測試集** | 檢驗模型的資料（模型沒看過） | 後 30% 的日子 | 正式考試 |
| **模型** | 從特徵預測標籤的方法 | 邏輯迴歸、決策樹、隨機森林 | 學生 |

> 💡 你在 Phase 8～10 寫的策略規則（例如「MA20 > MA60 就持有」），是**人工**設計的規則；機器學習是讓電腦從資料中**自動**找規則。

### 2. ⭐ 實作：預測明天漲跌

```
!pip install scikit-learn
```

（Colab 已經內建；本單元在 scikit-learn 1.9 版測試過。）

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from bt_toolkit import load_prices

df = load_prices("sample_long.csv")
r = df["Close"].pct_change()

# 特徵：只用「今天收盤時已知」的資訊
X = pd.DataFrame({f"ret_lag{k}": r.shift(k - 1) for k in range(1, 6)})    # 今天、昨天……的報酬
X["vol20"] = r.rolling(20).std()                                          # 20 日波動
X["ma_gap"] = df["Close"] / df["Close"].rolling(20).mean() - 1            # 與 20 日均線的距離

# 標籤：明天漲（1）或跌（0）——這是要預測的「未來」
y = (r.shift(-1) > 0).astype(int)

data = pd.concat([X, y.rename("y")], axis=1).dropna()
X, y = data.drop(columns="y"), data["y"]

split = int(len(data) * 0.7)                       # 依時間切分：前 70% 訓練、後 30% 測試
X_train, X_test = X.iloc[:split], X.iloc[split:]
y_train, y_test = y.iloc[:split], y.iloc[split:]
print(f"測試集中「明天上漲」的比例（基準率）：{y_test.mean():.1%}")

models = {
    "邏輯迴歸": LogisticRegression(max_iter=1000),
    "隨機森林（不限深度）": RandomForestClassifier(n_estimators=200, random_state=0),
    "隨機森林（深度 3）": RandomForestClassifier(n_estimators=200, max_depth=3, random_state=0),
}
for name, model in models.items():
    model.fit(X_train, y_train)
    print(f"{name}：訓練集準確率 {model.score(X_train, y_train):.1%}，"
          f"測試集準確率 {model.score(X_test, y_test):.1%}")
```

輸出：

```
測試集中「明天上漲」的比例（基準率）：52.5%
邏輯迴歸：訓練集準確率 50.5%，測試集準確率 52.5%
隨機森林（不限深度）：訓練集準確率 100.0%，測試集準確率 51.1%
隨機森林（深度 3）：訓練集準確率 60.6%，測試集準確率 52.3%
```

> 💡 標籤用了 `shift(-1)`（明天的報酬），這是**正確**的：標籤本來就是「要預測的未來」。危險的是把未來的資訊放進**特徵**（第 4 節）。

### 3. ⭐⭐ 讀懂結果

| 模型 | 訓練集 | 測試集 | 解讀 |
|---|---:|---:|---|
| 隨機森林（不限深度） | **100.0%** | 51.1% | **小明**：完美背下了訓練集，換了新資料就不會——典型的過度擬合 |
| 隨機森林（深度 3） | 60.6% | 52.3% | 限制模型的複雜度，過度擬合變少，但測試集仍然沒進步 |
| 邏輯迴歸 | 50.5% | 52.5% | 測試集 52.5% 剛好等於基準率——它其實就是一直猜「漲」 |

> 🔑 **準確率一定要和「基準率」比較。** 測試期間有 52.5% 的日子上漲，一個「每天都猜漲」的笨方法就能得到 52.5% 的準確率。三個模型的測試集準確率（51.1%～52.5%）**都沒有超過基準率**——它們什麼也沒學到。
>
> 這份練習資料是隨機產生的，本來就無法預測，所以這是**正確的結果**。但即使在真實市場中，日報酬的可預測性也非常低，**能穩定超過基準率一兩個百分點就已經非常困難**，扣掉成本後更是如此。

> 🤖 **那個 100% 的訓練集準確率，就是機器學習在金融中最大的危險**：模型強大到可以「背下」任何資料，包括純粹的雜訊。如果你只看訓練集（或用了有洩漏的驗證方式），你會以為自己找到了聖杯。

### 4. ⚠️ 資料洩漏：偷看未來的特徵

加入一個看起來很合理的特徵：「**5 日均線**與收盤價的距離」——但不小心用了**置中**的均線（`center=True`，包含未來兩天的價格）：

```python
leaky = X.copy()
centered_ma = df["Close"].rolling(5, center=True).mean()        # ❌ 置中：用到了未來 2 天
leaky["leak"] = (centered_ma / df["Close"] - 1).reindex(leaky.index)

model = RandomForestClassifier(n_estimators=200, random_state=0)
model.fit(leaky.iloc[:split], y_train)
print(f"加入洩漏特徵後的測試集準確率：{model.score(leaky.iloc[split:], y_test):.1%}")
```

輸出：`加入洩漏特徵後的測試集準確率：80.5%`

> 🚨 **只是一個參數 `center=True`，準確率就從 51% 跳到 80%。** 這就是 10.10 的前視偏差，在機器學習中特別難發現：特徵可能有幾十、幾百個，其中只要一個偷看了未來，模型就會「學會」利用它。
>
> **常見的洩漏來源**：置中的移動平均、用全期間資料做標準化（10.10 第 4 種）、財報公布時間、隨機切分訓練 / 測試集（11.7）、標籤和特徵的時間重疊。

### 5. ⭐ 機器學習在交易中的 7 個陷阱

| # | 陷阱 | 說明 | 回想 |
|---|---|---|---|
| 1 | **訊雜比極低** | 金融價格的雜訊遠大於可預測的訊號；模型很容易學到雜訊 | 10.12 |
| 2 | **過度擬合** | 模型越強大（深度學習、不限深度的樹），越能背下雜訊 | 本單元 |
| 3 | **資料洩漏** | 特徵偷看未來、標準化用全期間資料、隨機切分 | 10.10、11.7 |
| 4 | **非平穩性** | 市場的規律會改變（8.12），過去學到的規則未來可能失效 | 10.14 |
| 5 | **多重檢定** | 特徵、模型、超參數的組合可以有成千上萬種，總有一種在測試集上看起來很好 | 11.6 |
| 6 | **準確率 ≠ 賺錢** | 準確率 55% 但猜錯時都是大跌日，照樣虧錢；還要扣成本 | 3.5、10.6 |
| 7 | **黑盒子** | 不知道模型為什麼這樣預測，就無法判斷它何時會失效，也很難在回撤時堅持（Phase 7） | 8.2 |

> 🔑 回想 Phase 8 的費曼檢核題：「**你的優勢從哪裡來？**」如果你說不出機器學習模型為什麼有效，你就無法區分它是真的找到了規律，還是只是記住了雜訊。

### 6. 機器學習真正能幫上忙的地方

| 應用 | 說明 |
|---|---|
| **處理大量非結構化資料** | 從新聞、財報文字、社群貼文中萃取資訊（11.9） |
| **組合很多弱訊號** | 結合多個各自有一點點預測力的因子（8.9），而不是從原始價格中硬找規律 |
| **風險預測** | 預測波動度往往比預測報酬容易（波動有聚集性，11.3） |
| **市場狀態分類** | 判斷現在比較像哪一種環境（8.12），作為策略的過濾條件 |
| **執行優化** | 大型機構用來降低交易成本、決定下單時機 |

### 7. 如果你想嘗試，請遵守這些規則

- [ ] **先有假說**：為什麼這些特徵可能有預測力？（8.2）
- [ ] **特徵只用當時已知的資料**，並逐一檢查洩漏（10.10 檢查清單）
- [ ] **依時間切分**，用 walk-forward 或加了清除與禁區的交叉驗證（11.7）
- [ ] **和基準率比較**，並把預測轉成策略、**扣除成本**後回測
- [ ] **從簡單的模型開始**（邏輯迴歸、淺的樹），複雜的模型要有充分的理由
- [ ] **記錄所有嘗試**的特徵、模型、參數組合（11.6）
- [ ] **在隨機資料上測試**：模型應該失敗（10.18）

## 📌 重點整理

1. 機器學習 = **從資料中自動找規則**；元素：特徵、標籤、訓練集、測試集、模型。
2. 實驗：隨機森林**訓練集 100%、測試集 51%**——完美背下雜訊，換資料就失效。
3. **準確率要和基準率比**：三個模型都沒有超過「每天猜漲」的 52.5%。
4. **資料洩漏**：一個置中的均線讓準確率從 51% 變成 80%。
5. 7 個陷阱：**訊雜比低、過度擬合、洩漏、非平穩、多重檢定、準確率 ≠ 賺錢、黑盒子**。
6. 真正的用途：**非結構化資料、組合弱訊號、風險預測、狀態分類、執行優化**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「用 AI / 機器學習就能預測股價」 | 金融資料雜訊極高，強大的模型更容易過度擬合；日報酬的可預測性非常低。 |
| 「訓練集準確率很高，模型就很好」 | 訓練集準確率只代表背得多好；要看沒見過的測試集，並和基準率比較。 |
| 「準確率 55% 就能賺錢」 | 還要看猜錯時虧多少、扣除成本後是否仍有正期望值。 |
| 「模型越複雜越好」 | 在低訊雜比的資料上，複雜模型通常過度擬合得更嚴重；從簡單模型開始。 |

## 🛠️ 練習（約 2 小時）

**練習 1：調整模型複雜度**
把隨機森林的 `max_depth` 從 1 調到 20，畫出「訓練集準確率」與「測試集準確率」隨深度變化的兩條線。這就是過度擬合的典型圖形。

**練習 2：從預測到策略**
用邏輯迴歸的 `predict_proba()`，當「明天上漲的機率 > 0.52」時持有，否則空手，用 Phase 10 的 `backtest()`（注意 shift 的對應）加上成本回測，和買進持有比較。

**練習 3：找出洩漏**
在特徵中加入 `df["Close"].pct_change().shift(-1)`（明天的報酬）當作特徵，訓練後測試集準確率是多少？然後改成用全期間平均與標準差標準化 `ma_gap`，準確率有變化嗎？說明為什麼兩者都是洩漏。

**練習 4：真實資料**
用 0050 或 SPY 的真實資料重做第 2 節。測試集準確率有超過基準率嗎？超過多少？

## ✅ 自我測驗

**Q1. 隨機森林訓練集 100%、測試集 51%，代表什麼？**

<details><summary>看答案</summary>

代表嚴重的過度擬合：模型把訓練資料（包括其中的雜訊）完全背了下來，但沒有學到能推廣到新資料的規律，在沒看過的測試集上表現和亂猜差不多。

</details>

**Q2. 為什麼準確率要和基準率比較？**

<details><summary>看答案</summary>

因為如果某一類結果本來就比較常見（例如測試期間有 52.5% 的日子上漲），一個什麼都沒學、每次都猜同一個答案的方法就能達到這個準確率。模型的準確率必須明顯超過基準率，才代表它學到了有用的資訊。

</details>

**Q3. 列出機器學習在交易中的至少 4 個陷阱。**

<details><summary>看答案</summary>

任選 4 個：訊雜比極低；過度擬合；資料洩漏（特徵偷看未來、全期間標準化、隨機切分）；非平穩性（規律會改變）；多重檢定（特徵、模型、參數組合太多）；準確率不等於賺錢（還要看盈虧與成本）；黑盒子（不知道為什麼有效，難以判斷失效與堅持執行）。

</details>
