## 📖 開場故事：組一支球隊

教練有預算買 11 名球員。他有兩個選擇：

**A. 買 11 個最強的前鋒**
進攻火力驚人。但對手一反擊，沒有人防守，常常輸得很慘。這支隊伍的成績**大起大落**：有時候 5 比 0 大勝，有時候 1 比 6 慘敗。

**B. 前鋒、中場、後衛、守門員各司其職**
每個人單獨看都不是最強的，但他們**互補**：前鋒進攻時後衛守住後方，中場串連兩邊。這支隊伍很少大勝，但也很少大敗，整個賽季的積分反而比較高。

> ⚽ **策略組合就是組球隊**：不是找 3 個最強的策略，而是找 3 個**互補**的策略——一個賠錢的時候，另一個可能在賺錢。組合起來的資金曲線更平穩、回撤更小，**風險調整後的報酬更好**。

## 🧠 正文

### 1. ⭐ 相關性決定分散效果

兩個策略，各自年化波動 10%，各配置 50%。組合的波動取決於它們的**相關係數 ρ**：

**組合波動 = √（w₁²σ₁² + w₂²σ₂² + 2·w₁·w₂·ρ·σ₁·σ₂）**

| 相關係數 ρ | 組合波動 | 說明 |
|---:|---:|---|
| +1.0 | 10.0% | 完全同步：沒有任何分散效果 |
| +0.5 | 8.7% | 部分分散 |
| 0 | 7.1% | 無關：波動降低約 30% |
| −0.5 | 5.0% | 互相抵銷：波動降低一半 |

> 🔑 **報酬是加權平均，但風險不是**——只要相關係數小於 1，組合的波動就會**小於**各自波動的加權平均。報酬沒變、風險變小，風險調整後報酬就提高了。這就是「分散是唯一的免費午餐」這句話的意思（6.8）。

### 2. ⭐ 組合的夏普公式

假設有 N 個策略，每個夏普都是 0.5、波動相同、兩兩之間相關係數都是 ρ，等權重組合的夏普約為：

**組合夏普 ≈ 單一夏普 × √[N ÷（1 +（N − 1）× ρ）]**

| 策略數 N | ρ = 0 | ρ = 0.3 | ρ = 0.6 | ρ = 0.9 |
|---:|---:|---:|---:|---:|
| 1 | 0.50 | 0.50 | 0.50 | 0.50 |
| 2 | 0.71 | 0.62 | 0.56 | 0.51 |
| 3 | 0.87 | 0.68 | 0.58 | 0.52 |
| 5 | 1.12 | 0.75 | 0.61 | 0.52 |
| 10 | 1.58 | 0.82 | 0.62 | 0.52 |

> 🔑 **兩個重點**：
> 1. **相關性比數量重要**：10 個相關係數 0.9 的策略（夏普 0.52），還不如 2 個無關的策略（0.71）。
> 2. **10 個「差不多的」策略其實只是 1 個策略**：同一個想法的 10 種參數（例如 10 組均線），相關係數通常很高，組合起來幾乎沒有分散效果。

### 3. ⭐⭐ 實作：組合 3 個策略（課綱作業）

```python
import pandas as pd
import numpy as np
from bt_toolkit import perf_stats

strats = pd.read_csv("strategy_returns.csv", parse_dates=["Date"], index_col="Date")
print(strats.corr().round(2))
```

輸出：

```
        趨勢  均值回歸    套利
趨勢    1.00 -0.21  0.17
均值回歸 -0.21  1.00  0.15
套利    0.17  0.15  1.00
```

三個策略的相關係數都很低（−0.21～0.17）。等權重組合：

```python
combo = strats.mean(axis=1)            # 每天三個策略的平均報酬 = 每天再平衡的等權重組合

def show(name, r):
    p = perf_stats(r)
    print(f"{name:<6} 年化 {p['年化報酬']:>6.2%}  波動 {p['年化波動']:>6.2%}  "
          f"最大回撤 {p['最大回撤']:>7.2%}  夏普 {p['夏普比率']:.2f}  Calmar {p['Calmar']:.2f}")

for col in strats:
    show(col, strats[col])
show("組合", combo)
```

輸出：

```
趨勢     年化  4.65%  波動 12.20%  最大回撤 -25.58%  夏普 0.42  Calmar 0.18
均值回歸   年化  9.64%  波動  9.55%  最大回撤 -17.43%  夏普 0.98  Calmar 0.55
套利     年化  3.31%  波動  8.26%  最大回撤 -16.11%  夏普 0.42  Calmar 0.21
組合     年化  6.21%  波動  5.93%  最大回撤 -11.67%  夏普 1.01  Calmar 0.53
```

| 觀察 | 說明 |
|---|---|
| **波動大幅下降** | 組合 5.93%，比三個策略中波動最低的（8.26%）還低 |
| **最大回撤最淺** | −11.67%，比任何單一策略都淺 |
| **夏普最高** | 1.01，比最好的單一策略（0.98）還高——而另外兩個只有 0.42 |
| 年化報酬 | 6.21%，在三者之間（報酬是平均，風險不是） |

> 🎯 **兩個夏普只有 0.42 的「普通策略」，加上一個好策略，組合起來比那個好策略單獨更好。** 這就回答了費曼檢核題第 1 題。

**逐年來看：**

```python
yearly = (1 + strats).groupby(strats.index.year).prod() - 1
yearly["組合"] = (1 + combo).groupby(combo.index.year).prod() - 1
print((yearly * 100).round(1))
print("虧損的年數：", (yearly < 0).sum().to_dict())
```

輸出（節錄）：

```
        趨勢  均值回歸    套利    組合
2010  11.1  25.4  -9.4   8.5
2013  -2.5  -1.1  14.4   3.7
2016  34.4  13.7   4.3  17.2
2019  10.9  23.5  -6.4   8.9
2020 -15.9  -9.6  -2.9  -9.3
2023  -7.7   2.1   6.2   0.6
虧損的年數： {'趨勢': 5, '均值回歸': 2, '套利': 4, '組合': 1}
```

> ⚽ **球隊效應**：2013 年趨勢和均值回歸都虧錢，套利賺了 14.4%；2019 年套利虧錢，另外兩個賺錢。14 年中，單一策略虧損 2～5 年，**組合只虧了 1 年**。

### 4. 把組合放大到相同的風險

組合的報酬（6.21%）比均值回歸（9.64%）低，是不是比較差？回想 10.8：**夏普衡量的是效率，部位大小決定風險水準。**

```python
scale = strats["趨勢"].std() / combo.std()       # 放大到和趨勢策略一樣的波動
show("組合×" + f"{scale:.1f}", combo * scale)
```

輸出：

```
組合×2.1 年化 12.74%  波動 12.20%  最大回撤 -22.78%  夏普 1.01  Calmar 0.56
```

> 💡 **承擔和趨勢策略一樣的波動（12.2%），組合的年化報酬是 12.74%——將近趨勢策略（4.65%）的 3 倍**，而且最大回撤更淺。（實務上放大部位需要槓桿，有借貸成本與追繳風險，見 10.8 的提醒。）

### 5. 多商品組合

同樣的道理也適用於資產：

```python
prices = pd.read_csv("multi_asset.csv", parse_dates=["Date"], index_col="Date")
rets = prices.pct_change().dropna()
print(rets.corr().round(2))
for col in rets:
    show(col, rets[col])
show("四等分", rets.mean(axis=1))
show("股6債4", 0.6 * rets["股票"] + 0.4 * rets["債券"])
```

### 6. ⚠️ 組合的陷阱

| 陷阱 | 說明 |
|---|---|
| **危機時相關性上升** | 平常低相關的資產，在恐慌崩盤時常常一起跌（「危機時唯一上漲的是相關性」）。用全期間的相關係數，會高估危機時的分散效果 |
| **相關性會變** | 過去低相關，不代表未來低相關；要用滾動相關係數觀察（練習 2） |
| **假的分散** | 同一個想法的不同參數、同一個產業的不同股票，相關性其實很高 |
| **組合不能救爛策略** | 期望值為負的策略，加進組合只會拖累；組合的前提是**每個策略都有正的期望值**（Phase 10 的檢驗） |
| **管理成本** | 策略越多，監控、執行、資金分配越複雜（11.10） |

---

## 📌 重點整理

1. 組合 = **組球隊**：要的是互補，不是每個都最強。
2. **報酬是加權平均，風險不是**：相關係數 < 1 就能降低波動。
3. 組合夏普 ≈ 單一夏普 × √[N ÷（1 +（N − 1）ρ）]：**相關性比數量重要**。
4. 實作：3 個策略（夏普 0.42、0.98、0.42）組合後夏普 **1.01**、最大回撤 **−11.67%**，比任何單一策略都好。
5. 組合可以放大到相同風險：同樣 12.2% 的波動，年化從 4.65% 變成 12.74%。
6. 「持有很多檔」不等於分散；危機時相關性會上升；**組合不能救期望值為負的策略**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「只要選最好的那個策略就好」 | 低相關的普通策略組合起來，風險調整後報酬可能更好。 |
| 「持有越多檔越分散」 | 要看相關性；高相關的資產或策略加再多也沒有分散效果。 |
| 「過去低相關，未來也會低相關」 | 相關性會變動，危機時常常上升。 |
| 「把虧錢的策略加進組合可以分散風險」 | 期望值為負的策略只會拖累組合；每個成員都要先通過檢驗。 |

## ✅ 自我測驗

**Q1. 為什麼兩個普通的策略組合起來，可能比一個好策略更好？**

<details><summary>看答案</summary>

因為組合的報酬是各策略報酬的加權平均，但組合的風險（波動）會因為相關係數小於 1 而小於加權平均。低相關的策略會互相抵銷部分波動：一個虧錢時另一個可能賺錢，所以風險調整後報酬（夏普）提高、回撤變淺。在本單元的例子中，夏普 0.42、0.98、0.42 的三個策略，組合後夏普達到 1.01。

</details>

**Q2. 10 個相關係數 0.9 的策略，和 2 個相關係數 0 的策略，哪個組合的分散效果好？**

<details><summary>看答案</summary>

2 個無關的策略。依公式，單一夏普 0.5 時，10 個 ρ = 0.9 的策略組合夏普約 0.52，2 個 ρ = 0 的策略組合夏普約 0.71。相關性比數量重要。

</details>

**Q3. 組合有哪些陷阱？**

<details><summary>看答案</summary>

危機時相關性上升，分散效果在最需要的時候減弱；相關性會隨時間改變；同一想法的不同參數或同產業股票是假的分散；組合不能救期望值為負的策略；策略越多，管理與執行越複雜。

</details>
