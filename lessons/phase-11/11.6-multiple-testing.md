## 📖 開場故事：1000 個人擲硬幣

電視節目找了 1,000 個人，每個人擲 10 次硬幣。

節目結束時，主持人宣布：「我們找到了一位**擲硬幣天才**！他連續擲出了 **10 次正面**！」接著訪問他的「秘訣」：他說他會先深呼吸、用右手大拇指、默念三次……

但你算一下：連續 10 次正面的機率是 (1/2)¹⁰ = 1/1024。**1,000 個人中，平均就會有大約 1 個人做到**——而且至少有一個人做到的機率超過 60%。他不是天才，只是**人數夠多，總有人會很幸運**。

> 🪙 **多重檢定問題就是這個**：你測試了 1,000 個策略（或 1,000 組參數），最好的那一個看起來很厲害，但它可能就是那位「擲硬幣天才」。**測試的次數越多，「最好的結果」就越需要打折。** 這在量化研究中叫做「回測過度」（backtest overfitting）。

---

## 🧠 正文

### 1. 統計顯著性的直覺

一個策略的夏普比率，**有多大機率只是運氣？**

| 觀念 | 直覺 |
|---|---|
| **虛無假設** | 「這個策略其實沒有優勢（真實夏普 = 0），回測的好結果只是運氣」 |
| **t 值** | 觀察到的結果離「純運氣」有多遠；夏普的 t 值 ≈ **年化夏普 × √年數** |
| **p 值** | 如果策略真的沒有優勢，純靠運氣得到這麼好（或更好）結果的機率 |
| 常見門檻 | p < 0.05（t > 約 1.65，單邊） |

```python
import numpy as np
from scipy.stats import norm

for sharpe, years in [(0.5, 10), (0.5, 14), (1.0, 5), (1.0, 10)]:
    t = sharpe * np.sqrt(years)
    p = 1 - norm.cdf(t)
    print(f"夏普 {sharpe}、{years} 年：t ≈ {t:.2f}，p ≈ {p:.4f}")
```

輸出：

```
夏普 0.5、10 年：t ≈ 1.58，p ≈ 0.0569
夏普 0.5、14 年：t ≈ 1.87，p ≈ 0.0307
夏普 1.0、5 年：t ≈ 2.24，p ≈ 0.0127
夏普 1.0、10 年：t ≈ 3.16，p ≈ 0.0008
```

> 💡 回想 10.8：夏普 0.5、10 年的資料，p 值大約 0.057——**就算只測試一個策略**，也不到常用的 0.05 門檻。（這是簡化的近似公式，假設報酬大致常態、彼此獨立。）

### 2. ⭐⭐ 沒有優勢的 N 個策略，最好的那個有多好？

模擬 N 個**完全沒有優勢**的策略（每日報酬是平均為 0 的亂數），每個 14 年，看看其中**最好的**夏普是多少：

```python
rng = np.random.default_rng(7)


def max_sharpe_of_random(n_strategies, years=14, reps=30):
    """回傳 reps 次實驗中，n 個無優勢策略「最好的夏普」的平均值與 95% 分位。"""
    best = []
    for _ in range(reps):
        r = rng.normal(0, 0.10 / np.sqrt(252), (252 * years, n_strategies))
        sharpes = r.mean(axis=0) / r.std(axis=0) * np.sqrt(252)
        best.append(sharpes.max())
    return np.mean(best), np.percentile(best, 95)


for n in [1, 10, 105, 1000]:
    mean_best, p95 = max_sharpe_of_random(n, reps=30 if n < 1000 else 10)
    print(f"測試 {n:>4} 個無優勢策略：最好的夏普平均 {mean_best:.2f}，95% 分位 {p95:.2f}")
```

輸出：

```
測試    1 個無優勢策略：最好的夏普平均 -0.02，95% 分位 0.45
測試   10 個無優勢策略：最好的夏普平均 0.42，95% 分位 0.57
測試  105 個無優勢策略：最好的夏普平均 0.67，95% 分位 0.85
測試 1000 個無優勢策略：最好的夏普平均 0.84，95% 分位 0.93
```

> 🚨 **回想 10.4、10.13：你測試了 105 組均線參數，最好的夏普大約 0.6～0.7。** 而 105 個**完全沒有優勢**的隨機策略，最好的夏普**平均就有 0.67**。換句話說，那組「最佳參數」的表現，**完全落在純運氣能解釋的範圍內**。
>
> （105 組均線參數彼此高度相關，有效的獨立測試次數比 105 少得多，所以這個比較偏嚴格；但結論的方向不變——見第 4 節。）

### 3. ⭐ 修正方法

| 方法 | 做法 | 直覺 |
|---|---|---|
| **Bonferroni 修正** | 測試 N 次，每次的顯著門檻改成 α ÷ N | 擲硬幣 1,000 人，要求「天才」必須遠比 10 次正面更厲害 |
| **提高 t 值門檻** | 學術界有學者主張，新發現的因子應該要 t > 3 才算數（例如 Harvey、Liu 與 Zhu 在 2016 年的研究） | 因為過去已經有成千上萬的研究在同樣的資料上挖掘 |
| **扣除運氣的期望值** | 把觀察到的夏普，和「N 個無優勢策略的最好夏普」比較；超過的部分才可能是真本事 | 第 2 節的方法；更嚴謹的版本稱為「縮減夏普比率」（Deflated Sharpe Ratio，Bailey 與 López de Prado 在 2014 年提出） |
| **樣本外與 walk-forward** | 用沒看過的資料檢驗（10.13、10.14） | 最實用、最直接的防護 |

```python
alpha = 0.05
for n in [1, 10, 100, 1000]:
    z = norm.ppf(1 - alpha / n)
    print(f"測試 {n:>4} 次：Bonferroni 修正後需要 t > {z:.2f}；"
          f"14 年的資料約需要夏普 > {z / np.sqrt(14):.2f}")
```

輸出：

```
測試    1 次：Bonferroni 修正後需要 t > 1.64；14 年的資料約需要夏普 > 0.44
測試   10 次：Bonferroni 修正後需要 t > 2.58；14 年的資料約需要夏普 > 0.69
測試  100 次：Bonferroni 修正後需要 t > 3.29；14 年的資料約需要夏普 > 0.88
測試 1000 次：Bonferroni 修正後需要 t > 3.89；14 年的資料約需要夏普 > 1.04
```

> 🔑 **測試 100 次之後，14 年的回測需要夏普 > 0.88，才能說「不太可能只是運氣」**。大部分散戶的策略研究，都在不知不覺中測試了幾十到幾百次。

> ⚠️ Bonferroni 修正假設各次測試**彼此獨立**，當測試高度相關時（例如相鄰的均線參數），它會**過度保守**（門檻太高）。實務上把它當作「最嚴格的參考」，搭配樣本外檢驗使用。

### 4. 有效測試次數

| 情況 | 名目上測試次數 | 有效的獨立測試次數 |
|---|---:|---|
| 105 組均線參數（MA55/MA200 和 MA60/MA200 幾乎一樣） | 105 | 遠少於 105（可能只有十幾個「真正不同」的策略） |
| 試了 10 個完全不同的策略想法 | 10 | 接近 10 |
| 看了 30 次回測、每次「微調一下」 | 你可能沒有記錄 | 很難估計——這就是為什麼要記錄 |

> 💡 **有效測試次數**介於「1」和「名目次數」之間。粗略的做法：把高度相關的參數組合視為同一群，估計有幾群。比精確數字更重要的是**意識到它的存在**。

### 5. ⭐ 實務上該怎麼做？

| 做法 | 說明 |
|---|---|
| **記錄每一次測試** | 研究日誌（11.11）：日期、想法、參數、結果——包括失敗的 |
| **事先寫下假說與規則** | 規格書（8.13）在看結果前完成；Git 記錄（9.14） |
| **在報告中揭露測試次數** | 回測報告範本第 7 段（10.17） |
| **提高門檻** | 試得越多，要求越高的夏普、越長的樣本外 |
| **保留樣本外，只用一次** | 最有效的防護（10.13） |
| **優先相信有理由的策略** | 有合理優勢來源（8.2）的策略，比從資料中挖出來的策略可信 |

> 🪙 **回到擲硬幣節目**：如果那位「天才」在節目前就宣布「我會連續 10 次正面」，然後真的做到了——那才值得注意（事先假說 + 一次測試）。事後從 1,000 個人中挑出最好的，什麼也證明不了。

---

## 📌 重點整理

1. 多重檢定 = **1,000 人擲硬幣，總有人連續 10 次正面**：測試越多，最好的結果越需要打折。
2. 夏普的 t 值 ≈ **夏普 × √年數**；夏普 0.5、10 年只有 t ≈ 1.58。
3. 模擬：105 個**無優勢**策略中最好的夏普平均約 **0.67**——和 10.4 的「最佳參數」差不多。
4. 修正：**Bonferroni**（門檻 α ÷ N）、**t > 3**、**扣除運氣的期望值**、樣本外。
5. **有效測試次數**：相關的測試不等於獨立的測試，但都要算。
6. 實務：**記錄每一次測試、事先寫假說、揭露次數、優先相信有理由的策略**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「我挑出的是最好的策略，所以它一定有真本事」 | 從很多策略中挑出最好的，最好的結果本身就包含大量運氣。 |
| 「我沒有用最佳化工具，所以沒有多重檢定問題」 | 手動試了很多想法、看了很多次回測，也是多重檢定。 |
| 「p < 0.05 就代表策略有效」 | 測試很多次時，p < 0.05 的結果很容易純靠運氣出現；需要修正。 |
| 「失敗的測試不用記錄」 | 失敗的測試也是測試次數的一部分；不記錄就無法評估最好結果的可信度。 |

## ✅ 自我測驗

**Q1. 為什麼測試的策略越多，越容易找到「假的好策略」？**

<details><summary>看答案</summary>

因為每個策略的回測結果都包含運氣成分。測試的策略越多，其中至少有一個純靠運氣得到極端好結果的機率就越高，就像 1,000 人擲硬幣總有人連續 10 次正面。從大量測試中挑出的最好結果，大部分可能來自運氣，未來不會重複。

</details>

**Q2. 夏普 0.5、14 年的回測，t 值大約多少？測試了 100 次之後還算顯著嗎？**

<details><summary>看答案</summary>

t ≈ 0.5 × √14 ≈ 1.87，單次測試的 p 值約 0.03。但測試 100 次後，Bonferroni 修正要求 t > 約 3.29（14 年約需夏普 > 0.88），所以 0.5 的夏普不算顯著，很可能只是運氣。

</details>

**Q3. 為什麼 Bonferroni 修正在測試相鄰參數時會過度保守？**

<details><summary>看答案</summary>

Bonferroni 修正假設各次測試彼此獨立。相鄰的參數組合（例如 MA55/MA200 和 MA60/MA200）結果高度相關，有效的獨立測試次數遠少於名目次數，用名目次數修正會讓門檻過高。實務上可以把它當作最嚴格的參考，並搭配樣本外檢驗。

</details>
