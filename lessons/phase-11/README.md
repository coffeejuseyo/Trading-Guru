# Phase 11｜進階：投資組合、優化與量化研究

> **預計時數：40 小時**（11 個單元）
> **生活比喻：組一支球隊——不是找 11 個最強的前鋒，而是讓各位置互補。**

Phase 10 你學會了「檢驗**一個**策略」。但你應該也發現了：單一策略很難通過所有考驗，就算通過了，它也會有很長的低潮期。

這個階段要往上走一層：

| 第 1 段：組合（11.1～11.4） | 第 2 段：更嚴謹的研究（11.5～11.7） | 第 3 段：前沿與實務（11.8～11.11） |
|---|---|---|
| 把多個策略、多個資產組合起來，讓它們**互補** | 用蒙地卡羅、多重檢定修正、交叉驗證，更誠實地評估結果 | 機器學習、另類資料、自動化系統、完整的研究流程 |

> 🔑 **本階段的核心觀念：組合的力量來自「低相關」，而不是「每個都很強」。** 三個普通的策略組合起來，可能比一個好策略更好——這是整個量化投資界最接近「免費午餐」的東西。

## 學習地圖

```
  第 1 段：組合（11.1～11.4）
     多策略互補 → 效率前緣（報酬 vs. 風險的最佳搭配）
     → 風險平價（每個成員承擔一樣多的風險）→ 再平衡（定期扶正）
                                  │
  第 2 段：更誠實的評估（11.5～11.7）
     蒙地卡羅（重新洗牌 1000 次，看最糟會怎樣）
     → 多重檢定（試越多次，越要打折）→ 交叉驗證與穩健性（換人試吃）
                                  │
  第 3 段：前沿與實務（11.8～11.11）
     機器學習（會背書 ≠ 會應用）→ 另類資料（停車場的車）
     → 自動化系統（工廠生產線）→ 研究流程（科學方法）
                                  ▼
                 Phase 12：模擬交易到小額實盤
```

有 2～3 個策略時分開記錄，練習 11.1 的組合觀念；用 11.5 的蒙地卡羅看你的模擬日誌。
