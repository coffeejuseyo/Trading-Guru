## 📖 開場故事：期末專題

研究所的課程最後，教授不考試，而是要每個學生交一份**期末專題**：

> 「選三個題目，用這學期學到的所有方法，從頭到尾做一次完整的研究。我不在乎你的結果是正面還是負面——**我在乎你的方法是否正確、你的結論是否誠實。** 一份方法嚴謹、結論是『這個假說不成立』的報告，比一份方法有漏洞、結論很漂亮的報告分數高得多。」

> 🎓 **Phase 10 的期末專題就是這樣**：把 Phase 8 寫的 3 份策略規格書，用 Phase 10 學到的所有方法完整回測、檢驗，並各寫一份報告。完成它，你就達成了**里程碑 M3：能獨立完成一次可信的回測**。

| 3 | 每份策略：向量化回測 + 一種框架**交叉驗證** | 10.2～10.5 |
| 4 | 加入**真實成本**，並做成本敏感度 | 10.6 |

### 2. ⭐ 標準研究流程

```
  ① 準備
     □ 下載並清理資料，存成 CSV（記錄來源、下載日期、還原設定）
     □ 決定樣本外切分點，寫下來，之後不改
     □ 把 3 份規格書的參數與規則寫進程式（先不要看任何結果）
                    ↓
  ② 樣本內（可以反覆調整，但要記錄每一次修改）
     □ 向量化回測 + 框架交叉驗證，確認程式正確
     □ 加入成本；計算績效與交易統計
     □ 前視偏差檢查清單
     □ 參數穩健性（只用樣本內）
     □ 定案：凍結規則與參數，用 Git commit（9.14）
                    ↓
  ③ 樣本外（只做一次）
     □ 用定案的規則跑樣本外，和同期基準比較
     □ Walk-forward 或逐年拆解
     □ 曝險相當基準、擇時能力
                    ↓
  ④ 報告
     □ 用 10.17 的程式產生表格，填寫範本
     □ 寫結論：淘汰 / 繼續研究 / 進入模擬交易
     □ 自我審查清單
```

> 🔑 **第 ② 步結束時要「凍結」策略**：用 Git commit 記錄定案的版本（commit 訊息寫「樣本外測試前定案」），之後的樣本外測試必須用這個版本。這是你對自己誠實的證據。

### 3. 起始程式

[`code/capstone_starter.py`](code/capstone_starter.py) 已經幫你把流程串好：

| 部分 | 你要做的事 |
|---|---|
| `DATA_FILE`、`OOS_START`、`COSTS` | 換成你的資料、切分點、成本 |
| `signal_trend()`、`signal_mean_reversion()`、`signal_breakout()` | 依照你的規格書修改（範例是 8.3、8.4、8.5 的簡化版） |
| `evaluate()` | 自動計算：樣本內外、全期間、買進持有、曝險相當基準、交易統計、成本加倍、延遲一天、Beta 與捕獲率 |

**執行：**

```
python capstone_starter.py
```

（在 Colab 中：把 `bt_toolkit.py`、`capstone_starter.py`、資料檔上傳後，執行 `!python capstone_starter.py`，或把程式內容貼進儲存格。）

### 4. ⭐ 用練習資料跑一次

用 `sample_long.csv` 執行起始程式的結果（節錄）：

```
==================== 趨勢 ====================
樣本內              年化  -1.46%  最大回撤  -32.76%  夏普 -0.06
樣本外              年化   1.89%  最大回撤  -21.02%  夏普  0.22
全期間              年化  -0.28%  最大回撤  -38.06%  夏普  0.03
買進持有（全期間）        年化   8.67%  最大回撤  -42.84%  夏普  0.56
曝險相當 45%（全期間）    年化   4.28%  最大回撤  -21.49%  夏普  0.57
交易 32 筆，勝率 43.8%，盈虧比 1.32，期望值 0.07%，最大連虧 6
穩健性：成本加倍夏普 -0.06，延遲一天夏普 0.05
擇時：Beta 0.44，上漲捕獲 41%，下跌捕獲 45%

==================== 均值回歸 ====================
全期間              年化  -3.73%  最大回撤  -46.95%  夏普 -0.47
曝險相當 12%（全期間）    年化   1.22%  最大回撤   -6.24%  夏普  0.58
交易 102 筆，勝率 52.0%，盈虧比 0.51，期望值 -0.48%，最大連虧 5

==================== 突破 ====================
全期間              年化  -1.67%  最大回撤  -28.47%  夏普 -0.21
曝險相當 16%（全期間）    年化   1.61%  最大回撤   -8.22%  夏普  0.58
交易 40 筆，勝率 35.0%，盈虧比 1.29，期望值 -0.53%，最大連虧 5
```

**三個策略全部失敗**：沒有一個贏過買進持有，更沒有一個贏過曝險相當的基準；擇時捕獲率顯示，它們在下跌時承受的比例都比上漲時參與的比例還高。

> 🎓 **這是正確的結果！** `sample_long.csv` 是亂數產生的資料，價格沒有可以預測的規律——在這種資料上，任何策略都**不應該**穩定地贏。如果你的某個策略在這份資料上表現很好，**反而要懷疑**是不是有前視偏差或過度擬合。
>
> 這也提供了一個很有用的檢查方法：**把你的策略跑在隨機資料上，它應該失敗**。如果它在隨機資料上也「成功」了，你的回測程式一定有問題（10.12 的 `random_walk()` 可以幫你產生多份隨機資料）。

> 💡 用真實資料時，結果可能不一樣——真實市場中可能存在某些持續性的特性（8.2）。但也很可能三個策略都通不過全部檢驗，這很正常。**你的目標不是找到賺錢的策略，而是誠實地回答「它值不值得進入模擬交易」。**

### 5. 結論的三種選擇

| 結論 | 條件（參考） | 下一步 |
|---|---|---|
| **淘汰** | 樣本外明顯失敗、打不贏曝險相當基準、參數非常敏感、或有無法解釋的問題 | 記錄原因，存檔 |
| **繼續研究** | 有一些正面跡象，但某些檢驗沒通過（例如只在某些期間有效） | 提出**新的假說**（不是針對樣本外修改參數），用新資料或新市場測試 |
| **進入模擬交易** | 通過大部分檢驗：樣本外與 walk-forward 不錯、打得贏適當的基準、參數穩健、成本容忍度高 | Phase 12 模擬交易至少 3 個月 |

> ⚠️ 「繼續研究」不能變成「在同一份樣本外上反覆修改直到通過」——那就是燒掉樣本外（10.13）。

### 6. ⭐ M3 驗收清單

- [ ] 3 份策略都使用**真實資料**（還原價格），並記錄資料來源與下載日期
- [ ] 每份策略都做了**交叉驗證**（自寫 vs. 框架），差異說得出原因
- [ ] 每份策略都加入**真實成本**，並做成本加倍測試
- [ ] **前視偏差檢查清單**全部打勾
- [ ] 揭露**倖存者偏差**風險
- [ ] 樣本外切分點**事先決定**，策略在樣本外測試前已用 Git **凍結**
- [ ] 做了 **walk-forward** 或逐年拆解
- [ ] 做了**參數穩健性**測試（±20%、延遲一天）
- [ ] 和**同期買進持有**、**曝險相當基準**比較，計算擇時捕獲率
- [ ] 至少一個策略也跑在**隨機資料**上，確認它會失敗
- [ ] 3 份回測報告都填完範本，並揭露**總測試次數**
- [ ] 每份報告都有明確結論：**淘汰 / 繼續研究 / 進入模擬交易**
- [ ] 能用 1 分鐘向朋友說明其中一份報告

## 📌 重點整理

1. 期末專題：3 份規格書 × 完整回測流程 × 3 份報告 = **M3**。
2. 標準流程：**準備 → 樣本內（可調整、要記錄）→ 凍結 → 樣本外（只做一次）→ 報告**。
3. 起始程式 `capstone_starter.py` 串好了所有檢驗，只要換資料與訊號。
4. 練習資料上三個策略**全部失敗**是正確的——隨機資料上不應該有策略穩定獲勝。
5. **把策略跑在隨機資料上，它應該失敗**：這是檢查回測程式的好方法。
6. 結論三選一：**淘汰、繼續研究、進入模擬交易**；方法嚴謹比結果漂亮重要。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「專題的目標是找到賺錢的策略」 | 目標是用正確的方法，誠實回答策略值不值得進入模擬交易。 |
| 「三個策略都失敗，代表我做錯了」 | 大部分策略都會被淘汰；方法正確的負面結論也是好結論。 |
| 「樣本外失敗了，調整一下再測就好」 | 在同一段樣本外反覆修改會燒掉樣本外；要提出新假說並用新資料測試。 |
| 「策略在隨機資料上表現好，代表它很強」 | 隨機資料沒有規律，表現好幾乎一定是程式錯誤或過度擬合。 |

## ✅ 自我測驗

**Q1. 為什麼要在樣本外測試前用 Git「凍結」策略？**

<details><summary>看答案</summary>

為了留下「策略在看到樣本外結果之前就已經定案」的證據，確保樣本外測試只做一次、沒有根據樣本外結果回頭修改。這是對自己誠實的方式，也讓報告的讀者可以相信樣本外結果的可信度。

</details>

**Q2. 為什麼「把策略跑在隨機資料上，它應該失敗」是一個好的檢查方法？**

<details><summary>看答案</summary>

隨機資料中沒有任何可預測的規律，任何策略在扣除成本後都不應該穩定獲利。如果策略在多份隨機資料上都表現很好，代表回測程式可能有前視偏差、成本計算錯誤，或策略的評估方式有問題，必須找出原因。

</details>

**Q3. 結論為「繼續研究」時，應該怎麼做？不應該怎麼做？**

<details><summary>看答案</summary>

應該提出新的、有邏輯的假說，並用新的資料、新的市場或新的期間測試。不應該針對已經看過的樣本外資料反覆修改參數或規則直到結果變好，那會燒掉樣本外資料，造成過度擬合。

</details>
