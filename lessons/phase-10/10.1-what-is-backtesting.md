# 10.1｜回測是什麼？能做什麼、不能做什麼

> ⏱️ 約 2 小時｜[Phase 10 目錄](README.md)｜[下一單元：10.2 →](10.2-vectorized-backtest.md)

## 🎯 學完你會知道

- **回測**的定義：用歷史資料模擬「如果當時照規則交易，會發生什麼事」
- 回測**能做什麼**：淘汰爛策略、了解策略的個性、設定合理的期待
- 回測**不能做什麼**：保證未來、證明策略有效
- 回測結果和實際交易之間的**落差來源**
- 一個好回測的**五個特徵**
- 為什麼「擲硬幣」也能擲出漂亮的回測

---

## 📖 開場故事：模擬考與飛行模擬器

**模擬考**

小安準備大學考試，做了 20 回歷屆試題，平均 85 分。她很有信心。

但她的老師提醒了三件事：

1. 「如果你考試前**偷看過答案**，85 分就沒有意義。」
2. 「如果你**同一份考卷寫了五次**，第五次 95 分也不代表你真的會。」
3. 「今年的題型可能**和往年不一樣**。」

**飛行模擬器**

飛行員在真正開飛機前，要在模擬器裡飛幾百個小時，練習各種狀況：亂流、引擎故障、側風降落。模擬器**不能保證**真實飛行一定順利，但**沒在模擬器墜機過的飛行員，才有資格坐上真的駕駛艙**。

> ✈️ **回測就是交易的模擬考 + 飛行模擬器**：用過去的資料測試你的策略。它最大的價值不是「證明會賺錢」，而是**在不花真錢的情況下，先墜機幾次**——找出策略在什麼狀況下會失敗、會跌多深、會連虧多久。但它也有陷阱：偷看答案、背答案、以為未來和過去一樣。Phase 10 就是要教你怎麼正確地使用這台模擬器。

## 🧠 正文

### 1. 回測是什麼？

**回測（Backtesting）** = 把明確的策略規則（8.13 規格書），套用在歷史資料上，一天一天模擬「當時照規則交易會發生什麼事」，並計算結果。

| 你在 Phase 8 做的 | Phase 10 要做的 |
|---|---|
| 用眼睛在圖表上找 30 筆交易 | 用程式找出**所有**交易 |
| 手動記錄、容易看錯 | 照規則計算，不會看錯 |
| 沒有成本 | 加入手續費、稅、滑價 |
| 只看勝率和期望值 | 完整的績效、風險、交易統計 |
| 不知道結果可不可信 | 用樣本外測試、walk-forward 等方法檢驗 |

### 2. ⭐ 回測能做什麼？

| 用途 | 說明 | 模擬器比喻 |
|---|---|---|
| **淘汰爛策略** | 在歷史上都賺不了錢的策略，未來大概也很難 | 模擬器裡一直墜機的飛法，不要拿去真的飛 |
| **了解策略的個性** | 勝率、賠率、最大回撤、最長連虧、在什麼市場狀態下表現好壞 | 知道這架飛機在側風中會怎麼晃 |
| **設定合理的期待** | 實盤遇到 20% 回撤時，你知道「回測中也發生過」，不會恐慌（Phase 7） | 遇到亂流時知道「這在正常範圍內」 |
| **比較不同方案** | 同一個想法的不同版本，哪一個比較穩健？ | 比較不同的降落方式 |
| **找出 bug 與規則漏洞** | 規格書的模糊之處在寫程式時會被發現（8.13） | 發現操作手冊漏寫的步驟 |

### 3. ⭐ 回測不能做什麼？

| 做不到的事 | 原因 |
|---|---|
| **保證未來會賺錢** | 市場會改變；過去有效的優勢可能被套利掉（8.2） |
| **證明策略「有效」** | 只能說「在這段歷史上，這樣做的結果是如此」；好結果可能是運氣（3.11）或過度擬合（10.12） |
| **完全模擬真實交易** | 滑價、無法成交、漲跌停、心理壓力，都很難完整模擬 |
| **告訴你你撐不撐得住** | 回測中的 −30% 只是一個數字；實盤中的 −30% 是每天的煎熬（Phase 7） |

> 🔑 **心態**：回測結果是「**上限**」而不是「預期值」。實盤的表現通常會比回測差——因為成本、執行落差，以及回測時不自覺的過度擬合。

### 4. 回測與實盤的落差從哪裡來？

| 落差來源 | 例子 | 會在哪個單元處理 |
|---|---|---|
| **偷看答案** | 用到了當時還不知道的資料 | 10.10 前視偏差 |
| **只看倖存者** | 只測試現在還存在的股票 | 10.11 倖存者偏差 |
| **背答案** | 參數調到剛好適合過去 | 10.12～10.15 |
| **忽略成本** | 沒算手續費、稅、滑價 | 10.6 |
| **執行落差** | 開盤價買不到、跳空、漲跌停、流動性不足 | 10.6、Phase 12 |
| **心理落差** | 回撤時沒有照規則執行 | Phase 7、Phase 12 |
| **市場改變** | 優勢消失、市場結構改變 | 10.13～10.14、Phase 13 |

### 5. ⭐ 擲硬幣也能擲出漂亮的回測

先看一個實驗：用 10.2 會寫的回測工具，讓 **100 隻猴子**各自交易練習資料——每個月月底**擲硬幣**決定下個月要不要持有。

```python
import numpy as np
import pandas as pd
from bt_toolkit import load_prices, backtest, perf_stats

df = load_prices("sample_long.csv")
month_ends = df.resample("ME").last().index

rng = np.random.default_rng(0)
cagrs = []
for monkey in range(100):
    coin = pd.Series(rng.integers(0, 2, len(month_ends)), index=month_ends)  # 每月擲一次硬幣
    signal = coin.reindex(df.index, method="ffill").fillna(0)              # 整個月沿用
    res = backtest(df, signal)
    cagrs.append(perf_stats(res["strat_ret"])["年化報酬"])

cagrs = np.array(cagrs)
bh = perf_stats(df["Close"].pct_change())["年化報酬"]
print(f"買進持有的年化報酬：{bh:.2%}")
print(f"100 隻猴子中最好的：{cagrs.max():.2%}，最差的：{cagrs.min():.2%}，中位數：{np.median(cagrs):.2%}")
print(f"贏過買進持有的猴子：{(cagrs > bh).sum()} 隻")
```

輸出：

```
買進持有的年化報酬：8.67%
100 隻猴子中最好的：9.04%，最差的：-1.33%，中位數：4.11%
贏過買進持有的猴子：2 隻
```

（現在看不懂程式沒關係，10.2 會一步一步教。先看結果。）

> 🐒 **有 2 隻擲硬幣的猴子，14 年下來贏過買進持有。** 如果你只看到那隻最好的猴子的回測報告——年化 9%、比大盤好——你可能會以為牠找到了什麼秘訣。但牠只是運氣好。
>
> 🔑 這就是回測最根本的問題：**測試得夠多次，一定會找到看起來很棒的結果**（回想 3.11 運氣與技巧、8.8 多重比較）。Phase 10 後半段的所有方法，都是在回答一個問題：「**我的策略和那隻幸運的猴子，有什麼不同？**」

### 6. ⭐ 一個好回測的五個特徵

| # | 特徵 | 說明 | 考試比喻 |
|---|---|---|---|
| 1 | **規則先寫好** | 先有規格書（8.13）、先有假說（8.2），再看結果 | 先讀書，再考試 |
| 2 | **沒有偷看答案** | 每個決策只用當時已知的資料 | 考試時沒偷看答案 |
| 3 | **成本真實** | 手續費、稅、滑價都算進去 | 把交通時間算進去 |
| 4 | **經得起刁難** | 樣本外、不同期間、不同商品、參數微調都還行 | 換一份沒看過的考卷也考得好 |
| 5 | **誠實記錄** | 記下總共試了幾個版本、刪掉了什麼 | 不只報告考得最好的那一次 |

> 💡 這五點會對應到你最後的[回測報告範本](../../templates/backtest-report.md)。

## 📌 重點整理

1. 回測 = **模擬考 + 飛行模擬器**：用歷史資料模擬照規則交易的結果。
2. 能做：**淘汰爛策略、了解策略個性、設定合理期待、比較方案、找出 bug**。
3. 不能做：**保證未來、證明有效、完全模擬真實、測試你的心理**。
4. 回測結果是**上限**，實盤通常比較差。
5. 測試夠多次，**擲硬幣也能擲出漂亮的回測**——後半段的方法都在區分運氣與實力。
6. 好回測五特徵：**規則先寫、不偷看、成本真實、經得起刁難、誠實記錄**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「回測賺錢，實盤就會賺錢」 | 回測是上限；成本、執行、市場改變、心理都會讓實盤變差。 |
| 「回測年化 100% 的策略很厲害」 | 先懷疑有 bug、偷看未來或過度擬合。 |
| 「回測是為了找到最賺錢的策略」 | 回測是為了淘汰爛策略、了解策略的風險，並找出它為什麼可能失敗。 |
| 「回測結果好就代表策略有效」 | 可能只是運氣；需要樣本外測試與穩健性檢查。 |

## ✅ 自我測驗

**Q1. 回測最主要的價值是什麼？**

<details><summary>看答案</summary>

淘汰明顯無效的策略；了解策略的個性（勝率、賠率、最大回撤、連虧、適合的市場狀態）；設定合理的期待，讓實盤遇到回撤時不恐慌；比較不同方案；發現規則漏洞與程式錯誤。它不是用來證明策略一定會賺錢。

</details>

**Q2. 為什麼說回測結果是「上限」而不是預期值？**

<details><summary>看答案</summary>

因為實盤會遇到回測中難以完整模擬的不利因素：交易成本與滑價、無法成交或跳空、心理壓力導致沒照規則執行、市場結構改變；而且回測過程中常會不自覺地過度擬合過去的資料。這些因素幾乎都只會讓實盤結果變差。

</details>

**Q3. 猴子實驗想說明什麼？**

<details><summary>看答案</summary>

只要測試的策略夠多，純靠運氣也會出現績效看起來很好的結果。因此單看一個漂亮的回測結果沒有意義，必須進一步檢驗它是否只是幸運（多重比較、樣本外測試、穩健性分析），並確認它有合理的優勢來源。

</details>
