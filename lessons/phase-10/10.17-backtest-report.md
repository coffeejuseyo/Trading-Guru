## 📖 開場故事：寫一份實驗報告

高中化學課，老師要你做「溫度對反應速率的影響」實驗。做完之後，你要交一份實驗報告：

1. **目的與假說**：溫度越高，反應越快
2. **材料與方法**：用了什麼藥品、多少量、什麼溫度、怎麼計時
3. **結果**：數據表、圖表
4. **討論**：結果符合假說嗎？有什麼誤差來源？
5. **結論**

老師說：「報告的重點不是結果漂不漂亮，而是**別人照著你的方法做，能不能得到一樣的結果**。如果實驗失敗了，誠實寫出來，並分析原因——這和成功的實驗一樣有價值。」

> 🧪 **回測報告就是交易策略的實驗報告**：寫清楚假說、規則、資料、成本、結果與檢驗，讓別人（或三個月後的你）能夠**重現**和**評判**。寫報告也會逼你面對所有不想面對的問題：樣本外表現如何？試了幾次？和基準比呢？

## 🧠 正文

### 1. 為什麼要寫報告？

| 理由 | 說明 |
|---|---|
| **可重現** | 三個月後你會忘記用了什麼資料、什麼成本、什麼參數 |
| **逼自己誠實** | 範本中每一欄都要填：樣本外、基準、測試次數……沒辦法跳過不好看的部分 |
| **方便比較** | 每個策略都用同一份格式，比較起來一目了然 |
| **做決策的依據** | 報告的結論決定：淘汰、繼續研究、還是進入模擬交易（Phase 12） |
| **對抗後見之明** | 寫下「當時的判斷」，之後才能檢討（7.3） |

### 2. ⭐ 範本的 9 個段落

| # | 段落 | 要寫什麼 | 對應單元 |
|---|---|---|---|
| 1 | 基本資訊 | 名稱、版本、程式碼位置 | 9.14 |
| 2 | **假說** | 為什麼應該有效？優勢來源？生活比喻？ | 8.2、8.13 |
| 3 | 策略規則 | 標的、週期、進出場、部位、過濾、參數 | 8.13 |
| 4 | **資料** | 來源、期間、除權息、倖存者偏差、樣本內外切分 | 9.10、9.11、10.11、10.13 |
| 5 | 交易成本 | 手續費、稅、滑價 | 10.6 |
| 6 | **績效結果** | 樣本內、樣本外、同期基準、曝險相當基準 | 10.7～10.9、10.16 |
| 7 | **穩健性檢查** | 前視偏差、參數、成本、擇時能力、walk-forward、測試次數…… | 10.10～10.16 |
| 8 | **結論** | 值不值得進入模擬交易？最大風險？ | — |
| 9 | 費曼摘要 | 三句話講給朋友聽 | 0.3 |

> 🔑 **最重要的是第 2、7、8 段**：假說說明「為什麼」，穩健性檢查說明「有多可信」，結論說明「接下來怎麼做」。只有第 6 段的報告，只是一張成績單。

### 3. ⭐ 用程式自動產生績效表格

手動從程式輸出抄數字到報告，很容易抄錯。寫一段程式直接產生 Markdown 表格：

```python
import pandas as pd
from bt_toolkit import load_prices, sma, backtest, tw_costs, perf_stats, extract_trades, trade_stats

df = load_prices("sample_long.csv")
signal = (sma(df["Close"], 20) > sma(df["Close"], 60)).astype(int)
res = backtest(df, signal, *tw_costs())
bh = df["Close"].pct_change().fillna(0)


def metrics(ret):
    p = perf_stats(ret)
    return {
        "總報酬": f"{p['總報酬']:.1%}",
        "年化報酬（CAGR）": f"{p['年化報酬']:.2%}",
        "年化波動度": f"{p['年化波動']:.2%}",
        "最大回撤（MDD）": f"{p['最大回撤']:.2%}",
        "夏普比率": f"{p['夏普比率']:.2f}",
        "Sortino 比率": f"{p['Sortino']:.2f}",
        "Calmar 比率": f"{p['Calmar']:.2f}",
        "最長回撤期間": f"{p['最長回撤天數']} 天",
    }


def trade_metrics(start, end):
    s = trade_stats(extract_trades(df.loc[start:end], res.loc[start:end]))
    return {
        "交易次數": str(s["交易次數"]),
        "勝率": f"{s['勝率']:.1%}",
        "盈虧比": f"{s['盈虧比']:.2f}",
        "每筆期望值": f"{s['每筆期望值']:.2%}",
        "最大連續虧損次數": str(s["最大連虧"]),
    }


columns = {
    "策略：樣本內 2010–2018": {**metrics(res["strat_ret"].loc[:"2018"]), **trade_metrics(None, "2018")},
    "策略：樣本外 2019–2023": {**metrics(res["strat_ret"].loc["2019":]), **trade_metrics("2019", None)},
    "買進持有：樣本內": metrics(bh.loc[:"2018"]),
    "買進持有：樣本外": metrics(bh.loc["2019":]),
}
table = pd.DataFrame(columns).fillna("—")


def to_markdown(t):
    """把 DataFrame 轉成 Markdown 表格（不需要額外套件）。"""
    lines = ["| 指標 | " + " | ".join(t.columns) + " |",
             "|---|" + "---:|" * len(t.columns)]
    for idx, row in t.iterrows():
        lines.append(f"| {idx} | " + " | ".join(row.values) + " |")
    return "\n".join(lines)


print(to_markdown(table))
```

|---|---:|---:|---:|---:|
| 總報酬 | 34.6% | 47.7% | 47.4% | 117.0% |
| 年化報酬（CAGR） | 3.36% | 8.12% | 4.41% | 16.79% |
| 年化波動度 | 13.95% | 12.05% | 18.20% | 14.27% |
| 最大回撤（MDD） | -35.36% | -17.60% | -42.84% | -15.79% |
| 夏普比率 | 0.30 | 0.69 | 0.32 | 1.12 |
| Sortino 比率 | 0.42 | 0.99 | 0.45 | 1.63 |
| Calmar 比率 | 0.10 | 0.46 | 0.10 | 1.06 |
| 最長回撤期間 | 1678 天 | 1009 天 | 1698 天 | 449 天 |
| 交易次數 | 21 | 12 | — | — |
| 勝率 | 33.3% | 50.0% | — | — |
| 盈虧比 | 3.51 | 2.20 | — | — |
| 每筆期望值 | 2.10% | 2.04% | — | — |

> 💡 把這段程式存起來，每個策略都用它產生表格——**格式一致、不會抄錯、資料更新後重跑即可**。（交易統計在切分點附近的交易會被切開，所以樣本內外的交易次數加起來可能和全期間略有不同。）

### 4. ⭐ 範例報告

完整的範例在這裡：**[examples/report-ma-cross.md](examples/report-ma-cross.md)**——把 10.2～10.16 對均線策略做過的所有分析，整理成一份報告。

**閱讀範例時注意：**

| 段落 | 範例怎麼寫 | 學習重點 |
|---|---|---|
| 假說 | 一句話 + 比喻 + 優勢來源 + 預期特徵 | 事先說清楚「應該」長什麼樣子，之後才能比對 |
| 資料 | 寫明樣本內外**在研究開始前**決定 | 證明沒有事後挑切分點 |
| 績效 | 同時列出同期買進持有與**曝險相當基準** | 讓讀者自己判斷 |
| 穩健性 | 每一項都打勾並寫出數字；**不好的結果也寫**（參數敏感、沒有擇時能力） | 誠實 |
| 測試次數 | 寫出檢視過 105 + 140 組參數 | 多重檢定揭露 |
| 結論 | **「不值得」**，並列出 4 個理由與下一步 | 淘汰也是好結論 |

### 5. ⭐ 好報告的 6 個原則

| # | 原則 | 說明 |
|---|---|---|
| 1 | **可重現** | 資料來源、期間、成本、參數、程式碼位置都寫清楚 |
| 2 | **先寫假說** | 假說在看結果之前就寫下來（可以參考 Phase 8 的規格書） |
| 3 | **報告全部，不只最好的** | 樣本外、壞的年份、敏感的參數都要寫 |
| 4 | **和正確的基準比** | 同期間買進持有 + 曝險相當基準 |
| 5 | **揭露測試次數** | 總共試了幾個版本、幾組參數 |
| 6 | **結論要能行動** | 淘汰 / 繼續研究 / 進入模擬交易，以及理由 |

### 6. ⚠️ 常見的報告陷阱

| 陷阱 | 例子 | 為什麼不行 |
|---|---|---|
| **只報告最好的版本** | 試了 30 個版本，只寫最好的那一個 | 多重檢定：最好的那個很可能是運氣（10.12） |
| **只報告全期間** | 沒有樣本內外、沒有逐年拆解 | 看不出過度擬合與策略個性 |
| **選擇性的基準** | 和一個表現很差的基準比 | 讓策略看起來比實際好 |
| **沒寫成本假設** | 「年化 15%」——含不含成本？ | 無法判斷可信度 |
| **用模糊的語言** | 「表現不錯」、「相當穩健」 | 要用數字說話 |
| **結論過度樂觀** | 「這個策略未來每年可以賺 15%」 | 回測是上限，不是預期值（10.1） |

### 7. 報告完成後的自我審查清單

- [ ] 別人只看這份報告，能重現我的結果嗎？
- [ ] 假說是在看結果之前寫的嗎？
- [ ] 樣本外結果有寫嗎？和同期基準比了嗎？
- [ ] 曝險相當基準比過了嗎？
- [ ] 前視偏差檢查清單（10.10）全部打勾了嗎？
- [ ] 總測試次數寫了嗎？
- [ ] 不好的結果也寫了嗎？
- [ ] 結論是「淘汰 / 繼續研究 / 模擬交易」其中之一，並有理由嗎？
- [ ] 費曼摘要能讓不懂交易的朋友聽懂嗎？
- [ ] 報告與程式都用 Git 存檔了嗎（9.14）？

## 📌 重點整理

1. 回測報告 = **策略的實驗報告**：讓別人能重現、能評判。
2. 範本 9 段，最重要的是**假說、穩健性檢查、結論**。
3. 用程式**自動產生績效表格**，避免抄錯。
4. 範例報告：誠實寫出不好的結果，結論是「不值得」——**淘汰也是好結論**。
5. 6 個原則：**可重現、先寫假說、報告全部、正確基準、揭露測試次數、結論能行動**。
6. 避開陷阱：只報最好的、只報全期間、選擇性基準、沒寫成本、模糊語言、過度樂觀。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「報告只要放績效數字就好」 | 假說、資料、成本、穩健性檢查與結論同樣重要，甚至更重要。 |
| 「結果不好的策略不用寫報告」 | 淘汰的理由也要記錄，避免未來重複犯錯，也是誠實面對多重檢定。 |
| 「報告是寫給別人看的，自己研究不需要」 | 三個月後的你就是「別人」；報告也是對抗後見之明的工具。 |
| 「回測報告的年化報酬就是未來的預期報酬」 | 回測結果是上限，實盤通常會比較差。 |

## ✅ 自我測驗

**Q1. 回測報告中最重要的三個段落是哪些？為什麼？**

<details><summary>看答案</summary>

假說（說明策略為什麼應該有效、預期有什麼特徵，讓結果有可以比對的依據）、穩健性檢查（說明結果有多可信：前視偏差、樣本外、參數敏感度、基準比較、測試次數等）、結論（說明接下來要淘汰、繼續研究還是進入模擬交易，以及理由）。只有績效數字的報告只是一張成績單，無法判斷可信度，也無法支持決策。

</details>

**Q2. 為什麼「只報告最好的版本」是報告陷阱？**

<details><summary>看答案</summary>

因為試了很多版本後挑出最好的，最好的結果很可能主要來自運氣（多重檢定、過度擬合）。只報告最好的版本，會讓讀者高估策略的可信度。正確做法是揭露總共測試了多少個版本與參數組合，並對結果打折看待。

</details>

**Q3. 為什麼要用程式自動產生績效表格？**

<details><summary>看答案</summary>

避免手動抄寫數字時出錯；讓每個策略的報告格式一致，方便比較；資料或規則更新後，只要重新執行程式就能更新表格，確保報告與程式結果一致、可重現。

</details>
