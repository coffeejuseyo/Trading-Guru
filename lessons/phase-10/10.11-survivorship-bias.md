## 🎯 學完你會知道

- **倖存者偏差**是什麼：只看到「活下來」的，忽略了「消失」的
- 它在回測中**怎麼發生**：用今天還存在的股票回測過去
- 用模擬實驗親眼看到：倖存者偏差如何**灌水**買進持有與「抄底」策略
- 哪些策略**特別容易**受影響
- **降低倖存者偏差**的方法，以及資料取得的現實限制

## 📖 開場故事：只訪問成功創業的人

雜誌社想寫一篇「創業成功的秘訣」，他們訪問了 20 位成功的創業家，發現：

- 18 位都「**辭掉穩定的工作、全心投入**」
- 15 位都「**把房子拿去抵押籌資金**」
- 12 位都「**不聽家人的反對**」

結論：「想成功，就要破釜沉舟！」

但雜誌社沒有去訪問的，是**另外 2,000 位**也辭掉工作、抵押房子、不聽家人反對，結果**失敗**的創業者——他們的公司已經不存在了，沒有人會去訪問他們。

> 🪦 **倖存者偏差就是「只看到活下來的」**。在回測中，如果你只用「現在還在交易的股票」去測試過去，那些下市、破產、被合併的公司就**消失**了——而它們往往是表現最差的。你的回測就像只訪問成功創業家的雜誌：結論會偏樂觀，而且可能完全錯誤。

---

## 🧠 正文

### 1. 倖存者偏差在回測中怎麼發生？

| 情況 | 例子 | 問題 |
|---|---|---|
| **股票池用今天的名單** | 用今天的「台股前 100 大」回測 2014～2024 | 2014 年你不會知道哪些公司 10 年後會成為前 100 大 |
| **免費資料只有現存股票** | yfinance 通常找不到已下市的股票（9.10） | 下市股票的虧損被排除了 |
| **指數成分股用今天的** | 用今天的 0050 成分股回測過去 | 被剔除的（通常表現較差）消失了；被納入的（通常先漲了一大段）被提前持有 |
| **基金、策略的歷史績效** | 只統計「現在還存在」的基金 | 績效差的基金被清算或合併了 |

> 🔑 **倖存者偏差其實是一種前視偏差**（10.10 第 7 種）：用「今天才知道的事情」（誰活下來了）去做「過去的決策」（選股）。

### 2. ⭐ 模擬實驗：倖存者偏差有多大？

模擬 300 檔股票、10 年。每檔股票有不同的長期趨勢與波動；**價格跌到 20 元（從 100 元跌了 80%）就下市**，股價歸零（投資人血本無歸）。

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(3)
n_stocks, years = 300, 10
days = 252 * years

mu = rng.normal(0.03, 0.06, n_stocks) / 252            # 每檔股票的長期趨勢不同
vol = rng.uniform(0.25, 0.45, n_stocks) / np.sqrt(252)  # 每檔股票的波動不同
rets = rng.normal(0, 1, (days, n_stocks)) * vol + mu
prices = pd.DataFrame(100 * np.exp(np.cumsum(rets, axis=0)),
                      index=pd.bdate_range("2014-01-01", periods=days))

delisted = pd.Series(False, index=prices.columns)
for j in prices.columns:
    hit = prices.index[prices[j] < 20]
    if len(hit):
        prices.loc[hit[0]:, j] = 0.0                    # 下市：之後價值為 0
        delisted[j] = True

survivors = prices.columns[~delisted.values]
print(f"10 年間下市：{delisted.sum()} 檔，倖存：{len(survivors)} 檔")


def equal_weight_cagr(cols, start=0):
    """在第 start 天等權重買進 cols，持有到最後的年化報酬。"""
    p = prices[cols].iloc[start:]
    value = (p / p.iloc[0]).mean(axis=1)
    return value.iloc[-1] ** (252 / (len(p) - 1)) - 1


print(f"等權重買進持有【全部 300 檔】：年化 {equal_weight_cagr(prices.columns):.2%}")
print(f"等權重買進持有【只有倖存者】：年化 {equal_weight_cagr(survivors):.2%}")
```

輸出：

```
10 年間下市：37 檔，倖存：263 檔
等權重買進持有【全部 300 檔】：年化 12.00%
等權重買進持有【只有倖存者】：年化 13.49%
```

> 💡 只用倖存者，**連最簡單的買進持有都被灌水了每年約 1.5 個百分點**。10 年下來，累積差距超過 20%。

（這是模擬資料，數字本身沒有意義，重點是「方向」與「機制」。真實市場中，倖存者偏差的大小取決於市場、期間、股票池，學術研究中常見的估計從每年零點幾到一兩個百分點不等。）

### 3. ⭐⭐ 「抄底」策略：倖存者偏差的重災區

策略：**第一年結束時，買進過去一年跌最多的 30 檔股票**，持有 9 年（「跌深的好公司一定會漲回來」）。

```python
year1_ret = prices.iloc[251] / prices.iloc[0] - 1

# ❌ 倖存者偏差：只從「今天還存在」的股票中挑
losers_biased = year1_ret[survivors].nsmallest(30).index
# ✅ 正確：從「當時還在交易」的股票中挑
alive_then = prices.columns[prices.iloc[251] > 0]
losers_real = year1_ret[alive_then].nsmallest(30).index

print(f"❌ 只從倖存者中挑：年化 {equal_weight_cagr(losers_biased, start=251):.2%}，"
      f"其中後來下市 {delisted[losers_biased].sum()} 檔")
print(f"✅ 從當時所有股票中挑：年化 {equal_weight_cagr(losers_real, start=251):.2%}，"
      f"其中後來下市 {delisted[losers_real].sum()} 檔")
```

輸出：

```
❌ 只從倖存者中挑：年化 14.66%，其中後來下市 0 檔
✅ 從當時所有股票中挑：年化 7.06%，其中後來下市 10 檔
```

> 🚨 **倖存者偏差讓抄底策略的年化報酬從 7% 變成 15%——翻了一倍。** 真實情況下，跌最多的 30 檔中有 **10 檔後來下市歸零**；但在倖存者偏差的回測中，這些股票根本不存在，你「挑到的」全都是最後有活下來的。
>
> 🔑 **為什麼抄底策略特別嚴重？** 因為「跌很多的股票」正是最可能下市的股票。倖存者偏差剛好把抄底策略**最大的風險**（買到會倒的公司）完全隱藏起來。

### 4. 哪些策略特別容易受影響？

| 策略類型 | 影響程度 | 原因 |
|---|---|---|
| **抄底、均值回歸、低價股**（8.5） | 🔴 非常大 | 跌深的股票最容易下市 |
| **價值因子**（8.9） | 🔴 大 | 「便宜」的股票中有很多是價值陷阱，最後倒閉 |
| **小型股**（8.9） | 🔴 大 | 小公司下市比例高 |
| **動能、趨勢**（8.3、8.6） | 🟡 中 | 會避開下跌中的股票，但仍會高估 |
| **大盤 ETF、指數** | 🟢 小 | 指數本身會汰換成分股，ETF 價格已經反映了這個過程 |

> 💡 這也是為什麼本課程的練習多用**大盤 ETF**（0050、SPY）：ETF 本身持續存在，指數的成分股汰換已經包含在 ETF 的價格裡，倖存者偏差相對小。**一旦你開始做個股選股策略，倖存者偏差就是必須正面處理的問題。**

### 5. ⭐ 如何降低倖存者偏差？

| 方法 | 做法 | 現實限制 |
|---|---|---|
| **使用包含下市股票的資料庫** | 付費資料庫（例如 TEJ、CRSP 等）通常有下市股票的完整歷史 | 很貴，通常是機構或學校使用 |
| **使用「當時」的股票池** | 每個時間點，只從**當時**符合條件的股票中選（例如當時的市值前 100 大、當時的指數成分股） | 需要歷史成分股資料 |
| **從官方來源補齊** | 證交所、櫃買中心有下市公司的公告與部分歷史資料 | 整理很花時間 |
| **用 ETF 或指數做研究** | 單一 ETF 策略，或用產業 ETF 代替個股 | 策略範圍受限 |
| **誠實揭露** | 無法取得完整資料時，在報告中明確寫出「可能有倖存者偏差，結果偏樂觀」 | — |

> 🔑 **最低要求：知道它的存在，並在報告中寫清楚。** [回測報告範本](../../templates/backtest-report.md)的「資料」段落有一欄「是否包含已下市標的（倖存者偏差）」——不能留白。

### 6. 生活中的倖存者偏差

| 例子 | 看不到的「失敗者」 |
|---|---|
| 「老房子都很堅固，以前的建築品質比較好」 | 品質差的老房子早就拆掉了 |
| 「那個網紅靠當沖年賺千萬」 | 虧光錢、默默離開的人不會發文 |
| 「這檔基金成立以來年化 15%」 | 同一家公司績效差的基金已經被清算 |
| 「我爺爺抽菸活到 95 歲」 | 因抽菸早逝的人無法分享經驗 |
| 「書上的成功投資人都是長期持有」 | 長期持有錯誤公司而失敗的人沒有出書 |

> 🪦 每次看到一個驚人的成功故事，問自己：**「那些失敗的人在哪裡？」**

## 📌 重點整理

1. **倖存者偏差** = 只看到活下來的；在回測中，用今天還存在的股票測試過去。
2. 它是前視偏差的一種：用「今天才知道誰活下來」去做過去的決策。
3. 模擬實驗：買進持有被灌水約 1.5%／年；**抄底策略從 7% 灌水到 15%**。
4. **抄底、價值、小型股**策略受影響最大；大盤 ETF 相對小。
5. 降低方法：包含下市股票的資料、**當時的股票池**、用 ETF 研究、誠實揭露。
6. 看到成功故事，問：「失敗的人在哪裡？」

>
> 所以做個股策略時，一定要用當時的股票名單，拿不到完整資料就要在報告裡寫清楚結果可能偏樂觀。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「我用的是真實歷史價格，所以沒有偏差」 | 價格是真的，但股票池只有倖存者，就會偏樂觀。 |
| 「下市的股票很少，影響不大」 | 下市股票常常是虧損最大的，對抄底、價值、小型股策略影響特別大。 |
| 「用今天的成分股回測指數策略沒問題」 | 被剔除的股票消失、被納入的股票被提前持有，兩者都會灌水。 |
| 「用 ETF 研究就完全沒有倖存者偏差」 | 單一 ETF 的偏差較小，但如果你從「現在還存在的 ETF」中挑選，仍然有偏差。 |

## ✅ 自我測驗

**Q1. 為什麼說倖存者偏差是一種前視偏差？**

<details><summary>看答案</summary>

因為「哪些股票最後還存在」是事後才知道的資訊。用今天還存在的股票作為過去的選股範圍，等於在過去的決策中使用了未來才知道的結果（誰活下來、誰倒閉），因此屬於前視偏差的一種。

</details>

**Q2. 為什麼抄底策略特別容易被倖存者偏差影響？**

<details><summary>看答案</summary>

抄底策略買進的是跌最多的股票，而跌最多的股票正是最可能繼續惡化、最後下市或倒閉的股票。倖存者偏差把這些最終下市的股票從股票池中移除，等於把抄底策略最大的風險（買到會倒的公司）完全隱藏，使回測結果嚴重高估。

</details>

**Q3. 如果你拿不到包含下市股票的資料，該怎麼辦？**

<details><summary>看答案</summary>

1. 盡量使用「當時」的股票池（例如歷史成分股名單）；2. 改用 ETF 或指數進行研究；3. 從官方來源補齊下市公司資料；4. 至少在回測報告中明確揭露「可能存在倖存者偏差，結果偏樂觀」，並對結果打折看待。

</details>
