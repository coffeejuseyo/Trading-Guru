## 📖 開場故事：把交通時間算進去

小傑想比較兩份工作：

| | A 公司 | B 公司 |
|---|---|---|
| 月薪 | 42,000 | 45,000 |
| 通勤 | 走路 10 分鐘 | 開車 1 小時（單程） |

只看月薪，B 公司比較好。但把**油錢、停車費、每天多花的 2 小時**算進去之後，B 公司實際上可能比較差。

更麻煩的是 C 公司：月薪 50,000，但**要每天往返台北和台中**。薪水最高，但交通成本把它吃光了。

> 🚗 **回測沒算成本，就像比較工作只看月薪。** 每次買賣都要付手續費、交易稅，還有「實際成交價比預期差」的滑價。交易越頻繁（通勤越遠），成本吃掉的越多。**一個不算成本就賺錢的策略，扣掉成本後可能是虧錢的。**

## 🧠 正文

### 1. ⭐ 交易成本的三個組成

| 成本 | 說明 | 台股常見數字（以最新規定為準） | 回想 |
|---|---|---|---|
| **手續費** | 付給券商，買賣都要付 | 0.1425% × 折扣（網路下單常見 2～6 折），有最低收費 | 2.4 |
| **交易稅** | 付給政府，**只有賣出**要付 | 個股 0.3%；ETF 常見 0.1%；當沖另有優惠 | 2.4 |
| **滑價** | 實際成交價比預期差 | 視流動性而定：大型股 / ETF 很小，小型股可能很大 | 2.3 |

**一買一賣（來回）的總成本：**

```python
from bt_toolkit import tw_costs

for name, kwargs in [("ETF", dict(tax_rate=0.001)),
                     ("個股", dict()),
                     ("個股 + 滑價 0.1%", dict(slippage=0.001))]:
    buy, sell = tw_costs(**kwargs)
    print(f"{name}：買 {buy:.4%}，賣 {sell:.4%}，來回 {buy + sell:.4%}")
```

輸出：

```
ETF：買 0.0855%，賣 0.1855%，來回 0.2710%
個股：買 0.0855%，賣 0.3855%，來回 0.4710%
個股 + 滑價 0.1%：買 0.1855%，賣 0.4855%，來回 0.6710%
```

（手續費以 6 折計算；`tw_costs()` 的參數可以依你的券商調整。）

> 💡 **個股來回約 0.47%**：每做一次完整的買賣，就要先賺 0.47% 才打平。如果一年交易 50 次，光成本就要 23% 以上（概略計算）。

### 2. 在回測中加入成本

10.2 的 `backtest()` 已經預留了成本參數：

```py
cost = np.where(change > 0, buy_cost, sell_cost) * change.abs()
strat_ret = (1 + prev_pos * r_night) * (1 - cost) * (1 + pos * r_day) - 1
```

| 部分 | 意思 |
|---|---|
| `change = pos - prev_pos` | 今天開盤的部位變化：+1 = 買進、−1 = 賣出、0 = 沒交易 |
| `np.where(change > 0, buy_cost, sell_cost)` | 買進用買進成本、賣出用賣出成本 |
| `* change.abs()` | 只有部位改變時才收費；改變多少就收多少 |
| `(1 - cost)` | 在開盤成交的那一刻，資產扣掉成本 |

**用 6 天小例子手算驗證（10.2 第 7 節）：**

```python
import pandas as pd
import numpy as np
from bt_toolkit import backtest

t = pd.DataFrame({"Open": [100, 101, 103, 102, 105, 104],
                  "Close": [101, 102, 104, 103, 104, 106]},
                 index=pd.bdate_range("2024-01-01", periods=6))
signal = pd.Series([0, 1, 1, 1, 0, 0], index=t.index)
res = backtest(t, signal, buy_cost=0.001, sell_cost=0.004)
print(f"含成本總報酬：{res['equity'].iloc[-1] - 1:.4%}")
print(f"手算：{104 / 103 * (1 - 0.001) * (1 - 0.004) - 1:.4%}")
```

輸出：

```
含成本總報酬：0.4664%
手算：0.4664%
```

✅ 103 元買進（付 0.1%）、104 元賣出（付 0.4%），報酬從 0.97% 降到 0.47%。

### 3. ⭐ 成本對兩種策略的影響

用兩個**交易頻率不同**的策略來比較：

| 策略 | 規則 | 交易頻率 |
|---|---|---|
| **均線狀態**（10.2） | MA20 > MA60 時持有 | 低：14 年 34 次（一年約 2.4 次） |
| **RSI(2) 回檔**（8.5 範例 A） | 收盤 > 200 日均線且 RSI(2) < 10 進場；收盤 > 5 日均線或持有滿 10 天出場 | 高：14 年 103 次（一年約 7.4 次） |

RSI(2) 策略的「進場條件」和「出場條件」不同，用工具箱的 `state_signal()` 把它們轉成持有狀態（原理就是 10.3 的迴圈）：

```python
from bt_toolkit import load_prices, sma, rsi, state_signal, backtest, tw_costs, perf_stats

df = load_prices("sample_long.csv")
ma_signal = (sma(df["Close"], 20) > sma(df["Close"], 60)).astype(int)

entry = (rsi(df["Close"], 2) < 10) & (df["Close"] > sma(df["Close"], 200))
exit_ = df["Close"] > sma(df["Close"], 5)
rsi_signal = state_signal(entry, exit_, max_days=10)

scenarios = {
    "無成本": (0, 0),
    "ETF（稅 0.1%）": tw_costs(tax_rate=0.001),
    "個股（稅 0.3%）": tw_costs(),
    "個股＋滑價 0.1%": tw_costs(slippage=0.001),
}
for name, signal in [("均線狀態", ma_signal), ("RSI(2) 回檔", rsi_signal)]:
    n = ((signal == 1) & (signal.shift(1) == 0)).sum()
    print(f"【{name}】進場 {n} 次")
    for label, (b, s) in scenarios.items():
        p = perf_stats(backtest(df, signal, b, s)["strat_ret"])
        print(f"  {label}：總報酬 {p['總報酬']:.2%}，年化 {p['年化報酬']:.2%}，最大回撤 {p['最大回撤']:.2%}")
```

輸出：

```
【均線狀態】進場 34 次
  無成本：總報酬 132.44%，年化 6.22%，最大回撤 -31.92%
  ETF（稅 0.1%）：總報酬 112.36%，年化 5.53%，最大回撤 -33.92%
  個股（稅 0.3%）：總報酬 98.76%，年化 5.04%，最大回撤 -35.36%
  個股＋滑價 0.1%：總報酬 85.84%，年化 4.53%，最大回撤 -36.77%
【RSI(2) 回檔】進場 103 次
  無成本：總報酬 -4.84%，年化 -0.35%，最大回撤 -24.80%
  ETF（稅 0.1%）：總報酬 -27.90%，年化 -2.31%，最大回撤 -37.53%
  個股（稅 0.3%）：總報酬 -41.24%，年化 -3.73%，最大回撤 -46.95%
  個股＋滑價 0.1%：總報酬 -52.16%，年化 -5.14%，最大回撤 -55.00%
```

**觀察：**

| 策略 | 無成本 → 個股＋滑價 | 解讀 |
|---|---|---|
| 均線狀態 | 年化 6.22% → 4.53%（少 1.7 個百分點） | 交易少，成本傷害有限 |
| RSI(2) 回檔 | 年化 −0.35% → −5.14%（少 4.8 個百分點） | 交易多，成本傷害是均線策略的近 3 倍 |

> 🔑 **成本傷害 ≈ 交易次數 × 每次來回成本。** 均線策略 34 次 × 0.67% ≈ 23%；RSI(2) 策略 103 次 × 0.67% ≈ 69%——成本把一個本來打平的策略，變成虧損一半的策略。
>
> 💡 **為什麼 RSI(2) 在這份資料上沒賺錢？** 因為 `sample_long.csv` 是用亂數產生的，價格沒有「短期跌深會反彈」的特性，所以均值回歸策略沒有優勢——這其實是正確的結果！在真實市場中是否有效，要用真實資料回測（Part D）。這也提醒你：**高頻率策略需要更大的優勢才能打敗成本**。

### 4. ⭐ 損益兩平成本：策略能承受多高的成本？

把來回成本從 0 慢慢調高，看年化報酬什麼時候變成 0：

```python
for c in [0.002, 0.005, 0.01, 0.02, 0.03]:
    cagr = perf_stats(backtest(df, ma_signal, c / 2, c / 2)["strat_ret"])["年化報酬"]
    print(f"來回成本 {c:.1%}：年化 {cagr:.2%}")
```

輸出：

```
來回成本 0.2%：年化 5.71%
來回成本 0.5%：年化 4.95%
來回成本 1.0%：年化 3.70%
來回成本 2.0%：年化 1.22%
來回成本 3.0%：年化 -1.20%
```

均線策略在來回成本約 **2.5%** 時才會打平——它對成本的「容忍度」很高。

> 🔑 **損益兩平成本是很好的穩健性指標**：如果一個策略在來回成本 0.5% 時就打平，而你實際的成本是 0.47%，那它在實盤中幾乎沒有容錯空間——稍微多一點滑價就虧錢了。**好的策略，損益兩平成本應該遠高於你實際的成本。**

### 5. ⭐ 如何估計滑價？

滑價最難估計，因為它取決於**流動性、下單方式、市場狀況**：

| 情況 | 滑價大小 | 回想 |
|---|---|---|
| 大型 ETF、權值股，小額交易 | 很小（約一個價格跳動單位） | 2.1 買賣價差 |
| 中小型股 | 較大 | 2.3 |
| 開盤、收盤、消息發布時 | 較大（波動大、價差大） | 1.10 |
| 你的金額佔當日成交量比例高 | 很大（你自己推動了價格） | 2.3 市場衝擊 |
| 停損單在急跌時觸發 | 很大（跳空、追不到） | 6.2、10.3 |

**實務估計方法：**

| 方法 | 做法 |
|---|---|
| **買賣價差的一半** | 用市價單成交時，大約付出半個價差 |
| **跳動單位** | 假設每次成交差 1～2 個跳動單位（例如股價 50～100 元時，跳動單位為 0.1 元，約 0.1%～0.2%；跳動單位以交易所規定為準） |
| **保守倍數** | 不確定時，把成本加倍看看策略還活不活得下來 |
| **實盤紀錄** | Phase 12 模擬交易與小額實盤時，記錄「預期價 vs. 實際成交價」，回頭修正回測假設 |

> ⚠️ **寧可高估，不要低估。** 高估成本頂多讓你錯過一些邊緣策略；低估成本會讓你把虧錢的策略拿去實盤。

### 6. 其他容易忽略的成本

| 成本 | 說明 |
|---|---|
| **融資融券利息、借券費** | 用槓桿或放空時才有（2.5、2.6） |
| **期貨轉倉成本** | 期貨到期要換月，價差與手續費（1.6） |
| **股利所得稅、二代健保補充保費** | 領股利時可能產生（依個人稅率與規定） |
| **資金的機會成本** | 空手時資金可以放定存或貨幣市場基金（10.16） |
| **你的時間** | 每天盯盤、檢查訊號的時間（8.11） |

## 📌 重點整理

1. 成本 = **手續費（買賣都付）+ 交易稅（只有賣出）+ 滑價**；個股來回約 0.47%（手續費 6 折、未含滑價）。
2. 回測中：部位改變時扣成本，買進用買進成本、賣出用賣出成本；用小例子手算驗證。
3. **成本傷害 ≈ 交易次數 × 每次來回成本**：高頻策略需要更大的優勢。
4. **損益兩平成本**應該遠高於實際成本，才有容錯空間。
5. 滑價取決於流動性與下單方式；**寧可高估**，並在實盤中記錄修正。
6. 別忘了利息、轉倉、稅、機會成本與時間成本。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「成本才零點幾 %，影響不大」 | 成本 × 交易次數會累積；高頻策略可能被成本完全吃掉。 |
| 「滑價可以忽略」 | 小型股、急跌停損、大額交易時滑價可能很大；寧可高估。 |
| 「買賣成本一樣」 | 台股賣出才有交易稅，個股與 ETF 稅率也不同。 |
| 「有算手續費就夠了」 | 還有交易稅、滑價、利息、轉倉等成本。 |

## ✅ 自我測驗

**Q1. 為什麼同樣的成本，對 RSI(2) 策略的傷害比均線策略大很多？**

<details><summary>看答案</summary>

因為成本是每次交易都要付的，總成本大約等於交易次數乘以每次來回成本。RSI(2) 策略 14 年交易 103 次，是均線策略（34 次）的 3 倍，所以累積的成本傷害也大約是 3 倍。

</details>

**Q2. 什麼是損益兩平成本？為什麼它是重要的穩健性指標？**

<details><summary>看答案</summary>

損益兩平成本是讓策略報酬剛好變成 0（或剛好等於某個基準）的每次交易成本。它衡量策略對成本的容忍度：如果損益兩平成本只比實際成本高一點點，任何額外的滑價或成本變動都可能讓策略變成虧錢；損益兩平成本遠高於實際成本，策略才有足夠的容錯空間。

</details>

**Q3. 練習 4 參考答案**

<details><summary>看答案</summary>

實際費率 = 20 ÷ 10,000 = **0.2%**，是原本 0.0855% 的 2.3 倍以上。小資金頻繁交易時，最低手續費會大幅提高實際成本，讓高頻策略更難獲利；回測時要用實際的交易金額計算手續費，或改用較低頻的策略、較大的單筆金額。

</details>
