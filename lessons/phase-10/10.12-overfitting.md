# 10.12｜陷阱 3：過度擬合與資料探勘

## 🎯 學完你會知道

- **過度擬合**是什麼：策略記住了過去的「雜訊」，而不是學到真正的規律
- 實驗 1：在**純隨機**的價格上，也能「最佳化」出漂亮的策略
- 實驗 2：那組「最佳參數」換一份資料就**失靈**
- 實驗 3：**測試越多次，最好的結果就越好看**（多重檢定）
- 過度擬合的**來源**：參數、條件、規則、甚至你自己反覆修改
- **降低過度擬合**的 8 個方法

---

## 📖 開場故事：為了一張考卷背答案

小敏的數學很差，期中考前她拿到了**去年的考卷和答案**，於是她把 20 題的答案**全部背下來**：

> 第 1 題選 C、第 2 題答案是 37、第 3 題選 A……

她拿去年的考卷自我測驗——**100 分！**

但期中考的題目換了。她背的答案一個都用不上，考了 35 分。

她的同學小芸則是**弄懂了每一題的解法**。用去年考卷自我測驗只有 85 分（有幾題粗心），但期中考也考了 82 分。

> 📚 **過度擬合就是「背答案」**：策略的參數和規則被調整到**完美符合過去的資料**，包括過去那些純屬巧合的漲跌（雜訊）。用過去的資料測試，結果非常漂亮；但未來的資料是新的考卷，背下來的答案派不上用場。**真正的規律（解題方法）在新考卷上仍然有效；背下來的雜訊不會。**

## 🧠 正文

### 1. 訊號與雜訊

| | 訊號（Signal） | 雜訊（Noise） |
|---|---|---|
| 意思 | 真正存在、會重複出現的規律 | 純屬巧合、不會重複的波動 |
| 考試比喻 | 解題方法 | 去年考卷的答案 |
| 在價格中 | 例如：趨勢有延續傾向（如果它真的存在） | 例如：2017 年 3 月剛好漲了三天 |
| 未來會不會再出現？ | 會（至少一段時間） | 不會 |

> 🔑 **金融市場的雜訊非常多、訊號非常少。** 一個彈性很大的策略（很多參數、很多條件），很容易把雜訊也「學」進去。回測績效越好，不一定代表策略越好——可能只是背了越多答案。

### 2. ⭐ 實驗 1：在純隨機的價格上最佳化

產生一份**純隨機漫步**的價格（每天的漲跌完全隨機，**沒有任何可以預測的規律**），然後測試 406 組均線策略：

```python
import numpy as np
import pandas as pd
from bt_toolkit import sma, backtest, tw_costs, perf_stats


def random_walk(seed, years=10):
    """純隨機漫步：每天的漲跌都是獨立的亂數，沒有任何規律。"""
    rng = np.random.default_rng(seed)
    n = 252 * years
    close = 100 * np.exp(np.cumsum(rng.normal(0.0003, 0.012, n)))
    open_ = np.r_[100, close[:-1]] * np.exp(rng.normal(0, 0.003, n))
    idx = pd.bdate_range("2014-01-01", periods=n)
    return pd.DataFrame({"Open": open_, "High": np.maximum(open_, close),
                         "Low": np.minimum(open_, close), "Close": close}, index=idx)


def ma_sharpe(df, fast, slow, use_filter):
    c = df["Close"]
    sig = sma(c, fast) > sma(c, slow)
    if use_filter:
        sig = sig & (c > sma(c, 200))                     # 加一個 200 日均線過濾
    return perf_stats(backtest(df, sig.astype(int), *tw_costs())["strat_ret"])["夏普比率"]


A = random_walk(101)        # 「過去」的資料
results = []
for fast in range(5, 61, 5):
    for slow in range(20, 201, 10):
        if fast >= slow:
            continue
        for use_filter in [False, True]:
            results.append((fast, slow, use_filter, ma_sharpe(A, fast, slow, use_filter)))

results = pd.DataFrame(results, columns=["fast", "slow", "filter", "sharpe_A"])
results = results.sort_values("sharpe_A", ascending=False)
bh_A = perf_stats(A["Close"].pct_change().fillna(0))["夏普比率"]

print(f"共測試 {len(results)} 組；買進持有的夏普：{bh_A:.2f}")
print(results.head(5).round(3))
```

輸出：

```
共測試 406 組；買進持有的夏普：0.12
     fast  slow  filter  sharpe_A
188    30    50   False     0.392
220    35    40   False     0.376
130    20   110   False     0.357
132    20   120   False     0.316
222    35    50   False     0.302
```

> 😮 在一份**沒有任何規律**的隨機資料上，我們「找到」了 MA30 / MA50，夏普 0.39，是買進持有（0.12）的三倍多！如果你不知道這是隨機資料，你可能會寫一份很有說服力的報告：「MA30 / MA50 能有效捕捉中期趨勢……」

### 3. ⭐⭐ 實驗 2：換一份考卷

產生**另一份**隨機資料 B（同樣的統計特性，但是不同的亂數），把在 A 上找到的前 10 名參數拿去 B 測試：

```python
B = random_walk(202)        # 「未來」的資料：新的考卷
top10 = results.head(10).copy()
top10["sharpe_B"] = [ma_sharpe(B, int(f), int(s), bool(u))
                     for f, s, u in zip(top10["fast"], top10["slow"], top10["filter"])]
print(top10.round(3))
print(f"A 的前 10 名，在 B 的平均夏普：{top10['sharpe_B'].mean():.2f}")
```

輸出：

```
     fast  slow  filter  sharpe_A  sharpe_B
188    30    50   False     0.392    -0.212
220    35    40   False     0.376    -0.270
130    20   110   False     0.357    -0.027
132    20   120   False     0.316    -0.126
222    35    50   False     0.302    -0.163
90     15    90   False     0.298    -0.108
96     15   120   False     0.296    -0.126
156    25    60   False     0.295    -0.359
108    15   180   False     0.288    -0.209
94     15   110   False     0.282    -0.050
A 的前 10 名，在 B 的平均夏普：-0.16
```

> 🚨 **在 A 上表現最好的 10 組參數，到了 B 全部是負的夏普。** 這就是背答案的下場：A 上的好成績來自 A 的雜訊，B 的雜訊不一樣，答案就不對了。
>
> 這個實驗的意義：**最佳化本身就能製造出漂亮的回測結果，即使資料裡根本沒有規律。** 所以「最佳化後的回測很好」這件事，本身幾乎不能證明任何東西。

### 4. ⭐ 實驗 3：測試越多次，最好的越好看

回到 10.1 的猴子實驗：在同一份隨機資料 A 上，讓猴子每個月擲硬幣決定持有或空手，看「最好的那隻猴子」的夏普，如何隨著猴子數量增加：

```python
month_ends = A.resample("ME").last().index
rng = np.random.default_rng(5)
sharpes = []
for i in range(1000):
    coin = pd.Series(rng.integers(0, 2, len(month_ends)), index=month_ends)
    signal = coin.reindex(A.index, method="ffill").fillna(0)
    sharpes.append(perf_stats(backtest(A, signal)["strat_ret"])["夏普比率"])
sharpes = np.array(sharpes)

for n in [1, 10, 100, 1000]:
    print(f"測試 {n:>4} 個隨機策略，最好的夏普：{sharpes[:n].max():.2f}")
```

輸出：

```
測試    1 個隨機策略，最好的夏普：0.21
測試   10 個隨機策略，最好的夏普：0.36
測試  100 個隨機策略，最好的夏普：0.65
測試 1000 個隨機策略，最好的夏普：0.79
```

> 🔑 **擲硬幣的策略，只要試 1,000 次，就能找到夏普 0.79 的「好策略」**——比 10.8 中買進持有的 0.56 還高。
>
> 這就是**多重檢定（Multiple Testing）問題**（回想 8.8 的日曆效應）：你試了越多次，最好的結果就越可能只是運氣。所以**評估一個策略時，一定要知道「總共試了多少次」**——[回測報告範本](../../templates/backtest-report.md)有一欄「總共測試了多少個策略 / 參數組合？」，就是為了這個。

### 5. ⭐ 過度擬合從哪裡來？

| 來源 | 例子 | 背答案的比喻 |
|---|---|---|
| **參數太多** | 均線週期、RSI 週期、門檻、停損倍數、持有天數……每多一個參數，可能的組合就乘上好幾倍 | 背的答案越多，越像背考卷 |
| **條件太多** | 「RSI < 30 且 量 > 均量 1.3 倍 且 星期二 且 MACD 柱狀體連 2 天變大」 | 為每一題量身訂做解法 |
| **參數太精細** | 最佳均線是 47 天，46 和 48 都不行 | 答案剛好卡在那一個數字 |
| **事後加規則** | 「2020 年 3 月虧太多，加一條：波動太大時不交易」 | 看了答案再改解法 |
| **不知不覺的資料探勘** | 試了 50 個想法，只報告最好的那一個 | 考了 50 次，只拿最高分給爸媽看 |
| **樣本太少** | 只有 20 筆交易就下結論 | 只看 2 題就說自己會了 |

> ⚠️ **最隱蔽的是最後兩項**：你可能沒有用最佳化工具，但你**手動**改了 30 次規則、看了 30 次回測結果，每次留下「看起來比較好」的版本——這和電腦自動最佳化一樣，都是在背答案。Git 的紀錄（9.14）會誠實告訴你改了幾次。

### 6. ⭐ 降低過度擬合的 8 個方法

| # | 方法 | 說明 | 單元 |
|---|---|---|---|
| 1 | **先有假說，再看資料** | 策略要有合理的優勢來源（8.2），而不是從資料中「找」出來 | 8.2、8.13 |
| 2 | **參數越少越好** | 簡單的策略比較不容易背答案；能用 2 個參數就不要用 5 個 | — |
| 3 | **參數用「常見值」或理由** | 20、60、200 日均線，而不是 47、113 日 | 8.13 |
| 4 | **樣本外測試** | 留一段資料不看，最後才測 | 10.13 |
| 5 | **Walk-forward 分析** | 滾動式地「學一段、考一段」 | 10.14 |
| 6 | **參數高原** | 好參數附近的參數也要不錯，而不是孤立的高峰 | 10.15 |
| 7 | **多市場、多期間測試** | 同樣的規則在其他商品、其他時期也有效嗎？ | 10.18 |
| 8 | **記錄並揭露測試次數** | 誠實面對多重檢定；結果打折看待 | 10.17、Phase 11 |

> 🎓 **小芸的方法**：弄懂解題方法（有邏輯的假說）、用新的題目測試（樣本外）、不只考一次（walk-forward）、題目稍微變化也會做（參數穩健）。這就是接下來三個單元要教的。

## 📌 重點整理

1. **過度擬合** = 背答案：策略記住了過去的雜訊，而不是學到真正的規律。
2. 實驗 1：**純隨機資料**上也能最佳化出夏普 0.39（買進持有的三倍）的策略。
3. 實驗 2：那些「最佳參數」換一份資料，**全部變成負的夏普**。
4. 實驗 3：擲硬幣的策略試 1,000 次，最好的夏普可以到 0.79——**測試越多次，最好的結果越不可信**。
5. 來源：參數太多、條件太多、參數太精細、事後加規則、**不知不覺的資料探勘**、樣本太少。
6. 對策：**先有假說、參數少而有理由、樣本外、walk-forward、參數高原、多市場測試、揭露測試次數**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「回測績效越好，策略越好」 | 可能只是背了越多雜訊；要看樣本外與穩健性。 |
| 「我沒有用最佳化工具，所以沒有過度擬合」 | 手動反覆修改規則、只留下最好的版本，也是在最佳化。 |
| 「加更多條件可以過濾掉爛交易」 | 每個條件都可能只是在配合過去的資料；條件越多越容易過度擬合。 |
| 「最佳參數附近的參數表現差也沒關係」 | 孤立的高峰通常代表運氣；好策略的參數附近也應該不錯（10.15）。 |

## ✅ 自我測驗

**Q1. 為什麼在純隨機的資料上也能找到「好策略」？**

<details><summary>看答案</summary>

因為隨機資料中仍然有各種巧合的漲跌模式（雜訊）。測試大量參數組合時，總會有一些組合剛好和這些巧合吻合，看起來表現很好。但這些模式不會重複出現，所以換一份資料就失效了。這說明最佳化本身就能製造漂亮的回測結果，即使資料中沒有任何真正的規律。

</details>

**Q2. 什麼是多重檢定問題？它和回測有什麼關係？**

<details><summary>看答案</summary>

測試的次數越多，純靠運氣得到極端好結果的機率就越高。回測時試了很多參數、很多規則、很多想法，最後挑出最好的一個，那個最好的結果很可能主要來自運氣。因此評估策略時必須知道總共測試了多少次，並對最佳結果打折看待（Phase 11 會介紹更正式的修正方法）。

</details>

**Q3. 列出至少 4 個降低過度擬合的方法。**

<details><summary>看答案</summary>

任選 4 個：先有合理的假說再看資料；參數越少越好；參數使用常見值或有邏輯的理由；樣本外測試；walk-forward 分析；檢查參數高原（穩健性）；在多個市場與期間測試；記錄並揭露總測試次數。

</details>
