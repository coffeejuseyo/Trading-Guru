## 📖 開場故事：打者的打擊率與長打率

棒球教練評估打者時，不會只看一個數字：

| | 阿強 | 阿德 |
|---|---|---|
| 打擊率 | 0.320（常常安打） | 0.240（常常出局） |
| 長打率 | 0.400（多是一壘安打） | 0.520（全壘打很多） |
| 全壘打 | 5 支 | 30 支 |

阿德的打擊率比較低，但他一旦打中就是長打，**對球隊得分的貢獻可能更大**。

> ⚾ **交易統計就是打者的數據**：勝率像打擊率（多常獲利），盈虧比像長打率（打中時打多遠），期望值像「每個打席平均貢獻幾分」。8.3 說過趨勢跟隨是「低勝率、高賠率」——就像阿德，靠少數全壘打贏球。

## 🧠 正文

### 1. ⭐ 找出每一筆交易

10.2～10.8 看的是**每天**的報酬；交易統計看的是**每一筆**交易。工具箱的 `extract_trades()` 會找出所有「從空手變持有」到「從持有變空手」的區間：

```python
import pandas as pd
from bt_toolkit import load_prices, sma, backtest, tw_costs, extract_trades, trade_stats

df = load_prices("sample_long.csv")
signal = (sma(df["Close"], 20) > sma(df["Close"], 60)).astype(int)
res = backtest(df, signal, *tw_costs())

trades = extract_trades(df, res)
print(trades.head(5))
print(f"共 {len(trades)} 筆（含未平倉 {trades['open'].sum()} 筆）")
```

輸出：

```
  entry_date  exit_date  entry_price  exit_price    return  days   open
0 2010-03-29 2011-01-19        52.07       70.88  0.354838   296  False
1 2011-03-10 2011-03-29        71.44       70.94 -0.011673    19  False
2 2011-04-18 2011-06-27        73.90       72.27 -0.026660    70  False
3 2011-08-03 2012-02-22        74.92       85.87  0.140761   203  False
4 2012-04-24 2012-11-23        87.21       92.22  0.052470   213  False
共 34 筆（含未平倉 1 筆）
```

| 欄位 | 意思 |
|---|---|
| entry_date / entry_price | 進場日（開盤價） |
| exit_date / exit_price | 出場日（開盤價） |
| return | 這筆交易的報酬，**已扣除買賣成本**（用持有期間的每日策略報酬連乘） |
| days | 持有的日曆天數 |
| open | 資料結束時是否還沒賣出 |

> 💡 **驗算第一筆**：52.07 買、70.88 賣，未扣成本 = 70.88 ÷ 52.07 − 1 ≈ 36.12%；扣掉買 0.0855%、賣 0.3855%：1.3612 × 0.999145 × 0.996145 − 1 ≈ **35.48%** ✅

### 2. ⭐ 交易統計總表

```python
stats = trade_stats(trades)
for k, v in stats.items():
    print(f"{k}：{v:.4f}" if isinstance(v, float) else f"{k}：{v}")
```

輸出（整理成表格）：

| 指標 | 數值 | 公式 | 回想 |
|---|---:|---|---|
| 交易次數（已平倉） | 33 | | |
| **勝率** | 39.4% | 獲利筆數 ÷ 總筆數 | 3.5 |
| **平均獲利** | +11.36% | 獲利交易的平均報酬 | |
| **平均虧損** | −3.95% | 虧損交易的平均報酬 | |
| **盈虧比** | 2.87 | 平均獲利 ÷ \|平均虧損\| | 3.5 |
| **獲利因子** | 1.87 | 獲利總和 ÷ \|虧損總和\| | |
| **每筆期望值** | +2.08% | 勝率 × 平均獲利 + 敗率 × 平均虧損 | 3.4 |
| **最大連虧** | 6 筆 | | 3.10 |
| 平均持有天數 | 89.7 天 | | |

**驗算期望值：** 0.394 × 11.36% + 0.606 × (−3.95%) ≈ 4.47% − 2.39% ≈ **2.08%** ✅

> ⚾ 這就是典型的趨勢跟隨數據（8.3）：**勝率不到 4 成（打擊率低），但賺的時候平均賺 11%、賠的時候平均只賠 4%（長打率高）**，所以期望值是正的。
>
> 回想 3.5 的「勝率 × 賠率」表：勝率 39% 的策略，盈虧比只要大於約 1.55（= 61 ÷ 39）就能打平。這個策略的盈虧比 2.87，有足夠的安全邊際。

### 3. 獲利因子 vs. 盈虧比

| 指標 | 公式 | 差別 |
|---|---|---|
| **盈虧比** | 平均獲利 ÷ \|平均虧損\| | 只看「每筆」的大小，不管次數 |
| **獲利因子** | 獲利總和 ÷ \|虧損總和\| | 同時考慮大小與次數；**> 1 代表賺錢** |

> 💡 獲利因子 = 盈虧比 × 勝率 ÷ 敗率 = 2.87 × 0.394 ÷ 0.606 ≈ 1.87 ✅。一般認為扣成本後獲利因子 > 1.5 算不錯；但交易次數太少時，這個數字很不穩定。

### 4. ⭐ 獲利和虧損的持有時間

```python
closed = trades[~trades["open"]]
wins = closed[closed["return"] > 0]
losses = closed[closed["return"] <= 0]
print(f"獲利交易平均持有 {wins['days'].mean():.0f} 天，虧損交易平均持有 {losses['days'].mean():.0f} 天")
```

輸出：`獲利交易平均持有 159 天，虧損交易平均持有 44 天`

> 🔑 **獲利的交易抱得久（159 天），虧損的交易很快就出場（44 天）**——這正是「截斷虧損、讓獲利奔跑」（6.3、7.2 處分效應的反面）。如果你的策略剛好相反（獲利很快出場、虧損抱很久），通常代表出場規則有問題。

### 5. ⭐⭐ 拿掉最好的 3 筆交易

```python
top3 = closed["return"].sort_values(ascending=False).head(3)
print("最好的 3 筆：", [f"{x:.2%}" for x in top3])

all_growth = (1 + closed["return"]).prod() - 1
rest_growth = (1 + closed.drop(top3.index)["return"]).prod() - 1
print(f"33 筆已平倉交易的累積報酬：{all_growth:.2%}")
print(f"拿掉最好的 3 筆之後：{rest_growth:.2%}")
```

輸出：

```
最好的 3 筆： ['39.36%', '35.48%', '19.95%']
33 筆已平倉交易的累積報酬：66.79%
拿掉最好的 3 筆之後：-26.36%
```

> 🚨 **33 筆交易中，只要少了最好的 3 筆，整個策略就從賺 67% 變成虧 26%。**
>
> 這是趨勢跟隨的本質（8.3）：**利潤集中在少數幾筆大行情**，其他大部分交易都是小賺小賠、甚至虧損。這帶來兩個重要的啟示：
> 1. **執行紀律**：如果你在實盤中因為連虧 6 次而灰心，跳過了下一個訊號——而那剛好是一筆大行情——你就錯過了整個策略的利潤（Phase 7）。
> 2. **結果的不穩定**：策略好壞取決於少數幾筆交易，代表**運氣的影響很大**。換一段期間、少了一兩次大行情，結果可能完全不同（10.13～10.14）。

### 6. 最大連虧：心理準備

最大連虧 6 筆。回想 3.10：勝率 39% 的策略，在 33 筆交易中出現連虧 6 次是很正常的。

**實盤前的心理準備：**
- 回測中的最大連虧，**實盤很可能會遇到，甚至更長**
- 連虧 6 筆、每筆虧 4%（扣成本後），帳戶大約回撤 22%
- 寫進交易計畫：「連虧 N 筆在預期之內，不代表策略失效」（6.10、7.5）

### 7. 交易統計 vs. 資金曲線指標

| 資金曲線指標（10.7～10.8） | 交易統計（本單元） |
|---|---|
| 以「每天」為單位 | 以「每筆交易」為單位 |
| CAGR、波動、MDD、夏普 | 勝率、盈虧比、期望值、連虧 |
| 回答「帳戶整體表現如何？」 | 回答「策略的每一次出手品質如何？」 |
| 受部位大小影響 | 和部位大小無關（每筆的報酬率） |

> 🔑 兩者互補：資金曲線告訴你**結果**，交易統計告訴你**原因**。例如 MDD 很深，交易統計可以告訴你是因為「連虧太多次」還是「某一筆虧太大」。

### 8. 用 R 倍數思考（回想 6.4、7.6）

本單元的報酬是「每筆交易的報酬率」。如果策略有明確的停損（例如 2 × ATR），可以換算成 **R 倍數**：

**R 倍數 = 交易報酬 ÷ 進場時的風險（進場價到停損價的距離）**

用 R 倍數的好處是：不同價位、不同波動的股票，都能放在同一個尺度上比較；而且直接對應到 6.4 的部位計算——如果每筆風險是資金的 1%，期望值 0.3R 就代表每筆交易平均讓帳戶成長 0.3%。（練習 3）

## 📌 重點整理

1. `extract_trades()` 找出每一筆交易（已含成本），`trade_stats()` 計算交易統計。
2. **勝率 = 打擊率、盈虧比 = 長打率、期望值 = 每個打席的平均貢獻**。
3. 期望值 = 勝率 × 平均獲利 + 敗率 × 平均虧損；獲利因子 = 獲利總和 ÷ |虧損總和|。
4. 好的趨勢策略：**獲利交易抱得久、虧損交易很快出場**。
5. **拿掉最好的幾筆交易**是很好的壓力測試：利潤可能集中在極少數交易。
6. **最大連虧**是實盤前的心理準備；實盤可能更長。
7. 資金曲線指標告訴你結果，交易統計告訴你原因。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「勝率越高越好」 | 要搭配盈虧比；低勝率高賠率的策略期望值也可以很高（3.5）。 |
| 「大部分交易都在虧錢，策略一定不好」 | 趨勢策略常常如此，利潤來自少數大賺的交易。 |
| 「回測的最大連虧就是實盤的最大連虧」 | 實盤可能遇到更長的連虧；回測只是一段歷史樣本。 |
| 「33 筆交易就能準確評估策略」 | 樣本太少，少數幾筆交易就能改變結論。 |

## ✅ 自我測驗

**Q1. 勝率 39%、平均獲利 11.36%、平均虧損 −3.95%，期望值是多少？代表什麼？**

<details><summary>看答案</summary>

期望值 = 0.394 × 11.36% + 0.606 × (−3.95%) ≈ 2.08%。代表長期來看，每做一筆交易平均賺約 2%（已扣成本）。雖然勝率不到四成，但因為賺的時候賺得多、賠的時候賠得少，期望值仍然是正的。

</details>

**Q2. 「拿掉最好的 3 筆交易，策略就從賺錢變虧錢」，這告訴你什麼？**

<details><summary>看答案</summary>

1. 策略的利潤高度集中在少數幾筆大行情，執行時錯過任何一個訊號都可能錯過主要利潤，因此紀律非常重要；2. 結果受運氣影響很大——換一段期間，如果少了那幾次大行情，績效可能完全不同，需要用樣本外與不同期間的測試確認穩健性。

</details>

**Q3. 為什麼好的趨勢策略，獲利交易的持有時間通常比虧損交易長？**

<details><summary>看答案</summary>

因為趨勢策略的出場規則（例如均線死叉、移動停損）會在價格不如預期時很快出場（截斷虧損），而在趨勢持續時一直持有（讓獲利奔跑）。所以虧損交易通常很短，獲利交易則可能抱很久。如果相反，代表出場規則可能有問題。

</details>
