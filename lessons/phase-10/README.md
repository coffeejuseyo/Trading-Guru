# Phase 10｜時光機實驗室：回測 ⭐ 本課程重點

> **預計時數：70 小時**（18 個單元）
> **生活比喻：模擬考 + 飛行模擬器。用過去的資料測試你的策略，但要小心「偷看答案」——那樣考 100 分也沒有意義。**

這是整個課程的核心。前面九個階段的所有內容，都在這裡匯流：

| 你學過的 | 在回測中扮演的角色 |
|---|---|
| Phase 3 機率與統計 | 判斷結果是運氣還是實力、樣本夠不夠 |
| Phase 4～5 技術與基本面 | 產生訊號的原料 |
| Phase 6 風險管理 | 停損、部位大小、最大回撤 |
| Phase 7 交易心理 | 你能不能撐過回測中的那段回撤？ |
| Phase 8 策略規格書 | 回測的「考題」 |
| Phase 9 Python | 回測的「工具」 |

學完這個階段，你會達成**里程碑 M3：能獨立完成一次可信的回測**——不只是「跑出一個數字」，而是知道這個數字**可不可信**。

> 🔑 **本階段最重要的一句話：回測的目的不是證明策略會賺錢，而是盡力找出它為什麼不會賺錢。** 一個通過了所有「刁難」的策略，才值得進入 Phase 12 的模擬交易。

## 練習資料與工具箱

| 檔案 | 內容 |
|---|---|
| [`data/sample_long.csv`](data/sample_long.csv) | **模擬**日線資料，2010–2023 年共 3,650 個交易日（Date、Open、High、Low、Close、Volume），內含多頭、盤整、空頭等不同「天氣」 |
| [`code/bt_toolkit.py`](code/bt_toolkit.py) | **回測工具箱**：10.2～10.9 一步步寫出來的函式整理成一個檔案（回測、成本、績效指標、交易統計、報告） |

> ⚠️ `sample_long.csv` 是用亂數產生的**假資料**，不代表任何真實商品，只用來練習；用它得出的任何策略結論都**沒有實際意義**。練習時請把兩個檔案放在筆記本的同一個資料夾（Colab：上傳到左側檔案區）。Part D 的作業要換成你在 9.10 下載的真實資料。

> 💡 **工具箱怎麼來的？** 10.2 會從零寫出 `backtest()`，10.6 加入成本，10.7～10.9 寫出績效與交易統計。每個單元都會先「親手寫一次」，再告訴你工具箱裡對應的函式——就像先學會手算，再用計算機。

## 學習地圖

```
  第 1 段：會寫回測（10.1～10.6）
     模擬考的意義 → 自己寫向量化回測 → 事件驅動 → 現成框架 ×2 → 加入成本
                                  │
  第 2 段：看懂成績單（10.7～10.9）
     報酬、波動、回撤 → 風險調整後報酬 → 交易統計
                                  │
  第 3 段：抓出作弊與運氣（10.10～10.15）  ← 本階段最重要
     偷看答案 → 只看倖存者 → 背答案（過度擬合）
     → 練習題與正式考題分開 → 滾動考試 → 食譜的容錯度
                                  │
  第 4 段：寫出可信的結論（10.16～10.18）
     和基準比 → 回測報告 → 期末專題：3 個策略完整回測
                                  ▼
               🏁 M3：能獨立完成一次可信的回測
```
