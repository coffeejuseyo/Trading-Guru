# 10.16｜和基準比較

## 🎯 學完你會知道

- 為什麼每個策略都要和**基準**比較（回想 8.11）
- 選擇基準的原則：**同市場、同風險、同可投資性**
- ⭐ **曝險相當的基準**：策略只有六成時間在市場中，就要和「六成股票、四成現金」比
- 空手時的**現金利息**
- 用 **Beta、Alpha、上漲 / 下跌捕獲率**判斷策略有沒有「擇時能力」
- 一個殘酷但重要的結論：很多策略只是「**比較少持有股票**」

---

## 📖 開場故事：你的成績要和全班平均比

小宇拿著考卷回家：「我考了 78 分！」

媽媽問：「全班平均幾分？」

| 情況 | 全班平均 | 78 分代表 |
|---|---|---|
| 題目很簡單 | 92 | 其實落後很多 |
| 題目很難 | 55 | 非常優秀 |

而且如果小宇是**資優班**的學生，就應該和資優班的平均比，而不是和普通班比；如果他這次**只寫了一半的題目**（其他題目放棄），也要考慮這一點。

> 📏 **策略的績效沒有基準就沒有意義。** 年化 5% 是好是壞，要看同期間的市場表現、你承擔了多少風險、你有多少時間在市場中。**找到正確的比較對象**，常常是回測中最讓人清醒的一步。

## 🧠 正文

### 1. 選擇基準的三個原則

| 原則 | 說明 | 例子 |
|---|---|---|
| **同市場** | 交易台股，就和台股比；交易美股，就和美股比 | 台股個股策略 vs. 0050（含息） |
| **同風險** | 策略的波動、曝險較低時，基準也要調整 | 曝險 62% 的策略 vs. 62% 股票 + 38% 現金 |
| **可投資** | 基準必須是你真的買得到的東西 | 用 ETF（含費用），而不是無法直接買的指數 |

> 💡 回想 8.11：被動投資（營養師便當）是所有主動策略的基準。**如果主動策略扣掉成本、時間和壓力後，沒有比被動配置更好，就沒有理由執行它。**

### 2. ⭐⭐ 曝險相當的基準

均線策略只有約 62% 的時間持有股票。拿它和「100% 持有」的買進持有比，其實不太公平——它承擔的風險本來就比較低。

公平的比法：**每天固定 62% 股票、38% 現金**的被動組合。

```python
import numpy as np
import pandas as pd
from bt_toolkit import load_prices, sma, backtest, tw_costs, perf_stats

df = load_prices("sample_long.csv")
signal = (sma(df["Close"], 20) > sma(df["Close"], 60)).astype(int)
res = backtest(df, signal, *tw_costs())
strat = res["strat_ret"]
bh = df["Close"].pct_change().fillna(0)

exposure = res["pos"].mean()
matched = backtest(df, pd.Series(exposure, index=df.index))["strat_ret"]   # 每天固定持有 62%
print(f"策略的平均曝險：{exposure:.1%}")

for name, r in [("均線策略", strat), ("買進持有（100%）", bh), (f"曝險相當（{exposure:.0%}）", matched)]:
    p = perf_stats(r)
    print(f"{name}：年化 {p['年化報酬']:.2%}，波動 {p['年化波動']:.2%}，最大回撤 {p['最大回撤']:.2%}，"
          f"夏普 {p['夏普比率']:.2f}，Calmar {p['Calmar']:.2f}")
```

輸出：

```
策略的平均曝險：61.9%
均線策略：年化 5.04%，波動 13.30%，最大回撤 -35.36%，夏普 0.42，Calmar 0.14
買進持有（100%）：年化 8.67%，波動 16.90%，最大回撤 -42.84%，夏普 0.56，Calmar 0.20
曝險相當（62%）：年化 5.77%，波動 10.46%，最大回撤 -28.74%，夏普 0.57，Calmar 0.20
```

> 🚨 **「62% 股票 + 38% 現金」這個什麼都不用做的被動組合，在每一個指標上都贏過均線策略**：報酬更高、波動更低、回撤更淺、夏普更高。
>
> 換句話說，均線策略「回撤比買進持有小」的優點，**完全可以用「少買一點股票」達成**，而且做得更好、更省事。這就是 10.8「槓桿改變不了夏普」的另一面：降低部位也能降低回撤，不需要擇時。

### 3. 空手時的現金利息

策略空手的時候，資金不會憑空消失——可以放定存或貨幣市場基金，賺取利息。公平起見，兩邊都要加上：

```python
rf_daily = 0.015 / 252                                      # 假設現金年利率 1.5%
strat_cash = strat + (1 - res["pos"]) * rf_daily            # 空手的部分賺利息
matched_cash = matched + (1 - exposure) * rf_daily

for name, r in [("均線策略 + 現金利息", strat_cash), ("曝險相當 + 現金利息", matched_cash)]:
    p = perf_stats(r)
    print(f"{name}：年化 {p['年化報酬']:.2%}，夏普 {p['夏普比率']:.2f}")
```

輸出：

```
均線策略 + 現金利息：年化 5.66%，夏普 0.47
曝險相當 + 現金利息：年化 6.40%，夏普 0.62
```

> 💡 加上現金利息後，常常空手的策略會改善一些（工具箱的 `backtest()` 沒有自動加入，這是一個簡化）。但比較的結論不變：**曝險相當的被動組合仍然比較好**。

### 4. ⭐ Beta、Alpha 與捕獲率：有沒有擇時能力？

**Beta**：市場漲跌 1%，策略平均漲跌多少？**Alpha**：扣掉 Beta 能解釋的部分之後，策略多賺（或少賺）多少？

```python
beta, alpha_daily = np.polyfit(bh, strat, 1)       # 用迴歸找出：策略報酬 ≈ alpha + beta × 市場報酬
print(f"Beta：{beta:.2f}")
print(f"Alpha（年化）：{alpha_daily * 252:.2%}")

up, down = bh > 0, bh < 0
print(f"上漲捕獲率：{strat[up].mean() / bh[up].mean():.0%}（市場上漲的日子，策略平均拿到幾成）")
print(f"下跌捕獲率：{strat[down].mean() / bh[down].mean():.0%}（市場下跌的日子，策略平均承受幾成）")
```

輸出：

```
Beta：0.61
Alpha（年化）：-0.19%
上漲捕獲率：60%
下跌捕獲率：60%
```

| 指標 | 數值 | 解讀 |
|---|---:|---|
| Beta | 0.61 | 大約等於曝險（62%）——策略就像「六成的大盤」 |
| Alpha | −0.19% | 扣掉這六成大盤的貢獻後，策略沒有多賺，還略為少賺（成本） |
| 上漲 / 下跌捕獲率 | 60% / 60% | **漲的日子拿到六成、跌的日子也承受六成**——沒有「漲時多參與、跌時少參與」 |

> 🔑 **真正有擇時能力的策略，上漲捕獲率應該明顯高於下跌捕獲率**（例如漲的時候拿到 80%、跌的時候只承受 40%）。如果兩者差不多，策略只是「平均來說比較少持股」，並沒有挑對時機。
>
> 這份練習資料是隨機產生的，本來就沒有可以預測的趨勢，所以這個結果完全合理。但**這套檢驗方法對真實資料同樣有效**——很多看起來「回撤比較小」的擇時策略，做完這個檢驗後，會發現它們和「少買一點股票」沒有差別。

### 5. 常見的基準選擇

| 策略類型 | 建議基準 |
|---|---|
| 台股大盤擇時（如本單元） | 0050 或其他追蹤加權指數的 ETF（含息）；曝險相當的組合 |
| 台股個股選股 | 0050（大型股）、中小型股 ETF（小型股） |
| 美股策略 | SPY 等大盤 ETF |
| 多資產策略 | 股債 60/40 等平衡配置（8.11） |
| 市場中性策略（8.7） | 現金或短期利率（因為它不承擔大盤風險） |

> ⚠️ **基準要在研究開始前決定**，不要看了結果再挑一個「打得贏的基準」——那也是一種資料探勘（10.12）。

### 6. ⭐ 回到開頭的問題：這個策略值得做嗎？

把 Phase 10 到目前為止對均線策略的所有檢驗整理起來：

| 檢驗 | 結果 | 單元 |
|---|---|---|
| 交叉驗證（四種實作） | ✅ 回測程式正確 | 10.2～10.5 |
| 成本 | ✅ 交易少，成本影響有限 | 10.6 |
| 交易統計 | ⚠️ 利潤集中在少數大行情 | 10.9 |
| 前視偏差 | ✅ 已檢查 | 10.10 |
| 樣本外 | ❌ 樣本外期間輸給買進持有 | 10.13 |
| Walk-forward | ⚠️ 贏在大跌年份，多頭年年落後 | 10.14 |
| 參數穩健性 | ✅ 長期均線區域是高原 | 10.15 |
| **曝險相當的基準** | ❌ **被「62% 股票 + 現金」全面打敗** | 本單元 |
| 擇時能力 | ❌ 上漲與下跌捕獲率相同 | 本單元 |

**結論**：在這份資料上，均線策略**不值得做**——它的所有優點都可以用更簡單的被動配置達成。

> 🎓 **這不是失敗，而是成功的研究。** 你用一套嚴謹的流程，在不花一毛錢的情況下，淘汰了一個不值得執行的策略。回想 10.1：**回測的目的就是找出策略為什麼不會賺錢。** 大部分的策略想法都會被淘汰，這是正常的；能通過所有檢驗的，才值得進入 Phase 12 的模擬交易。

## 📌 重點整理

1. 沒有基準，績效就沒有意義；基準要**同市場、同風險、可投資**，並**事先決定**。
2. **曝險相當的基準**：策略只有 62% 時間在市場中，就要和「62% 股票 + 現金」比。
3. 本例中，曝險相當的被動組合**在每個指標上都贏過均線策略**。
4. 空手時的**現金利息**要算進去，兩邊都加。
5. **Beta ≈ 曝險、Alpha ≈ 0、上漲捕獲率 ≈ 下跌捕獲率** → 沒有擇時能力，只是比較少持股。
6. 淘汰一個策略是**成功的研究**。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「回撤比大盤小，策略就有價值」 | 少買一點股票也能降低回撤；要和曝險相當的基準比。 |
| 「只要和買進持有比就夠了」 | 曝險、風險不同時，要調整基準；還要考慮現金利息。 |
| 「打不贏某個基準，就換一個打得贏的」 | 基準要事先決定；事後挑基準也是資料探勘。 |
| 「策略被淘汰代表研究失敗」 | 淘汰不值得做的策略正是回測的價值。 |

## ✅ 自我測驗

**Q1. 為什麼要用「曝險相當」的基準？**

<details><summary>看答案</summary>

因為策略只有部分時間持有股票，承擔的市場風險本來就比較低，報酬與回撤自然都比全程持有小。和全程持有比較並不公平。曝險相當的被動組合（例如固定 62% 股票 + 38% 現金）承擔相近的市場風險，才能判斷策略的擇時是否真的創造了價值。

</details>

**Q2. 上漲捕獲率和下跌捕獲率都是 60%，代表什麼？**

<details><summary>看答案</summary>

代表市場上漲時策略平均參與六成，下跌時也承受六成，策略沒有在上漲時多參與、下跌時少參與，也就是沒有擇時能力。它的效果和「固定持有六成股票」差不多，降低的回撤只是因為持股比較少。

</details>

**Q3. 為什麼說淘汰一個策略是「成功的研究」？**

<details><summary>看答案</summary>

因為回測的目的是在不花真錢的情況下，找出策略為什麼不會賺錢。透過嚴謹的檢驗淘汰不值得執行的策略，避免了實盤虧損與浪費時間；大部分策略想法都會被淘汰，能通過所有檢驗的才值得進入模擬交易。

</details>
