## 1. 基本資訊
- 策略名稱：均線狀態策略（MA20 / MA60）
- 版本 / 日期：v1.0
- 程式碼位置：`lessons/phase-10/code/bt_toolkit.py`（`backtest()`）、10.2 的訊號程式

## 2. 假說（為什麼這個策略應該有效？）
> 價格趨勢有延續的傾向（8.3）：短均線在長均線上方代表中期趨勢向上，此時持有；趨勢轉弱時空手，避開大跌。生活比喻：衝浪——不預測浪，只是浪來了就順著走。
> 預期優勢來源：行為面（反應不足、從眾，8.2）。預期特徵：低勝率、高盈虧比；在空頭中保護資金，在盤整中反覆小虧。

## 3. 策略規則
| 項目 | 規則 |
|---|---|
| 商品 / 市場 | 單一大盤型標的（本範例為模擬資料） |
| 時間週期 | 日線；收盤後判斷，隔天開盤執行 |
| 進場條件 | 收盤後 MA20 > MA60 → 隔天開盤全額買進 |
| 出場條件（停損 / 停利 / 時間） | 收盤後 MA20 ≤ MA60 → 隔天開盤全部賣出；無停損、無停利、無時間停損 |
| 部位大小 | 全額（100% 資金），只做多 |
| 過濾條件 | 無 |
| 參數 | 快線 20、慢線 60（Phase 8 事先決定，常見參數，未經最佳化） |

## 8. 結論
- **這個策略值得進入模擬交易嗎？為什麼？**
  **不值得。** 程式正確、成本影響有限，但：(1) 樣本外落後同期買進持有；(2) 被曝險相當的被動組合全面打敗，上漲與下跌捕獲率相同，代表沒有擇時能力，回撤較小只是因為平均持股較少；(3) 參數 MA20/MA60 對擾動敏感；(4) 利潤集中在極少數交易。
- **最大的風險 / 弱點：** 多頭與盤整市場中長期落後大盤；績效依賴少數大行情與大空頭的出現。
- **預期在實盤中會遇到的差異：** 跳空與滑價會讓成本略高；連續多年落後大盤時，執行紀律會受到嚴重考驗。
- **下一步：** 若要繼續研究趨勢策略，改用參數高原區域（長期均線）並加入真實資料、多市場測試；同時把「曝險相當基準」列為必須打敗的門檻。

## 9. 用白話講給朋友聽（費曼版摘要）
> 這個策略在短均線高於長均線時持有、否則空手，想抓住趨勢並避開大跌。它確實在幾次大跌中保護了資金，但在多頭時常常落後。最關鍵的發現是：只要固定持有六成股票、其他放現金，什麼都不用做，結果反而更好——所以它的「避險效果」其實只是持股比較少，不值得花力氣執行。
