## 📖 開場故事：控制水量的水龍頭

想像整個經濟是一座花園，裡面種滿了植物（企業、工作、消費）。

花園管理員手上有一個**水龍頭**，控制流進花園的水量（市場上的錢）：

- **植物快乾死了**（經濟衰退、失業增加）→ 管理員**把水龍頭開大**，讓更多水流進來，植物重新長起來
- **水太多、到處淹水**（經濟過熱、通膨太高）→ 管理員**把水龍頭關小**，讓水退一點
- 但水龍頭的效果**有延遲**：今天轉水龍頭，可能要好幾個月甚至一兩年才看到效果

> 🚰 **央行就是這位花園管理員，利率就是水龍頭。** 降息 = 把水開大（放寬資金）；升息 = 把水關小（收緊資金）。全世界的投資人都盯著這個水龍頭。

## 🧠 正文

### 1. 央行是什麼？任務是什麼？

**央行（中央銀行）= 負責管理一個國家貨幣與金融體系的機構。**

| 央行 | 主要任務（簡化） |
|---|---|
| **美國聯準會（Fed）** | 「雙重使命」：**物價穩定**（控制通膨）+ **充分就業** |
| **中華民國中央銀行**（台灣） | 依法以促進金融穩定、健全銀行業務、維護對內及對外幣值之穩定、在上述目標範圍內協助經濟發展為主要經營目標 |
| 歐洲央行（ECB） | 以物價穩定為主要目標 |

> 🔑 不管是哪一國的央行，**控制通膨**都是核心任務之一（5.8）。通膨太高時，央行會傾向升息；經濟太弱時，央行會傾向降息。

### 2. 央行的四大工具

| 工具 | 怎麼運作 | 水龍頭比喻 |
|---|---|---|
| **① 政策利率** | 調整銀行之間借錢的基準利率（例如美國的聯邦基金利率、台灣的重貼現率），影響整個社會的借款成本 | **水龍頭的主開關** |
| **② 公開市場操作** | 央行在市場上買賣債券或發行存單，增加或收回市場上的資金 | 用水桶加水或舀水 |
| **③ 存款準備率** | 規定銀行必須保留多少比例的存款不能放貸 | 調整水管的粗細 |
| **④ 量化寬鬆（QE）/ 量化緊縮（QT）** | 在利率已經很低時，央行大量購買債券（QE）把錢注入市場；反過來縮減持有的債券（QT）把錢收回 | 開消防水管 / 抽水機 |

> 💡 **前瞻指引**：央行也會透過**講話**影響市場——例如表示「未來一段時間會維持低利率」，市場就會提前反應。所以央行官員的每一句話，都被市場放大檢視。

### 3. 升息、降息如何影響股市？

```
央行升息（把水龍頭關小）
    ↓
銀行借貸利率上升、債券殖利率上升
    ↓
┌─────────────────┬────────────────────┬──────────────────────┐
企業借錢變貴         消費者房貸、車貸變貴      存款、債券更有吸引力
→ 投資減少           → 消費減少              → 資金從股市流向債券
→ 獲利下降           → 企業營收下降           → 本益比下降（5.8）
└─────────────────┴────────────────────┴──────────────────────┘
    ↓
股市傾向下跌、經濟降溫、通膨（希望）下降
```

**降息則大致相反**：借錢便宜、消費投資增加、資金流向股市，股市傾向上漲。

> ⚠️ **但「降息 = 股市一定漲」並不成立。** 如果央行是因為**經濟快要崩潰**才緊急大幅降息，股市可能還是大跌（例如 2008 年金融海嘯、2020 年疫情初期，央行都緊急降息，但股市一開始仍然重挫）。要看**降息的原因**。

### 4. 鷹派 vs. 鴿派

| | 🦅 鷹派（Hawkish） | 🕊️ 鴿派（Dovish） |
|---|---|---|
| 立場 | 優先**對抗通膨** | 優先**支持經濟與就業** |
| 傾向 | 升息、維持高利率、收緊資金 | 降息、維持低利率、放寬資金 |
| 對股市（常見） | 偏負面 | 偏正面 |
| 比喻 | 嚴格的老師：寧可嚴一點，也不讓學生失控 | 溫和的老師：先讓學生有信心 |

新聞常說「央行發言**偏鷹**」，意思是央行暗示可能會繼續升息或維持高利率更久，市場通常會解讀為對股市不利。

### 5. ⭐ 市場關心的是「比預期多還是少」

回想 1.1：**價格反映的是預期。**

在央行開會之前，市場通常**已經猜好了**這次會怎麼做。（例如美國芝加哥商品交易所的 **FedWatch** 工具，會根據利率期貨價格，計算市場預期 Fed 升降息的機率。）

| 市場預期 | 央行實際決定 | 市場反應（常見） |
|---|---|---|
| 升息 0.25% | 升息 0.25% | 不太動（符合預期，已經反映了） |
| 升息 0.25% | **升息 0.5%** | **下跌**（比預期鷹派） |
| 升息 0.25% | **不升息** | **上漲**（比預期鴿派） |
| 不動 | 不動，但聲明暗示未來會升息 | 可能下跌（未來預期改變） |

> 🔑 **重要的不是「升息還是降息」，而是「和市場預期比，是更鷹還是更鴿」**，以及央行對**未來**的暗示。這也是為什麼有時候「明明升息了，股市卻上漲」。

### 6. 為什麼美國聯準會影響全世界？

| 原因 | 說明 |
|---|---|
| **美元是全球主要貨幣** | 國際貿易、原物料（石油等）大多用美元計價 |
| **資金流動** | 美國利率高 → 資金流回美國 → 其他國家（包括台灣）的股市、匯率受影響（1.8） |
| **美股影響全球** | 美股是全球最大的股市，台股常跟著美股走（1.11） |
| **其他央行常跟進** | 美國升息，其他國家為了穩定匯率與資金，常常也得跟著調整 |

> 🌊 比喻：Fed 就像一個巨大水庫的閘門。閘門一開一關，下游所有的河流（各國市場）水位都會跟著變化。

**開會時間（一般情況，以官方公布為準）：**
- **美國聯準會（FOMC）**：每年約開會 **8 次**，會後公布利率決議、聲明，主席召開記者會
- **台灣央行理監事會**：一般**每季**召開一次（約在 3、6、9、12 月）

> 💡 這些會議日期在 5.10 的經濟行事曆中都會標示，是市場最重要的事件之一。

### 7. 「不要跟 Fed 作對」

華爾街有一句老話：**「Don't fight the Fed」（不要跟聯準會作對）。**

- 央行在**大幅寬鬆**時（降息、QE），市場資金充沛，股市通常比較容易上漲
- 央行在**大幅緊縮**時（快速升息、QT），資金收緊，股市通常比較辛苦

> ⚠️ 這也是一個**方向性的經驗法則**，不是精確的交易訊號。央行政策的效果有延遲，市場也會提前反應，實際情況比這句話複雜得多。

## 📌 重點整理

1. **央行** = 花園管理員，**利率** = 水龍頭；核心任務之一是**控制通膨**。
2. 四大工具：**政策利率、公開市場操作、存款準備率、QE / QT**，加上**前瞻指引**。
3. **升息** → 借錢變貴、消費投資減少、資金流向債券 → 股市傾向下跌；降息大致相反。
4. 但要看**原因**：因為經濟崩潰而緊急降息，股市可能仍然大跌。
5. **鷹派**偏緊（對抗通膨），**鴿派**偏鬆（支持經濟）。
6. 市場關心的是**和預期比**更鷹還是更鴿，以及對**未來**的暗示。
7. **Fed 影響全世界**：美元、資金流動、美股、各國央行跟進；**不要跟 Fed 作對**是經驗法則。

>
> 美國聯準會影響最大，因為美元是全世界的主要貨幣，它一動，全世界的股市跟匯率都會跟著動。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「升息股市一定跌，降息一定漲」 | 要看是否符合預期、以及降息的原因（經濟崩潰時降息，股市仍可能大跌）。 |
| 「央行今天升息，明天經濟就會降溫」 | 貨幣政策效果有延遲，可能要好幾個月到一兩年。 |
| 「台灣股市只看台灣央行」 | 美國聯準會對台股的影響常常更大。 |
| 「央行官員講話不重要，看決議就好」 | 前瞻指引會改變市場對未來的預期，影響很大。 |

## 🛠️ 練習（約 40 分鐘）

**練習 1：判斷鷹鴿**
以下央行聲明，比較偏鷹派還是鴿派？
1. 「通膨仍高於目標，委員會準備在必要時進一步升息。」
2. 「考量經濟成長放緩，委員會將維持寬鬆的貨幣政策。」
3. 「我們將持續縮減資產負債表。」
4. 「勞動市場出現疲軟跡象，未來政策將更加審慎評估。」

**練習 2：預期遊戲**
市場預期 Fed 本次降息 0.25%。以下結果，股市比較可能上漲還是下跌？
1. 降息 0.5%，而且聲明說經濟前景依然穩健
2. 不降息
3. 降息 0.25%，但主席表示這可能是本輪最後一次降息

**練習 3：查資料**
1. 到美國聯準會官網查詢今年 FOMC 的會議日期，記在你的行事曆上。
2. 到中央銀行官網查詢最近一次理監事會的決議內容。
3. 用 FRED 查詢「Federal Funds Effective Rate」，觀察過去 20 年聯邦基金利率的變化，找出 2008 年、2020 年、2022 年發生了什麼事。

## ✅ 自我測驗

**Q1. 央行升息後，透過哪些管道影響股市？**

<details><summary>看答案</summary>

(1) 企業借款成本上升，投資減少、獲利下降；(2) 消費者房貸車貸成本上升，消費減少，企業營收下降；(3) 存款與債券報酬提高，資金從股市流向固定收益，投資人要求的報酬率上升，本益比下降。

</details>

**Q2. 為什麼「明明升息了，股市卻上漲」是可能的？**

<details><summary>看答案</summary>

因為市場已經預期並提前反映了升息。如果實際升息幅度小於預期，或央行暗示未來不會再升息（比預期鴿派），市場就可能上漲。

</details>

**Q3. 為什麼美國聯準會的決策會影響台灣股市？**

<details><summary>看答案</summary>

美元是全球主要貨幣、美國利率影響全球資金流向與匯率、美股是全球最大市場且台股常跟隨美股，加上其他國家央行常因此調整政策。

</details>

**Q4. 練習參考答案**

<details><summary>看答案</summary>

練習 1：(1) 鷹派；(2) 鴿派；(3) 鷹派（量化緊縮）；(4) 偏鴿派。

練習 2：(1) 比預期更鴿、且經濟穩健 → 較可能**上漲**；(2) 比預期更鷹 → 較可能**下跌**；(3) 降息符合預期，但暗示未來不再降息（未來偏鷹）→ 可能**下跌**或震盪。

</details>
