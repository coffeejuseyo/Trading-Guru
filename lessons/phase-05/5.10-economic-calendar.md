## 📖 開場故事：颱風預報公布前

氣象局預計下午 5 點發布颱風警報。

- 下午 3 點，超市已經擠滿人：大家**提前**搶購泡麵、礦泉水、蔬菜
- 下午 5 點，警報發布：如果颱風**比預期強**，晚到的人更瘋狂搶購；如果颱風**轉向**，大家鬆了一口氣，有人甚至後悔買太多
- 結果出來的那一刻，**價格與人潮變化最劇烈**

> 🌀 **重大經濟數據的公布，就像颱風警報**：大家在公布前就開始猜、開始調整部位；公布那一刻，如果結果和預期差很多，市場會在幾秒鐘內劇烈反應。

## 🧠 正文

### 1. 最重要的經濟數據與事件

#### 美國（對全球市場影響最大）

| 數據 / 事件 | 頻率（一般） | 為什麼重要 | 回想 |
|---|---|---|---|
| **FOMC 利率決議** | 每年約 8 次 | 直接決定利率方向 | 5.9 |
| **CPI（消費者物價指數）** | 每月 | 通膨是央行決策的核心 | 5.8 |
| **非農就業報告** | 每月（通常是月初的週五） | 就業狀況影響 Fed 判斷與經濟前景 | 5.9 |
| **GDP** | 每季（先發布初值，之後修正） | 經濟成長 | 5.7 |
| **PMI** | 每月 | 領先指標，50 為榮枯線 | 5.7 |
| **零售銷售** | 每月 | 美國經濟以消費為主 | 5.7 |

#### 台灣

| 數據 / 事件 | 頻率（一般） | 為什麼重要 |
|---|---|---|
| **央行理監事會** | 每季 | 台灣利率政策（5.9） |
| **出口統計** | 每月 | 台灣是出口導向經濟（5.7） |
| **景氣對策信號** | 每月 | 景氣燈號（5.7） |
| **CPI** | 每月 | 台灣通膨 |
| **GDP** | 每季 | |

#### 公司與市場層面

| 事件 | 說明 |
|---|---|
| **財報公布** | 季報、年報；獲利與預期的差異會造成股價大幅變動 |
| **法說會**（法人說明會） | 公司說明營運狀況與**未來展望**，展望常比過去的數字更重要 |
| **月營收**（台股） | 每月上旬公布上月營收（5.1、5.2） |
| **除權息** | 股價會扣除股利（1.2） |
| **指數成分調整** | 被納入或剔除的股票，會有被動基金的大量買賣（1.3） |
| **期貨、選擇權結算日** | 台指期通常為每月第三個星期三（1.6），結算前後可能有較大波動 |
| **長假前後** | 封關、開紅盤、美國重大假日；休市期間的消息累積在開盤時反映（1.10） |

### 2. 怎麼看經濟行事曆？

**經濟行事曆**（可以在 Investing.com 等財經網站找到）會列出每個數據的：

| 欄位 | 意思 | 例子（美國 CPI 年增率，示意） |
|---|---|---|
| **公布時間** | 什麼時候發布（注意時區換算） | 台灣時間晚上 8:30 |
| **重要性** | 通常用 1～3 顆星表示 | ⭐⭐⭐ |
| **前值** | 上一期的數字 | 3.2% |
| **預期值** | 經濟學家的平均預測（市場共識） | 3.1% |
| **實際值** | 公布的真實數字 | ？ |

**市場怎麼反應？——又是「和預期比」（1.1、5.9）：**

| 實際值 vs. 預期 | 對 CPI 來說代表 | 市場常見反應 |
|---|---|---|
| 實際 3.4% > 預期 3.1% | 通膨**比預期高** → 央行可能更鷹 | 股市下跌、債券殖利率上升 |
| 實際 3.1% = 預期 | 符合預期 | 反應較小 |
| 實際 2.8% < 預期 3.1% | 通膨**比預期低** → 央行可能更鴿 | 股市上漲 |

> 🔑 **同一個數字，可能是好消息也可能是壞消息，取決於市場原本預期什麼。** 有時候甚至出現「好消息是壞消息」：就業數據太好 → 市場擔心 Fed 會繼續升息 → 股市下跌。

### 3. 事件前後的市場特性

| 特性 | 說明 | 對交易者的影響 |
|---|---|---|
| **波動放大** | 公布前後價格可能大幅震盪 | 停損容易被打到 |
| **跳空** | 數據常在盤前或盤後公布，隔天開盤直接跳空（1.10） | **停損可能在更差的價格成交**（2.2） |
| **流動性變差** | 公布前大家觀望、掛單減少，價差擴大（2.3） | 滑價增加 |
| **方向難預測** | 即使猜對數據，市場反應也可能和你想的相反 | 「猜數據」很難賺錢 |
| **假動作** | 公布瞬間大漲（跌），幾分鐘後又反轉 | 容易被來回打臉 |

> 🔑 **對大多數散戶來說，「猜事件結果」並不是優勢**。你要和全世界的專業機構比速度、比解讀，而且結果常常像擲硬幣（3.11）。

### 4. 事件前後的風險管理原則

| 原則 | 做法 |
|---|---|
| **① 事先知道** | 每週日看一次下週的行事曆，標出重要事件（3 星） |
| **② 不要在事件前一刻才進場** | 避免「剛買進就遇到大波動」 |
| **③ 考慮降低部位** | 持有部位遇到重大事件，可以先減碼，降低跳空的影響 |
| **④ 把跳空風險算進部位大小** | 計算風險時，假設停損可能多虧一些（Phase 6） |
| **⑤ 財報前特別小心** | 個股財報可能造成**單日大幅跳空**，持有個股過財報要評估是否接受這個風險 |
| **⑥ 不要事後追價** | 數據公布後第一時間的劇烈波動，常常有假動作，衝動追進去容易被套（Phase 7 FOMO） |
| **⑦ 寫進交易計畫** | 在 [templates/trading-plan.md](../../templates/trading-plan.md) 的「不交易的情況」中寫下你的事件規則 |

> 🌀 比喻：颱風來之前，聰明的人會把陽台的盆栽收進來、檢查門窗。你不需要知道颱風會不會直撲，你只需要**確保不管怎樣，損失都在可承受範圍內**。

### 5. 建立你的事件行事曆

在你的筆記或行事曆中，建立一個每週更新的表格：

```markdown
## 本週事件行事曆（第 __ 週）

| 日期 | 台灣時間 | 事件 | 重要性 | 預期值 | 實際值 | 市場反應 | 影響我的部位嗎？ |
|---|---|---|---|---|---|---|---|
| 週二 | 20:30 | 美國 CPI | ⭐⭐⭐ | | | | |
| 週三 | 收盤後 | 台指期結算 | ⭐⭐ | — | — | | |
| 週四 | 02:00（隔天清晨） | FOMC 利率決議 | ⭐⭐⭐ | | | | |
| 週五 | 20:30 | 美國非農就業 | ⭐⭐⭐ | | | | |
| 每月上旬 | — | 持股公司月營收 | ⭐⭐ | | | | |
```

> 💡 **注意時區換算**：美國數據常在台灣時間晚上公布（受美國夏令時間影響，1.10），FOMC 決議常在台灣時間凌晨。這些消息會反映在**台指期夜盤**和**隔天台股開盤**。

## 📌 重點整理

1. 最重要的事件：**FOMC、CPI、非農就業、GDP、PMI**；台灣看**央行、出口、景氣燈號**；公司看**財報、法說會、月營收、除權息**。
2. 經濟行事曆看：**公布時間、重要性、前值、預期值、實際值**。
3. 市場反應取決於**實際值和預期值的差距**；「好消息」也可能是壞消息。
4. 事件前後：**波動放大、跳空、流動性變差、方向難預測、假動作**。
5. 猜事件結果對散戶通常**不是優勢**。
6. 風險管理：**事先知道、不在事件前一刻進場、考慮減碼、把跳空算進部位、不追價**。
7. **每週更新事件行事曆**，注意時區換算。

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「數據好，股市就會漲」 | 要看和預期的差距，而且好消息有時會被解讀為壞消息。 |
| 「我能猜中數據，就能賺錢」 | 猜中數據也可能猜錯市場反應，而且你在和專業機構比速度。 |
| 「設了停損，事件風險就控制住了」 | 事件常造成跳空，停損可能在更差的價格成交。 |
| 「數據公布後馬上追進去就對了」 | 第一時間的波動常有假動作，容易被來回打臉。 |

## 🛠️ 練習（約 45 分鐘 + 一個月的追蹤）

**練習 1：判斷市場反應**
以下情況，股市比較可能的第一反應是什麼？
1. 美國 CPI 實際 2.6%，預期 2.9%
2. 美國非農就業新增人數遠高於預期，而市場正擔心通膨
3. 某公司財報獲利成長 20%，但市場預期成長 35%
4. 台灣出口年增率大幅優於預期

**練習 2：建立行事曆**
到 Investing.com（或其他財經網站）的經濟行事曆，篩選**美國與台灣、3 星重要性**的事件，把**下個月**的重要事件填入你的事件行事曆。

**練習 3：一個月追蹤**（課綱作業）
接下來一個月，每遇到一個 3 星事件，就記錄：預期值、實際值、公布後台指期或美股期貨 / 美股的反應（漲跌幅）。月底回答：
1. 有幾次市場反應和「實際值 vs. 預期值」的方向一致？
2. 有沒有「好消息卻下跌」或「壞消息卻上漲」的例子？
3. 有沒有公布後先大漲（跌）、之後又反轉的例子？

## ✅ 自我測驗

**Q1. 經濟行事曆中的「預期值」為什麼重要？**

<details><summary>看答案</summary>

因為市場在數據公布前已經根據預期值調整價格，公布時真正推動價格的是「實際值與預期值的差距」，而不是數字本身的好壞。

</details>

**Q2. 為什麼「好消息」有時會讓股市下跌？**

<details><summary>看答案</summary>

例如在市場擔心通膨的時期，就業或經濟數據太好，可能讓市場預期央行會維持高利率或繼續升息（更鷹派），對股票評價不利，因此股市下跌。

</details>

**Q3. 持有部位遇到重大事件，有哪些風險管理做法？**

<details><summary>看答案</summary>

事先查行事曆知道事件時間；不在事件前一刻新進場；考慮先減碼以降低跳空影響；計算部位大小時把跳空與滑價的可能虧損算進去；事件後不要衝動追價；把事件規則寫進交易計畫。

</details>

**Q4. 練習 1 參考答案**

<details><summary>看答案</summary>

1. 通膨低於預期 → 央行可能更鴿 → 股市較可能**上漲**
2. 市場擔心通膨時，就業太好 → 擔心央行更鷹 → 股市可能**下跌**
3. 獲利成長但低於預期 → 股價可能**下跌**
4. 出口優於預期 → 台股較可能**上漲**（尤其出口相關類股）

</details>
