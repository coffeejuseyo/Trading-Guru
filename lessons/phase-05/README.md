# Phase 5｜看懂價值：基本面與總體經濟

> **預計時數：40 小時**（11 個單元）
> **生活比喻：要頂下一家店之前，你會看它的帳本、營收、負債，以及這條街未來會不會變熱鬧。**

Phase 4 教你看「價格」——市場現在怎麼想。Phase 5 要教你看「價值」——這家公司到底值多少錢、整體經濟往哪裡走。

| | 技術分析（Phase 4） | 基本面分析（Phase 5） |
|---|---|---|
| 回答 | **什麼時候**買賣？ | **買什麼**？值多少？ |
| 看什麼 | 價格、成交量 | 財報、估值、產業、經濟 |
| 比喻 | 看餐廳門口的排隊人潮 | 看餐廳的帳本與廚房 |

> 🔑 學完這個階段，你不會變成專業分析師，但你會：**看得懂財報的重點、會算本益比和 ROE、知道「便宜」和「好」不是同一件事、理解為什麼央行升息股市會跌**——而且能把這些講給朋友聽。

## 本階段的貫穿案例：阿明飲料

為了讓數字前後一致，本階段會用一家**虛構的公司「阿明飲料」**貫穿所有單元：

| 項目 | 數字（單位：百萬元，除非另註） |
|---|---:|
| 年營收 | 1,000 |
| 淨利 | 120 |
| 總資產 / 負債 / 股東權益 | 1,500 / 600 / 900 |
| 流通股數 | 5,000 萬股 |
| 股價 | 36 元 |

每個單元會從這張表出發，一步一步算出毛利率、EPS、本益比、ROE、殖利率、合理價值……

## 完成 Phase 5 的標準

- [ ] 能說出三大財報各在回答什麼問題
- [ ] 能計算毛利率、營業利益率、淨利率、EPS
- [ ] 能計算本益比、股價淨值比、殖利率、ROE，並說明各自的限制
- [ ] 能說明「好公司 ≠ 好股票」與「價值陷阱」
- [ ] 能解釋為什麼央行升息，股市常常會下跌
- [ ] 完成課綱作業：同產業 2 家公司比較分析
- [ ] 總複習測驗答對 80% 以上

> ⚠️ 本階段使用的公司為**虛構範例**，數字僅為教學用。真實公司分析請以公開資訊觀測站等官方資料為準。本課程不推薦任何個股。
