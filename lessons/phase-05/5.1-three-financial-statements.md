# 5.1｜三大財報概覽

## 🎯 學完你會知道

- 三大財報：**損益表、資產負債表、現金流量表**，各在回答什麼問題
- 用一家虛構的飲料店，看懂每張表的重點項目
- 三張表之間的關係
- 為什麼「**有賺錢但沒有現金**」是危險訊號
- 去哪裡找台股、美股的財報

---

## 📖 開場故事：頂下一家飲料店

阿傑想頂下一家飲料店，老闆說：「我們很賺錢喔！」

阿傑聰明地要求看三樣東西：

1. **今年的成績單**：賣了多少錢？扣掉所有成本後，真的有賺嗎？
2. **店裡的家當清單**：有多少設備、現金、存貨？欠了多少錢？
3. **錢包的實際進出**：賺的錢真的有收進來嗎？還是都被客人賒帳了？

老闆給了成績單，上面寫「淨賺 300 萬」。但阿傑看了錢包紀錄才發現：**大部分的錢都是「應收帳款」**——很多大客戶還沒付錢，店裡的現金其實快用完了。

> 📒 **這三樣東西，就是公司的三大財報。** 只看其中一張，很容易被騙；三張一起看，才看得清楚全貌。

---

## 🧠 正文

### 1. 三大財報一覽

| 財報 | 回答的問題 | 時間性質 | 生活比喻 |
|---|---|---|---|
| **損益表** | 這段期間**賺了多少錢**？ | 一段期間（一季、一年） | **成績單**：這學期考了幾分 |
| **資產負債表** | 在某一天，公司**有什麼、欠什麼**？ | 某一個時間點 | **家當清單**：此刻有多少財產與貸款 |
| **現金流量表** | 這段期間**現金實際怎麼進出**？ | 一段期間 | **錢包紀錄**：錢真的進來了嗎 |

### 2. 損益表：成績單

**阿明飲料的年度損益表**（單位：百萬元）

| 項目 | 金額 | 說明 |
|---|---:|---|
| **營業收入**（營收） | **1,000** | 賣飲料收到的錢 |
| − 營業成本 | −600 | 茶葉、牛奶、杯子、店員直接成本 |
| **= 營業毛利** | **400** | 賣東西本身賺的錢 |
| − 營業費用 | −250 | 房租、總部薪資、行銷廣告、研發 |
| **= 營業利益** | **150** | 本業經營賺的錢 |
| ± 業外收支 | 0 | 利息收入、投資收益、匯兌損益等（這裡假設剛好抵銷） |
| **= 稅前淨利** | **150** | |
| − 所得稅（20%） | −30 | |
| **= 本期淨利** | **120** | 最後真正賺到的錢 |

> 🧋 損益表就像一杯飲料的「**層層扣款**」：從客人付的錢開始，扣掉原料、扣掉房租薪水、扣掉稅，最後剩下的才是老闆真正賺的。
>
> 🔑 **營業利益**代表**本業**賺多少；**業外收支**可能來自一次性的事件（例如賣土地）。看一家公司時，要特別注意**淨利是不是靠業外撐起來的**（5.2 會再說明）。

### 3. 資產負債表：家當清單

**阿明飲料在年底的資產負債表**（單位：百萬元）

| 資產（有什麼） | 金額 | 負債 + 股東權益（錢從哪來） | 金額 |
|---|---:|---|---:|
| 現金 | 200 | 應付帳款（欠供應商） | 150 |
| 應收帳款（客人還沒付） | 100 | 短期借款 | 150 |
| 存貨（茶葉、杯子） | 100 | 長期借款 | 300 |
| 店面設備、裝潢 | 900 | **負債合計** | **600** |
| 其他資產 | 200 | 股本 + 保留盈餘等 | 900 |
| | | **股東權益合計** | **900** |
| **資產合計** | **1,500** | **負債 + 股東權益合計** | **1,500** |

**最重要的恆等式：**

> **資產 = 負債 + 股東權益**

> 🏠 比喻：你有一間 1,500 萬的房子（資產），其中 600 萬是向銀行借的（負債），900 萬是你自己的（股東權益，也叫「淨值」）。
>
> 🔑 **股東權益 = 如果把所有資產賣掉、還清所有債務，剩下屬於股東的錢**（帳面上）。

**常看的重點：**

| 重點 | 為什麼重要 |
|---|---|
| **負債比**（負債 ÷ 資產）：600 ÷ 1,500 = **40%** | 借太多錢，景氣不好時容易出問題 |
| **現金夠不夠**付短期債務 | 現金 200 vs. 短期借款 + 應付帳款 300，要注意短期的資金壓力 |
| **應收帳款、存貨**是否異常增加 | 可能代表賣不掉或收不到錢 |

### 4. 現金流量表：錢包紀錄

**為什麼需要現金流量表？** 因為損益表上的「淨利」**不等於**現金。

例如：
- 賣出飲料給公司行號，對方說「月底再付」→ 損益表算收入了，但**現金還沒進來**（應收帳款）
- 花 100 萬買新的製冰機 → 現金出去了，但損益表上是**分好幾年慢慢攤提**（折舊）

**阿明飲料的現金流量表**（單位：百萬元）

| 項目 | 金額 | 說明 |
|---|---:|---|
| 本期淨利 | 120 | 從損益表來 |
| + 折舊（不用付現金的費用） | +80 | 設備攤提的成本，實際沒有付出現金 |
| − 營運資金增加 | −20 | 應收帳款、存貨增加，把現金卡住了 |
| **= 營業活動現金流** | **180** | **本業實際收進來的現金** |
| 購買設備（資本支出） | −100 | 開新店、買設備 |
| **= 投資活動現金流** | **−100** | |
| 發放股利 | −60 | |
| **= 籌資活動現金流** | **−60** | 借款、還款、發股利、增資 |
| **本期現金淨增加** | **+20** | |

**三種現金流：**

| 類型 | 意思 | 健康的公司通常 |
|---|---|---|
| **營業活動** | 做生意本身賺進的現金 | **正的**，而且和淨利差不多或更多 |
| **投資活動** | 買設備、開新店、投資 | 通常是**負的**（在投資未來） |
| **籌資活動** | 借錢、還錢、發股利、增資 | 視公司階段而定 |

**⭐ 自由現金流（Free Cash Flow）**

> **自由現金流 = 營業活動現金流 − 資本支出** = 180 − 100 = **80**

這是公司**真正可以自由運用**的現金：可以拿來發股利、還債、或存起來。

> 💰 比喻：你的月薪（營業現金流）扣掉房貸和必要的修繕（資本支出），剩下真正能存、能花的錢，就是自由現金流。
>
> 🔑 很多專業投資人認為**自由現金流比淨利更難作假、更能代表公司真正的賺錢能力**。5.5 估值時會用到它。

### 5. ⚠️ 危險訊號：有賺錢，但沒有現金

| 比較 | 阿明飲料（健康） | 某公司 B（危險） |
|---|---:|---:|
| 淨利 | 120 | 120 |
| 營業活動現金流 | **180** | **−50** |
| 原因 | 折舊加回、營運資金正常 | 應收帳款暴增、存貨堆積 |

公司 B 損益表看起來很賺，但**現金一直流出去**：
- 可能是賣給信用不好的客戶，錢收不回來
- 可能是產品賣不掉，堆在倉庫
- 極端情況下，可能是**做假帳**（虛增營收）

> 🔑 **淨利長期為正，但營業現金流長期為負，是非常重要的警訊。** 很多財務危機和財報舞弊案，都有這個特徵。

### 6. 三張表的關係

```
損益表（成績單）
  本期淨利 120 ─────────────┬──────────────────────┐
                           ▼                      ▼
                現金流量表（錢包紀錄）      資產負債表（家當清單）
                從淨利出發，調整成現金      淨利（扣掉股利）累積到「保留盈餘」
                本期現金 +20 ───────────▶  資產中的「現金」增加 20
```

> 🔑 三張表是**互相連動**的。只看損益表，可能被「帳面獲利」騙；加上現金流量表，才知道錢是不是真的進來；加上資產負債表，才知道公司的體質和負債風險。

### 7. 去哪裡找財報？

| 市場 | 官方來源 | 說明 |
|---|---|---|
| 台股 | **公開資訊觀測站**（MOPS） | 上市櫃公司的財報、月營收、重大訊息 |
| 美股 | **SEC EDGAR** | 年報（10-K）、季報（10-Q） |
| 整理過的資料 | 各大財經網站、券商 App | 方便，但要注意資料正確性，重要數字回到官方來源確認 |

**台股的公布時程**（依主管機關規定，以最新規定為準）：
- **月營收**：每月上旬公布上個月的營收（台股特色，可以很快看到營運變化）
- **季報、年報**：依規定期限公布

## 📌 重點整理

1. **損益表** = 成績單：一段期間賺多少（營收 → 毛利 → 營業利益 → 淨利）。
2. **資產負債表** = 家當清單：某一天有什麼、欠什麼；**資產 = 負債 + 股東權益**。
3. **現金流量表** = 錢包紀錄：現金實際怎麼進出（營業、投資、籌資）。
4. **自由現金流 = 營業現金流 − 資本支出**，代表真正可自由運用的現金。
5. **淨利為正但營業現金流長期為負 = 警訊**。
6. 三張表互相連動，要**一起看**。
7. 資料來源：台股看**公開資訊觀測站**，美股看 **SEC EDGAR**。

## 🗣️ 一分鐘講給朋友聽（示範稿）

> 「看一家公司要看三張表，就像頂一家店之前要看三樣東西。第一是損益表，像成績單，告訴你一年賣了多少、扣掉成本費用和稅之後真正賺多少。第二是資產負債表，像家當清單，告訴你公司現在有多少財產、欠多少錢。第三是現金流量表，像錢包紀錄，告訴你錢是不是真的收進來了。
>
> 最重要的是要一起看，因為帳面上賺錢不代表有現金。例如東西賣出去了，但客人一直賒帳不付錢，成績單看起來很好，錢包卻是空的。如果一家公司長期有賺錢、現金卻一直流出去，那就要很小心。」

## ❌ 常見誤解

| 誤解 | 事實 |
|---|---|
| 「淨利很高就代表公司很好」 | 要看淨利是不是來自本業、有沒有實際收到現金。 |
| 「營收成長就是好事」 | 如果是靠賒帳、低價搶單換來的，可能傷害獲利與現金流。 |
| 「資產越多越好」 | 要看資產是用什麼錢買的（自有資金還是借款），以及資產能不能產生獲利。 |
| 「財報都是真的」 | 大部分公司的財報經過會計師查核，但仍可能有舞弊；現金流是很好的交叉檢查。 |

## 🛠️ 練習（約 75 分鐘）

**練習 1：填空**
某公司營收 500、營業成本 300、營業費用 120、業外收入 10、所得稅率 20%。計算毛利、營業利益、稅前淨利、本期淨利。

**練習 2：現金流判讀**
某公司過去三年：
| 年 | 淨利 | 營業現金流 | 資本支出 |
|---|---:|---:|---:|
| 1 | 100 | 130 | 60 |
| 2 | 150 | 40 | 70 |
| 3 | 200 | −30 | 80 |

1. 計算每年的自由現金流。
2. 你注意到什麼趨勢？可能的原因是什麼？

**練習 3：實際查財報**
到公開資訊觀測站，選一家你熟悉的上市公司，找出最近一年的：營收、毛利、營業利益、淨利、營業活動現金流、資本支出（「取得不動產、廠房及設備」）、總資產、總負債、股東權益。填在筆記裡，Phase 5 後面的單元會一直用到。

## ✅ 自我測驗

**Q1. 三大財報各在回答什麼問題？**

<details><summary>看答案</summary>

損益表：一段期間賺了多少錢。資產負債表：某一天公司有什麼資產、欠多少負債、股東權益多少。現金流量表：一段期間現金實際如何流入與流出。

</details>

**Q2. 為什麼淨利不等於現金？舉兩個例子。**

<details><summary>看答案</summary>

例如：(1) 賣出商品但客戶尚未付款（應收帳款），收入已入帳但現金未收到；(2) 購買設備時現金一次付出，但損益表上以折舊分年攤提；(3) 存貨增加卡住現金。

</details>

**Q3. 自由現金流怎麼算？為什麼重要？**

<details><summary>看答案</summary>

自由現金流 = 營業活動現金流 − 資本支出。它代表公司在維持與擴張營運所需的投資之後，真正可以自由運用的現金（發股利、還債、存起來），通常被認為比淨利更難操弄、更能代表真實的賺錢能力。

</details>

**Q4. 練習參考答案**

<details><summary>看答案</summary>

練習 1：毛利 = 500 − 300 = **200**；營業利益 = 200 − 120 = **80**；稅前淨利 = 80 + 10 = **90**；本期淨利 = 90 × 0.8 = **72**

練習 2：
1. 自由現金流：第 1 年 **70**、第 2 年 **−30**、第 3 年 **−110**
2. 淨利年年成長，營業現金流卻快速下降、甚至轉負 → **警訊**。可能原因：應收帳款或存貨大幅增加（客戶付款變慢、產品賣不掉），或是營收品質有問題，需要進一步檢查資產負債表。

</details>
