# 🗣️ 白話詞彙表

> 每個術語都附上「一句話解釋」和「生活比喻」。目標：**朋友問你時，你能馬上用生活例子回答。**

## 市場與商品

| 術語 | 一句話解釋 | 生活比喻 |
|---|---|---|
| 股票 | 公司所有權的一小份 | 和朋友合開飲料店，你持有其中 5% |
| 指數 | 一群股票的平均表現 | 全班的平均分數 |
| ETF | 一次買進一籃子資產的基金，可在股市交易 | 水果禮盒：一次買到多種水果 |
| 債券 | 借錢給政府或公司，定期收利息 | 借錢給朋友並寫一張借據 |
| 期貨 | 約定未來某天以某價格買賣 | 現在先訂明年中秋的月餅，價格先講好 |
| 選擇權 | 付一筆權利金，取得未來以某價格買或賣的「權利」 | 付訂金保留買房的權利；不想買就只損失訂金 |
| 流動性 | 能否快速、以合理價格買賣 | 熱門商品隨時有人接手；冷門古董很難脫手 |
| 多頭 / 空頭 | 價格上漲的市場 / 下跌的市場 | 牛往上頂、熊往下撲 |

## 交易機制

| 術語 | 一句話解釋 | 生活比喻 |
|---|---|---|
| 委託簿 | 所有掛單買價與賣價的清單 | 拍賣會場上的喊價板 |
| 買賣價差 | 最高買價與最低賣價的差距 | 換匯時銀行「買入價」與「賣出價」的差 |
| 市價單 | 用當下市場價格立刻成交 | 「不管多少錢，現在就給我」 |
| 限價單 | 只在指定價格或更好時成交 | 「超過 100 元我就不買」 |
| 滑價 | 實際成交價比預期差 | 網購搶限量鞋，按下去時價格已經變了 |
| 放空 | 先借來賣，之後買回來還 | 借朋友的腳踏車賣 5000，之後花 3000 買一台還他 |
| 槓桿 | 用小錢控制大部位 | 付 2 成頭期款買房，房價漲跌對你的影響被放大 5 倍 |
| 保證金 / 斷頭 | 押在券商的擔保品 / 虧到不夠擔保被強制平倉 | 押金不夠，房東直接收回房子 |

## 機率與統計

| 術語 | 一句話解釋 | 生活比喻 |
|---|---|---|
| 期望值 | 長期平均每次能賺或賠多少 | 賭場每一局不一定贏，但整年一定賺 |
| 勝率 | 賺錢交易佔全部交易的比例 | 打擊率 |
| 盈虧比（風險報酬比） | 平均賺的金額 ÷ 平均賠的金額 | 打擊率低但都是全壘打 |
| 標準差 / 波動度 | 數值偏離平均的程度 | 每天通勤時間是穩定 30 分，還是 20–60 分都有可能 |
| 肥尾 | 極端事件比常態分布預期得更常發生 | 「百年一遇」的颱風十年來了三次 |
| 相關性 | 兩個東西是否一起動 | 雨傘和雨衣的銷量 |
| 複利 | 利息也能再生利息 | 雪球越滾越大 |

## 分析方法

| 術語 | 一句話解釋 | 生活比喻 |
|---|---|---|
| 技術分析 | 用價格與成交量的歷史推測未來 | 看天氣預報 |
| 基本面分析 | 研究公司價值與經濟狀況 | 頂店前先看帳本 |
| K 線 | 用一根蠟燭表示一段時間的開、高、低、收 | 一天的心電圖摘要 |
| 支撐 / 壓力 | 價格容易止跌 / 止漲的區域 | 地板與天花板 |
| 移動平均線 | 過去 N 天的平均價格 | 看「最近 20 天平均體重」而不看每天的波動 |
| RSI | 衡量近期漲跌力道 | 跑步的心跳率 |
| 本益比 | 股價 ÷ 每股盈餘 | 買下這家店要幾年才能回本 |
| ROE | 股東權益報酬率 | 老闆每投入 100 元，一年賺回多少 |

## 風險管理與心理

| 術語 | 一句話解釋 | 生活比喻 |
|---|---|---|
| 停損 | 預先設定虧到某處就出場 | 煙霧偵測器：小火就響 |
| 部位大小 | 這筆交易要買多少 | 每次上桌只拿一部分籌碼 |
| 最大回撤（MDD） | 資產從最高點跌到最低點的幅度 | 從山頂掉到谷底的高度 |
| 分散 | 把資金分到不同資產 | 不把雞蛋放在同一個籃子 |
| 損失趨避 | 虧損帶來的痛苦大於同等獲利的快樂 | 掉 1000 元比撿到 1000 元印象更深 |
| FOMO | 害怕錯過的焦慮 | 看到排隊就跟著排 |

## 策略與回測

| 術語 | 一句話解釋 | 生活比喻 |
|---|---|---|
| 交易優勢（Edge） | 長期期望值為正的理由 | 攤販佔到最好的位置 |
| 趨勢跟隨 | 順著價格方向操作 | 衝浪：順著浪走 |
| 均值回歸 | 價格偏離太遠會回到平均 | 橡皮筋拉太遠會彈回來 |
| 回測 | 用歷史資料測試策略 | 模擬考 / 飛行模擬器 |
| 前視偏差 | 回測時用到了當時還不知道的資訊 | 考試前偷看答案 |
| 倖存者偏差 | 只看到存活下來的樣本 | 只訪問創業成功的人 |
| 過度擬合 | 策略過度貼合歷史雜訊 | 為一張考卷背答案，換題就不會 |
| 樣本外測試 | 用沒參與設計的資料驗證 | 練習題和正式考題分開 |
| Walk-forward | 滾動式地「訓練 → 測試」 | 每學一段就考一次新題目 |
| 夏普比率 | 每承擔一單位風險，得到多少超額報酬 | 考 85 分只花 1 小時 vs. 考 90 分花 3 小時 |
| 蒙地卡羅模擬 | 隨機重排或抽樣，模擬大量可能結果 | 把人生重新洗牌跑 1000 次 |
| 基準（Benchmark） | 用來比較績效的標準 | 跟全班平均比，而不只看自己的分數 |
