# Trading Guru：From Zero To Hero 交易學習課程

> 從「完全不懂股票」到「能自己設計策略、用程式回測、並且能把這些東西講給朋友聽懂」。

這是一套**給完全新手**的交易、策略與回測課程。每個觀念都搭配**生活上的例子**，目標不只是「自己懂」，而是**學完後能從容地跟別人解釋，而且對方聽得懂**。

> ⚠️ 本課程僅供教育用途，不構成任何投資建議。所有交易都有虧損風險，請只用你輸得起的錢練習。

---

## 一句話看懂這門課

學交易就像**學開車**：

| 學開車 | 學交易 | 對應階段 |
|---|---|---|
| 認識道路、號誌、車子構造 | 認識市場、商品、下單規則 | Phase 0–2 |
| 學會看儀表板、估算距離 | 學會機率統計、看懂價格與價值 | Phase 3–5 |
| 繫安全帶、保持車距、不酒駕 | 風險管理、資金管理、交易心理 | Phase 6–7 |
| 學各種開法：市區、高速、山路 | 學各種策略：趨勢、均值回歸、突破… | Phase 8 |
| 用駕駛模擬器練習 | 用 Python 寫程式做回測 | Phase 9–11 |
| 有教練陪同上路 → 自己上路 | 模擬交易 → 小額實盤 | Phase 12 |
| 能當別人的教練 | 能把整套東西教給別人 | Phase 13 |

| 節奏 | 每週投入 | 約需時間 | 適合誰 |

| 🐢 輕鬆版 | 5 小時（平日 30 分 + 週末 2.5 小時） | **約 24 個月** | 上班族、家庭忙碌 |

- **Phase 12 的模擬交易至少要跑滿 3 個月的「日曆時間」**（市場需要時間給你各種狀況），所以衝刺版實際約 **8 個月**。
- 建議預留 **15% 緩衝**（生病、工作忙、某章卡關）。標準版實際可抓 **13–14 個月**。
- 不想寫程式？可走「無程式路線」（約 395 小時），詳見 [學習時程規劃](docs/SCHEDULE.md#6-無程式路線)。

## 學習方法：費曼學習法（本課程的核心）

每學完一個單元，都要通過**「費曼檢核」**：

1. **用 1 分鐘、不用專業術語**，把這個觀念講給一個「完全不懂的朋友」聽（可以對著手機錄音）。
2. **舉一個生活例子**來比喻。
3. **說出一個常見誤解**，以及為什麼它是錯的。
4. 卡住的地方 → 回去重讀 → 再講一次。

> 如果你沒辦法簡單地解釋它，代表你還沒有真正理解它。

## 畢業時你會具備的能力

- ✅ 能解釋股票、ETF、期貨、選擇權、外匯、加密貨幣的差別與風險
- ✅ 能看懂 K 線圖與常見指標，也知道它們的**限制**
- ✅ 能用期望值、勝率、賠率評估一個策略值不值得做
- ✅ 能設定停損、計算部位大小，知道怎樣才「不會爆倉」
- ✅ 能寫出一份完整的**交易計畫書**
- ✅ 能用 Python 抓資料、寫策略、做回測，並看懂績效報告
- ✅ 能辨認回測裡的陷阱（前視偏差、倖存者偏差、過度擬合）
- ✅ 完成至少 3 個月的模擬交易與交易日誌
- ✅ **能用生活例子，把以上全部講給一個新手聽懂**
